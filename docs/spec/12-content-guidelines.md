# Beastkin Universe 内容创作指南 v3.0

> 本文档定义写作风格、世界观一致性和内容检查清单。不定义文件系统规则。

---

## 1. 世界观一致性

### 1.1 核心法则

- 所有角色为雌雄同体的雄兽人，人称代词统一使用"他"
- "精尽而亡"战斗体系：伤害转化为性欲值，达到上限时射精进入濒死僵滞
- 雄雄生殖体系

### 1.2 兽盾公司等级

| 等级 | 代号 | 制服颜色 |
|------|------|---------|
| 杂兵 | G | 军绿 |
| 监工 | O | 蓝色 |
| 武斗兵 | E | 黑色 |
| 枪械兵 | R | 白色 |
| 摔跤兵 | W | 深蓝 |

身份标识：长筒袜袜底印有编号。

## 2. 叙事风格

### 2.1 节奏

- 单章无字数上限
- 简单动作可延展为数百字描写
- 死亡/高潮场景必须放慢，分解为多个阶段

### 2.2 感官维度

每个关键场景必须同时包含：

| 维度 | 描写重点 |
|------|---------|
| 视觉 | 脂包肌、肌肉群、制服紧绷、身体曲线 |
| 听觉 | 喘息、呻吟、心跳、体液滴落、肌肉摩擦 |
| 嗅觉 | 汗味、体味、精液腥膻、血液铁锈味 |
| 味觉 | 精液的腥涩、血液的咸腥 |
| 触觉 | 体温传递、毛发质感、服饰材质、肌肉硬度 |

### 2.3 心理维度

- 内心独白
- 恐惧、欲望、回忆闪回
- 对死亡的认知变化

## 3. 死亡场景结构

1. **前奏**：意识到危险 → 身体僵硬/颤抖 → 求饶或逃跑 → 精槽值上升
2. **接触**：身体接触 → 体温/毛发/气味交换 → 制服被撕扯 → 性器官暴露
3. **刺激**：性器官被刺激 → 前列腺液分泌 → 精槽值快速上升 → 身体痉挛
4. **高潮**：精槽值突破 100% → 连续射精（注明股数）→ 身体抽搐/僵直 → 意识涣散
5. **余波**：身体瘫软 → 精液残留 → 瞳孔涣散 → 袜子的处理

## 4. 检查清单

### 4.1 基础规范

- [ ] 使用了 Scene 分幕结构
- [ ] 每个 Scene 有标题
- [ ] 文件名和编码符合规范（见 `02-work-coding.md`）
- [ ] 有卷首语和卷尾语（分章故事）

### 4.2 感官描写

- [ ] 视觉：脂包肌、肌肉群、制服紧绷
- [ ] 听觉：喘息、呻吟、心跳
- [ ] 嗅觉：汗味、体味、精液腥膻
- [ ] 味觉：精液的腥涩
- [ ] 触觉：体温传递、毛发质感

### 4.3 角色适配

**兽盾员工视角**：
- [ ] 有编号（G-XXX 等）和编号袜子的描写
- [ ] 有背景（家人/梦想/遗憾）
- [ ] 死亡过程分解为多个阶段
- [ ] 注明射精股数

**特工局视角**：
- [ ] 特殊功法正确展现（灼流暗劲/银针封穴等）
- [ ] 有装备描写

**卧底视角**：
- [ ] 有身份压力/暴露风险描写
- [ ] 有换装细节的感官体验

### 4.4 评述部分

- [ ] 使用了正确标签格式：`【出场状态→结局状态-兵种-序号-种族-姓名】`
- [ ] 死亡角色有完整的生活、梦想、遗憾描述
- [ ] 存活角色有心理创伤、道德困境、未来阴影挖掘
- [ ] 加强肉体视觉与嗅觉描写
