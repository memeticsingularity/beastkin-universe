# 配图文件命名规范 / Illustration File Naming Guide

## 文件命名规范 / File Naming Rules

本目录下的所有正文章节配图均遵循统一命名格式，以确保结构清晰、易于检索。

All main story chapter illustrations in this directory follow a unified naming convention for clarity and ease of retrieval.

**核心命名格式 / Core Naming Format:**

```
bsr_chXXX_序号_关键词.扩展名
```

- **`bsr`**: 项目标识 (Beast Shield: Reforged) / Project identifier
- **`chXXX`**: 三位数章节编号 (如 `ch001`, `ch015`) / Three-digit chapter number
- **`序号`**: 同一章节内的图片顺序号 / Image order number within the same chapter
- **`关键词`**: 描述图片核心内容的英文关键词 / English keyword describing core content
- **`.扩展名`**: 图片文件格式 / Image file format

**示例 / Example:**
`bsr_ch001_1_headshot.png`
对应正文第一章的“见图01-2”，描绘虎警员被爆头的场景。

Corresponds to "Image 01-2" in Chapter 1, depicting the headshot of the tiger police officer.
