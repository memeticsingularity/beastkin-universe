# Beast Shield / 兽盾宇宙 创作规范指南 v1.0

> **适用范围**：所有兽盾世界观（Beast Shield Universe）下的原创与改编作品
> **核心目标**：打造极致感官沉浸、慢节奏叙事的雄兽人世界文学体验

---

## 一、基础设定

### 1.1 世界观核心

**"精尽而亡"战斗体系**

- 所有攻击造成的伤害转化为性欲值（精槽值）
- 达到上限时射精并进入"濒死僵滞状态"
- 必须彻底排空精液才能完成击杀
- 此为世界核心法则，所有战斗与死亡场景必须体现

**世界性质**

- 近现代兽人都市背景
- 所有角色均为雌雄同体的雄兽人（双性征）
- 雄雄生殖体系
- 人称代词统一使用"他"

### 1.2 关键要素

**兽盾公司（Beast Shield Corporation）**

- 势力庞大的犯罪组织
- 员工等级：G级（杂兵）、O级（监工）、E级（武斗兵）、R级（枪械兵）、W级（摔跤兵）
- 制服颜色：军绿（G级）、蓝色（O级）、黑色（E级）、白色（R级）、深蓝（W级）
- 身份标识：长筒袜袜底印有编号

**赏金猎人体系**

- 通过击杀兽盾员工领取赏金
- 需要收集带编号的袜子作为凭证
- 赏金金额：G级100撸币、O级200撸币、E/R级500撸币、W级1000撸币

**特工局（Agent Bureau）**

- 与兽盾对抗的秘密组织
- 核心成员：总司令（德牧）、熊猫（神武传人）、红虎-雷炎寰（灼流暗劲）、银（银针封穴）等
- 拥有特殊功法：灼流暗劲、银针封穴术、青雉缚阳锁等
- 设有训练营培养幼年特工

**政府与警察系统**

- 名义上存在但虚弱无力
- 警察迫于兽盾权势不敢轻易逮捕其员工
- 部分正直警察会调查兽盾非法活动（如矿难、红色水晶）
- 玩家击杀兽盾员工时往往睁一只眼闭一只眼

**平民社会**

- 对兽盾员工普遍怀有恐惧和憎恶
- 个别强大或有正义感的平民会直接出手（如武道馆白熊）
- 实验农场、黑店等灰色产业经营者

**游戏玩家（VR视角）**

- 世界本质是VR游戏，玩家可以读档重来
- 升级系统、转职任务、技能学习
- 换装潜入、随从系统、隐藏资料解锁

**灰色产业**

- 俘虏贩卖店铺：出售兽盾俘虏，提供处决享受权
- 实验农场：种植需要精液灌溉的特殊作物
- 地下格斗场：按段位运作，摔跤兵表演与处决

## 二、语言风格要求

### 2.1 核心原则

**（1）取消字数限制**

- 单章/单幕无字数上限
- 追求极致细节，不压缩描写
- 建议短篇9000字以上

**（2）极致感官体验**
必须包含以下五感描写：

| 感官     | 描写重点                          |
|--------|-------------------------------|
| **视觉** | 脂包肌、肌肉群、制服紧绷、身体曲线、精液/血液形态     |
| **触觉** | 体温传递、毛发质感、服饰材质（紧身/粗糙/湿润）、肌肉硬度 |
| **嗅觉** | 汗味、体味（种族特征）、精液腥膻、血液铁锈味、环境气味   |
| **味觉** | 精液的腥涩、血液的咸腥、眼泪的咸、皮肤的咸湿        |
| **听觉** | 肌肉摩擦、制服撕裂、喘息、呻吟、心跳、体液滴落       |

**（3）直白朴素的描写**

- 不回避性器官和生理反应的直接描写
- 使用口语化、接地气的词汇
- 避免过度文学化的隐喻，保持真实感

### 2.2 身体描写规范

**必需描写的身体部位**

1. **脂包肌体型**
    - 厚重的脂肪层覆盖肌肉
    - 胸肌饱满圆润（因双性征而隆起）
    - 小腹微隆但腹肌轮廓隐约可见
    - 三角肌、肱二头肌、肱三头肌如连绵山丘

2. **性器官**
    - 必须详细描写勃起过程
    - 精液喷射的力道、次数、形态
    - 前列腺液（淫水/透明液体）的分泌
    - 卵蛋（睾丸）的收缩、大小、质地

3. **敏感部位**
    - 乳头（颜色、大小、勃起后的硬度）
    - 冠状沟、系带（敏感度差异）
    - 后穴（紧致度、温度、收缩）

4. **服饰细节**
    - 制服的紧绷、褶皱、湿润痕迹
    - 长筒袜的泛黄、编号、袜口松紧
    - 军靴/运动鞋的材质、磨损、鞋底

## 三、叙事结构

### 3.1 分幕格式

**必须使用Scene分幕结构**

```markdown

（场景内容，800-1500字）
```

## 四、剧情推进要求

### 4.1 节奏控制

**慢节奏叙事原则**

- 主线聚焦人物互动推动节奏
- 一个简单动作可以延展为数百字描写
- 死亡/高潮场景必须放慢，分解为多个阶段

**时间膨胀技巧**

- 1分钟的实际时间可以写2000字
- 分解动作的每一个阶段
- 加入角色的感知延迟（子弹时间效果）

**示例**：

```
差：狼兽人扑倒了他，开始攻击。

好：狼兽人的影子在月光下拉得很长。豕牙看到了，但身体来不及反应——他的猪脑还在处理"危险"这个信息，对方已经动了。那是极快的一扑，带着风声，带着体温，带着一股浓重的、狼类特有的腥臊味。豕牙只觉得肩膀一沉，一股巨大的力量将他压向地面。他的后脑勺撞在水泥地上，"咚"的一声闷响，眼前炸开一片金星。疼痛是延迟到达的，先是一片空白，然后是钝痛，从后脑勺扩散到整个头颅。他想叫，但喉咙被扼住了——那是一只粗糙有力的手，带着老茧，指腹压在他的喉结上，能清晰地感觉到脉搏的跳动...
```

### 4.2 描写维度

**必须同时包含的五个维度**：

1. **心理描写**
    - 角色的内心独白
    - 恐惧、欲望、回忆的闪回
    - 对死亡的认知变化

2. **神态描写**
    - 眼神的变化（聚焦、涣散、求饶、绝望）
    - 面部肌肉的抽动
    - 表情的细微变化

3. **动作描写**
    - 肌肉的收缩与放松
    - 身体的本能反应
    - 挣扎的力度与幅度

4. **环境描写**
    - 光线、声音、气味
    - 温度、湿度、触感
    - 空间的压迫感

5. **语言描写**
    - 对话要符合角色身份
    - 喘息、呻吟、气音
    - 语言的破碎与断续

## 五、故事类型与角色视角

### 5.1 多元故事类型

**（1）赏金猎人狩猎型**

- 经典模式：赏金猎人潜入→发现目标→击杀→收集袜子
- 示例：《黑石》系列、《守夜人》
- 重点：潜行、伪装、处决技巧、心理博弈

**（2）特工局行动型**

- 潜入兽盾设施执行任务（破坏、刺杀、情报收集）
- 示例：炎魉系列、魔影系列
- 重点：特殊功法运用（灼流暗劲、银针封穴）、团队协作、高科技装备

**（3）卧底/双重身份型**

- 主角伪装成兽盾员工深入敌营
- 示例：兽游世界主线（主角潜入兽盾大楼）
- 重点：身份伪装、同事关系、道德困境、被发现的风险

**（4）平民生存型**

- 普通平民在兽盾阴影下的生活与反抗
- 示例：《兽盾农家乐》（小谷的农场经营）
- 重点：日常压迫、灰色地带生存、意外卷入冲突

**（5）公司内部生态型**

- 展现兽盾内部的等级制度、欺凌、晋升竞争
- 示例：《兽盾员工的一天》
- 重点：同事关系、上级压迫、内部处决、小人物挣扎

**（6）VR游戏玩家型**

- 从玩家视角体验世界（死亡读档、技能升级）
- 示例：兽游世界主线（ch-1至ch-13）
- 重点：游戏机制、角色成长、多周目尝试

**（7）警察/正义势力型**

- 警察或正义平民对抗兽盾
- 示例：ch-6（牛警长保护证人）
- 重点：正义与现实的冲突、实力悬殊、牺牲

**（8）实验/改造型**

- 涉及血精石、流墟、特殊作物等实验元素
- 示例：魔影的起源、嗜精兽改造
- 重点：身体变异、力量与代价、生存挣扎

**（9）灰色产业交易型**

- 俘虏贩卖、实验农场经营等
- 示例：《俘虏快递》
- 重点：道德模糊地带、商品化生命、权力与欲望

### 5.2 多元角色视角

| 角色类型         | 视角特点         | 故事潜力       |
|--------------|--------------|------------|
| **兽盾G级杂兵**   | 底层、渺小、随时可被替代 | 平凡悲剧、生存挣扎  |
| **兽盾高级员工**   | 权力、傲慢、内部斗争   | 权力腐蚀、高处不胜寒 |
| **赏金猎人**     | 专业、麻木、心理波动   | 道德困境、人性考验  |
| **特工局成员**    | 正义、技能、使命感    | 理想与现实的冲突   |
| **幼年特工学员**   | 纯真与残酷训练      | 成长、失去纯真    |
| **警察**       | 正义但虚弱        | 无力感、牺牲     |
| **平民**       | 恐惧、憎恶、无奈     | 日常压迫、意外卷入  |
| **实验体/变异者**  | 身体变异、力量失控    | 身份认同、生存代价  |
| **VR游戏玩家**   | 上帝视角、读档重来    | 游戏与现实的模糊   |

| **俘虏（被贩卖者）** | 完全失去权力       | 绝望、求生、物化   |

## 六、角色塑造详解

### 6.1 兽盾员工（受害者视角）

**必需元素**：

- **编号**：G-XXX/O-XXX等，印在白袜袜底
- **姓名**：简单朴素，符合文化水平
- **背景**：来自农村/底层，有家人/梦想
- **身体**：脂包肌、体味、制服下的身体
- **心理**：恐惧→绝望→接受/不甘

**死亡过程必须包含**：

1. 意识到死亡来临
2. 回忆闪回（家人/梦想/遗憾）
3. 生理反应（精槽值上升）
4. 挣扎与求饶
5. 高潮射精（详细描写）
6. 生命消逝

### 6.2 赏金猎人/杀手（施害者视角）

**必需元素**：

- 专业、冷静、麻木
- 对生命的漠然
- 可能的心理波动（但很快被压制）
- 熟练的动作（体现经验）

### 6.3 特工局成员（正义执行者视角）

**必需元素**：

- **特殊功法**：灼流暗劲/银针封穴/其他神武
- **使命感**：对抗兽盾的信念
- **技能展现**：功法的具体运用（眼冒红光、隔空射精等）
- **心理**：正义与手段的灰色地带
- **装备**：高科技道具（催眠弹、跳蛋遥控装置等）

**功法描写示例**：

```
雷炎寰运起灼流暗劲，双眼泛起红光，毛色如火焰般鲜艳。他一拳击中牛兽人的后腰，灼热内力瞬间穿透皮肉，直冲精关。

"啊……！"牛兽人感到一股岩浆般滚烫的灼热感从击打处涌向下体，精槽值瞬间飙升。他想要抵抗，但那股热力已经侵入体内，强迫他的身体产生反应。

第三拳落下时，牛兽人再也控制不住，粗壮的牛鞭隔着紧身裤开始喷射...
```

### 6.4 卧底/双重身份者（伪装者视角）

**必需元素**：

- **身份压力**：伪装成兽盾员工的紧张感
- **同事关系**：与真正兽盾员工的互动
- **暴露风险**：随时可能被识破的恐惧
- **道德困境**：是否要救/杀某个兽盾员工
- **换装细节**：穿上兽盾制服的感官体验

### 6.5 平民（旁观者/受害者视角）

**必需元素**：

- **无力感**：面对兽盾暴力的恐惧
- **日常生活**：在阴影下的艰难生存
- **意外卷入**：无辜被卷入冲突
- **灰色生存**：与兽盾的妥协（如农家乐的小谷）
- **反抗火花**：正义感与勇气的闪现

### 6.6 实验体/变异者（异化者视角）

**必需元素**：

- **身体变异**：血精石融合、流墟感染等
- **力量与代价**：新能力伴随的代价（如嗜精兽的精液饥渴）
- **身份认同**：我还算是普通兽人吗？
- **生存挣扎**：控制变异、寻找解药
- **他人目光**：被恐惧、被利用、被研究

### 6.7 评述部分标签格式

```markdown
【活体→死-G-612-野猪兽人-豕牙】
他叫豕牙，编号G-612...
（深度描写他的生活、梦想、遗憾、身体特征、死亡过程）

【活体→活-赏金猎人-灰狼兽人-影爪】
影爪不是他的真名...
（描写他的心理、动机、未来阴影）
```

**标签格式**：【出场状态→结局状态-兵种代号-序号-种族-姓名】

## 六、死亡场景规范

### 6.1 死亡过程分解

**阶段一：前奏（恐惧积累）**

- 意识到危险
- 身体僵硬/颤抖
- 试图求饶或逃跑
- 精槽值开始上升

**阶段二：接触（感官爆发）**

- 身体接触（扼喉/压制/刺激）
- 体温、毛发、气味的交换
- 制服被撕扯/解开
- 性器官暴露

**阶段三：刺激（高潮积累）**

- 性器官被刺激
- 前列腺液分泌
- 精槽值快速上升
- 身体痉挛/挣扎

**阶段四：高潮（射精死亡）**

- 精槽值突破100%
- 连续射精（注明股数）
- 身体抽搐/僵直
- 意识涣散

**阶段五：余波（死亡确认）**

- 身体瘫软
- 精液残留
- 瞳孔涣散
- 袜子的处理（赏金猎人收集）

### 6.2 感官细节清单

**死亡场景必须包含**：

- [ ] 精液的股数和形态
- [ ] 身体的抽搐频率和幅度
- [ ] 眼神的变化过程
- [ ] 呼吸/呻吟的声音
- [ ] 制服/白袜的污染情况
- [ ] 体温的变化
- [ ] 气味的混合（汗、血、精液）

## 七、示例片段

### 7.1 优秀描写示例

```markdown
**Scene-3 精液的祭品**

阿壮感到自己的精槽在飞速上涨。

30%…50%…70%…

不是快感，是恐惧，是窒息，是死亡逼近时身体的本能反应。他的牛鞭在狼兽人手中胀得发疼，马眼口分泌出透明的液体，顺着杆身流下，沾湿了狼兽人的手指。那是一种混合了前列腺液和尿液的液体，带着牛类特有的腥臊味，在空气中迅速挥发。

"想什么呢？"狼兽人注意到了他的走神，手上的动作加快了一些，"专心点，这可是你这辈子最后一次爽了。"

阿壮的眼泪涌了出来，顺着脸颊流进嘴里，咸涩的味道让他更加绝望。他想起了母亲做的奶酪，那种在舌尖融化的、带着牧场青草香气的甜味。他想起自己答应过，明年春节要回去，带着桂花糕和新棉袄。

现在，这一切都要变成泡影了。

90%…100%…110%…
```

## 八、文件命名规范

### 8.1 编码体系

**格式**：`[世界观]-[性质]-[形式]-[序号]-[标识名]`

| 字段  | 选项                                |
|-----|-----------------------------------|
| 世界观 | `bs`=兽盾, `bsr`=兽盾-赤红, `bsp`=兽盾-天堂 |
| 性质  | `o`=原作, `a`=改编                    |
| 形式  | `cm`=主线分章, `cs`=支线分章, `s`=短篇      |
| 序号  | 自然数                               |
| 标识名 | 英文kebab-case                      |

**示例**：

- `bs-o-s-8-the-night-watch`（兽盾-原作-短篇-8-守夜人）
- `bs-a-cs-1-birthday-cake`（兽盾-改编-支线分章-1-生日蛋糕）

### 8.2 文件结构

```
[完整编码]/
├── README.md                    # 作品目录
├── metadata.yaml                # 元数据
├── [完整编码].md               # 故事正文（短篇）
│   或
├── ch-1-xxx.md                 # 第一章（分章）
├── ch-2-xxx.md                 # 第二章（分章）
├── ...
└── settings/
    └── story-setting.md         # 专属设定（可选）
```
