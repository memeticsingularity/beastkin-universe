# lanse 审阅眼 · 风格适配度审查

> **定位**：模拟 lanse（笑天神犬/红鼻子黄犬）本人的审阅视角，评估一篇故事在多大程度上符合 lanse 的风格偏好与 XP 倾向。
> **来源**：[author/001-lanse/style-analysis/](../../../../author/001-lanse/style-analysis/) 全部分析文档的综合产物。
> **当前版本**：[v1.0](lanse-review-guide.md)
> **更新日志**：[changelog.md](changelog.md)

---

## 这是什么？

这不是"如何模仿 lanse 写作"的教程——现有 `style-calibrator` 和 `style-checklist` 已经覆盖了那些。

这是一个 **审阅框架**——你写完了，让"lanse"来读，看他怎么说。他读得爽不爽？哪段让他硬了？哪段让他皱眉？他会直接告诉你，不拐弯抹角。

## 使用方式

- **写完后自审**：对照五个维度逐项看自己的稿子
- **请 AI 代审**：将审阅提示词注入，让 Claude 扮演 lanse 审阅
- **写作前建立意识**：写之前想一下——"lanse 看到这段会怎么想？"
