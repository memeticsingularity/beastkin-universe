# 兽盾故事出厂 preset v1.1（①③④）

> **触发**：作者选定本 preset ＝ 他要的就是"这一类"兽盾故事：**① 大狗口味** + **③ 兽盾视觉规范** + **④ 设定溯源**。
> **职责**：只对**当前对话里那个故事**的场景与内容负责。不约束全仓库，不扩张到别的篇目。
> **铁律**：三道闸门任一 fail，**不许交稿**。

---

## 一、执行顺序

```
1. 读场景 → 判断体裁（有性 / 无性 / 双版本）
2. 写 → 全程按闸门 A（视觉/世界观）+ B（大狗口味）+ C（设定溯源）落笔
3. 出厂自检（§六）→ 逐条打勾
4. fail 的条目就地修，修完重跑自检
5. 交稿（双版本时两版齐交）
```

## 二、闸门 A —— ③ 兽盾视觉 / 世界观（硬）

> 来源：`style-guide.md` §12/§14/§15/§16/§17/§21 + `CLAUDE.md` §8

### A1 物种白名单
兽盾方角色（杂兵/守卫/武斗兵/干部）**仅限**：熊、虎、牛、猪（野猪）、犬科（粗壮犬种）、狼。
❌ 豹、鬣狗、鹿、兔、羊等精瘦物种**不得**作兽盾兵。
（平民/幼兽不受此限，但不得因此让兽盾方角色破例。）

### A2 制服色 ↔ 等级 ↔ 袜色（不可乱配）

| 等级 | 制服色 | 袜子 | 鞋 |
|:--|:--|:--|:--|
| G 级 杂兵 | 军绿 | 白色长筒袜（袜口军绿条纹） | 军绿运动鞋 |
| O 级 监工 | 蓝 | 白色长筒袜（袜口蓝条纹） | 蓝色运动鞋 |
| R 级 枪械兵 | 白 | 白色长筒袜（袜口蓝圆环） | 卡其军靴 / 蓝白运动鞋 |
| E 级 武斗兵 | 黑（配金属护裆） | **黑色**长筒袜 | 黑色厚底军靴 |
| W 级 摔跤兵 | 深蓝 | 白色长筒袜（袜口蓝紫条纹） | 深蓝摔跤靴 |

- E 级黑制服**配黑袜**（有原文锚定，是白袜通则的唯一例外）。

### A3 登场公式（首次登场必走）
**四项必出**：`物种 → 制服色 → 体型（重量感） → 袜子`
**加分项**：下体鼓包、鞋。
- 信息分散在 2–3 段内、附着在行动上，**不许像填表一次性列完**。
- ✅「一只穿着军绿紧身制服的熊兽人靠在墙边打盹，膀大腰圆，白色长筒袜裹着粗壮的小腿，在袜口勒出一道肉痕。」
- ❌「一个绿制服走进来」（无物种）／❌「一只虎兽人走过来」（无制服色）

### A4 体型铁律
兽盾兵一律**肥壮 / 肉壮 / 脂包肌 / 粗壮 / 膀大腰圆 / 精壮结实**。
❌ **严禁**「精瘦 / 瘦小 / 纤细 / 苗条 / 修长 / 匀称」。
- 例外：鬣狗的「瘦骨嶙峋」、杜宾的「瘦长脸」（面型，非体型）可保留。

### A5 双性征（乳部必须写）
- 世界设定：所有兽人 = 下体男征 + **两枚乳头**（雌雄同体）。
- **乳部不是附加项，是与阴茎同级的核心性征**，须随种族差异化呈现：

| 种族 | 乳部要点 |
|:--|:--|
| 熊 | 藏于厚毛，乳晕深褐，可从毛丛中露出 |
| 虎 | 较小，藏胸毛深处，拨开条纹毛才见 |
| 牛 | 粗大、乳晕深褐，可被制服摩擦凸起 |
| 猪 | 粉褐，常被肚腩半遮 |
| 犬科/狼 | 小巧色深，毛短易见 |

- 至少出现 1 次乳部描写；受性刺激可泌乳（出现在临界或死后均可）。

### A6 术语与称呼
- 正文描述性文字**禁止**写「G级」「E级」等，须写「绿制服 / 黑制服 / 蓝制服」。
- 对话中**禁止**用等级术语互称；下级称上级用「长官」，上级直接命令或叫编号。
- 编号格式 `等级字母-数字`（如 G-04、O-41），印在**长筒袜袜底**。

### A7 全男世界观
全文仅用**「他」**。无「她」、无「母亲」概念（生育方亦称「生父 / 爹」）。

### A8 无流血 / 死亡机制
- 伤害 → 性欲值 → 强制射精 → **射尽而亡**。
- **无流血**（致命方式只有射精）。
- 下体要害：握住即可瞬间剥夺抵抗（种族本能，与意志无关）。
- 尸体保鲜：柔软温热、不僵硬、不腐臭；可写「甜腥味」，**严禁**「尸臭 / 僵硬」。

## 三、闸门 B —— ① 大狗口味（硬）

> 来源：`lanse-write-skill.md` §5 + `.process/POLISH-BENCHMARK.md`（含大狗 6 个"射点断章"提炼）

### B1 死亡必射
**没有不射精的死亡。** 直接型喷射、间接型主动射、快速型被动流，均可，但必须有射精与死亡确认。

### B2 精液「一定五要」
- 一要写**量**（多少股 / 量很大）
- 二要写**射向**（射在墙上 / 裤裆里 / 谁身上 / 多远）
- 三要写**质地**（浓白 / 稀薄 / 带血 / 透明）
- 四要写**终态**（还在流 / 停了 / 顺着腿淌 / 渗进布料）
- 五要写**环境互动**（打在什么表面、激起什么反应）

### B3 处决流程（仪式链条）
`制服/控制 → 掏出 → 刺激 → 求饶 → 临界（憋精/控制节奏） → 射精（全参数） → 死亡确认 → 死后处理`
（三模式：直接型 / 间接型 / 快速型，按手段选。）

### B4 死后仪式
每篇至少一个**标志性死后动作**：合眼 / 拉裤头 / 摆姿势 / 堆尸 / 塞垃圾桶 / 拍编号照 / 穿死者制服（换装）。

### B5 情感调色盘差异化
每次死亡从「**高潮 / 失控 / 羞耻 / 悲壮**」里选，**一篇至少 2 种**，不许全篇一个情绪。

### B6 处决方式差异化
**每具尸体的死法独一无二**。至少变化 3–4 个维度：射精量、射精方式、质地、身体反应、终态、死前反应、死亡节奏。

### B7 大狗式爽点收尾（关键）
- 射点/高潮落在**干净利落的处决或收尸动作定格**上（掀窗、塞桶、抹脖、拍臀、像扔垃圾）；
- 处决后配一句**冷幽默或轻蔑**（"这么废物还射这么多""算了让你爽一下吧""下辈子别来送命了"）；
- **句子短、动作快**，别把高潮埋在感官铺陈里。

### B8 断章节奏
- 欲望/处决戏放在章内中后段做**高潮**；
- 章末用**"还有下口猎物"的钩子**吊着，不要在泄劲的善后流水账上收。
- 允许章长为 1 个处决或 3 个处决——按"写到 high 就收"的自然节奏断，不硬凑。

### B9 感官在场（五感齐备 · 事后层）
> 依据 `templates/beastshield-writing-guidelines.md` §2.1「极致感官体验」＋ §2.2「身体描写规范」。
> **不是"至少 3 种"，是五感都要有。**

| 感官 | 描写重点 |
|:--|:--|
| **视觉** | 脂包肌、肌肉群、制服紧绷、身体曲线、精液／前列腺液形态 |
| **触觉** | 体温传递、毛发质感、服饰材质（紧身／粗糙／湿润）、肌肉硬度 |
| **嗅觉** | 汗味、种族体味、**精液腥膻**、环境气味（尿臊／馊味／油烟气／酒气） |
| **味觉** | **精液的腥涩**、汗／泪的咸、面汤的咸 |
| **听觉** | 肌肉摩擦、制服撕扯、喘息呻吟、心跳、**体液滴落** |

- **肉体是处决的主角，不是前缀**：汗水浸透的制服湿痕、胸肌晃动、脂包肌的厚实感、袜口勒痕——全程在场。
- **每场有袜的特写**：长筒袜紧绷包裹感、袜底编号、浸液变深。
- **嗅觉与味觉是最常被漏掉的两感，必须专门补**：
  - 嗅觉：处决后那一裤裆的**精液腥膻味要留在空气里**（被砖墙兜着、飘过桌子）；
  - 味觉：精液腥涩、汗／泪的咸，至少给一处。
- **身体描写四件套**（§2.2）：
  1. 脂包肌体型（厚脂肪覆肌肉／胸肌因双性征隆起／小腹微隆但腹肌隐约／三角肌肱二头肌肱三头肌如连绵山丘）
  2. 性器官（**必须详写勃起过程**／精液喷射的力道次数形态／前列腺液分泌／卵蛋的收缩大小质地）
  3. 敏感部位（乳首颜色大小硬度／冠状沟与系带／后穴）
  4. 服饰细节（制服紧绷褶皱湿痕／长筒袜泛黄编号松紧／军靴运动鞋的材质磨损鞋底）
- **务必写"事后"**（本 preset v1.1 新增，起因：结尾缺气味/处理/围观）：
  - **气味**：杀完那股腥膻不会跟着人走，它留在原地；
  - **尸体处理**：垃圾桶／木桶——兽盾世界的尸体是要"装桶拖走"的；
  - **围观者**：闹这么大动静，**店里的人一定看见了**；不写"没人看"（不真实），
    写成"都看见了、都低头、背后接碎话"——沉默不等于没看见。
  - **中止／未死的场次同理**（v1.2 补，起因：06《人情》）：差点死掉的人**不可能干干净净站起来**——
    要写他怎么瘫、怎么被架起来、谁替他擦、他的谢怎么出口。**HE 也不许省事后层**：
    先把人从地上架起来、把身上擦干净、把"谢"说出口，再谈收留与团圆。

## 四、闸门 C —— ④ 设定溯源（数值／事实不得自创）

> **为什么会加这道闸门**：preset v1.0 只覆盖了风格与视觉（①③），**没覆盖数值一致性**。
> 结果 bs-a-s-7 第 5 篇自创了赏格（R级 240 ／ G级 180），与设定集（R级 500 ／ G级 100）冲突。
> 这类错误不是"写得不好"——是**把世界观写坏了**，而且会顺着引用一路扩散。

### C1 凡数值／事实，必须溯源
文中出现的**任何世界硬数据**——**赏金／月薪／物价／编号格式／等级↔制服↔袜↔鞋配对／物种白名单／机制参数／身高体重**——
**必须来自 `worlds/beastshield/settings/` 的设定集原文。禁止自创。**

### C2 常用硬数据速查表（照抄，勿改）

**赏金／月薪（「薪资 = 赏金原则」）**

| 等级 | 制服色 | 编号格式 | 赏金 ＝ 月薪 |
|:--|:--|:--|:--|
| G级 杂兵 | 军绿 | `G-[自然数]` | **100 撸币** |
| O级 监工 | 蓝 | `O-[自然数]` | **200 撸币** |
| E级 武斗兵 | 黑 | `E-[自然数]` | **500 撸币** |
| R级 枪械兵 | 白 | `R-[自然数]` | **500 撸币** |
| W级 摔跤兵 | 深蓝 | `W-[自然数]` | **1000 撸币** |

**物价（原作 ch-4 商店）**：西瓜刀 200 撸币 · 飞刀 200 撸币 · 钢丝指环 200 撸币（勒颈窒息用）。

> 出处：`settings/0-original-setting/world-setting.md` §7.2 · `settings/1-recommended-canon/world-setting-player.md` §3.2 ·
> `settings/1-recommended-canon/world-setting-bounty-hunter.md` · `settings/0-original-setting/unit.md` · `settings/0-original-setting/setting.md`。

### C3 查不到怎么办（三选一，**不许编**）
1. 先检索 `settings/0-original-setting/` 与 `settings/1-recommended-canon/`；
2. 仍查不到 → **标注 `[待确认]` 并问作者**，不得臆造一个看着合理的数；
3. 设定集内部打架 → **以 `0-original-setting`（原作侧）为准**，并把差异记进过程文档。

### C4 引用即留痕
用到数值／事实时，在过程文档（`metadata.yaml` / 计划 / 设定）里**附上出处**（文件路径），便于复核。

## 五、双版本协议（有性版 / 无性版）

**当场景允许两种处理时，同一次产出写两版**：

| 闸门 | 有性版 | 无性版 |
|:--|:--|:--|
| A（③视觉/世界观） | **全量执行** | **全量执行**（一样不许省） |
| B1–B6（处决/情色核心） | 全量执行 | 转为**背景设定**，不正面描写（可保留死亡事实，不写过程） |
| B7 爽点收尾 | 执行 | **执行**（爽点不一定靠性，干脆动作+冷幽默照旧） |
| B8 断章节奏 | 执行 | **执行** |
| B9 感官在场 | 全量（含肉体/恋物） | 保留动作与制服质感，删性器官描写 |
| 分级标注 | 标 Lv.3–4 | 标 Lv.0–1，并在文首注明「无性版」 |

> **无性版不是"降级版"**：③ 与 B7/B8/B9 一条不许省。它只是把"性"这一路抽掉，故事照样必须像兽盾、必须好看。
> 两版共用同一场景与人物，**不许因为要写两版就把两边都写浅**。

## 七、例外申报

确实要脱离 ①③（如纯文学切片、实验性留白篇）时：

1. **必须显式申报**：写进该篇 `metadata.yaml`（新增字段 `preset_exception:`），说明**违反了哪几条、为什么**。
2. 未申报而脱离 → 按违约处理，打回。
3. 申报后放行，但**闸门 A（③）与闸门 C（④）默认仍需全量执行**——
   "不像兽盾"不算风格选择，"数值对不上"更不是——**那是把世界观写坏了**。
