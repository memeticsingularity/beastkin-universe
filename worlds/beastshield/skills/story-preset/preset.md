# 兽盾故事出厂 preset v1.0（①③）

> **触发**：作者选定本 preset ＝ 他要的就是"这一类"兽盾故事：**① 大狗口味** + **③ 兽盾视觉规范**。
> **职责**：只对**当前对话里那个故事**的场景与内容负责。不约束全仓库，不扩张到别的篇目。
> **铁律**：两道闸门任一 fail，**不许交稿**。

---

## 一、执行顺序

```
1. 读场景 → 判断体裁（有性 / 无性 / 双版本）
2. 写 → 全程按闸门 A + B 落笔
3. 出厂自检（§4）→ 逐条打勾
4. fail 的条目就地修，修完重跑自检
5. 交稿（双版本时两版齐交）
```

---

## 二、闸门 A —— ③ 兽盾视觉 / 世界观（硬）

> 来源：`style-guide.md` §12/§14/§15/§16/§17/§21 + `CLAUDE.md` §8

### A1 物种白名单
兽盾方角色（杂兵/守卫/武斗兵/干部）**仅限**：熊、虎、牛、猪（野猪）、犬科（粗壮犬种）、狼。
❌ 豹、鬣狗、鹿、兔、羊等精瘦物种**不得**作兽盾兵。
（平民/幼兽不受此限，但不得因此让兽盾方角色破例。）

### A2 制服色 ↔ 等级 ↔ 袜色（不可乱配）

| 等级 | 制服色 | 袜子 | 鞋 |
|:--|:--|:--|:--|
| G 级 杂兵 | 军绿 | 白色长筒袜（袜口军绿条纹） | 军绿运动鞋 |
| O 级 监工 | 蓝 | 白色长筒袜（袜口蓝条纹） | 蓝色运动鞋 |
| R 级 枪械兵 | 白 | 白色长筒袜（袜口蓝圆环） | 卡其军靴 / 蓝白运动鞋 |
| E 级 武斗兵 | 黑（配金属护裆） | **黑色**长筒袜 | 黑色厚底军靴 |
| W 级 摔跤兵 | 深蓝 | 白色长筒袜（袜口蓝紫条纹） | 深蓝摔跤靴 |

- E 级黑制服**配黑袜**（有原文锚定，是白袜通则的唯一例外）。

### A3 登场公式（首次登场必走）
**四项必出**：`物种 → 制服色 → 体型（重量感） → 袜子`
**加分项**：下体鼓包、鞋。
- 信息分散在 2–3 段内、附着在行动上，**不许像填表一次性列完**。
- ✅「一只穿着军绿紧身制服的熊兽人靠在墙边打盹，膀大腰圆，白色长筒袜裹着粗壮的小腿，在袜口勒出一道肉痕。」
- ❌「一个绿制服走进来」（无物种）／❌「一只虎兽人走过来」（无制服色）

### A4 体型铁律
兽盾兵一律**肥壮 / 肉壮 / 脂包肌 / 粗壮 / 膀大腰圆 / 精壮结实**。
❌ **严禁**「精瘦 / 瘦小 / 纤细 / 苗条 / 修长 / 匀称」。
- 例外：鬣狗的「瘦骨嶙峋」、杜宾的「瘦长脸」（面型，非体型）可保留。

### A5 双性征（乳部必须写）
- 世界设定：所有兽人 = 下体男征 + **两枚乳头**（雌雄同体）。
- **乳部不是附加项，是与阴茎同级的核心性征**，须随种族差异化呈现：

| 种族 | 乳部要点 |
|:--|:--|
| 熊 | 藏于厚毛，乳晕深褐，可从毛丛中露出 |
| 虎 | 较小，藏胸毛深处，拨开条纹毛才见 |
| 牛 | 粗大、乳晕深褐，可被制服摩擦凸起 |
| 猪 | 粉褐，常被肚腩半遮 |
| 犬科/狼 | 小巧色深，毛短易见 |

- 至少出现 1 次乳部描写；受性刺激可泌乳（出现在临界或死后均可）。

### A6 术语与称呼
- 正文描述性文字**禁止**写「G级」「E级」等，须写「绿制服 / 黑制服 / 蓝制服」。
- 对话中**禁止**用等级术语互称；下级称上级用「长官」，上级直接命令或叫编号。
- 编号格式 `等级字母-数字`（如 G-04、O-41），印在**长筒袜袜底**。

### A7 全男世界观
全文仅用**「他」**。无「她」、无「母亲」概念（生育方亦称「生父 / 爹」）。

### A8 无流血 / 死亡机制
- 伤害 → 性欲值 → 强制射精 → **射尽而亡**。
- **无流血**（致命方式只有射精）。
- 下体要害：握住即可瞬间剥夺抵抗（种族本能，与意志无关）。
- 尸体保鲜：柔软温热、不僵硬、不腐臭；可写「甜腥味」，**严禁**「尸臭 / 僵硬」。

## 三、闸门 B —— ① 大狗口味（硬）

> 来源：`lanse-write-skill.md` §5 + `.process/POLISH-BENCHMARK.md`（含大狗 6 个"射点断章"提炼）

### B1 死亡必射
**没有不射精的死亡。** 直接型喷射、间接型主动射、快速型被动流，均可，但必须有射精与死亡确认。

### B2 精液「一定五要」
- 一要写**量**（多少股 / 量很大）
- 二要写**射向**（射在墙上 / 裤裆里 / 谁身上 / 多远）
- 三要写**质地**（浓白 / 稀薄 / 带血 / 透明）
- 四要写**终态**（还在流 / 停了 / 顺着腿淌 / 渗进布料）
- 五要写**环境互动**（打在什么表面、激起什么反应）

### B3 处决流程（仪式链条）
`制服/控制 → 掏出 → 刺激 → 求饶 → 临界（憋精/控制节奏） → 射精（全参数） → 死亡确认 → 死后处理`
（三模式：直接型 / 间接型 / 快速型，按手段选。）

### B4 死后仪式
每篇至少一个**标志性死后动作**：合眼 / 拉裤头 / 摆姿势 / 堆尸 / 塞垃圾桶 / 拍编号照 / 穿死者制服（换装）。

### B5 情感调色盘差异化
每次死亡从「**高潮 / 失控 / 羞耻 / 悲壮**」里选，**一篇至少 2 种**，不许全篇一个情绪。

### B6 处决方式差异化
**每具尸体的死法独一无二**。至少变化 3–4 个维度：射精量、射精方式、质地、身体反应、终态、死前反应、死亡节奏。

### B7 大狗式爽点收尾（关键）
- 射点/高潮落在**干净利落的处决或收尸动作定格**上（掀窗、塞桶、抹脖、拍臀、像扔垃圾）；
- 处决后配一句**冷幽默或轻蔑**（"这么废物还射这么多""算了让你爽一下吧""下辈子别来送命了"）；
- **句子短、动作快**，别把高潮埋在感官铺陈里。

### B8 断章节奏
- 欲望/处决戏放在章内中后段做**高潮**；
- 章末用**"还有下口猎物"的钩子**吊着，不要在泄劲的善后流水账上收。
- 允许章长为 1 个处决或 3 个处决——按"写到 high 就收"的自然节奏断，不硬凑。

### B9 感官在场
- **触觉是主导感官**；每场至少调用 3 种感官。
- **肉体是处决的主角，不是前缀**：汗水浸透的制服湿痕、胸肌晃动、脂包肌的厚实感、袜口勒痕——全程在场。
- 制服恋物：长筒袜的紧绷包裹感、袜底编号、浸液变深——每场至少给袜一个特写。

## 四、双版本协议（有性版 / 无性版）

**当场景允许两种处理时，同一次产出写两版**：

| 闸门 | 有性版 | 无性版 |
|:--|:--|:--|
| A（③视觉/世界观） | **全量执行** | **全量执行**（一样不许省） |
| B1–B6（处决/情色核心） | 全量执行 | 转为**背景设定**，不正面描写（可保留死亡事实，不写过程） |
| B7 爽点收尾 | 执行 | **执行**（爽点不一定靠性，干脆动作+冷幽默照旧） |
| B8 断章节奏 | 执行 | **执行** |
| B9 感官在场 | 全量（含肉体/恋物） | 保留动作与制服质感，删性器官描写 |
| 分级标注 | 标 Lv.3–4 | 标 Lv.0–1，并在文首注明「无性版」 |

> **无性版不是"降级版"**：③ 与 B7/B8/B9 一条不许省。它只是把"性"这一路抽掉，故事照样必须像兽盾、必须好看。
> 两版共用同一场景与人物，**不许因为要写两版就把两边都写浅**。

## 五、出厂自检表（交稿前逐条打勾，任一 fail 不许交）

**闸门 A**
- [ ] A1 兽盾方角色全在白名单内
- [ ] A2 每个角色的制服色/袜色/鞋配对正确（E 级黑袜）
- [ ] A3 每个新登场角色走完登场公式四项
- [ ] A4 全文无「精瘦/瘦小/纤细」形容兽盾兵
- [ ] A5 至少 1 处乳部/双性征描写，且随种族差异化
- [ ] A6 正文无「G级/E级」；对话无等级术语互称；编号格式正确
- [ ] A7 全文仅「他」，无「她/母亲」
- [ ] A8 无流血；死亡走"射尽而亡"；无「尸臭/僵硬」

**闸门 B**
- [ ] B1 每次死亡都有射精 + 死亡确认
- [ ] B2 每处精液描写满足"一定五要"
- [ ] B3 每次处决走完仪式链条
- [ ] B4 至少 1 个标志性死后仪式动作
- [ ] B5 情感调色盘 ≥2 种
- [ ] B6 各具尸体死法不雷同
- [ ] B7 高潮收在干脆动作定格 + 有冷幽默/轻蔑
- [ ] B8 章末落在钩子上，不在善后流水账
- [ ] B9 每场 ≥3 种感官；肉体全程在场；每场有袜的特写

**双版本**
- [ ] 若走双版本：两版都过 A 全量；无性版 B1–B6 已转为背景且未正面描写

## 六、例外申报

确实要脱离 ①③（如纯文学切片、实验性留白篇）时：

1. **必须显式申报**：写进该篇 `metadata.yaml`（新增字段 `preset_exception:`），说明**违反了哪几条、为什么**。
2. 未申报而脱离 → 按违约处理，打回。
3. 申报后放行，但**闸门 A（③）默认仍需全量执行**——③是兽盾的底线，"不像兽盾"不算风格选择。
