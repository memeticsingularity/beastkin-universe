## 五、创作原则 / Creation Principles

1. **尊重原作 / Respect Original**: 改编作品需遵循兽盾世界观核心设定。
2. **标注来源 / Cite Sources**: 基于具体原作改编时需标注原作编码。
3. **独立存放 / Separate Storage**: 改编作品统一存放于本目录，不与原作混放。
