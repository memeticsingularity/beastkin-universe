## 系列定位

**核心美学**：玩家把兽盾世界当作个人 fetish 的沙盒，利用游戏规则把暴力、性、死亡压缩成可重复的游玩体验。

**叙事锚点**：
- 玩家就是“我”，没有代号，不扮演任何原作角色。
- 每篇独立，只围绕一个 fetish 主题 + 一个世界观机制展开。
- 不照搬《墨犬》《炎魉》《魔影》等已有故事的情节，只借用世界观规则。

## 核心原则

### 1. 第一人称玩家视角 ✅

玩家即叙述者“我”。所有感受、选择、评价都通过“我”的视角呈现。

```
我蹲在上面的通风管里，看着那个 G 级棕熊走过第三遍。
他的军绿短裤绷得太紧，白袜上的编号被汗水晕开了一点。
```

### 2. 每篇一个核心 fetish 主题 ✅

不要一篇里堆太多元素。先选一个主轴，其他元素作为辅助。

示例主轴：
- 体型差/碾压 → 以 W 级摔跤兵或巨大化敌人为目标
- 调教/SM → 以刑房、电击器、烙铁、自动飞机杯为道具
- 屠杀/踩踏 → 以更衣室、走廊、食堂等群体场景为目标
- 肉体改造 → 以实验农场、血精石、儡先生法阵为入口
- 羞辱/游行 → 以变装技能、公开场景、俘虏系统为工具

### 3. 基于世界观机制，不照搬情节 ✅

可以从已有机制出发，但不能复制已有故事的具体场景。

✅ **可以**：玩家利用“换装技能”伪装成 O 级监工，把一个 E 级虎兽人骗进刑房。

❌ **不要**：复制魔影/老雷的某个具体任务流程。

### 4. 读档重置是叙事工具 ✅

玩家可以失败、被杀、或者对结果不满意，然后读档重来。这让“反复实验同一目标”成为可能。

```
第一次他挣扎得太厉害，我没按住，被他反杀了。
读档。
这次我从背后接近，先卸了他的关节。
```

### 5. NPC 是素材，但要有基本特征 ✅

不需要背景故事，但需要给目标基本的身份信息：
- 种族 + 毛色
- 制服等级（G/O/E/R/W）
- 体型特征
- 编号（收尾时用于赏金兑换）

```
目标：G-834，棕熊兽人，深棕色毛发，军绿制服，白袜。
体型：将近三百斤，脂包肌，走动时大腿把短裤绷出褶子。
```

## 写作规范

### 对话标签
- 用「道」，不用「说」。

### 省略号
- 用「。。。」，三个句号。

### 制服色
- 统一写「军绿」，不写「绿」。

### 白袜
- 每篇至少出现一次，可描写编号、污渍、褶皱等。

### 死亡差异化
- 每个目标的射精反应、死法、尸体状态尽量不同。
- 可参考：喷射量、颜色、方式（喷/涌/渗/滴）、是否射得出、神经反射、抽搐方式。
