# 竹子的变态之旅 - 项目专属规则

## 项目定位

本项目是基于《兽盾》世界观的原创短篇系列，采用**第一人称玩家视角**，记录玩家“竹子”在 VR 游戏中以个人 fetish 驱动进行的各种玩法实验。

## 绝对规则

1. **玩家就是“我”**
   - 玩家昵称为“竹子”，仅用于系列标题、文档索引、玩家感想等元信息处。
   - 正文叙述中统一使用「我」，不使用第三人称或化名。
   - 不扮演原作角色。

2. **短篇单元剧形式**
   - 每篇独立，只围绕一个核心 fetish 主题展开。
   - 篇与篇之间可共享同一个玩家经验积累，但不要求连续剧情。

3. **基于世界观机制原创情节**
   - 可以任意调用 `worlds/beastshield/settings/0-original-setting/world-setting.md` 中的机制。
   - **禁止**照搬《墨犬》《炎魉》《魔影》《屠杀与善后》等已有故事的具体场景或情节。

4. **所有角色均为成人**
   - 兽盾世界观中无未成年角色，本项目亦不出现未成年角色。

## 写作风格

- **对话标签**：用「道」，不用「说」。
- **省略号**：用「。。。」。
- **制服色**：统一「军绿」。
- **白袜**：每篇至少出现一次。
- **段落**：中文段落以全角空格 `　　` 缩进，段落之间保留空行。

## 单篇要素

每篇应包含：
1. 本次 fetish 主题与世界观机制的组合说明
2. 目标对象的基本信息（种族、毛色、制服等级、体型、编号）
3. 场景与进入方式
4. 玩法推进过程
5. 射精死亡/处决结果
6. 玩家结算或感想

## 可调用世界观机制（非穷尽）

- 精槽系统 / 射精死亡
- 读档重置
- 赏金系统 / 白袜编号
- 换装技能
- 制服等级与兵种差异（G/O/E/R/W）
- 刑房与刑具（电击器、自动飞机杯、烙铁、抑制棒等）
- 实验农场 / 精液培育作物
- 俘虏快递 / 泄力棒
- 血精石 / 变异 / 儡先生法阵
- 流墟
- 神武与特殊功法（谨慎使用，避免战力崩坏）

## 禁止事项

- 未成年角色
- 脱离 VR 游戏框架的现实伦理说教
- 照搬其他改编作品的情节
- 过度背景故事（家乡、家人、梦想）
