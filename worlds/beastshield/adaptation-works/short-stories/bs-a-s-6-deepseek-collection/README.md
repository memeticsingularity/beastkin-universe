## 一、这是一本什么书

兽盾侧现有短篇系列，视角几乎都在**猎手**那一侧：潜入、摸哨、处决、善后。Series 1 到 Series 5，无论换成特工、赏金猎人还是受害者 POV，刀口始终朝下。

这一集反过来。

写的是兽盾内部**最不值钱的那些人**——G级杂兵，军绿制服，白袜，编号印在袜底，月薪一百撸币，谁都可以使唤。他们不杀人，他们扫地、搬货、看门、喂东西。他们也会死，但死得跟背景板一样，顺手就处理掉了。

**本集只写一件事：一个连自己都保不住的人，去保另一个更不值的。**

不是英雄救美，不是逆袭，不是越狱。是一个小杂兵蹲下来擦地。

## 二、写作铁律（本集四条，不破）

### 2.1 代词铁律：叙述永远用「他」

兽盾内部把改造体登记为「料」，公文里写「它」，口令里喊「它」。这是世界观的话术，不是叙述者的。

- **叙述者**：全篇用「他」，一次都不滑。死者、活人、敌人、实验体，都是「他」。
- **兽盾官方文本**：一律「它」「料」「该个体」。
- **角色口语**：G级小杂兵开口跟着喊「它」，因为大家都这么喊，喊了不惹事。他**察觉不到**自己哪天改了口——这个改口不写解释，只写那半句。

> 全世界的嘴都在说「它」，只有叙述在说「他」。读者会自己发现。**不解释。**

### 2.2 命名铁律：名字只能来自他自己

兽盾的世界里，人很少有名字。杂兵是「棕熊兽人 G-1428」，守卫是「灰狼兽人」，死者是「一具」。

- **叙述层**：只用「单字毛色 + 单字种族 + 兽人」的四字格式（灰狼兽人 / 棕熊兽人），符合 `style-guide.md §17.1`。
- **名字层**：他原来有名字。名字在**入册表**上留过一次，之后被编号盖住。
- **谁给他名字**：谁都没给。小杂兵不会取名字、不敢取名字、也没想过要取。他还原的**本来就是他的名字**。

**本集不允许出现"我给你起个名字"这种话。**那是施舍。这里要的是**认出来**。

### 2.3 共情铁律：不解释羁绊，只写动作

- 不写"这说明他们之间已经有了羁绊"。
- 写：他蹲下来，用抹布擦掉他脚背上干掉的东西——因为他自己够不到。
- 写：他买了件旧制服，拉链拉反了，扣子扣错一格，小杂兵在旁边憋着没笑。
- 写：他第一次开口说「他」，说完自己先愣了一下，赶紧改回「它」。

**第一次做的事，配得上慢写。**第一次被问疼不疼、第一次自己拉上拉链、第一次在地上划自己的名字——这三场，一场都不许赶。

### 2.4 结局铁律：不给出答案

- 不越狱，不康复，不团圆。
- 他确实咬死过一个G级。那具尸体不许被谁"原谅"，让档案里那条记录一直躺着。
- 读者自己掂量他配不配被救。

**狠的地方要克制。**不洒狗血。最疼的往往是轻轻一笔。

## 三、本集人物

### 灰狼兽人 · 灰雪

| 项 | 内容 |
|---|---|
| **叙述称呼** | 灰狼兽人（四字格式） |
| **名字** | **灰雪**——灰毛，生在雪季。只有入册表上写过一次 |
| **兽盾登记** | 「料-07」，无编号，无入职记录，不占编制 |
| **来源** | 野生兽人，从城外围捕。抓他那次他咬死了一个G级杂兵 |
| **改造** | 血精石植入，**半成品**：没变成嗜精兽，力气畸形地大，但精关失控——精槽一满自己先倒 |
| **外形** | 精壮偏瘦长的灰狼身——**注意：他的"消瘦"是长期营养不良的剧情设定，不是物种描写**。左耳缺一角，舌上有旧切口（不会说话），右手小指少一节 |
| **状态** | 铁链拘于武斗兵营最底层单间，链子短到站不直 |
| **关键** | 他一直听得懂。他一直记着自己是灰雪。**他从来不是怪物——他只是被当成了怪物。** |

### 棕熊兽人 · 石

| 项 | 内容 |
|---|---|
| **叙述称呼** | 棕熊兽人（四字格式） |
| **名字** | **石**——村里人叫的，一个字，没人叫他全名 |
| **兽盾登记** | G-1428 |
| **入职** | 十九岁，入职三个月。动机就是"包吃住就去"，无家可归，没有苦情背景 |
| **外形** | 军绿紧身短袖短裤，白袜，编号还在袜底没磨掉字。**体型偏壮但没长开**——同龄人里的中不溜，不是壮汉。叙事禁止用「精瘦」 |
| **岗位** | 喂料（最没人愿意干的活）、扫地、倒垃圾 |
| **关键** | 他什么都没想救。第一天进去腿是软的。他只是**怕第二天进来更臭**，所以蹲下去擦了地 |
| **弧线** | 嘴上叫「它」→ 心里冒出「他」→ 脱口喊出名字 → 把名字写在了饲料桶上 |
