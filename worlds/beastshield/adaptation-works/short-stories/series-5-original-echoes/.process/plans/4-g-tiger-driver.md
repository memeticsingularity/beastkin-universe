## 二、角色定位

| 维度 | 设定 |
|------|------|
| 物种 | 虎兽人（暂定橙虎/普通虎） |
| 等级 | G级杂兵 |
| 制服 | 军绿短袖+短裤、白色长筒袜（袜底编号 G-7721）、军绿色运动鞋 |
| 职业 | 司机，接送高级兵执行任务 |
| 体格 | 粗壮，虎纹明显 |
| 性格 | 底层怨气、侥幸心理、可怜的职责感 |
| 核心缺陷 | 好奇心害死虎——明明可以溜走，却选择进门查看 |
| 与原作一致性 | 死亡结局不可改变 |

## 三、故事结构

### 主悲剧线（4-g-tiger-driver.md）

| 节 | 内容 | 功能 |
|----|------|------|
| 一 · 出车 | 虎司机接任务，送四个 E 级兵去别墅 | 建立 G 级身份与阶级落差 |
| 二 · 等待 | 停车等待，抽烟玩手机，时间越久越不安 | 制造"本可以离开"的张力 |
| 三 · 进门 | 决定进去查看，发现四具尸体，被老雷从背后按住 | 好奇心触发死亡 |
| 四 · 浴室 | 被小雷观看下处决，老雷因小孩求情假意放人 | 虚假希望 |
| 五 · 副驾 | 逃回车上，发现老雷坐在副驾，被杀弃尸 | 反转与结局 |

### v1.2（2026-07-09）—感官细节全面深化

- **五感丰富化**：全面补充视觉（虎纹走向/肌肉轮廓/精液凝固状态）、触觉（体温/面料摩擦/虎毛触感/体重感）、嗅觉（精液腥/汗液咸/兽膻/皮革/夜风草木）、听觉（心跳/骨骼响声/精液滴落/座椅弹簧）、味觉（泪水的咸涩/烟草的苦）
- **脂包肌肉体强化**：
  - 虎三自身体型：虎纹走向、肌肉厚度、"不算壮但及格"的杂兵体格
  - E级黑熊：黑制服被大腿撑裂般紧绷、金属护裆重量感、鬃毛根、半吨体重压弹簧的震动
  - 浴室四尸：第一只熊（趴伏+裆部渗精）、第二只熊（断颈+胸肌裸露）的分别描写
- **慢节奏叙事**：每个动作增加moment-to-moment细节（如"钥匙插了几次才插进孔"→四次插入，每次划钥匙孔的声音和触感）
- **心理层次**：恐惧/本能快感/屈辱的混合心理，更细腻地刻画虎三在面对死亡时的内心撕裂
- **视角切换后老雷描写的克制**：老雷POV保持简洁、观察式、行动导向，与虎三POV的感官洪流形成反差

### v1.3（2026-07-10）—原作时间线缺口修复

- **问题识别**：bs-o-cs-3 中，老雷在浴室处理尸体，虎三逃回车上，老雷下一秒却已在副驾等待，时间线存在逻辑跳跃
- **修复方式**：
  - 虎三 POV 中增加"回头确认别墅门口空无一人"的心理陷阱
  - 老雷 POV 开头补叙：从二楼侧门提前离开 → 贴院墙阴影 → 翻矮墙抄近路 → 抢在虎三还在发抖摸钥匙时已坐进副驾
- **保留项**：原作"副驾截杀"的台词和场面保持不变

### v1.4（2026-07-14）—副驾上车合理性再强化

- **问题识别**：v1.3 解释了老雷如何提前到达车辆，但未充分说明「开车门/入座」为何没让虎三察觉；第六节甚至出现「我坐上驾驶位」的笔误
- **修复方式**：
  - 第五节虎三 POV：补写车厢无灯、副驾在阴影中、虎三只顾回头盯别墅门口；将「没有感觉到座椅的晃动」改为「没听见车门声，被心跳和引擎声盖住」
  - 第六节老雷 POV：修正「我坐上驾驶位」→「我坐上副驾驶位」
  - 第六节老雷 POV：增加暗劲卸力开车门、贴座椅滑入、压低身体静坐的轻功细节，解释车门无声与视觉隐蔽
- **效果**：老雷入座从「瞬移」变为「提前潜伏+虎三恐慌导致的感知盲区」
