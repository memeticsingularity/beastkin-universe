## 四、系列说明 / Series Notes

原作回响系列专注于那些在原作中只出现了几个段落、甚至只有一两句话的角色。他们或许连名字都没有——只有物种和制服等级——但在这个世界观里，他们也曾活着，也曾呼吸，也曾有自己的恐惧与渴望。

**选角标准：**
1. 在原作中有明确的场景，但视角不在他们身上
2. 主线死亡已被原作记载（本系列主线篇不改变原作剧情）
3. 有足够的文本线索支撑人物塑造
4. `-h` 后缀为幸存者分支，可改写死亡结局

**写作风格：** 遵循 lanse 原作风格（短段落、黑袜/白袜、制服等级色、处决流程完整），但允许在受害者心理层面做有限度的挖掘——这是"原作回响"区别于纯杀戮描写的核心定位。`-h` 幸存者分支可改写死亡结局，部分篇目有续篇（双POV展开）。
