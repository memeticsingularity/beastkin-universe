## 一、简介 / Introduction

**一句话钩子 / One-Line Hook**：门外那个小孩不是来踹门的。他是来看货的。

**故事概要 / Synopsis**：

清晨，早饭摊。一只 R级白制服的水牛兽人吃完面，去了后头的厕所。

门被踹响。三脚，都踹在插销上。他值了夜班，火气大，又是这条街上没人敢拦的白制服——他一把拉开插销，推开门。

门外那小孩往后退半步，先看他的制服，**然后把骂街的腔调一收，换成练过很多遍的那种亮嗓子**：

「这不是兽盾的杂碎吗——！爸！快来！有撸币赚了！」

摊子门口那张桌，一只灰狼兽人把筷子搁下，先把碗往桌子正中推了推，才站起来。

灰狼兽人揪住水牛兽人的后颈，一脚顶进他腿弯。将近三百斤的身躯跪在砖地上。他隔着一层白制服裤握住了那一团。

死了。

灰狼兽人脱掉尸体的右脚军靴，抬起粗腿，让袜底朝上——R-31。他掏出方匣对着袜底一按：**在册，赏金 500**。

小孩抱起那只靴子。两人走回桌子，接着吃面。

那间厕所的门，还开着。
