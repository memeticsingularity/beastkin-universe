## 一、简介 / Introduction

**一句话钩子 / One-Line Hook**：这一次，有人替他说话。

**故事概要 / Synopsis**：

同一个早上，同一个早饭摊。白制服的枪械兵（水牛兽人）吃完面去后头的厕所。踹门、骂街、喊价——"这不是兽盾的杂碎吗！爸！快来！有撸币赚了！"

灰狼赏金猎人把他扣在隔板上，隔着白制服裤握住了那一团。求饶、乳首渗出、裆部顶起、第一股隔着布喷出来、第二股顶到马眼——

"住手。"

摊主从灶台后头绕出来，围裙没解，手上还沾着面。他的手在围裙上抖了一下，可他还是走出来了："这人挺好。"

靠门那桌接了话，另一桌接了话，又有人接了话。声音一处一处冒出来，不高，也不喊。七八桌人全停了筷子，全在看。

那小孩拽了拽他爸的袖子："爸，五百呢。"

猎人把手松开了。"那身白的，早点脱了。"

水牛兽人顺着隔板滑下去——刚才那两股要是再出来一股，他就过去了。柴狗兽人先站起来，把袖子撸到胳膊肘，绕过地上那摊水走来："搭把手。"三个人把他从砖地上架起来；摊主拿抹布蹲下去，把他腿上那道白浊擦了，动作跟擦桌子一样。

那天下午，那身白制服塞进了灶膛，袜底那串 R-31 也跟着黑了。摊主给了他一条围裙、一双新袜子、后头一间小屋。

第二天早上，来了个穿黑制服的客人。水牛兽人端着碗过去，搁下。那客人抬头看了他一眼，又低下头吃面——没认出来。
