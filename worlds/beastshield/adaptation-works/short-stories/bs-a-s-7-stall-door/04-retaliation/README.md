## 一、简介 / Introduction

**一句话钩子 / One-Line Hook**：门外的人一脚一脚踹门。这一次，门里的人把门打开了。

**故事概要 / Synopsis**：

清晨，早饭摊。一只深蓝制服的棕熊兽人吃到一半，去了后头的厕所。他右肩有旧伤，阴天发酸。

门被踹响。第二脚正好落在插销上。他手开始抖——不是怕，是赛前更衣室那道门、那群起哄的声音又回来了。他蹲在最里头那格，没出去过。

第四脚踹完，他拔了插销。

门开。门外是一只喝了些酒的军绿制服野猪兽人。棕熊兽人一把把他抡进来，后脑按进坑口，磕了两下。

然后是膝顶、掐颈、隔着军绿紧身裤的那只手。挨的力气最后都会往下半身走——野猪兽人射空了，靠着隔板滑下去。

棕熊兽人把他摆成一个双肩压制，撂下一句「记住了，下回踹门，先问问里头蹲的是谁」，洗了手，走出去，坐回座位——**再下一碗**。
