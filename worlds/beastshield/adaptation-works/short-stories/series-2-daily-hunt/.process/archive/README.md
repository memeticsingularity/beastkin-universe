## 风格定位说明

### Style 1 - Variant A: 日常休闲模式

**核心特征**：

- 第一人称口语化视角
- 游戏元元素（系统提示、经验值、称号）
- 闲逛→偶遇→评估→击杀的流程
- 状态标签化（醉酒、瞌睡、偷懒）
- 轻松休闲的情感基调

**关键洞察：与原作"市中心开放世界阶段"的对应**

原作主线第一卷中，主角进入市中心后（Ch.09+），游戏机制发生本质变化：
> "自从进入市中心后，就再也没有接到过**主线任务**，似乎这个**游戏**是个纯开放**游戏**
> ，随便玩家怎么发展。"

Series 2 正是对这种"市中心开放世界体验"的系统化扩展：

- 原作 Ch.09+：零散描写了数次闲逛偶遇猎杀
- Series 2：将这种"开放世界日常"扩展为11篇独立单元剧

**原作 vs Series 2 对比**：
| 维度 | 原作市中心阶段(Ch.09+) | Series 2 |
|-----|----------------------|---------|
| 驱动方式 | 闲逛探图（无主线任务） | 闲逛驱动 ✅ |
| 遭遇模式 | 随机偶遇敌人 | 偶遇触发 ✅ |
| 叙事节奏 | 单元式猎杀，无连续剧情 | 单元剧快感 ✅ |
| 情感基调 | 游戏化、探索感 | 日常休闲 ✅ |

**结论**：Series 2 不是脱离原作的"同人变体"，而是原作"市中心开放世界阶段"的自然延伸和体验完整化。

## 创作规范（针对新故事创作）

基于 Series 2 的"开放世界日常"定位，新故事创作应遵循以下规范：

### 格式要求

**标题格式**：

```
# Story xxx：xxx
```

- 编号接续现有故事（如 Story 12、Story 13）
- 副标题概括核心场景或玩法

**分幕格式**：

- 中间加入分幕，每一幕以 `Scene-x XXXXX` 形式出现
- 每一幕可以短一点，但有新的标题
- 示例：`Scene-1 闲逛偶遇`、`Scene-2 观察评估`、`Scene-3 潜行接近`、`Scene-4 处决击杀`、`Scene-5 收获整理`

### 字数要求

- **取消字数限制**，要求超过 **9000字**
- 慢节奏叙事，不赶进度，享受过程

### 描写要求

#### (1) 语言风格

- **详细描写动作和细节**：大量细致入微、直白朴素的描写
- **感官的极致体验**：让读者仿佛身临其境
- **描写真实、充满细节**：每一个动作、每一处身体反应都要具体

#### (2) 剧情推进

- **主线聚焦人物互动推动节奏**
- **慢节奏叙事**：不急于推进剧情，享受观察和互动过程
- **故事推进要慢**：每一步都要有足够的心理建设和感官铺垫

#### (3) 五维度描写（必须全部包含）

- **心理描写**：主角的内心独白、评估、决策过程、吐槽
- **神态描写**：兽人的表情变化、眼神、面部细节
- **动作描写**：每一个肢体动作、身体反应、姿势变化
- **环境描写**：场景氛围、天气、光线、声音、气味
- **语言描写**：对话、自言自语、喘息、呻吟、求饶

#### (4) 兽人肉体描写（核心要求）

**视觉**：

- **脂包肌体型**：强调膀大腰圆、虎背熊腰的视觉效果
- **各种肌肉群**：胸肌、腹肌、大腿肌、小腿肌、臀部肌肉
- **制服细节**：绿/蓝/黑制服的材质、紧绷感、褶皱
- **白袜/黑袜**：位置、编号、污渍、与皮肤的接触

**触觉**（主角与兽人的接触必须详细描写）：

- **体温**：兽人身体的热度、不同部位的温差
- **毛发**：毛发的质地、硬度、顺滑度、触感
- **服饰**：制服布料的触感、袜子的质地、皮带的硬度
- **肌肉**：肌肉的硬度、弹性、紧绷时的状态、放松时的变化

**嗅觉**：

- 雄性气息、汗味、精味、环境气味

**味觉**（如适用）：

- 汗水的咸味、精液的味道等

### 示例参考

**符合规范的描写**：

```
我悄悄地跟在那只狗兽人身后，目光落在他被绿色制服紧裹的背上。
那是一块块隆起的肌肉在布料下的轮廓——不是健身房练出来的那种僵硬线条，
而是长期巡逻、站立、走动自然形成的脂包肌，厚实而有弹性。

Scene-2 尾随观察

他的白袜在黑色皮靴上方露出一截，袜口紧勒着小腿肚，
将那块肌肉勒出一道浅痕。我能想象那布料的粗糙触感，
以及下面毛发的硬度——狗兽人的毛发通常比熊兽人短而密，
像一层绒毛覆盖在皮肤上。当我靠近时，应该能感受到他体温透过制服传来的热度，
还有那股混杂着肥皂和雄性荷尔蒙的气息...
```

## v3版本升级记录 (2026-03-19)

### 版本演进概述

Series 2（日常猎杀）系列经历了三个主要版本的迭代升级：

```
v1 (任务导向) → v2 (休闲偶遇) → v3 (深度沉浸)
```

**v1版本**：以任务为导向的短篇故事，结构简单直接，约3,000字，处决方式单一（90%为割喉）。

**v2版本**：转向日常休闲偶遇模式，统一格式，增加状态标签和游戏化元素，仍保持约3,000字篇幅。

**v3版本**：全面升级至深度沉浸体验，引入完整的解锁机制v3.0，字数扩展至约15,000字，处决方式多样化（12+种），实现真正的开放世界日常猎杀体验。

---

### v3关键特性

#### 1. 详细解锁机制 v3.0

v3版本引入了完整的探索-解锁-执行流程：

- **探索阶段**：主角主动探图、观察环境、发现潜在目标
- **存档/读档机制**：关键决策点可存档，失败后可读档重试
- **失败场景**：解锁失败不会结束故事，而是进入不同的剧情分支
- **多路径解锁**：同一目标可通过多种方式接近和解锁

#### 2. 处决方式多样化

从v1/v2的90%割喉处决，v3大幅降低至约10%，引入12+种处决方式：

| 处决类型 | 具体方式        | 占比  |
|------|-------------|-----|
| 窒息类  | 勒颈、捂嘴、塞袜    | 25% |
| 刺杀类  | 背刺、割喉、飞刀    | 20% |
| 控制类  | 扭脖、点穴、银针    | 20% |
| 撸杀类  | 直接撸射、包皮play | 20% |
| 环境类  | 坠落、触电、重物    | 10% |
| 其他   | 心理play、临界玩弄 | 5%  |

#### 3. 统一格式规范

v3版本实现完全统一的格式标准：

```
# Story XXX：故事标题

Scene-1 场景名称
Scene-2 场景名称
Scene-3 场景名称
...
```

- 所有故事使用统一编号（Story 001 - Story 012）
- 每幕以 `Scene-X 场景名称` 格式呈现
- 场景标题概括该幕核心内容

#### 4. 五维度描写体系

v3版本强制要求每篇故事包含完整的五维度描写：

| 维度     | 描写重点             | 示例元素           |
|--------|------------------|----------------|
| **心理** | 主角内心独白、评估、决策、吐槽  | 欲望波动、风险评估、快感期待 |
| **神态** | 兽人表情变化、眼神、面部细节   | 放松→警觉→恐惧→崩溃的转变 |
| **动作** | 肢体动作、身体反应、姿势变化   | 肌肉颤抖、呼吸急促、本能挣扎 |
| **环境** | 场景氛围、天气、光线、声音、气味 | 雨声、夜色、雄性气息、汗味  |
| **语言** | 对话、自言自语、喘息、呻吟、求饶 | 威胁、求饶、无意识呻吟    |

#### 5. 去除量化"欲望值"

v3版本彻底移除v1/v2中使用的百分比欲望值系统：

**v1/v2做法**（已废弃）：

```
欲望值：30% → 50% → 80% → 100%（射精）
```

**v3做法**（身体反应导向）：

```
他的呼吸变得粗重，胸膛剧烈起伏，
制服下的肌肉不受控制地颤抖，
龟头渗出透明的液体，在月光下闪着微光...
```

通过**具体的身体反应**替代抽象数值，增强沉浸感和真实感。

### 版本变迁分析

#### 为什么从v2升级到v3？

**v2版本存在的问题：**

1. **篇幅过短**：3,000字难以支撑完整的沉浸体验，剧情推进过快
2. **重复性高**：90%使用割喉处决，读者容易产生"割喉疲劳"
3. **缺乏探索**：目标直接呈现，缺少发现和解锁的过程
4. **量化系统破坏沉浸**：百分比欲望值过于游戏化，打断叙事流畅性
5. **格式不统一**：部分故事有分幕，部分没有，阅读体验不一致

**v3版本的优化逻辑：**

| 问题     | v3解决方案      | 预期效果       |
|--------|-------------|------------|
| 篇幅短    | 扩展至15,000字  | 充分铺垫，慢节奏享受 |
| 处决单一   | 引入12+种方式    | 每篇新鲜感，避免疲劳 |
| 缺少探索   | 解锁机制v3.0    | 增加策略性和成就感  |
| 量化破坏沉浸 | 身体反应替代      | 增强真实感和代入感  |
| 格式混乱   | 强制Scene-X结构 | 统一阅读体验     |

#### v3版本的核心设计理念

**1. 从"看故事"到"体验猎杀"**

v3版本将读者从旁观者转变为参与者：

- 通过探索阶段让读者"发现"目标
- 通过解锁机制让读者"选择"策略
- 通过五维度描写让读者"感受"过程

**2. 慢节奏美学**

拒绝快餐式叙事，追求慢节奏的沉浸体验：

- 不急于推进剧情
- 享受观察和互动过程
- 每一步都有心理建设和感官铺垫

**3. 多样化与个性化**

每篇故事都有独特的"指纹"：

- 不同的处决方式
- 不同的目标状态
- 不同的环境互动
- 不同的情感基调

**4. 游戏性与叙事性的平衡**

保留游戏化元素（系统提示、经验值、称号），但将其融入叙事：

- 系统提示作为内心独白的一部分
- 经验值获取作为成就感反馈
- 称号系统作为成长轨迹记录
