## 二、核心特点

### 2.1 玩法亮点

| 元素       | 具体表现               |
|----------|--------------------|
| **正义动机** | 目击作恶，路见不平出手        |
| **陷阱埋伏** | 设置钢丝陷阱，绊倒狼队长       |
| **高空伏击** | 从横梁跳下，后颈刺杀虎兽人      |
| **游击战术** | 利用狭窄空间限制熊兽人，灵活游走   |
| **心理压迫** | 让胆小的狗兽人目睹同伴死亡，精神崩溃 |

### 2.2 处决方式统计

- **狼兽人（队长）**：匕首捅腹+割喉（精槽70%→100%），被陷阱绊倒后骑杀
- **虎兽人（傲慢）**：后颈刺入贯穿喉咙（精槽80%→100%），高空跳杀
- **熊兽人（愚笨）**：扭颈（瞬间100%），游击战后绕后拧断脖子
- **狗兽人（胆小）**：割喉（瞬间100%），吓尿后精神崩溃，干脆利落击杀

### 2.3 场景特色

**商业区→后巷→仓库区**：

- 商业区主干道：巡逻队欺压老人的案发地
- 后巷：狭窄昏暗无监控，完美伏击点
- 钢丝陷阱：横在脚踝高度，连接墙钉

## 三、叙事结构分析

### 3.1 章节流程

```
目击作恶 → 跟踪埋伏 → 第一只（狼队长） → 第二只（傲慢虎） → 第三只（愚笨熊） → 第四只（胆小狗） → 战后离去
```

1. **目击作恶**：四名绿制服杂兵围殴摆摊老者，收取保护费
2. **跟踪埋伏**：提前进入后巷设置钢丝陷阱
3. **第一只（狼队长）**：被钢丝绊倒，骑身捅腹割喉
4. **第二只（傲慢虎）**：从横梁跳下，后颈刺杀
5. **第三只（愚笨熊）**：游击战后扭颈，储精量惊人
6. **第四只（胆小狗）**：吓尿崩溃，干脆割喉
7. **战后离去**：老者感谢，获得"暗夜猎手"称号

### 3.2 节奏特点

| 阶段   | 节奏 | 描写重点      |
|------|----|-----------|
| 目击作恶 | 愤怒 | 正义感激发     |
| 跟踪埋伏 | 缓慢 | 耐心等待，设置陷阱 |
| 狼队长  | 快  | 陷阱触发，瞬间击杀 |
| 傲慢虎  | 快  | 高空跳杀，一击毙命 |
| 愚笨熊  | 紧张 | 游击周旋，寻找破绽 |
| 胆小狗  | 快  | 心理崩溃，干脆击杀 |

### 3.3 关键转折

- **老者感谢**：打破纯猎杀模式，赋予正义色彩，获得称号奖励

## 四、角色塑造分析

### 4.1 主角（无名猎手）

**基本信息**：

- 武器：匕首、钢丝戒指
- 称号：暗夜猎手（传闻度+1）

**性格特征**：

- 正义感："四个绿制服欺负一个老人...兽盾的人渣真是越来越没下限了"
- 冷静计划：观察路线，提前设置陷阱
- 灵活应变：游击战术，利用地形

**叙事功能**：

- 正义执行者，为民除害
- 专业猎手，展示多种战术

### 4.2 狼兽人（队长）

**基本信息**：

- 身份：巡逻队队长
- 武器：警棍

**性格特征**：

- 冷酷：用警棍戳老者胸口
- 警觉：东张西望，提醒队员"今晚还有两圈要巡"

**死亡特征**：

- 被陷阱绊倒，失去平衡
- 被骑身捅腹，痛苦死亡

### 4.3 虎兽人（傲慢）

**基本信息**：

- 行为：踢翻老者货摊

**性格特征**：

- 傲慢："跟他废什么话，不交就砸！"
- 嚣张："藏头露尾的鼠辈，有本事正面对决！"

**死亡特征**：

- 被高空跳杀，后颈贯穿
- 死前瞪眼，一脸不甘

### 4.4 熊兽人（愚笨）

**基本信息**：

- 体型：庞大如铁塔
- 行为：堵巷口，抱胳膊

**性格特征**：

- 愚笨：狂怒挥拳，每一拳都打空
- 受限：狭窄空间限制动作

**死亡特征**：

- 被游击消耗，绕后扭颈
- 储精量最大，射了二十多股

### 4.5 狗兽人（胆小）

**基本信息**：

- 状态：缩脖子，紧张

**性格特征**：

- 胆小：战战兢兢，狐假虎威
- 求生欲："别杀我...我什么都没做..."

**死亡特征**：

- 吓尿，尿液与精液混合
- 被干脆割喉，抽搐死亡

### 4.6 老者（受害者）

**叙事功能**：

- 触发正义动机
- 战后感谢赋予意义

闲逛→目击→埋伏→截杀"的日常正义模式。

## 十三、版本变迁分析 (v1→v2→v3)

### 版本演进

- **v1**: 基础巡逻队截杀模式，主角目击巡逻队欺压老人后设伏截杀四名队员（狼、虎、熊、狗），包含陷阱、高空跳杀、游击战等战术。
- **v2**: 优化了战斗节奏和正义动机铺垫，增加了四人的差异化性格塑造（警觉狼、傲慢虎、愚笨熊、胆小狗）。
- **v3**: 全面升级引入"详细资料解锁机制"，四名巡逻队员各自拥有独特的XP敏感点需要探索发现，处决方式与XP探索深度绑定。

### v3新增元素

- **详细解锁机制**: 四名巡逻队员均有独特XP需要探索
    - 狼队长格雷：耳后敏感（★★★★★），需从乳头→腹部→耳后逐步探索发现
    - 傲慢虎：尾根刺激（★★★★★），高空跳杀后探索发现
    - 愚笨熊：乳头刺激（★★★★★），扭颈后濒死状态探索发现
    - 胆小狗：肚脐周围（★★★★☆），直接询问后验证
- **探索阶段**:
    - 格雷：错误XP（乳头、腹部）反应微弱→正确XP（耳后）反应剧烈
    - 傲慢虎：错误XP（乳头）→正确XP（尾根）
    - 愚笨熊：直接找到正确XP（乳头）
    - 胆小狗：直接询问得知肚脐敏感
- **失败与读档**: 无（本篇章每次探索都在单次战斗中完成，无失败读档）
- **直接询问**: 对胆小狗直接询问XP，对方羞耻透露"肚子...摸我的肚子...肚脐周围..."
- **处决方式变化**:
    - 格雷：从单纯捅腹割喉升级为"腹部创伤+耳后刺激"组合
    - 傲慢虎：从后颈刺杀升级为"尾根刺激+窒息"组合
    - 愚笨熊：保持扭颈，但增加乳头刺激环节
    - 胆小狗：从干脆割喉升级为"肚脐刺激+钢丝勒毙"组合
- **字数变化**: v2约2300字→v3约5500字（增加约139%）

### v3评价

- **优点**:
    1. 四人四色XP设计极具差异化：警觉狼的耳后敏感、傲慢虎的尾根偏好、愚笨熊的乳头反应、胆小狗的肚脐敏感，每只都有独特探索路径
    2. 探索方式多样化：有逐步试探型（狼）、快速发现型（虎）、直接命中型（熊）、询问验证型（狗），避免单调重复
    3. 详细资料中的"特殊备注"增加角色深度（如格雷"疑似童年创伤后的快感转移"）
- **潜在问题**: 四连探索可能造成疲劳感；熊兽人濒死状态探索XP的伦理边界较模糊

### 差异化定位建议

- **建议模式**: 完整探索型
- **理由**: v3版本是Series
  2中群像塑造最丰富的一篇，四名巡逻队员各具特色，XP探索路径各不相同。建议保留完整探索流程，充分展示"
  团队截杀"
  玩法的策略深度——面对多人目标时，主角需要灵活运用陷阱、高空伏击、游击战、心理压迫等多种战术，并在每次击杀后进行XP探索，形成"
  战斗→探索→处决"的完整闭环。
