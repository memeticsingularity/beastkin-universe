# 日常猎杀任务：废弃仓库据点 —— 写作计划

## 一、故事大纲

### 核心任务

主角接到一个日常赏金任务：清理城东废弃仓库中的兽盾小型据点。据点内有5-6名绿制服杂兵和1名蓝制服小队长。

### 章节结构

```
开场（15%）：接受任务/准备 → 抵达据点外围
探索（25%）：潜入侦查 → 发现敌人分布
冲突触发（10%）：被发现或主动出手
战斗（40%）：杂兵清理 → 小队长对决
战后（10%）：搜刮/领赏 → 意外发现
```

## 二、角色设定

### 敌人配置

| 角色   | 类型     | 制服   | 性格标签  | 死亡方式 |
|------|--------|------|-------|------|
| 狗兽人A | 巡逻守卫   | 绿/白袜 | 懒散、大意 | 偷袭割喉 |
| 牛兽人  | 搬运工    | 绿/白袜 | 憨厚、迟钝 | 扭脖子  |
| 野猪兽人 | 守门员    | 绿/白袜 | 暴躁、易怒 | 正面击杀 |
| 虎兽人  | 蓝制服小队长 | 蓝/白袜 | 高傲、轻敌 | 全套处决 |

### 环境设定

- **废弃仓库**：位于城东工业区，曾是物流中心
- **结构**：主仓库+二层办公室+地下储藏室
- **时间**：黄昏时分，光线昏暗

## 三、关键情节点

### 1. 开场（约500字）

- 从武器店小熊猫处接任务
- 确认赏金：绿制服100撸币/只，蓝制服500撸币
- 准备装备：精钢匕首+钢丝戒指

### 2. 潜入侦查（约800字）

- 发动潜行技能，绕到仓库后方
- 观察敌人分布：门口1只，搬运区1只，二楼办公室有灯光
- 选择第一个目标：落单的巡逻狗兽人

### 3. 第一场处决 - 狗兽人（约600字）

- **控制**：从背后捂嘴+割喉
- **精槽变化**：惊恐中精槽快速上升
- **死亡**：跪着射精倒下
- **余韵**：脱袜取编号，尸体藏入集装箱

### 4. 第二场处决 - 牛兽人（约600字）

- **控制**：趁其搬货时从后方偷袭，抓住卵蛋
- **性格表现**：憨厚求饶，愿意配合
- **死亡**：扭脖子，精槽瞬满射精
- **特点**：精液量多（牛兽人设定）

### 5. 第三场处决 - 野猪兽人（约700字）

- **冲突**：正面遭遇，被迫迎战
- **战斗**：利用敏捷优势绕后
- **死亡**：匕首捅穿腹部，挣扎着射精死去
- **性格表现**：到死都在骂骂咧咧

### 6. Boss战 - 虎队长（约1200字）

- **对峙**：蓝制服小队长从二楼跃下
- **战斗**：势均力敌，主角被打中两次（精槽上涨）
- **转折**：发现对方也有"警觉时间"技能
- **决胜**：用钢丝戒指设陷阱，勒住脖子
- **处决**：完整四阶段（控制→挑逗→突破→射精死亡）
- **特点**：高傲到最后一刻才求饶

### 7. 战后（约600字）

- 收集6只袜子
- 在地下室发现"异常货物"（悬念）
- 返回武器店领赏
- 系统提示：升级+新技能解锁

- **v3.0** (2026-03-19): 详细资料解锁机制升级

    - 探索阶段描写细化：包含错误尝试的反馈和正确发现的成就感
