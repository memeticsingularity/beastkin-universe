## 一、故事大纲

### 核心概念

主角在商业区闲逛时，看到一只**兽盾绿制服杂兵**
急匆匆地寻找厕所，表情痛苦、步伐急促。主角尾随他进入偏僻的公共厕所，在隔间里将其解决。利用目标「尿急」的脆弱状态，毫无反抗之力。

### 章节结构（偶遇式）

```
开场（20%）：闲逛 → 目击目标急匆匆找厕所
尾随（25%）：跟踪至偏僻公厕 → 确认隔间
击杀（45%）：进入隔间 → 目标毫无防备被解决
战后（10%）：搜刮后离开，尸体留在隔间
```

## 二、角色设定

### 敌人配置

| 角色    | 类型  | 状态    | 性格标签    | 死亡方式  |
|-------|-----|-------|---------|-------|
| 斗牛犬兽人 | 绿制服 | 尿急、痛苦 | 粗心、毫无警觉 | 隔间内割喉 |

### 环境设定

- **地点**：商业区后巷的公共厕所，偏僻、肮脏、少有人使用
- **时间**：下午，人流稀少时段
- **特色**：隔间狭小，逃脱空间为零

## 三、关键情节点

### 1. 目击目标（约500字）

- 主角在商业区闲逛，观察周围
- 发现一只**斗牛犬兽人**夹着双腿、弓着腰，表情痛苦地快步行走
- 他一只手按着下腹，另一只手不断挠头，显然尿急难忍
- 主角内心OS："这表情...尿急到这种程度？"
- 决定跟上去看看

### 2. 尾随至公厕（约700字）

- **斗牛犬兽人**钻进一条后巷，找到一间老旧的公共厕所
- 厕所外观破败，门口挂着"清洁中"的牌子，但兽人根本不管
- 他冲进去，推开隔间门，解开裤子的声音清晰可见
- 主角等了几秒，确认厕所里没有其他人
- 悄悄跟进，反锁了厕所大门

### 3. 隔间猎杀（约1000字）

- 主角推开隔间门，**斗牛犬兽人**正背对着门、双手扶着墙解放
- 他太专注于排尿，完全没察觉到门被打开
- 主角从背后捂住他的嘴，**匕首**直接割喉
- **斗牛犬兽人**浑身僵硬，尿液和鲜血同时喷涌
- 他想转身挣扎，但尿急后的虚脱让他使不上力气
- 精槽快速上涨，射精死亡，精液混着尿液流进马桶
- 撸下白袜（编号NO.888），尸体让他趴在马桶上

### 4. 战后（约300字）

- 搜刮战利品，白袜入背包
- 主角看了眼尸体："尿急的时候最脆弱，记住了。"
- 从窗户翻出，继续闲逛

## 四、写作要点检查

### XP元素

- [ ] 尿急状态的痛苦表情（弓腰、夹腿、挠头）
- [ ] 隔间内的密闭空间感
- [ ] 白袜编号（NO.888）
- [ ] 精液与尿液混合的描写
- [ ] 尸体姿势（趴在马桶上）

### 系统元素（偶遇式）

- [ ] 精槽值显示（1次）
- [ ] 系统提示（击杀确认、经验值获得）
- [ ] 无任务提示、无倒计时
- [ ] 战利品自动进背包（白袜×1）

### 风格要点

- [ ] 目标尿急的狼狈状态
- [ ] 隔间的肮脏、狭小氛围
- [ ] 毫无防备的脆弱感

## 版本记录

- **v1.0** (2025-03-18): 初始版本
- **v2.0** (2025-03-19): 优化方案
    - 处决方式变更：【割喉】→ 【钢丝环勒颈/窒息塞袜】，理由：尿急状态导致目标虚脱无力，勒颈/窒息更符合"
      虚脱+窒息"的脆弱状态，且能延长濒死体验，增强精槽积累过程
    - 机制表达优化：减少"精槽值"量化提示（原显示1次），改用身体反应叙事（如"瞳孔扩散"、"肌肉痉挛"、"
      无意识抽搐"等生理反应暗示边缘状态）
    - 新增详细资料解锁机制：控射至90%边缘后，通过刺激兽人敏感点（如耳后、尾根、下腹）触发详细资料解锁，包含：真实姓名、入职日期、家庭住址、近期排尿记录等隐私数据
    -
  其他改进：强化隔间密闭空间的窒息氛围；增加尿液与精液混合的感官描写；白袜编号NO.888可关联解锁数据中的"
  幸运数字"彩蛋
- **v3.0** (2025-03-19): 详细资料解锁机制升级
    - 详细资料解锁机制 v3.0：加入探索阶段和失败场景
    - 斗牛犬兽人的XP探索：耳后（错误）、尾根（错误）、下腹（正确）
    - 尿急虚脱状态增加难度：目标反应迟钝，难以判断
    - 引入一次探索失败：尝试耳后时目标提前突破，读档重来
