# 日常猎杀：情侣约会 —— 写作计划

## 版本记录

- **v1.0** (2025-03-18): 初始版本
- **v2.0** (2025-03-19): 优化方案
    - 处决方式变更：浴室割喉 →
      浴缸溺毙/掐脖，理由：情侣偷情后处于极度放松状态，浴室场景适合利用水环境进行溺毙或掐脖，增加处决多样性，避免与其他故事的"
      割喉"同质化
    - 机制表达优化：减少"精槽值"量化提示，改用身体反应叙事（如：呼吸急促、肌肉痉挛、瞳孔扩散、无意识抽搐等生理表现）
    - 新增详细资料解锁机制：控射至90%边缘+刺激敏感点（如乳头、会阴、兽耳根部），通过边缘控制延长死亡过程，解锁目标的私密记忆与身体数据
    - 其他改进：
        - 强调偷情状态的"毫无防备"特性，与处决方式形成反差
        - 兔兽人 civilian 的处决可改为窒息（枕头/湿毛巾），保持多样性
        - 增加浴室水雾、蒸汽等环境氛围渲染

## 一、故事大纲

### 核心概念

主角发现一只**兽盾绿制服杂兵**偷偷溜出来和 civilian 约会，两人走进一家偏僻的情人旅馆。主角等待时机，逐个击破——先解决毫无防备的兽盾员工，再处理
civilian。

### 章节结构（偶遇式）

```
开场（20%）：闲逛 → 发现兽盾员工和 civilian 约会
尾随（25%）：跟踪至情人旅馆 → 确认房间
等待（20%）：等待两人分开或完事
击杀（30%）：逐个击破 → 先杀兽盾员工
战后（5%）：搜刮后离开
```

## 三、关键情节点

### 1. 发现目标（约500字）

- 主角在商业区闲逛，看到一只**豹猫兽人**鬼鬼祟祟
- 他穿着兽盾制服但摘了徽章，和一只**兔兽人 civilian**手牵手
- 两人走进一家偏僻的情人旅馆
- 主角内心OS："上班时间偷情？有意思。"

### 2. 尾随确认（约600字）

- 主角跟进旅馆，看到两人进了三楼的一个房间
- 在走廊等待，听到里面的声音
- 确认只有他们两人，没有其他人

### 3. 等待时机（约500字）

- 主角利用旅馆的通风管道或阳台，潜入房间
- 两人在床上缠绵，完全没注意到潜入者
- 主角躲在衣柜/浴室，等待最佳时机

### 4. 双杀（约1000字）

- **豹猫兽人**完事后去浴室洗澡，毫无防备
- 主角从浴室门后出现，割喉
- 精槽上涨，射精死亡，尸体倒在浴缸里
- **兔兽人**听到动静，惊恐求饶
- 主角不废话，一刀处决
- 撸下白袜（编号NO.520）

### 5. 战后（约200字）

- 搜刮战利品，白袜入背包
- 主角看了眼两具尸体："偷情有风险。"
- 从窗户离开
