# 日常猎杀：醉汉猎场 —— 写作计划

## 版本记录

- **v1.0** (2025-03-18): 初始版本，任务式结构（接受委托→执行任务→领赏）
- **v2.0** (2025-03-18): 重构为偶遇式，强调开放世界自由探索与临时起意的猎杀

## 一、故事大纲

### 核心概念

主角在工业区闲逛探索时，偶然发现三只**兽盾员工**从酒吧喝得烂醉走出。没有任务驱动，纯粹是"
看到猎物就下手"的自由猎杀。赏金只是事后顺带的收获。

### 章节结构（偶遇式）

```
开场（15%）：大世界闲逛 → 路过酒吧
发现（20%）：观察醉酒兽人 → 临时起意决定下手
尾随（15%）：跟踪到僻静处
第一场（20%）：截杀第一只（街头拐角）
第二场（20%）：截杀第二只（小巷深处）
第三场（10%）：截杀第三只（家门口）
战后（0%）：搜刮后继续前行，无领赏环节
```

- **时间**：深夜，路灯昏暗

## 三、关键情节点

### 1. 开场：闲逛发现（约400字）

- 主角在工业区大世界闲逛，找乐子/探索
- 路过"狂野之蹄"酒吧，听到里面喧闹
- 从窗户看到三只兽盾员工正在痛饮
- 内心OS："哟，送上门来的肥羊"

### 2. 尾随观察（约600字）

- 三只醉鬼走出酒吧（狗话痨、猪暴躁、牛傻笑）
- 主角临时起意："跟上去看看"
- 吐槽他们的醉态
- 寻找下手机会

### 3. 第一只：狗兽人（约800字）

- **场景**：第一个街角，狗兽人停下来小便
- **状态**：微醺但还有警觉
- **手法**：从背后捂住嘴，匕首割喉
- **精槽变化**：惊恐中快速上涨，100%射精
- **余韵**：尸体拖进垃圾桶后巷

### 4. 第二只：野猪兽人（约900字）

- **场景**：小巷深处，野猪在发酒疯
- **状态**：烂醉，站不稳但力气大
- **手法**：戏弄式战斗 → 利用醉酒弱点绕后
- **精槽变化**：被打中几次但精槽累积快
- **余韵**：尸体靠着墙坐着，像在睡觉

### 5. 第三只：牛兽人（约800字）

- **场景**：宿舍区门口，牛兽人在找钥匙
- **状态**：半醉，反应迟钝
- **手法**：扭脖子一击必杀
- **精槽变化**：瞬满射精（牛兽人特点）
- **余韵**：尸体趴在门口，精液流进地漏

### 6. 战后（约100字）

- 搜刮三只袜子进背包（白袜是固定战利品）
- 主角内心OS："今天的收获不错"
- 继续闲逛， Seamless 融入大世界
- 结尾无领赏环节，保持开放感

## 四、写作要点检查

### XP元素

- [ ] 醉酒状态的特殊反应（平衡不稳、反应慢）
- [ ] 白袜编号（NO.XXX）
- [ ] 精液分布（街上、墙上、袜子上）
- [ ] 尸体姿势（坐着、趴着、靠着）

### 系统元素（偶遇式）

- [ ] 精槽值显示（3次）
- [ ] 系统提示（击杀确认、经验值获得、升级提示）
- [ ] 无任务提示、无倒计时、无赏金结算
- [ ] 战利品自动进背包（白袜×3）

### 风格要点

- [ ] 轻松吐槽向（日常任务的惬意感）
- [ ] 醉酒兽人的搞笑表现
- [ ] 主角的"捡便宜"心态

## 版本记录

- **v1.0** (2025-03-18): 初始版本，任务式结构（接受委托→执行任务→领赏）
- **v2.0** (2025-03-18): 重构为偶遇式，强调开放世界自由探索与临时起意的猎杀
- **v3.0** (2026-03-19): 详细解锁机制v3.0升级，增加探索阶段与多样化处决方式
    - **探索阶段**：尝试不同敏感点（狗-耳根、野猪-尾根、牛-乳头），每个目标有独特正确XP
    - **失败与读档**：狗兽人首次探索失败（尝试乳头错误），读档重试后找到正确XP（耳根）
    - **直接询问分支**：对野猪尝试直接询问"你的XP是什么"，醉酒状态下野猪半真半假地透露
    - **多样化处决**：
        - 狗（微醺）：钢丝环勒颈 + 针封穴
        - 野猪（烂醉）：袜子塞嘴窒息 + 溺毙于尿液
        - 牛（半醉）：保留扭脖子（原作经典）
    - **存档/读档叙事**：第一人称回忆式与系统提示结合
    - **五维描写强化**：心理、神态、动作、环境、语言全面升级
