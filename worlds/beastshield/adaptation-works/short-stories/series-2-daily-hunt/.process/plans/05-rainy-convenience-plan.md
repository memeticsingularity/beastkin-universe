## 一、故事大纲

### 核心概念

暴雨夜，主角躲雨进便利店，发现一只**兽盾绿制服杂兵**正在吃泡面休息。雨停后目标返回巡逻路线，主角尾随至无人小巷将其解决。利用雨声掩盖动静，增加氛围感。

### 章节结构（偶遇式）

```
开场（20%）：暴雨突降 → 躲雨进便利店
发现（25%）：观察到休息的兽盾员工 → 判断可下手
等待（15%）：雨停后目标离开 → 开始尾随
击杀（35%）：雨中尾随 → 暗巷动手
战后（5%）：搜刮后离开，雨还在下
```

## 三、关键情节点

### 1. 开场：暴雨躲雨（约600字）

- 主角在商业区闲逛，突然下起暴雨
- 没有带伞，跑进最近的便利店躲雨
- 店内只有一只**狼犬兽人**坐在休息区，面前摆着一桶刚泡好的泡面
- 他穿着**兽盾绿制服**，外套搭在椅背上，看起来是巡逻间隙来休息的
- 主角买了罐热咖啡，坐在角落观察

### 2. 观察判断（约700字）

- **狼犬兽人**狼吞虎咽地吃着泡面，完全沉浸在食物中
- 他看了眼手表，似乎还有一段休息时间
- 主角注意到他随身只带了警棍，外套里可能有武器但暂时没穿
- 外面雨势渐小，但还在下
- 主角内心OS："雨声正好可以掩盖动静..."
- 决定等他离开后跟上去

### 3. 尾随开始（约400字）

- 雨势变小，**狼犬兽人**喝完最后一口汤，穿上外套准备离开
- 主角等他走出一段距离后才跟出去
- 街道上行人稀少，雨声淅沥
- 狼犬兽人哼着歌走回巡逻路线，心情似乎不错
- 主角保持跟踪，寻找下手时机

### 4. 动手击杀（约1100字）

- 跟到一条后巷，四下无人，雨声掩盖了脚步声
- 主角加速接近，从背后捂住他的嘴
- **狼犬兽人**惊恐挣扎，泡面还没消化完就遇到死神
- 匕首割喉，鲜血混着雨水流下
- 精槽快速上涨，他双腿发软跪倒在积水中
- 射精死亡，精液被雨水稀释，顺着水流进下水道
- 撸下白袜（编号NO.315），尸体让他趴在地上，像在避雨

### 5. 战后（约200字）

- 搜刮战利品，白袜入背包
- 雨还在下，冲刷着血迹
- 主角撑开从便利店买的便宜雨伞，继续走入雨中

## 版本记录

- **v1.0** (2025-03-18): 初始版本
- **v2.0** (2025-03-19): 优化方案
    - 处决方式变更：雨中割喉 → 扭脖/钢丝勒颈，理由：放松状态适合快速无声的处决方式，扭脖可强化"雨声掩盖"
      的战术感，钢丝勒颈则增加窒息元素的XP张力
    - 机制表达优化：减少"精槽值"量化提示，改用身体反应叙事（如"吃泡面时的满足感与突如其来的快感交织"、"
      喉咙被勒住时本能的求生欲与身体的诚实反应冲突"等）
    - 新增详细资料解锁机制：利用雨夜氛围，控射至90%边缘并刺激狼犬兽人的敏感点（如耳后、腹部），解锁详细资料后再执行处决
    - 其他改进：强化"雨中积水"与"精液被雨水稀释"的视觉对比；增加狼犬兽人"吃泡面放松"到"濒死射精"
      的状态反差描写
- **v3.0** (2025-03-19): 详细资料解锁机制 v3.0
    - 详细资料解锁机制 v3.0：加入探索阶段，通过尝试不同敏感点来发现目标的XP
    - 狼犬兽人的XP探索：耳后（正确）、腹部（错误）、尾根（部分正确，加速但不完全）
    - 雨夜氛围影响：湿滑的触感增加探索难度，雨水让皮毛变得湿润，增加了触摸时的不确定性
    - 探索过程：刺激腹部有反应但不强烈（部分正确）→ 刺激尾根反应增强但未达最佳（部分正确）→
      刺激耳后剧烈颤抖身体诚实（正确）
    - 主角内心OS："原来是这里..." 在发现正确敏感点时的顿悟
    - 控射至边缘状态后成功解锁详细资料，再执行钢丝勒颈处决
