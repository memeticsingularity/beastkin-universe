与 Series 1（哨兵清除系列）的潜行暗杀不同，**日常猎杀系列**

## 文档版本管理规范

### Plan文件的更新规则

**重要：不要直接修改原plan内容！**

当需要调整故事规划时，应在plan文件末尾追加版本更新记录：

```markdown
## 版本记录

- **v1.0** (日期): 初始版本，原方案描述...
- **v2.0** (日期): 第一次更新，修改内容...
- **v3.0** (日期): 第二次更新，修改内容...
```

**示例：**

```markdown
- **v1.0** (2025-03-18): 初始版本，任务式结构（接受委托→限时击杀→回公会领赏）
- **v2.0** (2025-03-18): 重构为偶遇式，主角大世界闲逛主动发现目标，无任务驱动
```

### Story文件的更新规则

**后缀版本管理**：通过后缀 `_v1`, `_v2` 等标识版本，旧版本迁移到 `history/` 文件夹。

**文件命名规则：**

- `XX-title-story_v1.md` - 第一版（首次创作）
- `XX-title-story_v2.md` - 第二版（第一次修改）
- `XX-title-story_v3.md` - 第三版（第二次修改）
- ...以此类推

**目录结构示例：**

```
story/
├── 02-drunk-hunt-story_v2.md      # 当前最新版（偶遇式）
├── 03-patrol-intercept-story_v2.md
└── history/
    ├── 02-drunk-hunt-story_v1.md  # 旧版（任务式）
    └── 03-patrol-intercept-story_v1.md
```

**工作流程：**

1. 第一次写 → `02-drunk-hunt-story_v1.md`
2. 修改时 → 创建 `02-drunk-hunt-story_v2.md`
3. 归档旧版 → 将 `v1` 移动到 `history/` 文件夹

**好处：**

- 一眼就能看出当前是第几版
- 旧版本有迹可循，不会直接消失
- 没有软链接，跨平台兼容

### 创作规范（重要）

#### 1. 机制表达方式

**性欲值表现**（修正）：

- ❌ 避免：频繁使用"精槽"一词和"性欲值+20%"的量化系统提示
- ✅ 推荐：通过**角色身体反应**表现状态变化
    - "突破精关"、"真的要射了"、"到了临界点边缘"
    - 喘息加重、身体颤抖、求饶等生理反应
- ⚠️ 系统提示仅用于关键节点：发现目标、击杀确认、技能解锁

**详细资料解锁机制 v3.0**：

**核心玩法**：

```
控制目标 → 自由探索敏感点 → 找到XP加速/没找到慢速 → 达到90% → 解锁成功/失败
     ↑________________________________________________↓
                      （存档点，失败可读档重试）
```

**探索阶段**（任意时间开始）：

- 刺激不同部位，观察目标反应
- **正确XP**：目标剧烈反应、身体诚实、性欲值增长加速
- **错误部位**：轻微颤抖、闷哼、性欲值增长缓慢
- 找到XP后可标记，后续操作自动加速

**解锁触发**（90%临界点）：

- **已找到XP**："果然在这里..." → 成功解锁详细资料
- **未找到XP**："该死，猜错了..." → 解锁失败（部分/无信息）
- **提前突破**：目标提前射精死亡 → 解锁完全失败

**心理博弈选项**：

- **直接询问**："想活命吗？告诉我你的敏感点在哪里。"（部分敌人会屈服招供）
- **威胁利诱**："说了也许会考虑放过你。"（高魅力角色适用）
- **反复试探**：多次尝试不同部位，直到找到正确XP

**解锁内容**：

- 基础信息：身高、体重、三围、种族
- 隐藏信息：真实姓名、XP类型、敏感度星级、内心想法、秘密记忆
- 战略价值：评估收服价值或选择最优处决方式

**存档/读档叙事处理**：

- 第一人称回忆式："上一次试了乳头，结果他提前射了。这次..."
- 直接游戏化：**系统提示**：是否读取存档？ [是/否]
- 直觉包装："直觉告诉我，他的敏感点不在这里..."（隐藏读档机制）

**随从系统**：

- 部分敌人满足条件可收服（威逼利诱、实力征服、送礼讨好）
- 增加策略维度：评估敌人价值→选择处决或收服
- 随从可作为临时战力或提供情报

#### 2. 叙事要求

**取消字数限制，要求**：

1. **语言风格**：详细描写动作和细节（大量细致入微、直白朴素的描写、感官的极致体验）
2. **剧情推进**：主线聚焦人物互动推动节奏，慢节奏叙事
3. **五维描写**：心理、神态、动作、环境、语言
4. **感官体验**：兽人肉体（脂包肌，各种肌肉群）、视觉、触觉（体温/毛发/服饰/肌肉）、嗅觉、味觉
5. **分幕结构**：中间加入分幕，格式 `Scene-x XXXXX`
6. **标题格式**：`#Story xxx：xxx`

#### 3. 玩法多样性要求

**避免同质化**：

- 禁止使用单一处决模板（如90%割喉）
- 根据目标状态选择处决方式：醉酒→扭脖、瞌睡→银针封穴、尿急→钢丝环
- 引入环境击杀、道具使用、种族差异化等

**v4建议**:

- 控制篇幅：日常猎杀8000字以内

- 节奏差异化：长短快慢结合
