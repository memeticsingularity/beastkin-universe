## 一、灵感库说明

### 1.1 什么是灵感库

灵感库是一个动态文档，用于：

- 随时记录突发奇想的创作点子
- 归档已使用/未使用的创意
- 提供快速查找和筛选功能
- 避免重复创作
- **确保所有灵感符合Series 3 v3.0标准**（见1.4节）

### 1.2 灵感分级

| 等级    | 标识 | 说明             |
|-------|----|----------------|
| ⭐⭐⭐⭐⭐ | 成熟 | 已完成详细规划，随时可写   |
| ⭐⭐⭐⭐  | 完善 | 有完整大纲，需进一步完善   |
| ⭐⭐⭐   | 骨架 | 有核心概念和场景，需扩展   |
| ⭐⭐    | 萌芽 | 仅有基础想法，需大量开发   |
| ⭐     | 碎片 | 零散点子，可能与其他灵感合并 |

### 1.3 凶手风格分类（v3.0）

根据Series 3 v3.0标准，所有灵感按凶手风格分类：

1. **炎型（高效冷漠）**: 面无表情，计时，顺手推开
2. **玩弄型**: 顺手玩弄几下，再弄射，像垃圾处理
3. **羞辱型**: 顺手羞辱几句，再弄射，像垃圾处理
4. **双主角配合**: 炎+魉配合，一个杀一个善后

**核心不变**：不管哪种风格，死后都必须像垃圾处理（擦手、推开、塞容器、腿露外面）

### 1.4 Series 3 v3.0标准 **[重要]**

所有灵感必须符合以下标准：

#### 必须包含（核心中的核心）

| 元素          | 说明           | 多样化示范           |
|-------------|--------------|-----------------|
| **顺手杀戮**    | 杀人不是目的，是顺手的事 | 炎从阴影伸手，10秒弄射    |
| **挣扎求饶**    | 可以写，但不要太多背景  | "快放开我！...不要！"   |
| **用尸体擦手**   | 必须步骤         | "在背肌/衣服/墙壁上擦了擦" |
| **顺手推开/丢弃** | 像扔垃圾一样       | 推开、踹开、扔下、抛入、滚落  |
| **垃圾化处理**   | **多样化！**见下表  | 姿势屈辱、位置随意、不被尊重  |
| **只脱一只鞋**   | 拍编号，不拍脸      | 快速、不讲究、像拆包裹     |

#### 尸体处理多样化示范（重要！避免公式化）

**核心原则**：垃圾不会被体面地塞进容器。随手丢在哪里、什么姿势，都可以。

| 场景         | 处理方式            | 屈辱点       |
|------------|-----------------|-----------|
| **垃圾桶**    | 上半身塞入，腰部卡住，腿露外面 | 像扔垃圾      |
| **更衣柜**    | 塞入/塞不进，腿露外面     | 私人空间被侵占   |
| **草丛/灌木丛** | 像扔死狗一样扔进去       | 被植物掩盖     |
| **走廊角落**   | 推入阴影处，脸朝下趴着     | 像被遗弃的物品   |
| **椅子/沙发上** | 推倒在座位里，瘫坐姿势     | 像在休息但已死亡  |
| **桌子/柜台上** | 上半身趴在台面，下半身垂下   | 像被摆放的物品   |
| **楼梯口**    | 推下楼梯，滚落几级       | 像垃圾滚落     |
| **门口**     | 靠在门框上，像靠着休息     | 被进出的门夹住   |
| **床/床垫上**  | 推倒在床上，被子盖住下半身   | 像在睡觉但精液浸透 |
| **厕所隔间**   | 趴在马桶上/坐在马桶上     | 极端屈辱      |
| **浴池/泳池**  | 推入水中，漂浮像死鱼      | 无声无息      |
| **泥潭/水坑**  | 脸朝下按入泥水         | 肮脏        |
| **货堆/箱子上** | 扔在货物上，像一件货物     | 物品化       |
| **墙角**     | 堆在角落，和其他杂物一起    | 像杂物的一部分   |

#### 禁止出现

| 禁止元素   | 说明           | v3.0处理方式 |
|--------|--------------|----------|
| 背景故事   | 家乡、家人、梦想     | 在挣扎时可以有  |
| 死亡价值   | "才刚当上组长"的同情  | 死亡只是数据   |
| 体面处理   | Series 2的仪式感 | 必须像垃圾    |
| 复杂play | 详细解锁机制       | 顺手玩弄即可   |

#### 放宽限制（v3.0 vs v2.0）

| 维度       | v2.0（过度） | v3.0（正确）      |
|----------|----------|---------------|
| **名字**   | 禁止，只用编号  | ✅ 可以有（雷爪-虎兽人） |
| **种族**   | 只熊虎牛     | ✅ 全种族可        |
| **凶手风格** | 只高效冷漠    | ✅ 可以玩弄/羞辱     |
| **挣扎求饶** | 删除       | ✅ 可以写         |
