## 一、故事大纲

### 核心概念

炎和魉潜入兽盾公司某分部外围的门卫室。一只肥胖的熊兽人门卫正在值班时打瞌睡，炎正面接近，顺手玩弄几下后发功处决。尸体塞进柜子，因为太胖塞不进去，腿露在外面。

### 凶手风格（玩弄型 - 顺手玩弄）

**炎**：

- 风格：玩弄型 - 顺手玩弄几下
- 不是专门设计复杂play，是顺手的
- 捏大包说"挺软的"，玩弄几秒再发功
- 14秒计时
- **核心**：杀完像垃圾处理（擦手、推开、塞容器）

**魉**：

- 善后，拍照编号
- 拖尸像拖垃圾
- 抱怨"太胖了"
- 塞柜子，腿露外面，拍编号G-008

## 三、关键情节点

### 1. 潜入观察（约600字）

- 炎和魉潜入兽盾分部外围
- 发现门卫室：小房间，一桌一椅一柜，监控屏幕
- 大壮-熊兽人正在打瞌睡
    - 330斤肥胖身材
    - 军绿色制服被撑得紧绷
    - 大肚腩随着鼾声起伏
    - 白袜粗腿，一只脚搭在桌上
- 炎观察："肥羊一只。"
- 魉："看起来睡得很死。"

**可以写**：体型、制服、鼾声、睡姿
**不写**：背景、家人、梦想

---

### 2. 玩弄与处决（约1500字）

**风格**：玩弄型 - 顺手玩弄几下

炎正面走向大壮。
大壮半睡半醒，迷迷糊糊睁开眼睛："谁...？"

炎直接伸手抓裆，握住那鼓囊囊的一大包。
大壮浑身一僵："你...你干什么...！"

炎捏了捏掌中的大包："挺软的。"
（顺手玩弄，不是专门设计）

玩弄几秒，大壮想挣扎但太胖了动作迟缓。
炎开始发功，灼流暗劲灌入。

大壮在椅子上扭动，粗腿乱蹬，白袜摩擦地面。
"放开...求你了...不要...！"
14秒后射精，精液浸透军绿色裤裆。

"14秒。"
炎抽出手，在大壮胸前的制服上擦了擦。（用尸体擦手）
顺手一推，大壮连人带椅翻倒在地，像垃圾一样。（顺手推开）
离开。

---

### 3. 善后处理（约800字）

魉现身，看着地上的尸体。
大壮仰面朝天，军绿色裤裆湿透，白袜粗腿摊开。

魉叹气："这么胖..."
拖尸体像拖垃圾一样，往柜子里塞。

柜子太小，大壮太胖。
上半身塞进去，腰部卡住，两条穿着白袜的粗腿露在外面。
（腿露外面！）

魉抱怨："太胖了塞不进去..."
使劲硬塞，柜门还是关不上。

脱下大壮右脚的鞋子。
军绿色运动鞋，里面白袜露出来，袜口勒进粗壮的脚踝。
袜底印着编号：G-008
拍照。（只脱一只，拍编号）

把鞋子扔在一边，像丢弃垃圾。
魉隐身离开。

---

### 4. 尾声（约200字）

门卫室恢复安静。
监控屏幕还在闪烁。
大壮的尸体塞在柜子里，两条腿露在外面，白袜脚垂在地上。
地上散落着一只军绿色运动鞋。

像什么都没发生。
只是少了一个正在打瞌睡的门卫。

## 四、写作要点检查

### 核心必须（不能变）

- [ ] 炎用尸体/衣服擦手
- [ ] 炎顺手推开尸体（像垃圾）
- [ ] 尸体塞入柜子，腿露在外面
- [ ] 魉只脱一只鞋拍编号G-008
- [ ] 整体感觉：死后像垃圾处理
- [ ] 炎顺手玩弄（捏大包说"挺软的"）

### 可以写

- [ ] 目标有名字（大壮）
- [ ] 挣扎求饶过程
- [ ] 凶手顺手玩弄几句

### 禁止写（底线）

- [ ] 背景故事（家乡、家人、梦想）
- [ ] 死亡有仪式感/价值感
- [ ] 尸体被体面处理
- [ ] 凶手专门设计复杂play

---

## 五、Scene-1 学习要点

**正确的（全部学习）**：

1. 雷爪有名字 ✓
2. 有挣扎求饶 ✓
3. 炎顺手弄死 ✓
4. 用背肌擦手 ✓
5. 顺手推开 ✓
6. 塞垃圾桶，腿露外面 ✓
7. 只脱一只鞋 ✓

**关键区别**：

- 炎型：面无表情高效（Scene-1雷爪）
- 玩弄型：顺手玩弄几下（本故事大壮）
- 羞辱型：顺手羞辱几句

**玩弄不是专门设计**：

- 不是详细解锁机制
- 只是顺手捏几下，说句话
- 然后直接发功
