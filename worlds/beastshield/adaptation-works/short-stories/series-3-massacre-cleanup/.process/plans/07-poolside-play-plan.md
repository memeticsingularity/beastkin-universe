## 一、故事大纲（v3.0）

### 核心概念

炎和魉潜入兽盾本部游泳池。一只水牛兽人阿浪正在池边休息，下半身泡在温水中。炎潜入水中，从下方接近，在水中握住牛鞭玩弄，20秒内完成击杀。精液在水中扩散，泛起白浊。尸体像死鱼一样漂浮在水中，随后被推到池边角落。

### 凶手风格（玩弄型 - 水中玩弄）

**目标：阿浪-水牛兽人**

- 风格：玩弄型，顺手捏几下，再弄射
- 台词简短："水里更敏感"、"20秒"
- 核心：水中隐秘玩弄，精液扩散的视觉

**核心**：玩弄几下再弄死，死后像死鱼一样漂浮。

### 2. 泳池杀戮：阿浪-水牛兽人（玩弄型）（约2500字）

**风格**：玩弄型，水中玩弄，顺手捏几下

阿浪靠在泳池边，下半身泡在温热的池水中，上半身露出水面。他闭着眼睛，享受着深夜的宁静。

炎悄无声息地潜入水中，从水下接近。

水下光线昏暗，但炎能清晰地看到阿浪那肥胖的身躯。水牛兽人的下半身浸泡在水中，泳裤随着水波轻轻晃动，勾勒出饱满的轮廓。

炎从水下伸出手，握住了阿浪的牛鞭。

"唔——！"阿浪猛地睁开眼睛，身体一僵。

他低头看向水中，但水面平静，什么都看不到。只能感觉到有一只手正握着自己的命根子，温热而有力。

"谁...谁在水里！"阿浪惊慌地喊道，双手抓住池边，想爬起来。

但那只手开始动了。

炎在水中把玩着掌中的牛鞭，手指轻轻捏了捏龟头，感受着那团柔软器官在水中的触感。水温让一切都变得更加敏感。

"水里更敏感。"

炎的声音从水下传来，闷闷的，带着一丝玩味。

"什...什么？快放开！"阿浪的脸涨得通红，牛鼻子里喷出粗气。他想挣扎，但泡在水中的身体使不上力气，而且那只手的刺激让他浑身发软。

炎开始运功，灼流暗劲透过掌心渗入阿浪的下体。

"唔...唔啊！"阿浪发出一声闷哼，肥胖的身躯在水中颤抖起来。

他能感觉到一股热流从被握住的位置涌入，顺着血管蔓延到全身。那根牛鞭在炎的掌心中急速充血、膨胀、硬挺起来，比平常任何时候都要硬。

而且，水确实让一切都变得更敏感。

每一次手指的摩擦，每一次掌心的包裹，都被水放大了数倍。阿浪能感觉到自己的肉棒在炎的手中脉动，马眼处开始不受控制地渗出前列腺液，混在池水中消散。

"不...不要..."阿浪的声音开始发颤，双手死死抓住池边，指节发白。

炎面无表情，但手中的动作却带着玩弄的意味。他捏了捏掌中的大包，感受着牛鞭在水中微微滑动的触感。

"挺软的。"

他低声说道，然后开始计时。

阿浪的呼吸越来越急促，牛胸口剧烈起伏，圆滚的腹部在水中微微晃动。他能感觉到自己的精囊在剧烈收缩，储存的精液被那股热流催动着，疯狂地涌动、寻找出口。

"求...求求你...放开我..."阿浪开始求饶，声音里带着哭腔。

但炎没有理会。他的手指在水中灵活地运动，拇指的指腹按压在阿浪阴茎根部的敏感点，那是能极大加速射精的位置。

水泡从水下冒出，是阿浪急促的呼吸造成的。

"快...快到了..."阿浪的意识开始模糊，下体传来的快感让他恐惧到了极点，也莫名地兴奋到了极点。他的臀部不自觉地向后顶，试图摆脱那只手，但这样的摩擦反而让炎握得更紧，带来了更强烈的刺激。

炎默数着时间。

阿浪的身体开始出现高频的颤抖。他的圆滚腹部剧烈收缩，像一口被挤压的大锅。白袜放在池边的双脚徒劳地蹬踹，脚趾在袜子里疯狂地蜷缩、伸展。

"20秒。"

炎低声说道。

阿浪达到了射精的边缘。

他的整个身体绷紧到了极致，圆滚的腹部向内收缩，腰部向后反弓，胯部向前挺送。那根粗壮的牛鞭在炎的掌心中剧烈脉动，龟头处的马眼张开——

喷射开始了。

第一股精液猛烈地从马眼激射而出，但因为是在水中，没有发出声音，只是形成了一团白浊的液体，在池水中缓缓扩散。紧接着是第二股、第三股...量极大，显示出这头水牛兽人旺盛的生命力。

精液持续不断地喷射，在阿浪周围的池水中形成一团不断扩大的白浊云雾，像一朵盛开的水下之花。池水开始泛起淡淡的白色，那是精液在扩散。

阿浪的身体随着每一次射精而剧烈痉挛。他的喉咙深处发出"嗬...嗬..."
的无意识呻吟，声音被水面闷住，变得模糊不清。他的意识在极致的快感中沉浮、湮灭，大脑已经完全失去了对身体的控制。

最后一股稀薄的精液从马眼缓缓溢出，顺着已经软化的柱身流下，混在池水中消散。

炎松开了手。

阿浪像一座崩塌的肉山，软软地向水中滑去。他的双手从池边滑落，肥胖的身躯缓缓沉入水中，然后——漂浮了起来。

像一条死鱼。

### 3. 垃圾般的处理（约600字）

炎从水中浮出，面无表情地看着漂浮在水面上的阿浪。

水牛兽人300斤的身躯仰面漂浮着，圆滚的腹部露出水面，像一座小小的岛屿。他的四肢无力地张开，随着水波轻轻晃动。最引人注目的是他的下体——泳裤被精液浸透，呈现出一片深色的湿痕，而周围的池水则泛着淡淡的白色。

炎游到池边，双手撑住池沿，翻身出水。

他的手掌和手指上沾满了池水和精液的混合物。他面无表情地看着掌心，然后——

随意地将手在阿浪尚且温热的、厚实宽阔的胸膛上擦了擦。

水牛兽人的皮肤因为池水的浸泡而泛着水光，表面覆盖着一层细密的水珠。炎的手掌在那层脂肪上摩擦，池水和精液的混合物很快被湿润的皮肤吸收，留下几道粘腻的污痕。

"20秒。"

他低声说道，声音平静得像是在报时。

然后，他像推开一件碍事的家具一样，顺手将阿浪漂浮的身体推向泳池中央。

"哗啦——"

阿浪沉重的身躯随着水波漂向泳池中央，像一条被丢弃的死鱼。他的脸朝上，牛眼半睁着，瞳孔已经扩散，失去了所有焦距，眼神空洞地望着天花板上昏暗的灯光。圆滚的腹部随着呼吸的停止而不再起伏，像一座静止的岛屿漂浮在水面上。

周围的池水泛着淡淡的白色，那是他射出的精液在扩散。

炎看都没看一眼，转身离开。

[魉善后]

魉从阴影中现身，看着泳池中漂浮的尸体，无奈地叹了口气。

"真是的...每次都处理得这么随意。"

他走到池边，蹲了下来。浓烈的雄性腥膻味扑面而来——那是精液、池水、水牛兽人特有的体味混合在一起的味道。

魉伸出纤细的手指，握住了阿浪漂浮在水面上的一只脚。入手处皮肤还温热，但正在迅速变凉。粗硬的牛毛扎手，白色的长筒袜因为池水而彻底湿透，紧紧贴合着粗壮的脚踝。

魉将这只大脚抬起，让脚底朝上。

白色袜底已经变成了深灰色，脚掌和脚跟处磨损明显，正中清晰地印着一个黑色的编号：

**G-007**。

魉只脱下了阿浪右脚的白袜。

他的动作很快，手指灵巧地卷下湿漉漉的袜口，沿着粗壮的脚踝向下褪。袜子因为湿透而紧贴着皮肤，发出细微的"啵"
的一声，终于脱离了牛蹄。露出的脚底粗糙厚实，趾间还有一些webbing的痕迹，脚掌的颜色比脚背更深。

魉拿出一个老式的翻盖手机，对准那只赤裸的牛蹄和手中的白袜。

"咔嚓。"

闪光灯在昏暗的泳池边亮起，照亮了袜底那个清晰的编号。

拍完照，魉随手将那只湿漉漉的白袜扔回阿浪脸上。袜子"啪"的一声盖在水牛兽人半张的口鼻上，像是一件被随意丢弃的垃圾。

"G-007，记录完毕。"

然后，魉抓住阿浪的两只脚踝，像拖死鱼一样将尸体拖到泳池边缘。水波随着尸体的移动而荡漾，将那团白浊的精液扩散到更大的范围。

他将阿浪推到一个泳池边的角落，那里堆放着一些清洁用具和塑料椅子。尸体靠在池壁上，上半身露出水面，下半身浸泡在水中，姿势别扭而屈辱。

"走吧，下一个。"

炎的声音从阴影中传来，平静而冷漠。

魉点了点头，身形渐渐隐去。

### 4. 善后总结（约300字）

尸体处理完毕：

- 阿浪-水牛兽人：泳池角落，上半身露出水面，下半身浸泡，像死鱼一样漂浮

魉拍完编号。

炎："走吧，下一个。"

两人离开，像什么都没发生。

泳池中只剩下泛白的池水、漂浮的精液，和角落里的那具水牛兽人尸体。

**不写**：赏金金额、心理活动、对死者的评价

## 四、写作要点检查（v3.0）

### 核心必须（这三条不能变）

- [ ] 炎用池水/尸体擦手
- [ ] 炎顺手推开尸体，漂浮像死鱼
- [ ] 尸体推到池边角落，姿势屈辱
- [ ] 魉只脱一只鞋拍编号
- [ ] 整体感觉：死后像垃圾处理

### 可以写（v3.0放宽）

- [ ] 目标有名字（阿浪）
- [ ] 挣扎求饶过程
- [ ] 凶手顺手玩弄几句
- [ ] 凶手风格多样（玩弄型）

### 禁止写（底线）

- [ ] 背景故事（家乡、家人、梦想、为什么加入兽盾）
- [ ] 死亡有仪式感/价值感
- [ ] 尸体被体面处理（Series 2的方式）
- [ ] 凶手专门设计复杂play（如Series 2的详细解锁）
