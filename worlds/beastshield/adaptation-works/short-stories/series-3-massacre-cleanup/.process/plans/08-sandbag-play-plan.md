## 三、场景设定

### 3.1 环境描述

- **地点**: 兽盾训练基地格斗室
- **时间**: 深夜
- **氛围**: 沙袋晃动声、沉闷的打击声、空旷回声
- **关键元素**: 成排悬挂的沙袋、格斗垫、昏暗灯光

### 3.2 目标信息

| 属性     | 内容                     |
|--------|------------------------|
| **名字** | 雷虎                     |
| **编号** | G-008                  |
| **种族** | 虎兽人                    |
| **体重** | 280斤                   |
| **特征** | 专注打沙袋，肌肉发达，虎纹明显        |
| **状态** | 专注、出汗、呼吸粗重             |
| **着装** | 黑色紧身背心、黑色短裤、白色长筒袜、格斗手套 |

### 3.3 虎兽人种族特性

- 肉刺颗粒，系带敏感
- 挣扎时带有虎兽人的野性和不甘
- 射精时会有低吼（被闷住）

## 四、场景分镜

### Scene-1 沙袋后的阴影

**字数**: 800字

**内容要点**:

1. 炎潜入格斗室，观察环境
2. 描述沙袋区：成排悬挂的沙袋，昏暗灯光
3. 发现目标：雷虎在打沙袋，专注
4. 炎躲在沙袋后，观察时机
5. 魉隐身配合，确认周围无其他人

**关键描写**:

- 沙袋晃动的节奏
- 雷虎的肌肉线条、汗水
- 炎的潜行和等待

---

### Scene-2 缝隙中的玩弄

**字数**: 1,200字

**内容要点**:

1. 雷虎专注打沙袋，每打一拳沙袋就晃一下
2. 炎从沙袋缝隙伸手，每次虎兽人贴近时刺激一下
3. 玩弄几轮：
    - 第一轮：轻触裆部，雷虎困惑但继续打
    - 第二轮：捏一下，雷虎停顿，四处张望
    - 第三轮：揉动，雷虎开始不安
4. 雷虎的困惑和恐惧逐渐升级
5. 台词："打拳别分心"

**关键描写**:

- 沙袋晃动的节奏感
- 每次刺激时雷虎的反应
- 玩弄的心理压迫
- 雷虎的困惑："怎么回事？"

---

### Scene-3 十二秒

**字数**: 1,000字

**内容要点**:

1. 炎不再隐藏，直接抓裆运功
2. 雷虎想挣扎，但被炎控制住
3. 灼流暗劲注入
4. 计时：12秒
5. 雷虎挣扎、求饶、射精死亡
6. 台词："12秒"

**关键描写**:

- 抓裆的动作
- 雷虎的挣扎（虎兽人的野性）
- 12秒的计时过程
- 射精死亡的身体反应

---

### Scene-4 像沙袋一样

**字数**: 600字

**内容要点**:

1. 炎用尸体擦手
2. 顺手推尸靠在沙袋上
3. 尸体姿势：背靠沙袋，头歪向一边，像废弃沙袋
4. 炎离开
5. 魉出现，拍照，拖尸

**关键描写**:

- 擦手动作
- 推尸靠在沙袋上的画面
- 尸体像废弃沙袋的屈辱感
- 魉只脱一只鞋拍编号

---

### Scene-5 寂静的格斗室

**字数**: 400字

**内容要点**:

1. 格斗室恢复寂静
2. 沙袋还在微微晃动
3. 尸体靠在沙袋上，像另一具沙袋
4. 环境渲染

**关键描写**:

- 沙袋晃动的余韵
- 尸体的姿态
- 死亡毫无价值的氛围

## 六、尸体处理细节

### 炎的处理

1. **擦手**: 在雷虎背肌/黑色背心上擦手
2. **推开**: 顺手推尸靠在沙袋上

### 魉的处理

1. **拖尸**: 像拖沙袋一样拖到角落
2. **塞入**: 扔在沙袋堆里，和真正的沙袋混在一起
3. **拍编号**: 只脱一只鞋，拍袜底编号G-008
4. **腿露外面**: 双腿露在沙袋堆外
