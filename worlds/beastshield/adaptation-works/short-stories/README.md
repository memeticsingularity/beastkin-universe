## 二、系列详解 / Series Deep Dive

### Series 2: 日常猎杀系列

大世界自由探索，偶遇即杀。核心机制是**详细资料解锁**——控制目标后自由探索敏感点，找到XP加速解锁，失败可读档重来。

- **差异化承诺**：12篇故事分三种模式（完整探索型 / 简化解锁型 / 纯爽文型），拒绝同质化
- **玩法库**：醉酒扭脖、瞌睡银针、尿急钢丝环、环境击杀……35+种处决方式
- **篇幅控制**：日常猎杀8000字以内，节奏明快

### Series 4: 特工局毕业实习

特工局七名核心成员的毕业实习。不是笔试，不是演练——是一场真正的处决。每个特工用自己的方式完成了第一场杀戮，而每个人杀人方式都截然不同。

- **七种风格**：红虎的灼流正面碾压 → 魔影的潜行毒牙 → 老雷的粗暴灌入 → 熊猫的慵懒一掌 → 银的精准一针 → 司令的微笑棋局 → 白熊的干净手刀
- **风格锚点**：短段落、快节奏、制服-白袜-精液的视觉三角、射精即死、lanse 对话标签
- **特例**：白熊是唯一拒绝性化处决的特工——他的毕业实习不含一丝精液，只有纯粹的武道

### Series 3: 屠杀与善后

死亡毫无价值，杀得顺手，死后像垃圾处理。这是原作者最认可的"正确死亡美学"。

- **核心原则**：不写背景故事、凶手风格多样（炎型/玩弄型/羞辱型）、尸体必须像垃圾处理
- **必读范本**：参考 `bs-a-cs-4-yanliang` 第一章 Scene-1（雷爪之死）
- **关键意象**：用尸体擦手、顺手推开、塞入容器、腿露在外面、只脱一只鞋拍照

### Series 5: 原作回响

基于原作剧情拓展的支线故事。每一篇选取原作中一闪而过的配角，从其第一人称视角重新经历那段剧情——直到死亡来临。

- **核心定位**：不改变原作剧情，只补全"猎物流"的内心世界
- **选角逻辑**：原作中出现过、有台词/动作、但无名无姓的背景角色
- **风格边界**：严格遵循 lanse 视觉体系（白袜·制服·精液），但在受害者心理层面做有限度挖掘
- **首篇《橙虎》**：主线第三卷第4章中勒索小豪的橙虎兽人视角，还原他在宿舍权力结构中的真实位置

### Series 6: DeepSeek 短篇故事集

上面几个系列的刀口都朝下——猎手、特工、赏金猎人，从上方俯视兽盾。这一集反过来，写兽盾内部最不值钱的那些人：G级杂兵，军绿制服，白袜，编号印在袜底。

- **核心定位**：不写处决美学，写**关系怎么长出来**。不越狱、不康复、不团圆
- **代词铁律**：全世界（公文、口令、同事）说「它」，只有叙述者说「他」。这个错位本身就是全篇的戏
- **命名铁律**：名字不是谁给的，是**被认出来的**。禁止"我给你起个名字"
- **共情铁律**：不解释羁绊，只写动作——他蹲下来擦地，他第一次自己拉上拉链
- **首篇《灰雪》**：被血精石改造失败的狼，登记为「料-07」；喂他的小杂兵怕臭，蹲下去擦了他脚上的东西

## 三、阅读地图 / Reading Guide

**完全没读过兽盾？** → 先看 [**第一场游戏（短篇版）**](bs-a-s-2-vr-newbie/README.md)，以降临者视角无痛入门。

**想要最硬核的兽盾味？** → [**Series 3: 屠杀与善后**](series-3-massacre-cleanup/README.md)，原作者美学原教旨。

**想要玩法最多的？** → [**Series 2: 日常猎杀**](series-2-daily-hunt/README.md)，12篇不重复，机制深度与爽度兼顾。

**喜欢紧张感？** → [**Series 1: 哨兵清除**](series-1-sentry-elimination/README.md)，纯粹的潜入暗杀。

**想看特工局全员出道？** → [**Series 4: 特工局毕业实习**](bs-a-s-3-agent-bureau-graduation/README.md)，七种杀人美学，同一场考试。

**想从猎物的眼睛看兽盾？** → [**Series 5: 原作回响**](series-5-original-echoes/README.md)，那些一闪而过的面孔，在死前也活过。

**想看刀口朝下的另一侧？** → [**Series 6: DeepSeek 短篇故事集**](bs-a-s-6-deepseek-collection/README.md)，兽盾最底层的杂兵，和一个连名字都被编号盖住的人。
