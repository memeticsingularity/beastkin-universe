# 《兽盾农家乐》故事设定档案

---

## 1. 世界观背景

故事发生在兽盾公司（Beastshield Corporation）统治下的城市边缘。兽盾是一家臭名昭著的企业，员工多为欺软怕硬的地痞流氓，在基层横行霸道。主角小谷曾在打工期间多次被兽盾员工欺辱。

在兽盾的权力金字塔顶端，隐藏着一个更隐秘的阶层——**噬精兽（Semivores）**（原作称"嗜精兽 Semen-Eater Beast"）。他们是兽盾精英贵族圈中的特殊群体，以兽人精液（被他们称为"生命之源"）为食，拥有超乎常人的恢复力和生命力，但失去理智的风险也极高。兽盾默许甚至扶持了这类群体的存在，而小谷爷爷毕生研究的正是将噬精兽转化为普通兽人的解药。

> **原作背景补充**：五百年前人兽大战中，嗜精兽种族被十二神武传人赶尽杀绝，领袖"血君王"以生命为代价施下邪恶禁咒，将族人灵魂封印入血液。两百年前的"嗜精兽根除战役"后，幸存的嗜精兽尸体被集体埋葬于蟒蛇岛，其血液与土壤混合沉淀百年后结晶为**血精石**。兽盾公司发现此事后大力开采，用于员工强化实验——但成功率极低，失败者往往射精死亡。农家乐故事中的"噬精兽"即对应原作世界观中的嗜精兽群体，古博士等角色可能正是血精石转化后的产物。

---

## 2. 核心设定

### 2.1 实验农场

小谷的爷爷是一位生化学家，留下了一片实验农场。农场种植的不是普通作物，而是需要兽人精液灌溉的特殊植物。

**已知作物**：

| 作物名 | 特性 | 精液需求量 | 效果 | 副作用 |
|--------|------|-----------|------|--------|
| 蛮力萝卜 | 白色普通种子 | 较少（单只兽人即可） | 食用后力量大增 | 无 |
| 欲望黑参 | 通体漆黑，带紫色光泽 | 蛮力萝卜的三倍以上，需连续高强度灌溉 | 精力极度旺盛，睡眠变浅，感官敏锐 | 无 |
| 活力紫茎 | 茎秆泛紫红色，散发甜香 | 需求量高，需大规模同时灌溉 | 强效恢复和增强体力，提升恢复力和某些方面能力 | 无 |
| 魅欲藤 | 粉紫色雾气，幼苗带甜香 | 极高，需多重高强度刺激 | 大幅提升作物产量 | 施肥者自身会进入极度敏感状态，可能导致集体发情 |

### 2.2 肥料获取机制

- **来源**：兽盾公司员工（或其他兽人）的新鲜精液
- **获取方式**：
  1. 用爷爷研发的"无色无味迷药"使目标全身发软、意识模糊、带有催情效果
  2. 通过手动刺激使目标射精
  3. 可控制射精量（捏住根部止精）以避免目标死亡
- **副作用**：过量射精会导致目标死亡；长期被榨取需注射营养液和维持管

### 2.3 经营体系

| 阶段 | 描述 |
|------|------|
| 初期 | 地下室单独处理，手动操作 |
| 发展期 | 后院搭建木棚，批量管理"肥料" |
| 扩张期 | 欲望黑参需要一次处理多只兽人，跟班协助同时榨取 |
| 转型期 | 活力紫茎大规模种植；农家乐开始正经经营；后棚扩建为宿舍 |
| 稳定期 | 与警方达成联盟；前成员成为正式员工；形成分工明确的小团队 |

### 2.4 噬精兽（Semivore）

兽盾精英贵族圈中的隐秘阶层，以兽人精液（被他们称为"生命之源"）为食。

| 特性 | 说明 |
|------|------|
| 食性 | 必须定期摄入兽人精液维持生命，摄入量远超普通兽人；高级个体可吸食血液 |
| 能力 | 超乎常人的恢复力和生命力，感官敏锐，力量远超普通兽人 |
| 风险 | 失去理智的风险极高，过量摄入会导致兽化暴走 |
| 社会 | 兽盾默许甚至扶持其存在，形成封闭的精英供养体系 |
| 转化 | 小谷爷爷毕生研究的正是将噬精兽转化为普通兽人的解药 |

**原作设定对照（嗜精兽 Semen-Eater Beast）**：

- **起源**：五百年前人兽大战中被十二神武传人赶尽杀绝的嗜精兽种族。领袖"血君王"以生命施下禁咒，将族人灵魂封印入血液，死后结晶为血精石
- **历史**：两百年前曾发生"嗜精兽根除战役"，幸存的嗜精兽尸体被集体埋葬于蟒蛇岛，其血液与土壤混合沉淀百年后形成血精石矿脉
- **变异机制**：血精石植入/注射后，其中封印的灵魂会夺舍宿主。匹配成功则共存为嗜精兽；匹配失败则伴随宿主一起射精死亡
- **种族意识**：嗜精兽具有强烈的种族认同（牙董视其为"荣耀"，"无数人求而不得的 superior existence"）
- **与农家乐差异**：农家乐中的噬精兽更偏向"精英阶层/研究者"（如古博士），原作中的嗜精兽更偏向"被追杀的种族/战斗兵器"，但核心食性（以精液为食）和来源（血精石转化）一致

### 2.5 血精石（Blood Essence Stone）

小谷爷爷研究的核心物质，与噬精兽转化密切相关。

| 属性 | 说明 |
|------|------|
| 本质 | 从噬精兽体内提取或人工合成的浓缩精华结晶 |
| 终极造物 | 血精石终极造物可赋予食用者近乎不死的能力，但会抹除记忆与人格 |
| 副作用 | 失忆、人格重构、身份完全丧失；需要大量精液维持生命体征 |
| 关联 | 古博士利用小谷与阿岚外貌相同这一点误导老周，制造"小谷即阿岚"的疑云，诱骗其参与实验 |

**原作设定对照**：

- **来源**：嗜精兽尸体掩埋百年后结晶（蟒蛇岛矿脉）。黑色血精石为血君王本人形成
- **外观**：通常为红色水晶；最顶级的为黑红色（血君王级）
- **作用**：植入体内后使人变异为嗜精兽；极大强化身体能力（力量、速度、恢复力等）
- **实验流程**：注射红色药液 → 灼热感蔓延 → 肌肉膨胀 → 勃起痛苦挣扎 → 射精死亡（失败）/ 成功转化
- **成功率**：极低，失败即死。成功者力量"突飞猛进，与之前判若两人"
- **特殊案例**：大奔（白牛兽人）在主线第三部中被注射血精石后射精死亡，随即被岚董用禁咒"阎王讨命符"复活。因死亡同时中止了转变过程，他获得了血精石的强化效果（力量大增、感官敏锐）却没有变成嗜精兽，不依赖精液存活
- **与农家乐的关联**：古博士展示的"血精石改良版"可能正是基于原作血精石的提纯/改良技术；小谷爷爷研究的"解药"可能对应着逆转血精石转化过程的方法 |

### 2.6 产业链真相

农家乐的作物并非供应普通市场，真正的买家是兽盾精英圈中的噬精兽。

```
实验农场（小谷）
    ↓ 特殊作物
古博士（表面供应商）
    ↓ 转交
兽盾研究所噬精兽研究部门
    ↓ 分配
兽盾精英贵族圈（Semivores）
```

- **小谷的处境**：在不知情的情况下，爷爷的农场成为了噬精兽供应链的一环
- **古博士的双面身份**：既是爷爷的同事，也是兽盾研究所的噬精兽研究员，本身是噬精兽
- **雷克斯的揭露**：Vol.2 Ch.16 雷克斯通过警局调查渠道揭露了这条产业链

**原作背景补充**：

在原作主线第三部中，兽盾公司进行组长提拔测试，实则是**筛选嗜精兽候选人的血精石实验**。儡部长亲自主持，将红色药液注射给员工，成功者获得力量强化但变异为嗜精兽，失败者则在痛苦挣扎中射精死亡，尸体被堆成尸山处理。农家乐中的"兽盾研究所噬精兽研究部门"正是原作中这一实验体系的延续——古博士等研究员可能直接参与了血精石的提纯与改良，而农家乐种植的作物（蛮力萝卜、欲望黑参等）则是为噬精兽提供的"稳定食源"，避免了直接吸食活人精液带来的社会风险。

## 3. 主要角色档案

### 3.1 小谷

- **种族**：牛兽人
- **当前身份**：实验农场主 / "兽盾农家乐"餐厅老板 / 外貌与老周死去的搭档"阿岚"极为相似的独立个体（Vol.2 揭露）
- **特点**：原社畜，事业无成；继承农场后展现出极强的经营头脑和冷酷执行力
- **能力**：食用蛮力萝卜后力量大增，可单手提起黑熊兽人

**身份变化时间线**：

| 阶段 | 章节 | 身份 |
|------|------|------|
| 起点 | Ch.1 前 | 普通社畜牛兽人，一事无成 |
| Vol.1 | Ch.1-25 | 实验农场主 / "兽盾农家乐"老板；黑暗经营者 |
| Vol.2 | Ch.1-15 | 从复仇经营者逐渐转变为守护者 |
| 揭露 | Vol.2 Ch.19 | 古博士利用小谷与阿岚外貌相同这一点误导老周，制造"小谷即阿岚"的疑云，诱骗其参与实验 |

**心理转变**：单纯复仇 → 经营野心 → 掌控一切的满足感 → 柔软守护（Vol.2）→ 身份崩塌（Vol.2 Ch.19）

- **种族**：黑熊兽人
- **当前身份**：农场核心成员 / 小谷的第一个跟班
- **特点**：力气大，熟悉兽盾内部情况，干活得力
- **隐患**：对旧识虎威有深厚感情，忠诚建立在恐惧之上而非真心归附

**身份变化时间线**：

| 阶段 | 章节 | 身份 |

| 转化 | Vol.1 Ch.3 | 被小谷收为第一个跟班 |
| 稳定 | Vol.1 Ch.9-25 | 核心跟班，负责农场体力劳动和兽盾情报 |
| 发展 | Vol.2 Ch.1-19 | 成为农场核心战力；与虎威关系逐渐公开稳定 |

### 3.3 老夯（刘夯）

- **种族**：野猪兽人
- **当前身份**：小谷的第二个跟班 / 农场核心成员
- **特点**：老实憨厚，重情重义，真心依赖和信任小谷

**身份变化时间线**：

| 阶段 | 章节 | 身份 |
|------|------|------|
| 前史 | — | 兽盾基层员工（送货、看仓库） |
