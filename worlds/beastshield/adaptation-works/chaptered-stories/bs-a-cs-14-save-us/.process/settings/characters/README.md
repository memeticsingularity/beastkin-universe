## 建档规范

### 基础格式
- 文件名：`[等级]-[编号]-[拼音].md`
- 等级字母小写：`g`, `o`, `e`, `r`, `w`
- 编号至少3位，不足补零：`g-001`, `o-089`
- 拼音采用全拼，无分隔符或驼峰，格式为`[种族][毛色]`：`xiong-zong`, `niu-hui-lan`
- 按角色归属放入对应子目录

### 核心世界观要求（v2.0 新增）

**背景设定前提**：兽盾世界所有伤害转化为性欲值（精槽），射精=死亡。战斗的核心机制是性刺激而非纯暴力。每个角色档案必须体现这一世界观。

#### 1. 「性机制」区块（必填）
每个角色必须在`## 差异化设计维度`之前插入独立的性机制表格：

```
## 性机制

| 项目 | 内容 |
|------|------|
| **特有敏感部位** | 唯一位置+神经分布+刺激反应 |
| **精槽特性** | 容量/增速/控精能力/特殊体质 |
| **制服性特征** | 制服如何强调性特征（紧身/暴露/被注视） |
| **性互动方式** | 角色在性战斗/性互动中的定位和方式 |
| **性偏好维度** | side（非插入式）/ vers（皆可）/ 特殊倾向。影响角色亲密互动和处决方式的选择 |
```

#### 2. 时间线性化
- 战斗/处决场景必须体现精槽管理——不是"打死"，而是"撸到射精死"。处决方式可多样化：撸杀、口交致死、互相自慰比赛、腿交控精等非插入方式同样符合世界观
- 制服描写加入性维度——第一次穿着时身体被勒出的形状、他人的目光
- 入职兽盾后必须有性相关的经历（目睹处决、参与清理、提拔科测试见证等）
- **禁止**纯暴力描写替代性暴力描写
- **注意**：赏金猎人才杀兽盾员工换赏金，兽盾员工不一定杀平民

#### 3. 关系多样性
- 不能全都单身——同楼层/同区域的守卫之间有自然的关系
- 兽盾封闭环境下的同僚炮友、兵营暧昧、长期伴侣都合理
- 炮友关系不一定是插入式——互相抚摸、亲吻、口交、互相自慰等 Side 式亲密同样常见
- 「角色关系图」要体现性关系维度

#### 4. 种族敏感部位参考

| 种族 | 常见敏感部位 |
|------|-------------|
| 牛族 | 角根/鼻镜/髋部/腰侧 |
| 虎族 | 虎鞭肉刺（部分个体）/后颈/肩胛间 |
| 熊族 | 掌垫/颈后/旧疤处 |
| 狗族 | 耳根/尾根 |
| 猪族 | 腹股沟/乳首 |
| 狼族 | 尾椎/喉部 |

#### 5. 特工局特殊规则
特工局成员的处决方式必须是性化的（灼流暗劲通过肉棒传导、银针封穴瞬间满精槽等）。

#### 6. 「Side」性偏好维度（v2.1 新增）
Side 指非插入式性偏好——角色可能更倾向亲吻、抚摸、口交、互相自慰、腿交等方式，而非肛交。在角色设计中：

- **处决方式多样化**：不只是"撸到射"，口交致死、互相自慰比赛输家死亡、腿交控精等同样成立
- **亲密关系多样化**：同僚炮友不一定是插入式，可以只是互相抚摸、拥抱解决
- **战斗互动多样化**：某些角色可能通过贴面缠斗、皮肤摩擦等非插入方式控精

在 `性机制` 表的 `性偏好维度` 行标注即可。无需每个角色都定义，但应避免"全员插入式"的单一倾向。
