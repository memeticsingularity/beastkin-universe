# 老雷 / 雷炎寰

## 基本信息

- **种族**：红虎兽人
- **身份**：特工局资深特工，魔影的搭档
- **年龄**：35岁
- **外貌**：身材魁梧健壮，年过三旬，黑色紧身作战服。最醒目的视觉标签：
  - **黑铁臂铠**：双臂佩戴黑色铁质臂铠，战斗时泛红冒火星
  - **血红双眼**：开启灼流暗劲时，双眼会变得血红
  - **严重洁癖**：随身携带手帕，战斗后会清理尸体和地面

## 性格

**表面**：
- 暴力、狂妄、不耐烦
- 对敌人冷酷无情，喜欢用力量碾压
- 口头禅："记得在阎王面前报我老雷的名号"

**深层**：
- **严重洁癖强迫症**：战斗后必须清理尸体、拖洗地面、擦拭精液
- **温柔反差**：对"乖孩子"会给予温柔的处决（如Ch.6熊兽人）
- **责任感强**：一旦接受任务，绝不擅离岗位，即使洁癖发作也坚守岗位

**内核**：
- 对魔影的复杂情感：嫌弃他杀人磨磨唧唧，但每次都会为他镇守后路
- 对"干净"的执念源于某次任务中的创伤（未揭示）

## 能力

### 灼流暗劲（核心功法）
- **原理**：将一股灼热的暗劲通过拳脚传导至敌人前列腺，引发强制勃起并射精死亡
- **表现形式**：
  - 普通状态：三拳连击，每一拳都将暗劲深入一层
  - 十层功力：开启"焚体缠身"状态，全身被暗红色气焰包裹，攻击附带范围灼烧效果
- **副作用**：开启十层后，自身性欲值会急剧上升，必须及时"泄火"（找猎物或自行解决）

### 外练功夫
- 肉身强度极高，可弹开麻醉枪子弹
- 力量型战斗风格，擅长近身肉搏

## 战斗风格

- **暴力、直接、高效**：不喜欢花哨，一拳解决就绝不两拳
- **群体战斗优势**：灼流暗劲的传导效果在密集敌人中尤为致命
- **温柔处决**：对某些"听话"的敌人，会给予相对"体面"的死法

## v2 改动说明（与v1的差异）

| 维度 | v1 | v2 |
|------|-----|-----|
| 角色存在 | **完全缺席** | **核心双主角之一**，每3章切换视角 |
| 战斗功能 | 无 | **一楼镇守**，阻断所有增援，为魔影争取时间 |
| 性格展示 | 无 | **洁癖强迫症**贯穿始终（拖尸、擦地、整理尸体） |
| 温柔反差 | 无 | Ch.9 对牛跟班的"留活口"，展现老雷罕见的温情面 |
| 与魔影互动 | 无 | 对讲机通讯、计划变更、最终汇合，完整展现搭档默契 |

## 与原作主线的关联

老雷在 v2 中的角色定位与原作主线第二卷完全一致：
- **暴力美学代表**：灼流暗劲三拳连击、焚体缠身的设定完全承接原作
- **洁癖强迫症**：原作Ch.6中拖尸、擦地、整理尸体的经典场景在v2中复刻并扩展
- **温柔反差**：原作中对最后一只熊的温柔处决，在v2中转化为对牛跟班的"留活口"
- **与魔影的搭档关系**：原作中"互相看不对眼但又离不开对方"的动态，在v2对讲机通讯中展现
