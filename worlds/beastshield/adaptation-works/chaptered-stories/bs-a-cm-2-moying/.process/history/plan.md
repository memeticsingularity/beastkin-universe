# 魔影 v2 重写计划

> 目标：解决 v1 "逻辑崩盘" 问题，重建任务框架与后果链，贴合原作主线第二卷笔风与世界观。
> 版本：v2.0 | 制定日期：2026-05-17

---

## 一、v1 致命问题诊断

### 1.1 "逻辑崩盘" 的核心表现

v1 版本（`chapters/ch-01-2.md` 等）将魔影从原作主线中抽离，做成"死亡线"，但抽掉了任务框架后，故事变成：

- **无差别猎杀缺乏动机**：魔影在更衣室里一个接一个地杀，不知道为什么要杀这么多，杀了之后也没后果。
- **无任务目标**：没有"为什么要潜入这栋大楼"的合理解释，猎杀本身成了目的。
- **无后果链**：兽盾组织毫无反应，杀了十几个守卫，楼上楼下照常运转，没有通讯失联、没有巡逻队排查、没有封锁楼层。
- **老雷戏份缺失**：原作核心双主角结构被拆散，老雷的暴力美学与温柔反差完全消失。
- **玩弄逻辑空洞**：魔影的戏谑和玩弄只是为了"爽"，不服务于任何任务目标。

### 1.2 与原作主线第二卷的背离

原作主线第二卷（`bs-o-cm-1-main-story-2`）的核心结构：

```
场景A（魔影潜入执行任务）→ 场景B（老雷并行/镇守）→ 角色汇合 → BOSS战 → 战后/教育场景
```

v1 完全丢掉了这个结构，把魔影变成了一个在更衣室里等待猎物上门的"陷阱蜘蛛"，而非执行任务的特工局刺客。

## 二、v2 核心改动概要

### 2.1 重建任务框架

| 维度 | v1 | v2 |
|------|-----|-----|
| 魔影身份 | 赏金猎人/神秘刺客 | **特工局顶尖刺客**，有明确组织归属 |
| 潜入动机 | 无，单纯猎杀 | **营救被兽盾抓捕的特工局卧底"白鸽"** |
| 老雷角色 | 完全缺席 | **一楼镇守，阻断增援**，双线并行 |
| 猎杀逻辑 | 无差别屠杀 | **清除障碍、获取情报、制造混乱**，服务于任务 |
| 时间压力 | 无 | **天亮前必须撤离**，增援30分钟后到达 |
| 后果链 | 无 | 通讯失联→巡逻排查→楼层封锁→虎卫组/黑制服出动 |

### 2.2 任务核心设定

**任务代号**："黑鸽行动"
- **目标**：营救被兽盾刑讯部关押在十三层刑房的特工局卧底"白鸽"（真实身份：兔族兽人情报员，掌握兽盾"红水晶实验"关键证据）。
- **时间窗口**：凌晨 02:00 - 05:00（天亮前必须撤离，否则兽盾总部进入日间高警戒状态）。
- **潜入方式**：魔影从通风管道进入十层，老雷正面突破一层大门，制造"双线入侵"假象，分散兽盾注意力。
- **失败代价**：
  - 白鸽被处决，特工局三年布局毁于一旦。
  - 兽盾将加速"红水晶实验"，更多兽人沦为变异体。
  - 魔影与老雷若未能及时汇合，将陷入兽盾总部重围。

### 2.3 多线叙事结构（回归原作）

```
Ch.1-3：魔影潜入十层（清除守卫、获取情报、换装）
        ↓ 对讲机通讯
Ch.4-6：老雷一楼镇守（阻断增援、屠杀、洁癖发作）
        ↓ 预定信号：魔影到达十三层
Ch.7-9：魔影十三层渗透（刑房营救、发现实验证据）
        ↓ 任务转折
Ch.10-12：汇合与BOSS战（虎组长+牛组长联手拦截）
        ↓ 战后
Ch.13-15：撤离与余波（时间压力下的逃脱、白鸽状态、新情报指向"蟒蛇岛"）
```

## 三、完整章节大纲（12章）

### Chapter 1：通风管道的余温
- **核心任务**：魔影从外部通风管道潜入十层，解决首批守卫，获取基础情报。
- **新信息/转折**：发现十层守卫比预期多一倍——兽盾似乎提前得到了风声。
- **处决方式**：
  - 狗兽人：捂嘴撸杀（致敬原作Ch.1开场，但节奏更克制）。
  - 熊兽人：审问后处决（获取"白鸽已被转移至十三层"情报）。
- **情感基调**：戏谑开场 → 发现异常后的警觉。
- **与主线逻辑关联**：引入任务目标与初步异常，建立"时间压力"感。

### Chapter 2：蓝白制服的重量
- **核心任务**：换装潜入，获取更高层通行证，继续清除十层守卫。
- **新信息/转折**：从蓝制服干部身上搜出加密通讯器，得知"虎组长已下令加强十一层炼药房警戒"。
- **处决方式**：
  - 牛兽人：窒息塞袜（致敬原作Ch.1牛兽人，但服务于"获取钥匙卡"目标）。
  - 虎兽人：毒血匕首背刺（首次展示血毒能力）。
- **情感基调**：戏谑 → 黑色幽默（牛兽人被自己的袜子熏到干呕）。
- **与主线逻辑关联**：情报揭示兽盾内部已有警觉，任务难度升级。

### Chapter 3：露台上的抛物线
- **核心任务**：清理露台守卫，制造"意外坠楼"假象，为后续行动争取时间。
- **新信息/转折**：通过对讲机与老雷首次通讯，得知一楼已出现增援，老雷正在处理。
- **处决方式**：
  - 棕熊兽人：撸杀后抛尸下楼（致敬原作Ch.3）。
  - 野猪兽人：勒颈窒息（快速处决，避免惊动邻层）。
- **情感基调**：戏谑 → 紧张（通讯中老雷的声音带着灼流暗劲的喘息）。
- **与主线逻辑关联**：双线叙事启动，老雷的战况直接影响魔影的时间窗口。

### Chapter 4：灼流与洁癖（老雷视角）
- **核心任务**：老雷一楼镇守，阻断三批增援，展现灼流暗劲与洁癖强迫症。
- **新信息/转折**：发现增援中有"黑制服武斗兵"——兽盾已出动精英部队，任务等级提升。
- **处决方式**：
  - 牛兽人：灼流暗劲三拳连击（致敬原作Ch.6）。
  - 虎兽人：掐脖摁墙射精（致敬原作Ch.6）。
  - 熊兽人：温柔扭脖+精液射入小便池（致敬原作Ch.6，洁癖发作）。
- **情感基调**：暴力 → 温柔反差 → 黑色幽默（拖尸打扫）。
- **与主线逻辑关联**：老雷的镇守是魔影能继续潜入的前提，黑制服出现预示最终BOSS战。

### Chapter 5：催眠瓦斯与三头睡狮
- **核心任务**：魔影用催眠弹制服房间内的狮子+双虎守卫，获取十一层布局图。
- **新信息/转折**：布局图显示十三层刑房有"特殊审讯室"，白鸽可能被注射了某种药物。
- **处决方式**：
  - 双虎：撸杀（批量处理，缩短描写）。
  - 狮子：后入奸杀（致敬原作Ch.4，但增加"从狮子口中获取口令"的前置审问）。
- **情感基调**：戏谑 → 危机（发现白鸽状态可能不佳）。
- **与主线逻辑关联**：任务目标从"营救"升级为"营救+获取实验证据"。

### Chapter 6：虎卫组的獠牙
- **核心任务**：魔影遭遇虎组长率领的虎卫组，首次正面BOSS战。
- **新信息/转折**：虎组长透露"你们特工局内部有我们的人"——任务从一开始就暴露了。
- **处决方式**：
  - 白虎、蓝虎：血毒匕首背刺（展示血毒的麻痹催情效果）。
  - 黄虎：血毒扩散全身僵直射精。
  - 虎组长：全力撸杀（致敬原作Ch.4，但增加"审问内鬼身份"环节，虎组长至死未吐露）。
- **情感基调**：戏谑 → 冷酷 → 震惊（内鬼情报）。
- **与主线逻辑关联**：引入"内鬼"悬念，为后续章节铺垫。

### Chapter 7：熊族的领地与鼾声
- **核心任务**：魔影穿越十一层熊族领地，解决休息室内熟睡的熊守卫。
- **新信息/转折**：在熊组长办公室发现"红水晶实验"初步报告——兽盾在用兽人做变异实验。
- **处决方式**：
  - 熟睡熊兽人（×4）：睡梦中撸杀（致敬原作Ch.7）。
  - 年轻熊兽人：噩梦反射捏射（致敬原作Ch.7，魔影的噩梦伏笔）。
- **情感基调**：黑色幽默 → 阴郁（魔影的噩梦暗示其变异起源）。
- **与主线逻辑关联**：世界观扩展，红水晶实验与魔影自身变异形成对照。

### Chapter 8：炼药池的粉红深渊
- **核心任务**：魔影潜入炼药房，利用春药池解决大批熊守卫。
- **新信息/转折**：发现炼药房不仅产春药，还生产"红水晶萃取液"——兽盾的变异实验与春药部门有关联。
- **处决方式**：
  - 熊守卫（×8）：推入炼药池春药溺毙（致敬原作Ch.8）。
  - 熊组长：足底舔杀（致敬原作Ch.8，金钟罩罩门设定）。
- **情感基调**：戏谑 → 悲悯（熊组长的责任感与死亡）。
- **与主线逻辑关联**：获取"红水晶萃取液"样本，任务目标再次升级。

### Chapter 9：老雷的加班与跟班牛
- **核心任务**：老雷继续镇守一楼，处理最后一批增援，收服"牛跟班"作为临时向导。
- **新信息/转折**：牛跟班透露"十三层刑房由牛族管辖，牛组长正在亲自审讯白鸽"。
- **处决方式**：
  - 增援守卫（×6）：灼流暗劲群体击杀（致敬原作Ch.9）。
  - 牛兽人（跟班）：收服而非处决（老雷首次"留活口"，展现温柔反差）。
- **情感基调**：暴力 → 黑色幽默 → 意外温情（牛跟班的"安乐死"式服务）。
- **与主线逻辑关联**：老雷获取十三层情报，决定上楼支援魔影。

### Chapter 10：刑房深处的白鸽
- **核心任务**：魔影潜入十三层刑房，营救白鸽，遭遇牛组长拦截。
- **新信息/转折**：白鸽已被注射"红水晶萃取液"，处于半变异状态，神志不清。
- **处决方式**：
  - 牛守卫（×2）：灼流暗劲（老雷赶到，首次汇合）。
  - 牛组长：双人合击——老雷灼流暗劲破防，魔影毒牙补刀（致敬原作 teamwork）。
- **情感基调**：紧张 → 悲壮（白鸽的惨状）。
- **与主线逻辑关联**：任务核心目标达成，但白鸽状态引发新问题。

### Chapter 11：红水晶的回响
- **核心任务**：撤离途中，魔影因接触白鸽的变异血液，触发自身血毒的不稳定反应。
- **新信息/转折**：魔影回忆起五年前蟒蛇岛的初次任务——自己的血毒正是红水晶实验的产物。
- **处决方式**：
  - 追兵（×4）：血毒爆发群体麻痹射精（魔影失控状态下的无差别攻击）。
- **情感基调**：危机 → 阴郁 → 黑色幽默（老雷一边压制魔影一边拖尸）。
- **与主线逻辑关联**：承接主线第二卷回忆线，揭示魔影能力起源。

### Chapter 12：天亮之前
- **核心任务**：时间耗尽，天亮在即，魔影与老雷带着白鸽强行突围。
- **新信息/转折**：成功撤离，但白鸽身上的"红水晶实验"证据指向兽盾更高层——"蟒蛇岛地下设施"。
- **处决方式**：
  - 最后拦截的黑制服武斗兵（×2）：老雷十层焚体缠身爆发秒杀。
- **情感基调**：紧张 → 释然 → 黑色幽默（老雷洁癖发作，要求魔影"把身上的血擦干净再上车"）。
- **与主线逻辑关联**：任务完成，但引出更大的阴谋，为后续故事留门。

## 四、解决逻辑崩盘的具体策略

### 4.1 任务框架：每一次猎杀都是手段

| 章节 | 猎杀对象 | 任务功能 |
|------|---------|---------|
| Ch.1 | 狗、熊 | 清除入口障碍，获取基础情报 |
| Ch.2 | 牛、虎 | 获取高层通行证与通讯器 |
| Ch.3 | 棕熊、野猪 | 制造意外假象，争取时间 |
| Ch.4 | 增援杂兵 | 阻断增援，为魔影争取时间 |
| Ch.5 | 狮子、双虎 | 获取十一层布局图与口令 |
| Ch.6 | 虎卫组 | 消除追击威胁，获取内鬼情报 |
| Ch.7 | 熟睡熊族 | 穿越领地，获取实验报告 |
| Ch.8 | 熊守卫、熊组长 | 获取红水晶萃取液样本 |
| Ch.9 | 增援杂兵 | 最后清场，收服向导 |
| Ch.10 | 牛守卫、牛组长 | 营救目标，消灭拦截 |
| Ch.11 | 追兵 | 失控状态下的自卫 |
| Ch.12 | 黑制服武斗兵 | 最终突围 |

### 4.2 后果链：兽盾的反击机制

```
Ch.1 守卫失联 → 巡逻队例行检查（Ch.2）
Ch.2 干部死亡+通讯器丢失 → 虎组长下令加强警戒（Ch.3）
Ch.3 露台尸体坠楼 → 楼层封锁，电梯停机（Ch.4）
Ch.4 一楼增援全灭 → 黑制服武斗兵出动（Ch.5）
Ch.5 虎卫组出动 → 魔影遭遇正面拦截（Ch.6）
Ch.6 虎组长死亡 → 熊组长接管，炼药房戒备（Ch.7-8）
Ch.8 炼药房沦陷 → 牛组长亲自镇守刑房（Ch.9-10）
Ch.10 白鸽被劫 → 总部警报，全面追缉（Ch.11-12）
```

### 4.3 多线叙事的逻辑关联

- **对讲机通讯**：魔影与老雷通过特工局加密频道保持联系，每3章一次通讯，通报战况与计划变更。
- **预定信号**：魔影到达十三层时发出"鸽鸣"信号，老雷立即上楼汇合。
- **计划变更**：Ch.6发现内鬼后，原定撤离路线作废，改为老雷强行突破电梯井。
- **时间同步**：每章开头标注时间（02:15 / 02:40 / 03:10……），让读者感知时间压力。

### 4.4 魔影"玩弄猎物"的逻辑化

| 场景 | 玩弄方式 | 任务功能 |
|------|---------|---------|
| Ch.1 熊兽人 | 审问后处决 | 获取"白鸽转移"情报 |
| Ch.2 牛兽人 | 窒息塞袜 | 逼问钥匙卡位置 |
| Ch.5 狮子 | 后入奸杀前审问 | 获取十一层口令 |
| Ch.6 虎组长 | 边撸边审 | 试图获取内鬼身份 |
| Ch.8 熊组长 | 足底舔杀 | 利用罩门快速解决强敌，节省时间 |

## 五、角色关系弧光设计

### 5.1 魔影与老雷：双主角配合

| 阶段 | 关系状态 | 表现 |
|------|---------|------|
| Ch.1-3 | 分离，通讯联系 | 魔影戏谑调侃，老雷不耐烦但可靠 |
| Ch.4-6 | 老雷战况升级 | 魔影从通讯中感知老雷的灼流暗劲爆发 |
| Ch.7-9 | 魔影独自深入 | 老雷决定上楼，突破电梯井 |
| Ch.10 | 首次汇合 | 老雷一拳破防牛组长，魔影补刀——完美配合 |
| Ch.11 | 魔影失控 | 老雷压制魔影的血毒暴走，展现搭档责任 |
| Ch.12 | 共同撤离 | 黑色幽默收尾（洁癖发作） |

### 5.2 魔影与自身血毒：欲望与控制的斗争

- **日常状态**：血毒是工具，魔影完全掌控。
- **压力状态**（Ch.7噩梦）：血毒引发记忆闪回，控制力下降。
- **失控状态**（Ch.11）：接触红水晶萃取液后，血毒暴走，无差别攻击。
- **恢复状态**（Ch.12）：老雷帮助压制，魔影重新掌控——但留下隐患。

### 5.3 老雷与牛跟班：意外的温情

- 老雷本打算处决牛跟班（Ch.9）。
- 牛跟班主动提出"可以帮你救人"，老雷鬼魅一笑，留他一命。
- 牛跟班在Ch.10帮助老雷伪装押送，在Ch.12的突围中意外挡下一刀，重伤。
- 老雷的洁癖强迫症在牛跟班面前首次"破例"——允许他"脏着"躺在车里。

## 六、处决方式多样化列表

参考 `gameplay-elements-library.md`，确保每章至少1种主要处决方式+1-2种战术元素：

## 八、与原作主线的逻辑关联

v2 故事时间线设定在**原作主线第二卷之前三个月**，是魔影与老雷的某次日常任务。通过本次任务：

1. **获取的"红水晶实验"情报**，直接引向原作主线第二卷中"蟒蛇岛回忆线"（Ch.13-15）。
2. **发现的"内鬼"线索**，为原作中特工局内部清洗埋下伏笔。
3. **白鸽的半变异状态**，是魔影对红水晶实验产生个人关注的起点。
4. **老雷与牛跟班的意外关系**，为外传《炎魉》中"收服随从"机制提供前史参照。
