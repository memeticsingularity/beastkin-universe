## 二、兵种配置详解

### 2.1 G级 - 绿制服杂兵 (Green Uniform)

**外观特征：**

- 军绿色紧身短衣短裤
- 长筒白袜 + 运动鞋
- 无护裆装备

**数量分布：**

- 总部一楼大厅：约10-15人
- 仓储部院子：约10-15人
- 分部一楼：16人
- 各楼层巡逻：2-4人/层

**战斗能力：**

- 敏捷低，攻击动作慢
- 无特殊技能
- 容易被潜行暗杀

**处决方式：**

- 背后偷袭割喉
- 正面快速撸射
- 熟睡中处决

### 2.2 E级 - 黑色武斗兵 (Elite/Black Uniform)

**外观特征：**

- 黑色紧身制服
- 黑袜 + 黑色军靴
- 部分有护裆装备

**数量分布：**

- 武斗兵营：各兽种约10-20人
- 总部高级区域：少量

**战斗能力：**

- 死忠于兽盾
- 受过严格训练
- 近战能力强

**特殊个体：**

- 虎队长（武斗部队调派）
- 熊组长（十一层炼药房）
- 牛组长（十三层刑房，"冥府牛头"）

### 2.3 R级 - 白色枪械兵/远程兵 (Ranged/White)

**外观特征：**

- 军绿色背心
- 白色紧身裤
- 卡其色军靴 + 白袜
- 弹药架 + 狙击枪

**数量分布：**

- 总部对面建筑：1名狙击手

**战斗能力：**

- 远程狙击
- 近战能力弱
- 被刺客职业完克

### 2.4 O级 - 蓝色监工/高级兵 (Officer/Blue)

**外观特征：**

- 蓝白图案紧身制服
- 公司logo白袜
- 蓝色运动型工作靴

**数量分布：**

- 十层以上高层：每层数人
- 分部高层区：较多

**战斗能力：**

- 经过筛选和训练
- 身材更加粗壮
- 身手良好

### 2.5 W级 - 摔跤兵 (Wrestler)

**外观特征：**

- 蓝色摔跤服
- 摔跤靴（可脱下）
- 白袜

**数量分布：**

- 体训房：至少1名

**战斗能力：**

- 体型格外粗壮
- 对催眠弹有抵抗力
- 力量型

### 2.6 特殊兵种

| 兵种      | 特征          | 出现位置   |
|---------|-------------|--------|
| **虎卫组** | 全黑制服，虎兽种专属  | 十二层办公室 |
| **特种兵** | 类似特种兵装备     | 特工局基地  |
| **厨师长** | 裸体围裙        | 厨房区域   |
| **组长级** | 黑制服黑长袜，体型巨大 | 各层负责人  |

## 三、据点类型分类

### 3.1 总部大楼型

**特征：**

- 几十层摩天大厦
- 等级分层制度（越高越强）
- 各楼层功能分区明确

**楼层功能：**

- 1层：大厅、门卫
- 2层：物资储备区
- 3层：体训房（健身器材）
- 4层：食堂
- 10层+：高层办公区
- 顶层：董事长办公室

### 3.2 分部办公楼型

**特征：**

- 十几层建筑
- 种族分区（熊族/牛族领地）
- 特殊功能房间

**特殊区域：**

- 更衣室（守卫换班）
- 炼药房（春药生产）
- 刑房（审讯逼供）
- 员工宿舍（临时休息）

### 3.3 兵营训练型

**特征：**

- 按兽种分区
- 大量黑制服武斗兵
- 训练设施齐全

**设施：**

- 训练大厅
- 盥洗室
- 值班室
- 玻璃鱼缸（流墟关押）

### 3.4 仓储物流型

**特征：**

- 郊区位置
- 院子装卸区
- 仓库储存区

**人员：**

- 绿制服装卸工
- 蓝制服组长
- 黑制服部长

## 四、场景分布分析

### 4.1 外围区域

**典型场景：**

- 院子装卸区（仓储部）
- 大门口站岗（兵营）
- 侧墙窗户（潜入点）

**守卫配置：**

- 2人站岗（大门）
- 巡逻人员
- 少量杂兵

### 4.2 大厅/走廊

**典型场景：**

- 一楼大厅（接待区）
- 走廊巡逻路线
- 电梯口

**战斗特点：**

- 开阔空间，易被发现
- 适合正面战斗
- 可利用飞刀远程攻击

### 4.3 办公室/值班室

**典型场景：**

- 组长办公室
- 值班室
- 会议室

**潜入特点：**

- 可偷听情报
- 守卫警觉性高
- 适合暗杀

### 4.4 宿舍/休息室

**典型场景：**

- 员工临时宿舍
- 更衣室
- 休息室

**处决特点：**

- 守卫熟睡/放松警惕
- 可批量处决
- 鼾声掩盖动静

### 4.5 特殊区域

| 区域      | 功能   | 特色          |
|---------|------|-------------|
| **体训房** | 健身训练 | 大量器材，半裸守卫   |
| **炼药房** | 春药生产 | 药池，通风管道     |
| **刑房**  | 审讯逼供 | 刑具架，刑床      |
| **厨房**  | 餐饮制作 | 厨师，食材（精液寿司） |
| **储物间** | 物资存放 | 武器，白袜库存     |
| **厕所**  | 如厕   | 处决高发区       |

## 五、处决方式统计

### 5.1 背后偷袭型

**适用场景：**

- 巡逻守卫
- 站岗士兵
- 背对玩家的敌人

**具体手法：**

- 勒住喉咙 + 握住下体
- 从背后捂住口鼻 + 注射毒素
- 背后割喉

**典型案例：**

- 更衣室首次狩猎（狗兽人）
- 走廊巡逻虎兽人
- 露台吸烟熊兽人

### 5.2 正面羞辱型

**适用场景：**

- 被包围时
- 实力碾压
- 戏谑玩弄

**具体手法：**

- 正面握住下体揉搓
- 捏碎卵蛋强制射精
- 言语羞辱 + 物理刺激

**典型案例：**

- 黑牛兽人（墙角求饶）
- 熊组长（三分钟赌约）
- 牛组长（刑房折磨）

### 5.3 熟睡中处决

**适用场景：**

- 宿舍区域
- 换班休息
- 催眠瓦斯后

**具体手法：**

- 床上撸射
- 割喉处决
- 窒息处决

**典型案例：**

- 熊族宿舍（魔影一边睡觉一边撸）
- 体训房催眠瓦斯后批量处决
- 虎卫组房间（催眠弹）

### 5.4 环境利用型

**适用场景：**

- 特殊地形
- 陷阱机关
- 危险区域

**具体手法：**

- 推入炼药池
- 吊起窒息
- 从高楼抛下

**典型案例：**

- 熊守卫被推入炼药池
- 虎兽人被吊在阳台
- 熊兽人从十楼抛下

### 5.5 玩弄折磨型

**适用场景：**

- 高级兵种
- 有私仇
- 时间充裕

**具体手法：**

- 多穴位银针刺激
- 电击 + 飞机杯
- 乳头折磨

**典型案例：**

- 雪豹练习对象（北斗泄阳针法）
- 牛组长（十九次射精）
- 犀牛守卫（老雷的"人道"处决）

## 六、据点设计共同特点

### 6.1 空间设计规律

1. **分层制度**：楼层越高，守卫等级越高
2. **功能分区**：明确划分工作/休息/训练区域
3. **巡逻路线**：固定路线，可预测
4. **潜入点**：侧墙窗户、通风管道、暗门

### 6.2 守卫行为模式

1. **换班制度**：固定时间换班，更衣室聚集
2. **巡逻规律**：固定路线，可伏击
3. **警觉程度**：底层低，高层高
4. **放松时刻**：吸烟、如厕、休息

### 6.3 尸体处理方式

1. **隐藏**：厕所隔间、垃圾堆、脏衣篓
2. **展示**：走廊排列、尸山、艺术品式摆放
3. **抛弃**：窗外抛下、垃圾桶塞入
4. **不处理**：大量屠杀后现场保持

### 6.4 制服与装备规律

1. **颜色区分等级**：绿 < 蓝白 < 黑
2. **袜子作为赏金**：白袜（杂兵）、黑袜（高级）
3. **护裆装备**：高级兵种才有
4. **武器配置**：杂兵冷兵器，高级兵护具齐全

## 七、为 Casual Massacre v2.0 的设计建议

### 7.1 据点规模建议

- **小型据点**：10-20人（单楼层/小建筑）
- **中型据点**：30-50人（3-5层建筑）
- **大型据点**：50-100人（整栋大楼）

### 7.2 兵种配比建议

| 据点类型 | G级  | E级  | O级  | 特殊 |
|------|-----|-----|-----|----|
| 小型   | 60% | 30% | 10% | -  |
| 中型   | 50% | 35% | 12% | 3% |
| 大型   | 40% | 40% | 15% | 5% |

### 7.3 场景设计建议

**必备区域：**

1. 入口/大厅（正面冲突或潜入选项）
2. 走廊（巡逻路线，伏击点）
3. 休息室/宿舍（批量处决机会）
4. 厕所（经典处决场景）

**可选区域：**

1. 训练室/健身房（半裸守卫，视觉享受）
2. 办公室（情报获取，高级目标）
3. 储藏室（道具获取）
4. 特殊功能房（炼药房、刑房等）

### 7.4 处决多样性建议

**避免"割喉疲劳"：**

- 20% 背后偷袭
- 20% 正面羞辱
- 20% 熟睡处决
- 20% 环境利用
- 20% 玩弄折磨

**尸体处理多样化：**

- 顺手推开（Casual Massacre v3.0标准）
- 塞入容器（垃圾桶、储物柜）
- 腿露外面（羞辱式摆放）
- 用尸体擦手（原作常见）

### 7.5 原作美学要点

1. **死亡毫无价值**：杂兵死得轻松随意
2. **精液横流**：每具尸体都射精
3. **白袜 fetish**：强调袜子细节
4. **肌肉展示**：紧身制服勾勒身材
5. **羞辱元素**：尸体姿势的侮辱性摆放

## 十、结语

原作系列的据点设计具有以下核心特点：

1. **规模适中**：既有大型总部，也有小型据点
2. **等级分明**：颜色制服区分，楼层递进
3. **空间多样**：办公、训练、休息、特殊功能齐全
4. **处决自由**：多种方式可选，鼓励创意
5. **美学统一**：精液、白袜、肌肉、羞辱元素贯穿始终

Casual Massacre v2.0 应参考这些设计原则，在保持原作美学的同时，增加处决方式的多样性，避免单一重复，让每个据点都有独特的体验和记忆点。
