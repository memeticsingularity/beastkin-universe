## 三、世界观核心机制（必读）

### 伤害→性欲转化

兽盾世界观的第一条核心规则：

**每一次攻击造成的伤害都会转化为性欲值（俗称"精槽"）。**

这意味着：
- 战斗中性欲是持续积累的，不是突发的
- 挨打越多，越兴奋
- 双方在战斗中都会勃起（程度因伤害量而异）
- 处决时精槽满溢自然导致射精→死亡

**写作必须体现**：
- 每一次有效打击后：被击中的部位发热→暖流向下蔓延→阴茎反应
- 这不是"受伤后硬了"——是"伤害直接转化为性快感"
- 胜者在战斗过程中也可能全程勃起打完

### 精槽积累→射精死亡

```
连续受击 → 精槽上升 → 阴茎半硬 → 硬 → 龟头膨胀 → 马眼张开 → 
 濒临极限（腰部发酸/会阴跳动） → 触碰/撸动触发 → 
  射精（七八股浓精） → 身体放松 → 瞳孔涣散 → 死亡
```

**关键点**：
- 射精就是死亡。在本世界观中，不可能有"活着的射精"
- 所以纯情色场景（卖肉）可以勃起、抚摸、插入，但不能射精
- 只有死战到最后关头才能射精

## 四、处决机制

### 核心原理：死亡=射精

在本世界观中，**射精=死亡**，但触发方式不限于生殖器刺激。

任何致命行为（割喉、拧头、窒息、重击、贯穿、碾压）都会触发身体的最大反射——死亡射精。生殖器刺激只是其中一种方式，而非唯一方式。

### 处决三路径

| 路径 | 触发方式 | 射精特点 | 前例 |
|:----|:---------|:---------|:----|
| **A. 直接刺激** | 胜者用手/嘴/脚等刺激败者生殖器至射 | 射精在撸动节奏中爆发，量多可控 | ch-06/07/08 |
| **B. 致命一击** | 重击/贯穿/拧头等暴力手段直接致死 | 射精是死亡反射，身体绷直→喷射，无撸动 | 尚未使用 |
| **C. 窒息/压制** | 勒喉/压胸等导致缺氧死亡 | 射精在窒息最后阶段爆发，痉挛→射 | 尚未使用 |

**每场必须用不同路径或相同路径的不同细节。**

### 精槽→射精通用流程

```
连续受击 → 精槽上升 → 阴茎半硬 → 硬 → 龟头膨胀 → 马眼张开 → 
  濒临极限 → 致命触发 → 射精（七八股浓精）→ 断气
```

路径ABC的区别在"致命触发"环节：
- A：触碰+撸动 = 触发
- B：最后一击（重拳/角顶/断颈）= 触发
- C：窒息临界点（断氧10-15秒后）= 触发

### 其他敏感带

除了阴茎，以下敏感带在战斗/处决中也可利用：
- **乳头**：虎/熊的乳头在胸肌上，熊族较大，刺激可加剧精槽上升
- **后穴**：插入可加速精槽积累，作为处决前奏
- **大腿内侧**：触摸/咬此处可引发强烈反应

## 六、赛后清场

每场比赛结束后的清场画面是lanse的固定风味，**必须描写**。

### 清场固定元素

- **G级杂兵**：穿军绿制服+白袜，负责抬尸/洗地

## 七、情色内容基线

### 每章情色基线

**每章必须有情色内容**（卖肉或处决）。不能出现连续多章无性。

| 章节类型 | 最低要求 |
|:--------|:---------|
| 赛前/日常章（ch-01~05） | 至少1处卖肉场景（勃起/抚摸/自慰/共浴） |
| 比赛章（ch-06起） | 处决射精全程 + 战斗中的精槽反馈 |

### 纯卖肉场景（不致死）

可以出现以下情色内容而不导致死亡：
- 勃起、硬挺、龟头露出
- 抚摸、撸动（但在射精前停止）
- 自慰（不射精）
- 共浴、共眠、裸体接触
- 身体打量、性化视线

**关键**：只要不射精，就不会死。这为前期篇章提供了情色空间。

## 八、写作红线（禁止项）

### ❌ 禁止深度心理描写

- ❌ 哲学性、内向化的独白（"如果他死了谁会记得他""我怕的不是输而是明天过后"）
- ✅ 允许的内心活动仅停留在**即时反应**层面：
  - "好壮" "真他妈疼" "怕有什么用" "操" "爽"
  - 对身体的直接感受："硬了""热""想射"
  - 对对方身体/动作的即时评价

### ❌ 禁止假名

- 所有角色名以 `story-setting.md` 官方名单为准
- 旧版曾用"牛刚""虎啸""犬忠"——永不再用

### ❌ 禁止编号

- 行文中永不出现 E-XXX、W-XXX、B-XXX、D-XXX 编号
- 不需要用编号来区分角色

### ❌ 禁止内衣描写

- 兽盾兵不穿内裤
- 下身只有黑色紧身短裤，脱裤直接见下体
- 制服：黑色紧身短袖 + 黑色紧身短裤 + 黑色长筒袜 + 黑色厚底军靴

### ❌ 禁止过度环境描写

- 不写大段的环境铺陈
- 环境描写服务于感官强化（光线/气味/触感），每次1-2句足够

## 九、战斗描写规范

### 情色维度（最重要）

战斗不是纯物理的——战斗就是性。

每场战斗写作自查：
- [ ] 受伤后是否有"热感向下蔓延"的描写？
- [ ] 双方是否有勃起进程？
- [ ] 精槽积累是否有体感描写？
- [ ] 处决前的临界状态是否清晰？

### 感官强化优先级

1. **视觉**：皮毛色、制服黑、精液白、血液红
2. **触觉**：握感（粗/细/硬/软/热）、温度、湿润度
3. **嗅觉**：汗水味、精液味、血腥味、阵营体味（熊甜、熊麝香等）
4. **听觉**：喘息、呻吟、肉体撞击、射精的啪嗒声、尸体被抬走的轮子声

### 段落控制

- 常规段落：2-5行
- 战斗高潮段：可拉到6-10行（每个打击/每次精槽积累分一段）
- 每段聚焦一个感官或动作节拍，不要堆砌
