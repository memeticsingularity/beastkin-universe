## 版本命名规范

| 版本号  | 含义          | 示例                 |

## 每个版本文件夹内必须包含

### 1. SVG文件

- 命名：`[描述]-v[版本号].svg`
- 要求：自包含，无需外部资源即可正常显示
- 尺寸建议：1600x1200 或 1920x1080

### 2. DESIGN.md

包含以下内容：

```markdown
# [图表名称] v[版本] 设计文档

## 设计目标
- 解决什么问题？
- 为谁设计？（作者/读者/AI辅助）

## 数据来源
- 基于哪些章节？
- 关键设定文件引用

## 设计决策
- 布局选择理由
- 颜色编码说明
- 关系线类型定义

## 限制与注意
- 哪些关系未显示？
- 可能的误解点
```

### 3. CHANGELOG.md

```markdown
# 版本变更记录

## v1.0 (2026-03-16)
- 初始版本
- 包含前10章32人关系
- 标记跨宿舍/跨阵营关键互动

## v1.1 (日期)
- 变更内容
```

### 关系线类型

| 类型     | 颜色                     | 线型  | 标记     |
|--------|------------------------|-----|--------|
| 同宿舍    | 同阵营色                   | 实线  | 无      |
| 跨宿舍同阵营 | 同阵营色                   | 虚线  | 无      |
| 约定/承诺  | #228B22 ( green )      | 实线  | 双向箭头   |
| 亲密行为   | #DC143C ( crimson )    | 实线  | 心形或双箭头 |
| 敌对/对峙  | #8B0000 ( dark red )   | 粗实线 | 双向箭头   |
| 跨阵营互动  | #4169E1 ( royal blue ) | 点划线 | 无      |

### 标签规范

- 角色名：10-12px，居中
- 编号：E-xxx/W-xxx/B-xxx/D-xxx，9px，灰色
- 描述：9-10px，限制在一行内
