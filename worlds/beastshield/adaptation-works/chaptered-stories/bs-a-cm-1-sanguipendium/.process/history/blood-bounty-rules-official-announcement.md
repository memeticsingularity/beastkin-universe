# **第一届兽盾四营血酬淘汰赛 正式规则公告**

## **第一章 总则**

**第一条 赛事名称**
第一届兽盾四营血酬淘汰赛（以下简称“本赛”）。

**第二条 赛事性质**
本赛为兽盾公司主办、面向全城公开的单败淘汰制近身格斗赛事。赛事以决出生死为胜负唯一标准，最终仅存一名优胜者。

**第三条 参赛资格与阵营划分**

1. 参赛者总数限定为 **32名**。
2. 参赛者依其所属种族兵营，划分为 **四大阵营**，每阵营初始名额为 **8人**：
    * **虎之阵营**：参赛者须为虎兽人。
    * **熊之阵营**：参赛者须为熊兽人。
    * **牛之阵营**：参赛者须为牛兽人。
    * **犬之阵营**：参赛者须为大科兽人（各类犬种、狼犬、鬣狗等皆可）。

## **第二章 赛事流程与时间**

**第四条 整体赛程**
本赛全程共计35个自然日，具体安排如下：

* **第1日**：赛事规则公布。
* **第2-3日**：选手招募期。各阵营接受自愿报名，若名额未满，由该阵营长官强制征补。
* **第4日**：**公开抽签仪式**。一次性确定全部32名选手的对阵次序与完整晋级路径。
* **第5-6日**：选手休整备战期。
* **第7-10日**：第一轮（32进16），每日进行4场比赛。
* **第11-13日**：休赛期。
* **第14-17日**：第二轮（16进8），每日进行2场比赛。
* **第18-20日**：休赛期。
* **第21-24日**：第三轮（8进4），每日进行1场比赛。
* **第25-27日**：休赛期。
* **第28-29日**：半决赛（4进2），每日进行1场比赛。
* **第30-34日**：最终休整与宣传期。
* **第35日**：决赛。

**第五条 对阵原则**

1. 第一轮（32进16）与第二轮（16进8）实行 **“同阵营回避”原则**，确保选手不会与同阵营成员对战。
2. 自第三轮（8进4）起，此原则失效，同阵营选手可能相遇。
3. 所有对阵关系及晋级路径于抽签仪式后完全锁定，不可更改。

## **第三章 战斗规则与奖金制度**

**第六条 战斗形式**

1. 比赛形式为 **一对一近身格斗**。
2. **严禁使用任何武器、暗器或外来道具**。仅允许使用自身肢体、爪牙进行攻击。
3. 比赛场地为标准竞技台，离开台面或丧失意识均不影响比赛继续，直至一方死亡。

**第七条 胜负判定**
比赛的唯一终结方式为 **一方选手死亡**。不存在平局、点数判胜或裁判中止。

**第八条 奖金计算规则**

1. 每获胜一场比赛，选手可获得基础胜利奖金 **500撸币**。
2. 单场实际获得奖金由以下公式决定：
   > **单场奖金 = 500撸币 × (9 - 己方阵营赛前存活人数) × (9 - 对方阵营赛前存活人数)**
   > * “赛前存活人数”指该场比赛开始前，该阵营尚未战死或退赛的选手数量。
3. 冠军选手将获得其所有获胜场次奖金的累计总和。
4. 公司将在赛事结束后，根据冠军最终表现，额外授予 **1倍至16倍不等的奖金乘数**。

**第九条 冠军额外奖赏**
最终优胜者除奖金外，还将获得：

1. 晋升为兽盾公司武斗兵营 **营地头目** 职位。
2. 永久性大幅提升月度薪俸。
3. 在公司内部享有相应的特殊地位与权限。

## **第四章 选手管理与待遇**

**第十条 集中管理**
所有参赛选手自抽签仪式后，须入住指定 **选手村**，接受统一封闭管理，直至其战死、退赛或夺冠。

**第十一条 住宿标准**

1. 第一轮与第二轮赛事期间，选手按所属阵营分配至 **四人宿舍** 居住。若某阵营人数不足四人，则空置床位，不与其他阵营混编。
2. 自第三轮（8强）开始，所有存活选手升级至 **条件更优的单人宿舍**。

**第十二条 待遇与医疗**

1. 选手的饮食、训练设施及日常待遇将随其晋级轮次逐步提升。
2. 选手村医疗站仅提供 **基础医疗支持**，包括但不限于：伤口清创与包扎、骨折固定、止痛药剂。不提供高阶再生治疗或快速康复服务。

**第十三条 对外联络**
选手在村期间，对外联络受到严格监管，仅可通过官方渠道进行有限度的信件寄收与视频通讯。

## **第五章 退赛与投降规则**

**第十四条 赛前退赛**

1. 选手可在 **其本人任一比赛场次正式开始前**，提出退赛申请。
2. 退赛申请一经提出，即视为自动放弃 **此前所有累计获得的比赛奖金**。
3. 提出退赛的选手，必须参加当众举行的 **“命运抽签”仪式**，以决定其最终处罚。

**第十五条 赛中投降**

1. 比赛进行中，选手可随时以口头、手势等明确方式表示 **投降**。
2. 投降的生效， **完全取决于对手是否接受**。若对手停止攻击并接受投降，则比赛终止，投降者视为退赛。
3. 若对手拒绝接受投降并继续攻击，则比赛继续进行，直至一方死亡。
4. 投降生效者，与赛前退赛者同等对待：奖金清零，并参加 **“命运抽签”**。

**第十六条 命运抽签处罚**
退赛者或投降生效者，须从以下八支签中公开抽取一支，处罚即时生效：

| 签号     | 处罚内容                                                       |
|:-------|:-----------------------------------------------------------|
| **签一** | **携款离场**：可保留提出退赛/投降前已获得的所有奖金，自由离开。后续安全自负。                  |
| **签二** | **货物出售**：立即转为“俘虏快递”商品，剥夺一切权利，售予出价最高者。                      |
| **签三** | **等级剥夺**：降级为最低级（G级）绿制服杂兵，发配至最艰苦岗位。                         |
| **签四** | **双重处罚**：先执行“签三”降级，随后作为商品出售（同签二）。                          |
| **签五** | **公开处刑**：于下一比赛日开始前，在公开场合被处决。                               |
| **签六** | **高额罚金**：需缴纳等同于 **其退赛/投降场次若获胜可获奖金** 的罚金。无法缴清者，处罚转为 **签八**。 |
| **签七** | **无偿劳役**：强制进行为期一个月的无薪高危劳役。                                 |
| **签八** | **强制参赛**：退赛/投降请求被驳回，必须按原定计划完成比赛。此怯懦行为将记入档案。                |

## **第六章 公众观赛与博彩**

**第十七条 赛事转播**
本赛将在白之都主要公共区域设置大型屏幕进行全程实时转播，并开设付费专属频道提供多角度直播服务。

**第十八条 官方博彩**
兽盾公司将开设官方投注窗口，欢迎公众对赛事胜负、晋级进程、阵营存续等多种内容进行投注。

**第十九条 商业活动**
赛事期间，公司将推出各类授权周边商品，并与城内商家合作举办相关主题活动，共襄盛举。
