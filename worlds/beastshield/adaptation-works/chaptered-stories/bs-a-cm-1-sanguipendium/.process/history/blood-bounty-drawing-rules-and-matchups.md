# **第一届兽盾四营血酬淘汰赛 - 抽签规则与对阵全录**

## **一、抽签规则与规避机制**

### **1. 抽签基本原则**

- 所有32名选手进入同一抽签池。
- 采用**顺序抽签+顺延调整**机制。
- 抽签过程公开透明，全程有录像及公证人员监督。

### **2. 规避规则（硬性要求）**

> **第一轮（32进16）及第二轮（16进8）确保同阵营选手不会相遇。**

**实现方式：**

- 将32个签位划分为**8个1/8区**（每区包含4个连续签位）
- **核心约束**：每个1/8区内的4名选手必须来自四个不同阵营（虎、熊、牛、狗各一人）

### **3. 1/8区划分（签位编号1-32）**

```
1/8区1: 签位 1, 2, 3, 4
1/8区2: 签位 5, 6, 7, 8
1/8区3: 签位 9,10,11,12
1/8区4: 签位13,14,15,16
1/8区5: 签位17,18,19,20
1/8区6: 签位21,22,23,24
1/8区7: 签位25,26,27,28
1/8区8: 签位29,30,31,32
```

### **4. 抽签流程详解**

1. **原始抽签顺序确定**：通过随机摇号产生32名选手的出场顺序。
2. **按签位顺序落位**：从签位1开始，依次尝试将当前待分配的选手放入该签位。
3. **规避检查**：检查如果将选手放入此签位，是否会使其所属的**1/8区**内出现两个同阵营选手。
4. **顺延调整**：
    - 如果检查通过 → 选手落位，处理下一个签位
    - 如果检查不通过 → 该选手**暂时跳过**，保留在待分配池中，继续用下一个待分配选手尝试此签位
5. **重复直至完成**：直到所有32个签位都有选手落位。

## **五、重要说明**

1. **同阵营规避验证**：
    - 第一轮：所有16场比赛均为跨阵营对决
    - 第二轮：每个1/8区内的胜者对决也必然是跨阵营（因区内初始四阵营各一人）

2. **最早可能的内战**：
    - **第三轮（8进4）**：相邻1/8区的冠军若同阵营，则将在四分之一决赛中内战
    - 示例：若区1冠军为熊营，区2冠军也为熊营 → 四分之一决赛A为熊营内战

3. **奖金倍率计算基准**：
    - 每场比赛开始前，根据双方阵营的当前存活人数计算倍率
    - 存活人数 = 该阵营尚未战死且未退赛的选手数量

4. **退赛影响**：
    - 如有选手退赛，其所在阵营存活人数-1
    - 后续所有涉及该阵营选手的比赛倍率将立即重新计算
