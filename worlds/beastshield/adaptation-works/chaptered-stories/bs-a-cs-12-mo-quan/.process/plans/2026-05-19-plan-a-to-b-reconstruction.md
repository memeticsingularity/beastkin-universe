# Plan A → Plan B 思路重构记录

> 本文档记录墨犬续写 Ch.9–Ch.12 从 Plan A（暗室路线）转向 Plan B（武林路线）的完整思路变迁。
> 日期：2026-05-19

---

## 一、Plan A 的原始设计

### 核心路线
- **Ch.9**：边缘区平民区，兽盾小队进驻征收，黑狗纯旁观。E级白虎首次登场，建立"走狗"形象。
- **Ch.10**：暗室刺客（黑豹、灰狼、蟒蛇）夜袭兽盾小队，高效全灭刺杀。黑狗缩在铁皮棚里目击全程，恐惧压倒色欲。
- **Ch.11**：黑狗黎明捡漏，对G级尸体逐一色色，最后发现E级白虎濒死未死，后入触发锁血技能吸收。
- **Ch.12**：未规划，但隐含为"白虎醒来后的互动/加入"。

### Plan A 的问题
1. **暗室出场过早**：暗室作为与兽盾敌对的第三方势力，其正式亮相需要更强的铺垫和神秘感。在 Ch.9–Ch.11 就登场，缺乏足够的前置伏笔，显得仓促。
2. **黑狗路线过于透明**：Ch.9旁观→Ch.10旁观→Ch.11捡漏，三连续纯旁观/被动模式，主角缺乏主动性和意外变量。
3. **周乙旭反馈的"无意义幸存者"**：Ch.2–Ch.8 中大量的尸体和幸存者未能回收进入主线叙事，他们"死得毫无价值"。
4. **战斗与色色未绑定**：原作世界观的核心设定（战斗=色色、攻击导致射精、射精过量致死）在 Plan A 中未能充分体现。暗室的击杀是物理刺杀，与情色机制无关。

## 二、Plan B 的核心转向

### 1. 移除暗室，引入武林
- **暗室推迟**：暗室不再在 Ch.9–Ch.11 登场，延后至更后面的章节（Ch.13+），作为长线伏笔。
- **武林登场**：引入"武林"（武术家/江湖势力）作为 Ch.9–Ch.11 的核心外部变量。武林是兽盾世界中的反抗力量，以传统武术对抗兽盾的现代军事化压迫。

### 2. 战斗-情色捆绑机制（世界观核心）
基于原作设定和世界观的深化，明确以下机制：

| 机制 | 说明 |
|------|------|
| **攻击即刺激** | 所有物理攻击（拳、脚、武器、暗器）直接转化为性刺激。被击中者会勃起、流前列腺液、甚至射精。 |
| **射精分级** | 低强度刺激 → 少量射精（不会立即致死，但持续可控射精可榨干至死）。高强度刺激/致命一击 → 一次性大量射精（即死）。 |
| **物理击杀仍成立** | 体术、暗器、武器击杀依然有效，但击杀瞬间目标会射精。死亡方式可以是"射尽而死"或"物理击杀+射精"。 |
| **战斗色情化** | 战斗场面本质上是群体性色色场面。兽盾兵的粗壮身体在受击时勃起、白袜绷直、制服被体液浸透，构成视觉奇观。 |

### 3. 回收 Ch.2–Ch.8 的幸存者
- Ch.9 开场改为兽盾**收尸队/审判队**进驻 Ch.2–Ch.8 的发生地（青石镇及周边）。
- 收尸队清点尸体、捕获幸存者，准备进行"无能审判"（兽盾内部对任务失败者的处决）。
- **周乙旭的"死亡美学"**：尸体被像垃圾处理一样搬运、堆叠；幸存者被捆绑、羞辱；处决过程冷酷高效。
- 这解决了"前八章幸存者无意义"的问题——他们被带回主线，成为审判和处决的对象。

### 4. 章节结构重组

#### Ch.9：审判日
- **场景**：青石镇（Ch.2–Ch.8 事件现场）。
- **核心事件**：
  1. 兽盾收尸队（E级白虎带队，G级辅助）进入现场，清点尸体、捕获幸存者。
  2. 尸体被堆叠、搬运、登记——展示"死亡毫无价值"的美学。
  3. 幸存者（若有）被绑在广场上，E级白虎主持"无能审判"。
  4. 白虎宣判：全部处决。
  5. **执行瞬间，武林人士到场**——打断处决。
- **黑狗位置**：躲在暗处（废墟/屋顶），目击收尸和审判全过程。色欲被粗壮收尸兵触发，但恐惧压制行动。
- **本章功能**：回收前八章叙事遗产；建立白虎的冷酷专业形象；武林首次亮相（只闻其声/见其影，或只出现一人）。

#### Ch.10：武林 vs 兽盾（上）
- **场景**：青石镇广场及周边。
- **核心事件**：
  1. 武林人士（3–5人，物种精瘦敏捷型：豹、狼、蛇、狐等，与兽盾的熊虎牛猪形成反差）现身。
  2. 双方对峙——白虎试图以兽盾威压压制，武林不吃这套。
  3. **战斗爆发**：战斗-情色捆绑机制全面启动。
  4. 武林招式（点穴、暗器、轻功）击中兽盾兵 → 兽盾兵当场勃起/射精。
  5. G级杂兵被逐一"点射"（点穴致射精昏厥或死亡）。
  6. 白虎亲自上阵，与武林首领（暂定：黑豹武术家）交手，不分胜负。
- **黑狗位置**：继续旁观，但被战斗中的色色场面刺激到几乎忍不住。
- **本章功能**：正式展示"战斗=色色"的世界观机制；武林实力亮相；白虎的战斗力展示。

#### Ch.11：武林 vs 兽盾（下）
- **场景**：继续战场，可能转入巷战或建筑内。
- **核心事件**：
  1. 战斗升级。武林使用合击技/暗器阵，兽盾小兵持续"被点射"。
  2. 白虎逐渐落入下风——武林专门研究过兽盾的弱点（制服敏感点、物种生理特征）。
  3. 白虎被重击（穴位/暗器）→ 大量射精 → 体能暴跌 → 再受致命伤。
  4. **白虎濒死**：重伤倒地，黑色紧身制服被血和精液浸透，白色胸毛染红，瞳孔涣散，但还有一口气。
  5. 武林以为白虎已死（或没时间补刀），迅速撤离（兽盾援军将至）。
  6. 战场留下：大量G级尸体（部分死于射精榨干，部分死于物理击杀）、濒死的白虎、以及躲在暗处的黑狗。
- **黑狗位置**：确认安全后，从藏身处爬出。
- **本章功能**：白虎从"冷酷走狗"跌落至"濒死猎物"，完成最大反差；战场清空，为Ch.12捡漏铺垫。

#### Ch.12：捡漏
- **场景**：战后废墟，黎明到上午。
- **核心事件**：
  1. 黑狗进入战场，对G级尸体逐一"享用"（先G后E）。
  2. 尸体还是温热的，部分死于射精榨干的尸体裆部还硬着，精液残留丰富。
  3. 黑狗最后发现白虎还有气 → 后入濒死白虎。
  4. **吸收触发**：后入过程中意外吸收锁血技能。
  5. 射精后粗糙照顾（包扎、喂水、移位）。
  6. **断章**：白虎睁开眼睛，只说一个字"你……"。
- **本章功能**：黑狗正式确立"捡漏者"定位；首次能力吸收；白虎完成"鬼门关觉醒"前置。

## 三、关键设定保留与变更

| 设定 | Plan A | Plan B | 说明 |
|------|--------|--------|------|
| **E级种族** | 白虎（已定案） | 白虎（保留） | 不变。白色毛发+黑色制服=最强视觉反差。 |
| **E级形象** | 纯走狗，冷酷专业 | 纯走狗，冷酷专业 | 不变。Ch.9–Ch.11 前段维持走狗形象，濒死后转变。 |
| **黑狗定位** | 旁观者→捡漏者 | 旁观者→捡漏者 | 不变。但旁观内容从"暗杀"变为"战斗色情"。 |
| **战斗机制** | 物理刺杀（匕首、毒、钢丝） | 武术点穴+暗器+体术，捆绑射精 | 根本变化。所有攻击都导致勃起/射精。 |
| **敌方势力** | 暗室（第三方） | 武林（反抗势力） | 暗室推迟，武林提前。 |
| **尸体来源** | 暗室刺客击杀 | 武林点击杀（射精死/物理死混合） | 来源变化，但"捡漏"核心保留。 |
| **Ch.2–Ch.8 幸存者** | 未回收 | 回收为审判对象 | 解决叙事断裂问题。 |
| **色色模式** | 权力压迫（Ch.9）+ 恐惧（Ch.10）+ 尸体（Ch.11） | 战斗色情（Ch.10–11）+ 尸体（Ch.12） | 新增"战斗即色色"模式。 |

## 四、世界观机制补充（战斗-情色捆绑）

### 兽盾兵的生理弱点
- **制服敏感化**：兽盾的制服（尤其是G级的军绿制服和E级的黑色紧身制服）经过特殊处理，面料对摩擦和压迫极度敏感。被击中时，布料与皮肤的摩擦直接转化为性刺激。
- **白袜/黑袜敏感带**：长筒袜的袜口勒紧大腿根部，形成天然的"敏感度放大区"。点穴或踢击中腿部时，刺激通过袜带传导至裆部。
- **金属护裆（E级）**：护裆本身是一个"双刃剑"——保护要害的同时，任何撞击都会通过金属传导，造成强烈的震荡刺激，极易引发射精。

### 武林的战术优势
- **专攻下三路**：武林招式专门针对兽盾兵的生理弱点设计。点穴不点死穴，点"精穴"（刺激前列腺/精囊的穴位）。
- **暗器涂药**：部分暗器涂有催情/助勃药物，确保中暗器者迅速进入勃起状态。
- **轻功游击**：利用兽盾兵粗壮笨重的体型劣势，快速游走、多点打击，让兽盾兵在移动和受击中不断射精流失体力。

### 死亡方式分类
1. **射精榨干**：持续低强度刺激 → 持续小量射精 → 体力流失 → 虚脱昏厥 → 最终精液耗尽死亡。尸体特征：裆部湿润、精液大量残留、面容安详（或扭曲快感）。
2. **致命点穴/暗器 + 射精**：一击致命，但死亡瞬间触发一次性大量射精。尸体特征：致命伤口 + 裆部大量精液喷涌痕迹。
3. **物理击杀 + 射精**：武器/体术击杀，死亡瞬间射精。尸体特征：外伤 + 勃起/射精痕迹。

## 五、作者意图与读者体验

### 为什么要这样改？
1. **长线叙事**：暗室是更大的伏笔，不应在主角尚未成长时就揭开面纱。武林作为"阶段性反派/变量"更合适。
2. **世界观一致性**：原作强调"兽人射精会虚弱/死亡"，Plan B 将这一机制融入战斗，比 Plan A 的纯物理刺杀更符合设定。
3. **主角成长曲线**：黑狗从 Ch.2–Ch.8 的"被迫逃亡"，到 Ch.9 的"旁观审判"，到 Ch.10–11 的"旁观战斗色情"，再到 Ch.12 的"主动捡漏"，是一个从被动到主动的渐进过程。
4. **周乙旭反馈落地**："死亡毫无价值"美学在收尸、审判、战斗中全面体现；前八章幸存者被回收。

### 读者体验变化
- **Plan A**：悬疑暗杀（暗室）→ 恐怖（黑狗恐惧）→ 情色（捡漏）。节奏是"静→惊→色"。
- **Plan B**：冷酷审判（兽盾）→ 战斗色情（武林vs兽盾）→ 情色（捡漏）。节奏是"冷→战→色"。
- Plan B 的战斗场面本身成为情色高潮的前戏，阅读爽度更连贯。
