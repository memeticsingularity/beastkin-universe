# 《墨犬》故事设定档案

> 基于原作前两章及续写Ch.3-Ch.17整理的角色、道具、场景与核心机制档案。

---

## 世界观基础设定

### 雌雄同体

**本作世界中所有兽人均为雌雄同体**，同时具备：
- **雄性性征**：阴茎、睾丸、雄性激素驱动的体味与肌肉
- **雌性性征**：乳头/乳房（种族差异显著）

**种族差异**：
| 种族 | 乳部特征 |
|------|---------|
| 熊、虎、牛 | 胸前两枚乳头，乳晕深色，大小随物种而异 |
| 猪 | 胸前两枚乳头，粉褐色，常被肚腩肥肉半遮 |
| 狗/犬科 | 胸前两枚乳头，小巧色深，毛短易见 |

**创作要求**：乳头/乳房描写与下体描写同等重要，在性征描写和情色场景中不可遗漏。所有角色（包括兽盾兵、武林猎手、主角）均遵循此设定。

## 创作宪法（原作者 lanse 原话）

> **"性格是喜欢壮兽人的平民吧。"**
> **"你这样理解就好。"**
> **"大概是能不杀的兽盾兵就不杀，但是肯定还是以自保为前提。"**
> **"不过杀了的也不会浪费，会去揩油。"**

**这四句话是黑狗全部行为逻辑的起点和终点。**

- **平民**：不是杀手，不是特工，不是英雄。决策靠朴素好恶，不靠职业素养或道德准则。
- **喜欢壮兽人**：核心驱动力之一，会干扰决策。遇敌时先想"好壮"，再想"危不危险"。
- **能不杀就不杀，自保优先**：不杀不是因为仁慈，是因为"没必要"。但威胁到生存时，身体本能（金钟罩、烈火掌）会自发反杀。
- **杀了的会揩油**：市井式的实用主义。死了就是死了，但肉体还在，别浪费。

**身体与灵魂的撕裂**：
- **身体（墨犬/暗室首座）**：职业杀手的肌肉记忆，高效杀戮、精准攻击下体、不留活口。
- **灵魂（黑狗/平民）**：拿了核弹发射按钮的小孩，凭好色和任性做生死决策。

**所有剧情张力都从这种撕裂里来。**

## 核心角色

### 黑狗（现在的灵魂）
- **身份**：一个学了**夺舍能力**的年轻人，在夺舍过程中失忆
- **状态**：失忆，连自己原本的兽人种族/身份都**没有设定**（允许自由发挥）
- **性格**：
  - **好色但求生优先**：喜欢壮兽人的平民；遇敌时先有生存冲动，色欲作为干扰项扭曲决策
  - **天真+残忍**：杀人后会拍脸问"你还醒着吗"，帮死者合眼，但也会揩油（搜身、玩弄尸体）
  - **被动反应型（底色）**：不是猎手，不会冷静盘算；战斗靠本能、意外触发、摔倒后顺势
  - **对能力不熟悉（底色）**：触发金钟罩/烈火掌时会困惑"咦？怎么回事？"——可以逐渐从"完全困惑"变成"有点熟悉"，但不应变成"掌控"
  - **手下留情型**：能不杀的兽盾兵就不杀（以自保为前提），杀了的会揩油
- **目标**：寻找自己的身世（包括**自己的身世**和**杀手的身世**）；躲避兽盾追杀
- **核心驱动力**：生存/保命 > 寻找身份线索 > 满足性欲 > 恻隐之心

### 墨犬（身体原主人 / 原灵魂）
- **种族**：黑色犬科兽人
- **身份**：**武林败类**，已吸收多人能力，但**还不是暗室首席**
- **身体等级**：**差不多最强的肉体**
- **核心功法**：**吸收别人的能力为己用**——所以他会很多种武功（金钟罩、烈火掌、寸止等）
- **能力触发方式**：**被动触发**，不是主动运功。在接触/吸收过程中自动获取他人能力
- **外观变化**：吸收能力后外观会变化
  - 吸收越多能力 → 体型变得**越大只/越壮**
  - 吸收**大力类**能力 → 身体变**硬**
  - 吸收**火焰类**能力 → 身体变**红**
  - 具体变化**看情况**，允许自由发挥
- **状态**：已死亡（灵魂被夺舍后成为第一章洞穴里的娇小尸体）
- **死亡/失忆经过**：原墨犬试图**后入吸收**年轻人的夺舍功法时，反被夺舍；年轻人的灵魂占领身体后，**承受不住原身体过于强大的力量**，导致失忆
- **遗留**：武功化为身体本能，记忆碎片偶尔影响黑狗的表述

**关键细节**：
- 现在的"黑狗" = **年轻人的灵魂** + **墨犬的身体** + **墨犬的武功**（全部本能触发）
- 武功属于**身体（原墨犬）**，年轻人的灵魂只能被动触发，无法主动驾驭
- 第一章洞穴里的娇小尸体 = 被驱逐的**原灵魂（墨犬）**
- 洞穴里的卡片等遗留物与原灵魂有关，黑狗看不懂但会随身携带
- **夺舍是一次性技能**：年轻人只是好奇学了夺舍功法，没想过用，结果被动触发。不能再夺舍别人

- **兵种**：兽盾公司 E级武斗兵/任务负责人

## 神秘功法（属于身体原主人）

**重要**：这些武功属于**这具身体的原主人**（一位武林高手），黑狗作为"灵魂租客"只能被动触发，无法主动驾驭。

### 金钟罩
- **类型**：被动防御
- **触发**：危急关头由身体本能自动触发
- **效果**：刀枪不入，能弹开锐器攻击
- **本质**：原主人的铁布衫/金钟罩类硬气功，在这个世界表现为内劲护体

### 烈火掌
- **类型**：接触型攻击
- **效果**：通过肢体接触向敌人体内输送内劲，使其精关崩溃、射精致死
- **本质**：原主人的阳刚内劲掌法，被这个世界的"射精死亡"规则放大为致命攻击

### 寸止
- **类型**：特殊控制
- **触发条件**：黑狗动了恻隐之心时，身体本能响应
- **效果**：双指并拢按压目标睾丸与肉棒连接处，向内输入内劲，强行中止射精，令兽人幸存
- **本质**：原主人的点穴/气功截脉技法
- **意义**：符合黑狗"普通价值观、手下留情"的性格——不是武功选择他，而是他的性格触发了武功的仁慈用法

## 憋精功设定

### 核心原理
- **不是"完全没射"**：是射了很多发后，阴茎射累了，强行憋住中断射精，留下一部分续命
- **前提**：需要储精量足够多才能学会（粗壮兽种更容易掌握）
- **副作用**：昏迷一段时间，消耗极大，使用后极度虚弱
- **触发方式**：精关在极端刺激下的**被动自动闭锁**，不是角色主动控制

### 外观特征（与普通射精死亡的区别）

| 特征 | 真尸体（射精死亡） | 憋精功假死者 |
|------|------------------|-------------|
| 裤裆 | 湿成一滩，精液射空 | **湿成一滩，有残精**（射了一部分） |
| 棍棍 | 射完后软垂，马眼松弛张着 | **半硬或软垂，马眼半张/张着，挂着残精** |
| 呼吸 | 无 | 极其微弱 |
| 胸口 | 无起伏 | 微弱起伏 |
| 意识 | 无 | 昏迷后逐渐苏醒，极度虚弱 |

### 在《墨犬》中的使用
- **Ch.11 白虎**：与武林激战后进入假死状态，被黑狗误认为尸体

## 杀手组织：暗室（The Darkroom）

> 出自新纪元主线第6-8章。墨犬（身体原主人）所在的杀手组织。

### 组织概况

| 项目 | 内容 |
|------|------|
| **正式名称** | 暗室（The Darkroom） |
| **核心制度** | **十座**——按暗杀战绩排名，前十位上座成为"十座"，是组织战力顶梁柱 |
| **最高指令** | **通室令**——紧要关头才能颁布的最高权限严令，可调动全部十座 |
| **与兽盾关系** | **敌对竞争**。兽盾保镖行业兴起后，暗室生意难做，很多年轻好苗子折损在兽盾兵手里 |
| **与政府/警局关系** | 警局勤峰警官曾主动拉拢暗室合作对抗兽盾，提供情报和权限，换取资金和人才 |

### 墨犬（原身体主人）与暗室的关系

- 墨犬（身体原主人）夺舍前**还不是首席**，只是个"吸收了很多人能力的武林败类"
- 黑狗（年轻人灵魂）夺舍后走投无路，**进入暗室，慢慢才变成首席**
- 首席 = **武功最高**，但**不管事务**；管事的是**四座（年长老）**
- 首席**不止一任**，只是职位，黑狗/墨犬只是"这一任"首席
- 他的功法"**吸收别人的能力为己用**"可以解释为什么暗室杀手各有独门绝技——也许不是他自己练的，是吸来的
- 暗室杀手普遍擅长攻击兽人下体（精关），与墨犬的"烈火掌"思路一致
- **熊猫角色**可安排在中期暗室线出场

## 势力关系

- **兽盾公司**：搜捕队身穿印有盾型logo的军绿紧制服，奉命击杀黑狗
- **暗室（杀手组织）**：与兽盾是**敌对竞争关系**。兽盾保镖行业兴起后，暗室生意难做，很多年轻好苗子折损在兽盾兵手里
- **杂兵的认知**：G级杂兵**不知道**黑狗体内有武林高手的灵魂/武功，他们只是奉命搜捕"一只黑色犬科兽人"
- **追杀原因推测**：
  - 兽盾高层可能知道黑狗身体的秘密（杀手组织的身体）
  - 也可能兽盾与暗室有系统性敌对，黑狗作为暗室成员是重点清除目标
  - 底层执行者完全被蒙在鼓里，只知道"黑色犬科兽人，携带不明卡片，死活不论"
- **黑狗当前状态**：**被武林和兽盾双重追杀的怪物**——失忆后既被兽盾搜捕，也被武林人士追杀（因为这具身体原主人的仇家）
- **武林追杀者（第二卷主角）**：
  - 不是单一组织，而是**松散的江湖猎网**——特工局、炎魉、独立赏金猎人、暗室外围等各路人马因不同原因追查墨犬下落
  - 信息来源滞后于兽盾公司，靠江湖传闻、武功感应、线人追踪
  - 追查途中**顺手清理兽盾兵**，每章换一个杀手，物种/武功/性格各异（创意承载方）
  - 与兽盾兵的互动必须**有色、不秒、有过程**——符合 lanse "死亡无价值但过程有价值"的美学
- **黑狗前期实力**：**前期他还不是很强**，可以捡漏别人杀死的尸体来吸收能力，但无法主动驾驭身体内的武功
- **黑狗长线发展**：进入暗室，慢慢变成首席。首席只是武功最高，不管事，管事的是四座

### 尸体处理规则

- **处理方式**：兽人死亡后，尸体由绿制服搬送至据点集中点，装入木桶/大垃圾桶统一处理（不焚烧）
- **保鲜机制**：兽盾世界尸体不会迅速腐败，保持柔软温热
- **严禁描写**：焚烧尸体、尸臭、尸僵
- **可描写**：绿制服拖拽尸体脚踝、黑色爪子陷进毛发、肚皮朝外翻着、精液硬壳反光
- **出处**：第八章青石镇据点设定，木桶/垃圾桶装尸体是标准流程
