# 墨犬 Ch3-Ch5 整体修改计划

## Context

读者暮游对前五章（原作两章 + 续写三章）给出尖锐反馈：续写部分（Ch3-Ch5）的主角形象与原作（Ch1-Ch2）严重割裂。具体表现为：

1. **生存逻辑被色欲完全挤占**：后三章黑狗遇敌时毫无规避意识，主动送上门，全靠金钟罩/烈火掌被动救场
2. **前后性格不统一**：前两章黑狗会先呼救、拷打情报、评估威胁；后三章变成"看到壮兽人就扑上去"
3. **失忆不能解释行为**：失忆=不记得过去，不等于失去风险意识
4. **零成长**：五次战斗后对自身能力仍只有"咦？又不疼了？"
5. **主心轴缺失**：读者完全无法预测黑狗的行为动机

本次修改目标：**在不推翻核心情节、不违背原作笔风的前提下，为黑狗重建"生存本能优先、色欲作为干扰项"的行为逻辑**，让续写形象与原作形象重新重合。

---

## 核心修改原则

### 原则1：行为顺序必须是 "生存冲动 → 色欲干扰 → 冲动扭曲/覆盖"

原作Ch1-Ch2的行为链条：
- Ch1：熊兽人扑来 → 先格挡求生（金钟罩触发）→ 反杀后才是好色（吮吸熊根）
- Ch2：先埋伏勒住虎兽人 → 拷问情报（生存逻辑）→ 玩对方下体是附带

后三章Ch3-Ch5必须恢复这个顺序。黑狗**不是不想逃/躲**，而是色欲让他做出了最差选择。

### 原则2：给黑狗一个持续可见的"非色欲目标"

项目设定中黑狗的优先级排序是：生存 > 追查身份 > 色欲 > 怜悯。续写偏离了这个排序。

修改后，每章开头/中间必须出现以下至少一项：
- **卡片**：洞穴里那具尸体身上的不明卡片，是他唯一能追查身份的线索
- **对讲机**：从敌人通讯中捕捉关于自己的情报
- **下山目的地**：不能只是"往下走"，要有明确的目标感（比如"找人问卡片""找个能安全过夜的地方研究地图"）
- **对自身能力的困惑与试探**：不是被动等触发，而是有"刚才那一下又是怎么回事？"的持续追问

### 原则3：让黑狗从每次险境中产生"微小认知"

不需要顿悟，不需要 mastery，但要有"慢半拍的成长"。例如：
- Ch3后：知道对讲机会暴露位置，开始谨慎使用/监听
- Ch4后：知道敌人会用"窒息/压制"对付自己，产生对水的恐惧或对大体型敌人的警觉
- Ch5后：意识到制服可以带来阶级误认，开始有意识地利用伪装

### 原则4：维持原作笔风不变

- 第三人称紧贴黑狗感官，无游戏UI
- 口语化、弹幕式内心OS
- 情色与生死绑定，直白露骨
- 无道德判断，无诗意修辞
- 战斗靠摔倒、滑倒、意外触发，不靠精密招式
- 黑狗的底色仍是"失忆好色小鬼"，不是"冷静猎手"

## 逐章修改方案

### 第三章：山腰伏击（ch-3-hillside-ambush.md）

**当前问题**：黑狗听到对讲机后不是害怕想逃，而是"哇两个都好壮"主动钻出去装可怜。

**修改要点**：

1. **开头强化生存焦虑**
   - 黑狗下山时有明确目标："得找个有人烟的地方问问这张卡片是什么"
   - 对讲机响起时，他的第一反应是恐惧+想躲（"完了，还有同伙"），腿软是因为累+怕，不是因为好色
   - 他想绕路，但山道狭窄，两人已经往上走，绕路会暴露行踪或被追上

2. **被迫接触，而非主动送上门**
   - 改成：黑狗本想躲在岩石后等他们过去，但手电筒光柱已经照过来，被发现只是时间问题
   - 装可怜是**临时想出来的对策**（"硬跑跑不过，不如赌一把"），不是本能扑上去摸
   - 色欲是在接近后才爆发的："哇，好壮"的内心弹幕出现在已经接触之后

3. **战斗中插入恐惧和后怕**
   - 被狼兽人勒住时，强调窒息恐惧（"喘不上气了！"），而不只是"哇好硬"
   - 金钟罩触发时，除了"咦？又不疼了？"，加入"幸好……"的侥幸感
   - 杀掉肥豪后，加入一丝后怕："刚才要是没摔那一下……"让他意识到自己的命是捡来的

4. **留下老灰的动机更明确**
   - 不只是"像狗"，而是"他会帮我对付对讲机，留着有用"（实用主义+色欲的结合）
   - 黑狗帮他压精关时，可以更慌乱："希望能管用……"

5. **搜身强化身份追查**
   - 从肥豪或老灰身上搜到关于"黑色犬科"的命令纸条或素描，让黑狗意识到"他们在找我，而且知道我的样子"

**保留核心情节**：1v2遭遇战，肥豪死，老灰活，获得补给。

### 第四章：月下河滩（ch-4-riverside-moonlight.md）

**当前问题**：黑狗在河里大摇大摆洗澡，河马来杀他他先看对方裆部。

**修改要点**：

1. **洗澡有明确目的**
   - 不是为了舒服，是为了洗掉身上的汗味和泥土（"这样下山才不会被老远闻到"）
   - 他选择夜深时洗，且边洗边竖着耳朵听动静，保持警惕
   - 可以快速洗完，但河水太舒服让他多泡了一会儿——这是**小疏忽**，不是完全无脑

2. **河马出现时的反应顺序**
   - 先听到对岸脱衣服的窸窣声 → 立刻蹲进水里躲藏（生存本能）
   - 看到是蓝色制服（O级）时，先产生恐惧（"比之前的绿衣服等级高"）
   - 然后才是"哇好大"的好色反应——**恐惧和色欲同时存在**，让读者感受到他在两种冲动之间摇摆

3. **水中战斗强化求生恐惧**
   - 河马说"上级要你死"后，黑狗的恐惧要具体："他们知道我不怕刀？"
   - 被按进水里时，强调溺水恐慌（"呛水了！喘不上气！"），而不仅仅是对肉体的触感
   - 烈火掌触发是**绝望中的意外**（手指乱抓滑入股沟），不是主动寻欢
   - 杀死河马后，黑狗的反应不只是"又死了啊"，还要有"差点淹死……"的余悸

4. **战利品触发认知升级**
   - 命令纸条"建议采用窒息/压制战术"让黑狗产生警觉："他们知道刀子捅不死我……那下次会不会更危险？"
   - 穿上蓝制服时有复杂心理：太大不合身，但"至少能骗一骗"
   - 对防水地图产生好奇："这是下山的路？还是他们的巡逻路线？"

5. **保留诗意画面**
   - 水中白色云雾、把河马当肉垫躺等经典画面保留，但黑狗躺上去的理由可以是"累瘫了"而非单纯"好玩"

**保留核心情节**：河边洗澡遇河马，水中战斗，获得蓝制服、身份牌、地图、命令纸条。

### 第五章：山脚客栈（ch-5-mountain-inn.md）

**当前问题**：黑狗穿着敌制服大大咧咧进客栈，无视角落里的呼吸声。

**修改要点**：

1. **选择客栈有理由**
   - 黑狗需要找个地方研究地图和命令纸条（"得弄清楚他们在哪搜我"）
   - 他选了废弃客栈，因为"没人住的话，兽盾的人应该不会来查"
   - 进入时小心翼翼，先贴着门听了一会儿

2. **发现豹兽人后的紧张**
   - 听到呼吸声时，黑狗的肌肉应该绷紧，准备逃跑或偷袭
   - 但身体太累了，反应慢了半拍
   - 豹兽人先开口喊"长官"，黑狗愣住——这是**意外**，不是他计划好的

3. **将计就计的心理层次**
   - 黑狗的第一反应："他认错人了？"
   - 第二反应："等等，这蓝衣服……"
   - 第三反应（表面镇定，内心慌乱）："先别拆穿，看看能不能套情报"
   - 他的"长官"表演是**边演边学**，不是胸有成竹

4. **服务场景中插入情报搜集**
   - 黑狗在享受服务的同时，可以问豹兽人关于"搜捕黑色犬科"的任务细节
   - 豹兽人的谄媚回答让黑狗了解到：低层士兵不知道自己是谁，只知道"抓黑狗"
   - 这让黑狗的身份追查动机更强烈："他们为什么要杀我？我到底是谁？"

5. **放走豹兽人的动机更复杂**
   - 保留"今天心情好"的任性底色
   - 但加入一层："这家伙什么都不知道，杀了也没用"
   - 给鞋垫和钱的行为保持"孩子气的残忍/温柔"，但结尾的命令（"拖住黑狗"）要让黑狗自己都觉得好笑——"他根本不知道我就是"
   - 这种黑色幽默需要建立在黑狗**清醒地意识到自己在演戏**的基础上，而不是纯粹的孩子过家家

6. **结尾强化下一步目标**
   - 离开客栈时，黑狗看着调度表，产生一个模糊的计划："R级小队……得避开这些时间"
   - 让他从一个"被动挨打"的角色，变成"虽然还是很混乱，但至少想活下去"的角色

**保留核心情节**：客栈误认，豹兽人服务换命，获得调度表、食物、钱。

## 笔风维持检查清单（每章修改后必查）

- [ ] 第三人称紧贴黑狗感官，无"他心想"等过渡
- [ ] 内心OS直接呈现，如弹幕（"妈的""完了""哇"）
- [ ] 无游戏术语（精槽、系统提示、处决状态）
- [ ] 无诗意修辞（"月光如流水""命运的重锤"）
- [ ] 无道德判断（"可耻地硬了"→"爽到棍棍立了起来"）
- [ ] 情色描写直白露骨，器官名称直接
- [ ] 战斗靠意外、滑倒、本能触发，不靠精密计算
- [ ] 射精=死亡机制保持，股数/温度/气味细节到位
- [ ] 白袜元素保持（长筒、盾型logo、脚汗味、袜底藏钱）
- [ ] 尸体不腐设定保持（无尸臭、无僵硬）
- [ ] 黑狗仍称敌人"大哥""好汉"等带有底层市井气息的称呼，而非"猎物""废物"

## 验证方法

修改完成后，逐章回答以下读者反馈中的核心质疑：

1. **"主角选择了'或'"（战或逃）**：修改后的黑狗遇敌时，是否有"先想躲/逃/对策"的生存冲动？
2. **"色欲肘击了生存逻辑"**：色欲是否是作为"干扰项"而非"唯一驱动力"出现？
3. **"前后人物性格差别"**：修改后的Ch3-Ch5黑狗，能否与Ch1-Ch2的黑狗重叠到同一个形象上？
4. **"失忆不太能合理化"**：黑狗的行为是否有了"当下动机"（查卡片、躲追杀、找安全处）作为支撑？
5. **"像换了一个角色"**：黑狗是否仍然是"失忆好色小鬼"，但同时也是一个"想活下去的失忆好色小鬼"？

如果以上5个问题都能给出"是"，则修改成功。
