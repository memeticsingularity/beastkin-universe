# 墨犬·第二卷：猎网（武林视角线）总体设计

> 日期：2026-05-22
> 定位：lanse 期待的"杀手方承载创意 + 死亡无价值"美学回归
> 视角：第三人称限知，每章紧贴该章武林人士的感官

---

## 一、世界观可用元素梳理（基于原作设定集）

### 1.1 可用势力（江湖生态）

| 势力 | 代表武功 | 特点 | 第二卷用途 |
|------|---------|------|-----------|
| **特工局系** | 银针封穴、北斗泄阳针法 | 组织严密，正派背景 | 可出场 1–2 人作为"正道追杀者" |
| **炎魉系** | 灼流暗劲 | 赏金猎人组合，黑白制服 | 可作为高端战力标杆 |
| **独立赏金猎人** | 各异 | 单干，风格极端个人化 | **主力承载方**，每章一个 |
| **暗室（预留）** | 暗杀术 | 尚未详细设定 | 第三卷再展开 |

> 核心原则：第二卷的"武林"不是单一组织，而是**松散的江湖猎网**——各路人马因不同原因追查墨犬下落，彼此未必认识，甚至互相竞争。

### 1.3 可用武功/技能（杀手方创意池）

| 武功 | 来源 | 效果 | 色色化用法 |
|------|------|------|-----------|
| 银针封穴 | 特工局 | 扎穴位使敌人无法动弹 | 封精关，想射射不出，折磨至崩溃 |
| 北斗泄阳针法 | 特工局顶级 | 七针齐下瞬间精槽满 | 直接引爆，瞬间射精死亡 |
| 灼流暗劲 | 炎魉 | 内劲打入体内，握持肉棒传输 | 测量功力——看猎物能坚持几秒 |
| 影袭 | 潜行系 | 瞬移到敌人背后 | 从背后突袭，点穴后玩弄 |
| 点穴/寸止 | 墨犬体系 | 按压穴位中止生理反应 | 让对方在边缘反复，不给他射 |
| 幻术/迷香 | 原创 | 精神控制 | 幻觉中的自慰直至精尽 |
| 毒功 | 原创 | 毒入精关 | 毒发时伴随射精暴毙 |

| 钢丝指环 | 勒颈 | 窒息快感同步 |
| 烙铁 | 烫灼敏感部位 | 疼痛转化为精槽 |
| 抑制棒/跳蛋 | 远程遥控震动 | 塞入后穴，遥控折磨 |

## 二、对轴方案（与第一卷时间线对齐）

### 2.1 核心设定

- 墨犬身体原主人是"武林败类"，已吸收多人能力，**在武林中有仇家/悬赏**
- 夺舍后（黑狗）被**武林和兽盾双重追杀**
- 武林追杀者的信息来源**滞后于兽盾公司**——兽盾有对讲机、编号系统、公司情报网；武林靠江湖传闻、武功感应、线人

### 2.2 时间线对轴

```
第一卷（主角线）          第二卷（武林线）
─────────────────────────────────────────────────
Ch.1 黑狗洞穴醒来         武林追杀者甲从北方启程，
                         收到"墨犬重现"的线报
                         
Ch.2–Ch.7 下山途中        武林追杀者乙在茶棚/客栈
                         打听消息，顺手杀兽盾兵

Ch.8 到达青石镇           武林追杀者丙发现兽盾营地
                         （Ch.10 夜袭的前奏）

Ch.9 白虎审判日           武林多路人马向青石镇靠拢

Ch.10 武林夜袭营地        【双线交汇点】
                         狐陈媚、蛇刘青战死
                         其他追杀者继续追踪

Ch.11–Ch.17 收编团队      武林追杀者丁/戊/己
                         从其他方向追查，
                         一路杀兽盾兵，
                         最终锁定青石镇
─────────────────────────────────────────────────
                         第二卷尾声：
                         各路追杀者逼近青石镇
                         → 第三卷交汇决战
```

### 2.3 单元剧格式

每章开头用**极简标注**定位时间与空间：

```
某处矿山。三天前，黑狗还在山腰挣扎。
```

或：

```
白之都后街。与黑狗抵达青石镇同日。
```

这样读者自然理解这是猎网的另一根线，不需要额外解释。

## 三、武林人士设计模板

### 3.1 设计维度（每章都要换）

| 维度 | 说明 | 示例 |
|------|------|------|
| **物种** | 任意，充分发挥多样性 | 蛇、狐、猴、鹰、蝎、蛛 |
| **体型** | 精瘦/精壮/矮小/高大均可 | 精瘦蛇、矮壮猴、修长狐 |
| **武功** | 一个核心特色武功 | 点穴、毒功、幻术、暗器 |
| **性格** | 杀人风格 | 冷酷/玩味/羞辱/任务型 |
| **目标** | 追查墨犬的动机 | 报仇/悬赏/清理门户/夺功 |

### 3.2 与兽盾兵的互动格式（色色层）

**避免秒**：武林人士遇到兽盾兵后，**不能直接击杀**，必须有前戏：

1. **遭遇**：兽盾兵发现入侵者，摆出战斗姿态（粗壮肉体紧绷）
2. **压制**：武林人士用武功控制/削弱（点穴、毒、幻术）
3. **玩弄**：利用武功制造特殊刺激（不是单纯的肉体摩擦，而是"武功+性"）
4. **死亡**：射精死亡，细致描写
5. **善后**：用尸体擦手、顺手推开、塞容器、腿露外面

### 3.3 兽盾兵出场规范（lanse 标准）

- **物种**：熊、虎、牛、野猪为主；壮狗少量
- **体型**：粗壮、肥胖、极壮
- **不写背景故事**：出场即死，不需要过去
- **可以有名字**：如雷爪-虎兽人
- **可以写挣扎求饶**
- **必须写死后处理**

## 五、笔风注意事项

### 5.1 与第一卷的区别

| 维度 | 第一卷 | 第二卷 |
|------|--------|--------|
| 视角 | 黑狗（失忆、冲动、好色） | 各章武林人士（清醒、有目标、武功娴熟） |
| 节奏 | 逃亡求生，被动触发 | 主动猎杀，掌控全局 |
| 色色 | 即兴、混乱、意外 | 精心设计、武功加持、处决美学 |
| 死亡 | 憋精功复活（调节期） | **不可逆死亡，尸体无价值**（lanse 模式） |

### 5.2 必须遵循的规范

- **第三人称限知**：紧贴该章武林人士的感官
- **内心 OS 直接蹦出**：不加引号
- **口语化到极致**
- **严禁游戏化术语**：不用"精槽""处决状态"等词
- **死亡无价值**：不写兽盾兵的过去，死后像垃圾处理
- **色色细致度回升**：回到 Ch.1–Ch.2 的感官密度
