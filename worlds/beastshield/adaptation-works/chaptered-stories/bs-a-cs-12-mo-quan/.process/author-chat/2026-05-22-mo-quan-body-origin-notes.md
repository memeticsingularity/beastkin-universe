## 二、墨犬本体身份设定

### 2.1 夺舍前的身份

| 项目 | 内容 |
|------|------|
| **种族** | 黑色犬科兽人 |
| **身份** | **武林败类**（非首席，非英雄） |
| **地位** | 暗室成员，但**还不是十座之一**，更不是首席 |
| **核心能力** | **吸收别人的能力为己用**——已吸收多人能力，包括金钟罩、烈火掌、寸止等 |
| **特殊经历** | 曾吸收一个**会灼流暗劲的徒弟** |
| **性格推断** | 好色、贪婪、不择手段（否则不会去学"夺舍"这种邪门功法） |

### 2.2 "学了技能的弟子"

lanse 的原话揭示了一个关键反转：

- **墨犬不是天生强者**，他原本只是一个**"学了夺舍能力的弟子"**
- 他学夺舍的目的可能是为了**吸收更多能力**，变得更强大
- 他在试图**后入吸收一个年轻人**（夺舍功法持有者）时，**反被夺舍**
- 年轻人的灵魂进入墨犬的身体，墨犬的原灵魂被驱逐（成为洞穴里的娇小尸体）

这意味着：
- **墨犬的"强"是偷来的/吸来的**，不是修炼来的
- 武林追杀他的动机之一可能是**清理门户/为被吸收者报仇**
- 他的身体虽然强大，但**灵魂层面是个小偷**

### 2.3 身体等级

- **"差不多最强的肉体"**——因为吸收了太多能力，身体已被改造到极致
- 吸收能力后外观会变化：体型变大、变硬、变红（取决于吸收的能力类型）
- 这具身体对各种武功有**肌肉记忆**，但新灵魂（黑狗）无法主动驾驭

## 三、夺舍机制详解

### 3.1 触发条件

| 条件 | 说明 |
|------|------|
| **方式** | 后入（anal sex） |
| **前提** | 对方需**打残或打晕**，失去反抗能力 |
| **结果** | 后入会**杀死**对方，同时完成夺舍/吸收 |
| **选择标准** | 不是见人就吸，要**挑强者**；也可以**捡漏**（别人杀死的尸体，趁热吸收） |

### 3.2 一次性技能

- 夺舍是**一次性技能**，不能反复使用
- 原主（年轻人/黑狗的灵魂）只是**好奇学了**，没想过用，结果**被动触发**
- 被动触发的原因：墨犬试图后入吸收年轻人时，年轻人的夺舍功法被动反弹
- 夺舍后，**年轻人不能再夺舍别人**——这具身体就是他唯一的容器
- 失忆的副作用：年轻人（黑狗）甚至不知道自己曾经夺舍过

### 3.3 用户倾向（与 lanse 的协商）

用户倾向于**后入与夺舍解绑**：
- "单纯的后入不会夺舍"
- 需要**额外操作**或条件才能触发夺舍/吸收
- 避免限制现有情节中已有的后入描写

**当前共识**：普通后入只是性行为，不会触发吸收；吸收需要特定条件（如对方失去反抗能力 + 触碰前列腺 + 内劲运转）。

## 四、与暗室的关系

### 4.1 暗室制度

| 项目 | 内容 |
|------|------|
| **正式名称** | 暗室（The Darkroom） |
| **核心制度** | **十座**——按暗杀战绩排名，前十位上座 |
| **最高指令** | **通室令**——紧要关头才能颁布的最高权限严令 |
| **与兽盾关系** | **敌对竞争**。兽盾保镖行业兴起后，暗室生意难做 |

### 4.2 墨犬在暗室中的地位

- 夺舍前：**普通成员**，不是十座，更不是首席
- 夺舍后（黑狗）：走投无路，**进入暗室，慢慢才变成首席**
- 首席 = **武功最高**，但**不管事务**；管事的是**四座（年长老）**
- 首席**不止一任**，只是职位，黑狗/墨犬只是"这一任"首席
- **熊猫角色**可安排在黑狗进入暗室后出场

## 五、与武林的关系

### 5.1 武林追杀墨犬的原因

1. **清理门户**：墨犬作为"武林败类"，用邪门功法吸收同门/同道的能力，武林要除掉他
2. **报仇**：被墨犬吸收过的武林人士的师门/亲友来寻仇
3. **夺功**：想要夺取墨犬体内已吸收的各种武功
4. **悬赏**：墨犬的人头在武林/暗室/甚至兽盾那里都有悬赏

### 5.2 追杀者的构成

lanse 明确指出：
- 黑狗是**"被武林和兽盾双重追杀的怪物"**
- 武林追杀者**不是单一组织**，而是各路江湖人士：
  - 特工局（银针封穴系）——正派背景，清理门户
  - 炎魉（灼流暗劲系）——赏金猎人，拿钱办事
  - 独立赏金猎人——为悬赏而来
  - 暗室外围/敌对势力——竞争或仇杀

### 5.3 追杀者的信息来源

- **兽盾**：有对讲机、编号系统、公司情报网，效率高，先找到黑狗（Ch.1 洞穴）
- **武林**：靠江湖传闻、武功感应、线人，信息滞后，所以 Ch.1 没有出现
- Ch.10 武林夜袭营地 = 武林追杀路线上的一个节点——他们追踪墨犬踪迹时发现了兽盾营地

## 六、对第二卷创作的影响

### 6.1 追杀动机多样化

每章的武林人士可以有完全不同的追杀动机：
- **报仇型**：师兄被墨犬吸收了能力，来寻仇
- **悬赏型**：听说墨犬人头值大钱
- **清理门户型**：武林正派，不能容忍"夺舍"这种邪功
- **夺功型**：想杀了墨犬，夺取他体内的能力
- **误打误撞型**：本来在打兽盾，意外发现墨犬线索

### 6.2 追杀者的认知差异

- **不知道夺舍已经发生**：大多数追杀者追的是"墨犬"这具身体，不知道里面已经换了一个年轻人的灵魂
- **发现异常**：部分敏锐的追杀者可能发现"墨犬变弱了/风格变了/失忆了"
- **第三卷冲击点**：当武林人士最终面对黑狗时，发现他不是那个"武林败类"，而是一个失忆的、好色的、手下留情的"平民"

### 6.3 黑狗的吸收潜力

lanse 的原话：
> "别人杀死的尸体 他趁热也可以"
> "前期他还不是很强"

这意味着第二卷中，黑狗可以通过**捡漏武林人士杀死的兽盾兵尸体**来悄悄吸收能力，为第三卷的实力提升做铺垫。
