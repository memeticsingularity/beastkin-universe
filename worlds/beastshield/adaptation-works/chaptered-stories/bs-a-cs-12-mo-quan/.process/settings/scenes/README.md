# 第二卷场景档案（武林猎网 vs 兽盾）

> 墨犬项目第二卷核心战斗场景库。
> 每个场景对应一章（或一章中的核心战斗），包含布局、敌人配置、猎手组合与结伴理由。
> 敌人配置遵循：1名高级士官（蓝/白/黑制服）+ 10~16名绿制服杂兵。
> 兽盾兵种族白名单：熊、虎、牛、猪、壮狗。

## 核心设计原则

1. **每场战斗都要有"过程"**：不秒，有交锋、有喘息、有转折
2. **兽盾兵死后像垃圾处理**：用尸体擦手、顺手推开、塞容器
3. **猎手的物种特性必须体现在战斗中**：牛的冲撞、蛛的缠绕、龟的耐耗
4. **结伴必须有理由**：不是硬凑，是命运/利益/仇恨的交汇
5. **色色细致度**：武林猎手方承载创意，兽盾兵方保持规范
