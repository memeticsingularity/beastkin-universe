# 墨犬（续写）· Lanse 风味落地指南

> 本文件是 `bs-a-cs-12-mo-quan` 项目专属的 lanse 风格适配手册。
> 母本：[lanse-style-checklist.md(../../../../../../author/001-lanse/style-analysis/lanse-style-checklist.md)
> 分析基准：[lanse-writing-style-analysis.md(../../../../../../author/001-lanse/style-analysis/lanse-writing-style-analysis.md)
>
> 用途：续写时逐项自检、润色时对照修正、评审时核查偏差。

## 一、本作定位：与主线 lanse 的关系

墨犬是 lanse 宇宙中的 **支线（side story）**，与主线三部曲共享以下公约：

| 共享元素 | 说明 |
|----------|------|
| 制服编码 | G=军绿，O=蓝/蓝白，E=黑，白=特殊 |
| 射精即死 | 核心机制，贯穿始终 |
| 白袜母题 | 兽盾员工视觉标识 |
| 精液美学 | 量、射向、质地、终态精细描写 |
| 短段落 | 1-3 句一段 |
| 第三人称 | 本作采用（与主线第二/三部一致） |

**但本作有以下独特性，决定了风味指南必须做本地化调整：**

| 本作特征 | 对风格的影响 |
|----------|-------------|
| **失忆主角视角** | 黑狗的"天真好色"语感不同于魔影的轻浮或大奔的淳朴 |
| **能不杀就不杀** | 每章不一定有处决——没有处决时，需用其他感官场景补足"lanse 味" |
| **憋精功假死** | 死亡的可逆性改变了射精描写的功能（假死 vs 真死写法不同） |
| **团体养成线** | 后期章节（Ch.14–17）转向室内/安顿场景，新角色登场公式的触发频率降低 |
| **平民登场** | 白羊兽人这类非兽盾角色，公式不适用，但需保留感官细节 |

## 二、硬性要求（本作必须满足）

### 2.1 白袜——每章至少 1 次

这是**最容易被遗漏、也是最关键的硬性要求**。白袜不只在新角色登场时出现，还应渗透在以下场景中：

| 场景类型 | 白袜插入方式 | 示例 |
|----------|-------------|------|
| 动作/战斗 | 角色蹬地发力时 | "穿着白袜的脚尖在泥地上犁出一道沟" |
| 对话/审讯 | 对方蹲/跪/坐时 | "他蹲下来，白袜上缘勒进小腿肉里" |
| 室内/休息 | 角色伸腿、脱靴时 | "灰牛翻身，白袜裹着的小腿从毯子下露出来" |
| 过渡/移动 | 上车、爬梯、跨步时 | "他踩上车沿，白袜绷在小腿上勒出一道红印" |
| 情色场景 | 腿被架起、掰开时 | "白袜包裹的粗腿被架到肩上，袜底盾型logo对着脸" |

**原则**：同一章有多次白袜描写时，第二次和第一次视角/状态不同（静态→动态→触感→污损）。

**Ch.14 缺失补位方案**：灰牛躺宿舍时露出的白袜小腿、黑狗踩卡车踏板时裤腿上滑露出白袜、搬尸时白袜沾血污。

**Ch.17 缺失补位方案**：灰牛或河马在宿舍伸腿时露出白袜、白羊兽人视角看到绿制服的白袜、黑狗跨过门槛时裤腿上滑。

### 2.2 新角色登场公式

每个**新登场的兽盾角色**必须走完公式：

```
物种 → 制服色 → 体型（胸肌/腰/背） → 下体鼓包 → 白袜 → 鞋
```

**可接受的变化**（来自 `lanse-style-variants.md`）：

| 变体 | 适用场景 |
|------|---------|
| 从下往上写 | 先看见腿/袜子/鞋，再往上看到制服和脸 |
| 打散成两段 | 一眼看制服和物种，交手后补下体和白袜 |
| 只写前两步 | 非当前焦点角色，或远处未走近的角色 |

**不可接受**：完全不写公式，或公式信息严重缺失。

### 2.3 对话标签——统一用「道」

| ✅ 正确 | ❌ 错误 |
|---------|--------|
| "。.。"他道 | ~~"。.。"他说~~ |
| "。。。"他颤声道 | ~~"。。。"他颤抖着说~~ |
| "！"他惊道 | ~~"！"他惊讶地说~~ |
| "什么？"他问道 | ~~"什么？"他问~~ |

**允许的修饰范围**（占全部对话标签的 ≤20%）：
- 「低声道」「颤声道」「厉声道」「喃喃道」
- 「吼道」「怒道」「笑道」「冷声道」

**禁止**：用「说」「问」「答」「解释」「回应」作对话标签。

**注意**：黑狗的内心独白（无引号、直接叙事呈现）不受此限制。

**待修正**：Ch.17 "灰牛低声解释" → "灰牛低声解释道"

### 2.4 省略号——统一用「。。。 」

| 用途 | 格式 | 示例 |
|------|------|------|
| 恐惧/犹豫 | 汉字全角+空格 | "你。。。你要干什么。。。" |
| 气喘吁吁 | 三个点 | "别。。。别。。。要射了。。。" |
| 断气/死亡 | 三个点 | "呃。。。啊。。。呃。。。" |

**禁止**：用单个点「…」或英文省略号「...」替代。Ch.1–2 中偶有「…」和混用，后续章节统一走三个点格式。

### 2.5 精液描写永远不省略

每次射精必须写清楚以下参数中的至少 3 项：

- **量**：股数（3股/7股/十几股）或总量描述
- **射向**：何处（肚皮/脸上/墙上/体内）
- **质地**：浓/稀/拉丝
- **力度变化**：初射有力→末股流淌
- **终态**：停了/还在流/顺着往下淌

**假死 vs 真死的精液处理不同**：

| 类型 | 精液描写特征 |
|------|-------------|
| 真死（肥豪） | 射到精尽，量全、色浓、终态硬壳 |
| 假死（黄豹/老灰） | 射了一部分后中止，残精描述偏"半截" |
| 假死（白虎） | 射了大量但仍存活，终态写"还在渗"而非"干涸" |

## 三、描写系统：本作执行细则

### 3.1 制服颜色编码

| 颜色 | 等级 | 本作出现的角色 |
|------|------|---------------|
| 军绿 | G级 | 熊兽人（Ch.1）、肥豪/老灰（Ch.3）、黄豹（Ch.9）、灰牛/黑獒/褐鹿等 |
| 蓝/蓝白 | O级 | 河马（Ch.4） |
| 黑 | E级 | 白虎（Ch.9） |
| 白 | R级/特殊 | 水牛（R级，Ch.6）、杜宾（R级，Ch.6） |
| 无制服 | 平民 | 白羊兽人（Ch.17） |

### 3.2 高频用词表（本作优先选用）

| 部位/概念 | 首选词 | 禁止 |
|----------|--------|------|
| 腿部 | 粗腿、粗壮的双腿、白袜裹着的小腿 | 腿（裸用） |
| 生殖器 | 肉棒、XX鞭（虎鞭/熊鞭/牛鞭） | 阴茎（少用）、鸡巴（除非黑狗内心） |
| 射精口 | 马眼 | 尿道口 |
| 精液 | 浓精、精液 | 白浆、白浊（可偶尔用） |
| 胸部 | 胸肌、乳头 | 乳首（极少用） |
| 下体轮廓 | 鼓包、帐篷、轮廓 | 无 |
| 死亡状态 | 精尽、精关失守 | 无 |

### 3.3 本作特有的高频词

| 词 | 使用场景 |
|----|---------|
| 精关 | 内劲控制的核心概念 |
| 金钟罩 | 防御功法 |
| 烈火掌 | 攻击/触发功法 |
| 寸止 | 控制功法（本作特色机制） |
| 憋精功 | 假死功法（本作特色机制） |
| 内劲 | 气功设定 |
| 点穴封喉 | 封喉手法（褐鹿） |
| 死透/没死透 | 黑狗确认死亡的常用内心话 |

### 3.4 环境描写的度

lanse 的环境描写偏弱。本作可以适度强化环境感官，但遵守以下限制：

- **光线**：可写（月光/晨光/暮色/火光/手电筒），不超过 1 句
- **气味**：可写（精液腥膻/汗味/泥土/血腥），经常写更好——这是色感的一部分
- **温度**：可写（尸体的温度/水冷/体热），不超过 1 句
- **空间布局**：简单交代即可（"左边是货架，右边是柜台"）
- **禁止**：纯风景描写（超过 3 句的环境描写就太多）

## 四、黑狗的语体规范

黑狗的心理语体是"lanse 味"在本作中的重要载体。以下是他区别于其他主角的特征：

### 4.1 内心独白的风格

| 特征 | 合格示例 | 不合格示例 |
|------|---------|-----------|
| 短促、口语化 | "哇，好壮！" | "这只熊兽人的体魄真是令人赞叹" |
| 好色直白 | "好烫。。。" / "好硬。。。" | 太含蓄 |
| 实用主义 | "留着说不定还有用" | 道德思辨 |
| 对自己力量茫然 | "幸好又有那怪保护了" | 准确分析武功原理 |

### 4.2 原作独特的俏皮味——刻意保留

Ch.1 原作中有一些独特的俏皮比喻——"奶花"、"放烟花"、"像是一个撒娇的小孩"。这些在续写（Ch.3–17）中几乎完全消失了。**这是需要刻意回归的方向。**

黑狗的内心独白不仅应该"短促、好色"，还应该带一种**天真的俏皮感**——他不是冷酷的杀手，而是一个失忆的、对世界充满好奇的"大号幼犬"。

| 原作比喻（Ch.1–2） | 续写现有风格 | 应回归的方向 |
|-------------------|-------------|-------------|
| "浓白的奶花在绿帐篷尖端炸开" | "精液一股接一股喷出来" | 保留精液描写硬指标 + 叠加俏皮比喻 |
| "如同放烟花一般" | — | 黑狗看到大量射精时可类比"放烟花" |
| "像是一个撒娇的小孩" | "像泄了气的皮球" | 减少功能化描述，增加拟人/俏皮比喻 |
| "这简直是天堂！" | "哇，好壮！" | 保留，但可更夸张（"爽死了！"） |
| "好喜欢！" | — | 面对壮兽人可回归这种直白的花痴感叹 |

**具体执行规则**：
- 每 3–4 章至少出现 1 次黑狗式的俏皮比喻
- **每次比喻要有新意**，不能照搬原作或重复自己。原作用过"奶花""放烟花"，就不要再用；续写用过"喷泉""水枪"，下一章就要换别的
- 俏皮比喻集中在**黑狗内心独白**中，不在叙事层出现
- 续写中新增的俏皮比喻应保持"黑狗本色"：带点幼稚、好色、但不邪恶
- **比喻素材来源**：日常生活物件的夸张化（水枪、喷泉、包子、小山、腊肠、铁桶……），避免文艺化比喻

### 4.3 对话中的黑狗

- 对下属：简短、随意、爱起外号
- 对敌人：威胁中带调侃
- 对壮兽人：花痴隐藏在执行任务中
- 需要保持 lanse 式"XX道"标签

## 五、处决/情色场景模板

### 5.1 标准处决（真死）

```
制服（掌击/点穴/扑倒） → 
掏出下体（拉开裤头） → 
刺激开始（揉/撸/搓） → 
求饶出现（"要射了"） → 
临界点（身体绷紧） → 
射精（第一股→后续多股→力度减弱） → 
死亡确认（喘声变低→头歪→不动了） → 
战后处理（擦拭/搜刮/评价）
```

### 5.2 假死（憋精功）

```
制服 → 刺激 → 射出一部分 → 精关本能闭锁 → 
假死状态（无呼吸/无心跳/但体内有微弱生机） → 
（之后某章）被外力唤醒或自然苏醒
```

**假死时的精液描写不同**：不是"射干净"，而是"射到一半停住"，残精的描述重点是"半截"、"马眼半张"、"龟头上挂着干涸的残精"。

### 5.3 团队内情色（非致死）

Ch.16–17 以来的"同室戏"场景中，情色元素以**半硬状态、性压抑、感官擦边**为主：

- "牛鞭在湿裤衩里若隐若现——还半硬着"
- "他的裤裆湿了一片——前列腺液从吓软的棍棍里渗出来"
- 不展开成完整处决，但保留感官细节

## 七、章节结尾处理

### 7.1 故事正文结尾

lanse 的章节结尾倾向于**简洁的行动或一句评价收束**，不抒情。

| ✅ 合格 | ❌ 不合格 |
|--------|---------|
| "十种呼吸声里多了饱腹后的满足。" | "这是一个充满希望的开始" |
| "等待夜幕降临。" | "命运的齿轮开始转动" |
| "第一顿。才刚开始。" | 抒情总结 |

### 7.2 「故事评述与感慨」系统

本作每章末尾的「故事评述与感慨」「他们最后的故事」「还活着的人们」是**项目管理工具，不是故事正文**。规则：

- 不属于 lanse 风格判定范畴
- 评述部分避免抒情（平实记录即可）
- 保持与正文一致的术语（精关、精尽、憋精功等）

## 八、写作前自检清单

下笔一个场景前，快速过一遍：

- [ ] 这一章白袜出现了吗？
- [ ] 如果有新兽盾角色登场，公式走完了吗？
- [ ] 对话标签是「道」还是「说」？
- [ ] 省略号用了「。。。」格式吗？
- [ ] 如果有射精，量/射向/质地/终态写了几项？
- [ ] 段落超过 3 句了吗？
- [ ] 制服颜色正确吗？（G=军绿，O=蓝，E=黑，R=白）
- [ ] 黑狗的内心独白是短促/口语化的吗？
