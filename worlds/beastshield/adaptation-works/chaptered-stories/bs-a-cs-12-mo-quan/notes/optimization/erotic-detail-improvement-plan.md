## 二、提升方案

### 方案1：恢复"说明书式"器官描写

**射精前**（至少3步）：
1. 包皮被精液/前列腺液撑开的过程
2. 龟头从包皮中滑出的分步（先露冠、再全出、颜色变化）
3. 卵蛋收紧上提、阴囊皱缩

**射精中**（带时间层次）：
- 第1股：最猛、最远、颜色最深（憋久了）
- 中间3-5股：持续、稳定、量最大
- 最后2-3股：无力、距离近、颜色变淡、变成滴落
- **停顿感**：每一股之间的肌肉抽搐、呼吸间隙

**射精后**（常被忽略）：
- 龟头从紫红 → 暗红 → 苍白
- 包皮慢慢回缩盖住龟头（或盖不住，因为太大）
- 残余精液从马眼滴落、沿阴囊流淌
- 阴囊松弛、卵蛋下垂

**示例写法**（水牛R-1可改进）：
> 水牛兽人再也压不住精关。他白色裤裆里那根酱红色的牛鞭先是猛地一跳，隔着湿布都能看见龟头正在急剧胀大，紫红色的冠部把包皮撑得薄如蝉翼——然后"噗"地一声，包皮被精液顶开，龟头整个弹了出来，肿胀发亮，马眼已经张开了。第一股精液射得又猛又远，穿透白色布料，在空中划出一道浓黄的弧线，"啪"地砸在黑狗胸口，烫得他缩了缩脖子。紧接着第二股、第三股……一股比一股近，一股比一股稀，最后几股只是顺着龟头往下淌，滴在白袜袜口上，把盾型iogo泡成了奶黄色。

### 方案2：增加黑狗的"主动感官探索"

原作中黑狗是**好奇的探索者**，不只是被动接受。续写中他越来越"熟练"，反而少了那份天真探索感。

**必写动作清单**（每场色色戏至少选2个）：
- [ ( **凑近闻**：射完后凑到龟头/精液前闻气味，点评"好咸""好浓""和熊的不一样"
- [ ( **舔手指**：沾了精液后舔指尖，皱眉或满意
- [ ( **捏睾丸**：射完后捏卵蛋感受"空了"还是"还有"
- [ ( **包皮把玩**：用手指拨弄对方包皮，看龟头是否敏感
- [ ( **量温度**：手掌贴上去感受"比老熊的烫""比虎的凉"
- [ ( **数股数并点评**："才五股？比肥豪少多了"
- [ ( **对比**：和之前杀过的敌人做天真对比

### 方案3：恢复"尸体性利用"

这是原作最独特的细致度来源之一。Ch.3后黑狗杀完人直接搜身，缺少"死后性互动"。

**可选场景**（不每场都写，但每隔1-2章必须有）：
- 射完还没死透时，黑狗凑上去吮吸残余精液
- 把脸埋进尸体裆部深吸一口气，评价体味
- 用手指继续拨弄尸体的龟头，看还会不会抽搐
- 用尸体的白袜擦拭自己或对方的精液
- 坐在尸体肚皮/胸口上休息，同时把玩尸体性器官

**尺度边界**（保持不变）：
- ✅ 尸体保持温热柔软（兽盾保鲜机制）
- ✅ 吮吸、拨弄、擦拭
- ❌ 尸臭、僵硬、腐烂

### 方案4：强化主角快感实时堆叠

Ch.5–Ch.6 中黑狗作为"承受方"（被口交、被后入）时，自己的快感写得不够密。

**必写清单**（黑狗被服务/被进入时）：
- [ ( **自己的棍棍状态**：立起、翘角度、顶在布料上的形状
- [ ( **体内感受**：被顶到的具体位置（"顶到某个点""胀满感从深处蔓延"）
- [ ( **体温变化**：皮肤发烫、耳朵发热、手心出汗
- [ ( **本能反应**：收缩后庭、夹紧、腰部扭动、脚趾蜷缩
- [ ( **内心OS**："这……这简直是天堂"级别的实时弹幕

### 方案5：环境杀的"感官加倍"

ianse 表扬了环境杀（水下、贴紧），这是续写的创新优势。但环境杀可以**更色**。

** underwater（水下）**：
- 精液在水中形成"浓白云雾" ✅ 已有
- 可加：精液被水流拉成"丝状"→"带状"→最终消散的时间感
- 可加：河水被精液染得"温热"，黑狗皮肤感受到的温度变化
- 可加：水下视线模糊，只能看见对方裤裆喷出白色"烟柱"

** confined space（贴紧/压制）**：
- 可加：两人汗液混合的气味、制服摩擦的滋滋声
- 可加：无法躲避的近距离接触，呼吸喷在对方颈部
- 可加：射精后精液在两人身体之间形成"黏合层"

## 三、Ch.7+ 应用建议

### 立即执行（写作时自查）

1. **开写前先定"探索动作"**：这场色色戏里，黑狗会主动闻/舔/捏哪个部位？
2. **射精必写5段式**：包皮撑开 → 龟头弹出 → 第一股（猛）→ 中间股（稳）→ 最后股（无力滴落）
3. **主角快感每200字插入一次**：自己的棍棍、体内感受、体温、内心OS，四选一
4. **每2章至少1次尸体互动**：吮吸、拨弄、坐肚皮上把玩
