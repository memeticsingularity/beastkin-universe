## 故事文件格式（强制 · 动手前必读）

**权威源：** [`docs/spec/11-story-format.md`](../../docs/spec/11-story-format.md)（Beastkin Universe 故事格式规范 **v4.0**）
新建或修改任何故事正文（分章 `ch-*.md`、短篇 `.md`）之前**先读该规范**，不要凭记忆、也不要照抄既有文件——历史遗留里有多种不合规写法。
可复制骨架：`templates/world-template/work-template/forms/{chaptered,short}/chapters/`；
每一块写什么见 skill `.dsh/skills/story-craft`；自检清单见 `.dsh/skills/story-format-guard`。

要点（规范 §1 分章 / §2 短篇）：

| | 分章故事 | 短篇 |
|---|---|---|
| H1 | `# Chapter {自然数} {中文标题}` | `# Story {中文标题}` |
| 分幕标题 | `## 第{N}幕 {幕标题}`（**H2**；无幕形态也合法） | 同左 |
| 结束标记 | `**Chapter {自然数} END**` | `**Story END**` |
| 评述区 | `## 故事评述与感慨` + 三个 `###` 子块 | 同左 |

**顺序固定为**：

```
H1 → --- → nav 行 → --- → > *{卷首语}* → --- → 正文（0..N 幕）
   → --- → > *{卷尾语}* → **Chapter {N} END** → --- → nav 行 → --- → ## 故事评述与感慨
```

- **结束标记恰好出现一次**，且在卷尾语之后、评述区之前；文件末尾不得再有第二个
- `###` 只用于评述区的三个固定子块（`他们最后的故事` / `还活着的人们` / `故事感慨`）
- 同一作品内「有幕 / 无幕」保持统一
- 存量正文的 v4.0 迁移欠债见 [`project-docs/story-format-todo.md`](../../project-docs/story-format-todo.md) §零（不追溯强制）

### ❌ 禁止的旧写法（已全库清除，不得回潮）

| 位置 | 禁止写法 | 应为 |
|---|---|---|
| H1 | `# MS-001: 作品名 - 第N章：标题` | `# Chapter {N} {标题}` |
| H1 | `# 作品名 - 第N章：标题` | `# Chapter {N} {标题}` |
| H1 | `# SS-00N: 标题` | `# Story {标题}` |
| 分幕 | `**Scene-1 {标题}**`（v3.0 旧法） | `## 第1幕 {标题}` |
| 结束标记 | `**第一章完**` / `**第二章完**` / `**终章**` | `**Chapter {N} END**` |
| 结束标记 | `**完**` | `**Story END**` |
| 结束标记 | 两个标记挤在同一行（`**Chapter 15 END** \| **…全文完**`） | 各占一行 |
| 卷尾语 | 写在结束标记之后 | 写在结束标记之前 |

发现以上任一种写法，即视为格式违规，应改为规范写法。

## 兽盾兵行为与对话风格

依据 `world-setting.md`：
- 员工来源：**地痞流氓、有前科者、四肢发达头脑简单**
- 员工素质：**自私自利，五大三粗，内部动辄动手动脚**
- 内部管理：**粗野豪放**
- 站岗状态：偷懒、打盹、抽烟是常态
- 同事关系：缺乏怜悯，嘲笑同事死亡

### 对话风格
- **粗俗带脏字**：他妈、傻逼、老子等
- **句式短、不绕弯子**：命令式、直接威胁
- **O级可以有管理者的傲慢**，但本质上还是粗人，不是文雅反派
- **G级在恐惧时哭爹喊娘**符合人设
- 不要写出精心设计的反派人物的台词感

### 错误示例 vs 正确示例
```
❌ "说凶手往西去了。跟着运输队。你们这些武林蠢货，永远慢三步。"
✅ "往西跑了。跟运输队走的。你们这些练武的傻逼，吃屎都赶不上热乎的。"
```

```
❌ "角是被一根根掰断的。我数了，三下。第一下他还能叫，第二下只剩喘气，第三下——"
✅ "老子在上面全看完了。那黑狗崽子两手抓着他角，咔嚓咔嚓的。"
```

## 写作规则

### lanse 风味硬性要求
- 对话标签优先用「道」（可兼容「说」，不可通篇只用「说」）
- 省略号用「。。。」（三个句号，非英文...）
- 长筒袜每章至少出现1次（白袜/黑袜按等级匹配即可）
- 制服色推荐用「军绿」，可兼容「绿色」

### 死亡/射精描写
- **严禁复制粘贴公式**：每个敌人死亡时的射精反应必须差异化
- 根据死法/武器/姿势差异化：
  - 撞死/摔死/勒死/毒死/咬死各有不同的生理反应
  - 同一武器杀多人时，每个人反应不同（缠脖子/缠腰/倒吊→三种射精方式）
- 差异化手段：射精量/颜色/方式（喷/涌/渗/滴）/是否射得出/神经反射等

### 出场公式（去公式化要求）
- 角色登场信息（物种+毛色+制服+白袜+体型）必须给全
- 但**打散到2-3个段落里**，与行动/对话穿插，不要像checklist一次性列完

### G级杂兵背景限制
- 禁止贫穷务农/被迫养家/攒钱开饭馆设定
- 必须走犯罪/赌徒/盲从打手方向

### 更新入库流程

当作者提供新的 `.txt` 更新文件（例如 `兽盾农家乐 单独第四卷 更新中(N).txt`）时，按以下步骤处理：

1. **读取源文件**
   - 默认位置：`D:\Users\jiangzy\Downloads\兽盾农家乐 单独第四卷 更新中(N).txt`
   - 编码通常为 **UTF-8 with BOM**，读取时使用 `encoding='utf-8-sig'`

2. **拆分为章节 Markdown**
   - 按 `^第[一二三四五六七八九十百千万]+章$` 拆分章节
   - 章节文件路径：`chapters/volume-4/ch-N-english-title.md`
   - 每个段落以全角空格 `　　` 缩进
   - **段落之间必须保留空行**（源 `.txt` 往往没有空行，生成时主动插入）
   - 文件顶部保留返回目录链接、英文标题与一句话摘要

3. **更新索引与状态**
   - 更新 `chapters/volume-4/README.md` 章节列表、简介与最后更新日期
   - 更新项目根目录 `README.md` 的分卷总览（章节数、状态）
   - 如有新角色登场，按角色建档规范创建/更新档案，并同步 `.process/settings/characters/README.md`

4. **更新完整版原文**
   - 更新 `original-text/beastshield-farmhouse-complete.txt` 中对应卷的内容
   - 定位该卷起始行（如 `第四卷  我和我们共同的未来（上）`），保留之前所有卷，替换该卷至末尾
   - 同样遵循：段落前加 4 个半角空格缩进，段落之间保留空行

5. **提交**
   - 提交信息严禁暴露剧情、角色命运或关键转折
   - 示例：`feat: 兽盾农家乐第四卷追加Ch.9-10入库 + 角色档案同步更新`
