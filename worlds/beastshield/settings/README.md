# 设定库 / Settings Library

> 存放《兽盾》世界观的核心设定文档，包括官方设定、推荐正典与故事变体。
> Houses core setting documents for the BeastShield universe, including original settings, recommended canon, and story variants.

---

## 一、目录结构 / Directory Structure

| 路径 | 说明 | Description |
|------|------|-------------|
| [`0-original-setting/`](0-original-setting/) | 官方原始设定 | Official original settings |
| [`1-recommended-canon/`](1-recommended-canon/) | 推荐正典 | Recommended canon |
| [`2-story-specific-settings/`](2-story-specific-settings/) | 故事独有设定（支线/番外） | Story-specific settings |

---

## 二、设定分类 / Settings Categories

### 官方原始设定 / Original Settings

包含世界观原作者提供的核心设定文档：

- 兽盾公司组织架构与职级体系
- 游戏机制（性欲值系统、成长系统、随从系统）
- 主要地点与场景设定
- 核心种族与角色设定

### 推荐正典 / Recommended Canon

经社区整理与验证的推荐正典设定：

- 统一术语表
- 角色档案标准化模板
- 时间线与事件年表

### 故事变体 / Story Variants

不同创作线或改编作品使用的变体设定：

- VR线/元兽御主线变体
- 特定改编作品的世界观调整
- 平行宇宙设定

---

## 三、发现入口 / Discovery

### 按主题筛选 / Filter by Theme

- `组织架构 / Organization`: 兽盾公司、特工局、光照神教
- `游戏机制 / Game Mechanics`: 性欲值系统、成长系统、随从系统、换装系统
- `职级体系 / Rank System`: 绿制服(G)、蓝制服(O)、黑制服(E)、白制服(R)、深蓝制服(W)
- `地点 / Locations`: 白之都、兽盾总部、地下格斗场、新兵营
- `种族 / Races`: 牛、虎、熊、狼、野猪、狗等兽人种族

### 按用途筛选 / By Purpose

- `创作参考 / Writing Reference`: 官方原始设定、推荐正典
- `改编依据 / Adaptation Basis`: 推荐正典、故事变体
- `设定扩展 / Setting Expansion`: 故事变体

---

## 四、使用规范 / Usage Guidelines

1. **原作优先 / Original First**: 以 `0-original-setting/` 中的官方设定为最高依据。
2. **正典引用 / Canon Citation**: 改编作品应引用 `1-recommended-canon/` 中的统一术语。
3. **变体标注 / Variant Labeling**: 使用变体设定时需在作品中明确标注。
