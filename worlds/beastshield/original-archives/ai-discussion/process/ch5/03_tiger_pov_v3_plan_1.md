# 第五章 白虎视角扩写创作思路 v3（整合版）

## 一、扩写定位

**核心机制**：XP解锁系统 + 控射玩法（白牙被探索视角）

**时间线**：两条时间线整合呈现

- 时间线A：第一次（白牙被探索，心理防线被击穿）
- 时间线B：第二次（白牙被熟练处理，主角知道他的弱点）

**核心概念**：

- 白牙不知道自己有隐藏的详细资料可被解锁
- 精槽90%时主角的言语刺激会触发他的心理崩溃
- 白牙的"硬汉外壳"在边缘状态下被逐步剥开

---

## 二、白牙的XP设计（被解锁视角）

### 2.1 白牙（白虎兽人，本段主角）

**XP解锁条件**：

- 精槽90% + 特殊互动：让他"求饶"（打破硬汉外壳）
- 难点：白牙耐受力高，需要持续精准刺激才能让他崩溃

**解锁内容**：

- 习性："外强中干"（欺软怕硬，遇到更强者立刻软弱）
- 隐藏属性：对兽盾公司并非忠诚，只是怕丢工作
- 讽刺点：收保护费时的凶狠全是装的，内心深处厌恶自己

**时间线A（第一次被探索）**：

- 白牙在90%精槽时，主角故意放缓动作，开始言语羞辱
- "你平时不是很凶吗？""只是个欺软怕硬的懦夫？"
- 白牙的心理防线逐步崩溃，最终求饶
- **叮咚！**（主角视角）解锁"外强中干"
- 白牙在死前意识到：对方看穿了自己

**时间线B（第二次被熟练处理）**：

- 主角已经知道白牙的弱点，直接精准打击
- "又要哭了？""纸老虎"
- 白牙崩溃得更快，因为对方太了解自己
- 白牙死前的恐惧：这个人怎么知道我的内心？

---

## 三、两条时间线对比结构

### 第一幕：收保护费（两条线相同）

白牙去武器店收保护费，内心愧疚但表面凶狠。

### 第二幕：发现尸体（两条线相同）

白牙发现老张和老三的尸体，愤怒但无知。

### 第三幕：被伏击（关键差异）

| 阶段   | 时间线A（第一次被探索）     | 时间线B（第二次被熟练处理） |
|------|------------------|----------------|
| 被偷袭  | 从背后被抓住弱点，挣扎      | 同样的偷袭，但对方更精准   |
| 控射   | 被维持在90%，对方放缓动作   | 直接被控在90%，对方熟练  |
| 心理战  | 对方逐步试探："你不是很凶吗？" | 对方直接嘲讽："又要哭了？" |
| 崩溃   | 逐步崩溃："求...求你..." | 快速崩溃，对方太了解自己   |
| XP解锁 | **叮咚！**（主角获得资料）  | 主角已知，直接羞辱      |
| 发现   | 对方看穿了自己的伪装       | 对方怎么知道我的内心？    |

## 四、白牙的心理变化

### 4.1 时间线A：逐步崩溃

**90%精槽时**：

- 白牙还在硬撑，试图保持硬汉形象
- 主角："你平时不是很凶吗？"
- 白牙："我...我只是..."

**言语羞辱阶段**：

- 主角："只是个欺软怕硬的懦夫？"
- 白牙内心：他怎么知道的？不，不可能...
- 白牙："不...不是..."

**心理防线崩溃**：

- 主角："你内心深处知道，你就是个垃圾。"
- 白牙："求...求你...别说了..."
- 内心：被看穿了...我所有的伪装...

**死亡**：

- 带着被看穿的恐惧和屈辱死去

### 4.2 时间线B：快速崩溃

**90%精槽时**：

- 主角直接说："又要哭了？"
- 白牙震惊：他怎么知道我会哭？

**熟练嘲讽**：

- 主角："纸老虎，上次你就这样。"
- 白牙内心：上次？什么意思？
- 但他已经没有力气思考

**死亡**：

- 带着困惑和恐惧死去
- 死前听到对方说"和上次一样"

## 五、关键场景设计

### 场景1：时间线A - 逐步崩溃

```
白牙精槽：90%
主角：（放缓动作）"你平时不是很凶吗？"
白牙：（硬撑）"我...我只是..."
主角："只是个欺软怕硬的懦夫？"
白牙：（内心震惊）他怎么...
白牙：（声音颤抖）"不...不是..."
主角："你收保护费时的凶狠全是装的吧？"
白牙：（防线崩溃）"求...求你...别说了..."
（叮咚！主角获得解锁提示）
主角：（冷笑）"果然，纸老虎。"
```

### 场景2：时间线B - 快速崩溃

```
白牙精槽：90%
主角："又要哭了？"
白牙：（震惊）什么...他怎么...
主角："和上次一样，射吧。"
白牙：（困惑）上次...什么意思...
（已经没有力气思考）
白牙：（崩溃）"不...不要..."
主角："纸老虎。"
```
