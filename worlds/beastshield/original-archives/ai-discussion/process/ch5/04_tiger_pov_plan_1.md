# 第五章 白虎视角扩写创作思路

## 一、扩写定位

**时间线**：主角屠杀三只杂兵之前
**主角**：白牙（白虎兽人，绿制服杂兵，后被主角杀死）

**核心场景**：

1. 武器店收保护费
2. 离开武器店去后巷找同伴
3. 发现尸体→被主角伏击→死亡

**与原文的衔接**：

- 承接：小熊猫店主说"白虎之前来收过保护费了"
- 引出：白牙去后巷找同伴，被主角杀死

---

## 二、角色设定

### 2.1 白牙（白虎兽人，本段主角）

**名字**：白牙（Bai Ya）

- 朴实的底层杂兵名字，体现白虎种族特征（白色+虎牙）
- 简单易记，符合杂兵身份

**身份**：白牙，兽盾绿制服杂兵，负责这片区域的"保护费"收取
**性格**：

- 表面上凶悍（对小熊猫凶狠）
- 实际上只是执行命令（内心并不享受欺凌弱小）
- 对同伴有一定责任感（发现同伴失踪去找）
- 实力在杂兵中较强（但远不如主角）

**外形**：

- 白色毛发的虎兽人，身材魁梧
- 绿制服被他撑得紧绷
- 白袜军靴（尚未被扒）

### 2.2 小熊猫店主

**状态**：被白牙收保护费时的恐惧、卑微
**伏笔**：白牙离开时小熊猫松了口气，但不知道白牙再也回不来了

---

## 三、情节结构

### 第一幕：武器店收保护费

**场景**：武器店内，白牙例行公事来收钱
**冲突**：

- 小熊猫哀求已经交过两次了
- 白牙虽然有点不忍，但必须执行公司规定
- 最终小熊猫被迫交了钱

**细节**：

- 白牙内心os："我也只是按规矩办事"
- 小熊猫的恐惧让白牙感到一丝愧疚，但很快压下去
- 离开时白牙警告小熊猫"下次准时点"

### 第二幕：离开武器店

**场景**：白虎走在去后巷的路上
**心理活动**：

- 盘算今天收了多少保护费
- 发现老张（白熊）和老三（白狼）应该在后巷巡逻，但一直没消息
- 决定去查看

**伏笔**：

- 路过垃圾桶时还没发现问题
- 发现地上有拖行的痕迹（第一只白熊被拖行的痕迹）

### 第三幕：后巷发现

**场景**：后巷垃圾桶旁
**高潮**：

- 发现垃圾桶外挂着白袜粗腿
- 认出是老张和老三
- 震惊、愤怒、恐惧
- 还没来得及反应，主角从背后偷袭

### 第四幕：死亡

**衔接v3屠杀扩写**：

- 被主角抓住弱点
- 挣扎最剧烈（三只中最强）
- 最终不敌，被处决
- 临死前意识到"这就是那个凶手"

---

## 四、写作风格

### 4.1 视角转换

**第三人称限知视角**（白牙视角）：

- 不知道主角的存在（直到被偷袭）
- 不知道同伴已死（直到发现尸体）
- 读者知道他会死，但他不知道（悲剧感）

### 4.2 与原作的呼应

| 原文             | 本扩写        |
|----------------|------------|
| 小熊猫说"白虎来收过保护费" | 展示收保护费过程   |
| 白牙被主角伏击        | 展示白牙如何走进陷阱 |
| "雪白的屁股"        | 白牙临死前被扒光   |

### 4.3 情感基调

- **收保护费**：无奈、麻木（底层员工的生存）
- **发现尸体**：震惊、愤怒、恐惧
- **被伏击**：绝望、不甘

## 五、关键场景

### 场景1：保护费对话

```
小熊猫："这才月初啊...能不能宽限几天..."
白牙：（内心：我也没办法，公司规定...）
白牙：（表面）"少废话，不交就砸店！"
```

### 场景2：发现同伴

```
白牙："老张？老三？你们在哪？"
（看到垃圾桶外的白袜）
白牙："什么——唔！"
（主角从背后偷袭）
```

### 场景3：临死

```
白牙：（挣扎）"你...你是什么人..."
主角：（冷笑）"来收你们命的人。"
白牙：（意识到这就是凶手，但已经晚了）
```

## 六、与v3屠杀扩写的衔接

**时间线**：

```
白牙收保护费 → 去后巷 → 被主角杀死（v3扩写开始）
                         ↓
                    主角扒光白牙 → 升级 → 换装
                         ↓
                    主角去武器店 → 小熊猫说"白虎来过了"
```

**呼应**：

- 白牙收保护费时警告小熊猫
- 主角换装后小熊猫以为白牙又来了
- 形成讽刺：白牙再也回不来了

## 七、v2 修正说明

### 7.1 发现的问题

**v1 版本（`ch5-tiger-pov-draft.md`）存在与原文不符的设定：**

1. **保护费次数错误**：v1 中小熊猫说"已经交过两次了"，但原文中小熊猫对主角说的是"
   我这个月已经交过保护费了"（只交过一次，即白牙这次）。

2. **时间线过长**：v1 中尾声写"几小时后"，但实际上从白牙收保护费 → 被杀 → 主角换装来武器店，应该是连续发生的，时间间隔不应太长。

### 7.2 修正内容

| 项目     | v1（错误）    | v2（修正）            |
|--------|-----------|-------------------|
| 小熊猫台词  | "已经交过两次了" | "才月初啊..."（本月第一次）  |
| 时间间隔   | "几小时后"    | "十几分钟后"           |
| 小熊猫对主角 | 无台词       | "已经交过保护费了"（与原文一致） |

### 7.3 修正后的时间线

```
白牙收保护费（月初第一次）→ 去后巷 → 被主角杀死
                                    ↓
                              主角扒光白牙 → 升级 → 换装 → 去武器店（十几分钟后）
                                    ↓
                              小熊猫："已经交过保护费了"（指白牙那次）
```
