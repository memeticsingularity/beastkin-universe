2. **核心特点** - 玩法亮点表格、处决方式统计、场景特色

4. **角色塑造分析** - 基本信息、性格特征、人物弧光图、叙事功能、角色关系
5. **行文风格分析** - 叙事视角、语言特色表格、感官描写层次表格
6. **情色/战斗场景分析** - 场景机制、处决流程五阶段表格、差异化描写
7. **核心设定与世界观** - 设定揭示、组织架构图、战力/等级体系表格
8. **剧情推进** - 主要事件、伏笔与线索、前后作关联
9. **主题与隐喻** - 核心主题、象征元素、情感基调
10. **写作技巧评价** - 优点、特点、可借鉴要素、可改进空间
11. **总结** - 核心特点标签、一句话总结

## 更新内容详情

### 新增标准化元素

1. **基本信息表格**
    - 章节标题
    - 主要角色
    - 视角
    - 核心事件
    - 时间线
    - 字数估算

2. **玩法亮点表格**
    - 元素列 + 具体表现列
    - 突出每章的核心游戏机制

3. **处决方式统计**
    - 按角色分类
    - 包含股数统计
    - 处决方式描述

4. **叙事流程图**
   ```
   阶段1 → 阶段2 → 阶段3 → 阶段4
   ```

5. **节奏特点表格**
    - 阶段列
    - 节奏列（快/慢/紧张等）
    - 描写重点列

6. **人物弧光图**
   ```
   [初始状态] → [转变过程] → [最终状态]
   ```

7. **语言特色表格**
    - 维度（词汇/句式/修辞）
    - 特点
    - 示例

8. **感官描写层次表格**
    - 视觉/听觉/嗅觉/触觉
    - 对应示例

9. **处决流程五阶段表格**
    - 控制/挑逗/临界/射精死亡/余韵
    - 对应内容和描写重点

10. **组织架构图**
    - 树形结构展示势力组织

11. **战力/等级体系表格**
    - 层级/代表/特征

12. **核心特点标签**
    - 每章5-6个关键词标签
    - 便于检索和分类
