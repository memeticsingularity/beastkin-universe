- **Volume / 卷次编号**: Volume 1
- **Chapters / 章节数**: 13 chapters / 13章
- **Status / 当前状态**: Completed / 已完成
- **Version / 文档版本**: 1.0.0
- **Last Updated / 最后更新**: December 13, 2025 / 2025年12月13日

**Synopsis / 故事简介**:
A furry enthusiast acquires a mysterious VR game called *Beast World*. In the game, all damage and attacks are converted into "Lust Value." When Lust Value reaches its limit, the character will "ejaculate" to death. Players must utilize this unique mechanism to survive, grow, and gradually uncover the secrets of the Beastshield Company.

一名兽圈爱好者获得了一款神秘的VR游戏《兽游世界》。在游戏中，所有攻击伤害都会转化为性欲值，当性欲值达到上限，角色便会"喷射"死亡。玩家必须利用这一机制，在游戏中生存、成长，并逐步揭开兽盾公司的秘密。

**Core Content / 核心内容**:
- Game mechanics tutorial / 游戏机制教学与教程关卡
- Beastshield Company rank system / 兽盾公司职级体系揭秘
- Blood Essence Stone and Semen-Eater Beast mutation / 血精石与嗜精兽变异
- First confrontation between Agent Bureau and Beastshield / 特工局与兽盾的初次对抗
- Azure Sparrow Yang-Binding Lock of the Twelve Divine Weapons / 十二神武之青雉缚阳锁

## Worldview Setting (Main Story Core) / 世界观设定（主线核心）

### Major Organizations / 主要组织

- **Beastshield Company / 兽盾公司**: The most powerful organization in White Capital, involved in arms smuggling, contraband trafficking, and research on Blood Essence Stones and Semen-Eater Beasts / 白之都势力最大的组织，从事走私军火、贩卖违禁品，研究血精石和嗜精兽
- **Agent Bureau / 特工局**: A secret organization opposing Beastshield, with members mostly inheritors of the Twelve Divine Weapons / 对抗兽盾的秘密组织，成员多为十二神武传人
- **Light Cult / 光照神教**: A mysterious religious organization with intricate ties to Beastshield / 神秘宗教组织，与兽盾有千丝万缕的联系

### Rank System / 职级体系

1. **Ordinary Employee/Grunt / 普通员工/杂兵**: Green uniform / 绿制服
2. **Cadre / 干部/组长**: Blue uniform / 蓝制服
3. **Minister / 部长**: Black uniform / 黑制服
4. **Chairman / 董事**: Chairman Ya, Chairman Hui, Chairman Lan, etc. / 牙董、辉董、岚董等

### Core Settings / 核心设定

- **Blood Essence Stone / 血精石**: Red crystal that mutates the host into a "Semen-Eater Beast" / 红色水晶，植入体内后使人变异为"嗜精兽"
- **Semen-Eater Beast / 嗜精兽**: Aberrations that must continuously consume beastkin semen to survive; advanced ones can consume blood / 需要不停吞噬兽人精液才能存活的异类，高级嗜精兽可吸食血液
- **Twelve Divine Weapons / 十二神武**: Weapons of twelve warriors from the human-beast war five hundred years ago, each with special abilities / 五百年前人兽大战中十二位勇士的武器，各有特殊妙用
- **Five Elements Seal / 五行封禁**: Dragon Martial God's ultimate technique, known as the world's strongest defense / 龙武神的绝技，号称天下最强防御
