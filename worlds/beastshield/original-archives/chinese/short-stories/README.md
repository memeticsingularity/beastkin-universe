# 短篇故事集 / Short Stories Collection

> 收录兽盾宇宙独立短篇故事，每篇故事自成一体，可按任意顺序阅读。
> A collection of standalone short stories set in the BeastShield Universe. Each story is self-contained and can be read in any order.
>
> 各故事均包含成人内容（暴力、性、死亡等），阅读前请注意分级标识。
> All stories contain adult content (violence, sexual themes, death, etc.). Please note the age rating before reading.

---

## ⚠️ 新增或修改短篇前必读

短篇文件格式以 [`docs/spec/11-story-format.md`](../../../../../docs/spec/11-story-format.md)（故事格式规范 v3.0 **§2 短篇故事格式**）为**唯一权威源**。

- **H1**：`# Story {中文标题}`
- **结束标记**：`**Story END**`，**恰好一次**
- **不要照抄既有文件的写法**——历史遗留里存在 `# SS-00N: 标题` 与 `**完**` 等已废弃形式。详见 [`worlds/beastshield/AGENTS.md`](../../../AGENTS.md) 的「故事文件格式（强制）」。

## 三、阅读建议与分级说明 / Reading Advice & Content Warnings

- **R18**: 所有故事均包含成人内容，包括但不限于：
    - 暴力、勒杀、窒息、虐杀
    - 性内容、性暴力、非自愿行为
    - 死亡、尸体处理、道德困境
- **建议读者**: 仅适合18岁以上、对黑暗主题与成人内容有心理准备的读者。
- **阅读顺序**: 各篇独立，可随意跳读，但按编号顺序可渐入世界观。
