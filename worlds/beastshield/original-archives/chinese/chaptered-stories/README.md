## ⚠️ 新增或修改章节前必读

章节文件格式以 [`docs/spec/11-story-format.md`](../../../../../docs/spec/11-story-format.md)（故事格式规范 v3.0）为**唯一权威源**。

- **H1**：`# Chapter {自然数} {中文标题}`
- **结束标记**：`**Chapter {自然数} END**`，**恰好一次**
- 顺序：正文 → `---` → 卷尾语 `> *…*` → 结束标记 → `---` → 导航行 → `---` → `## 故事评述与感慨`
- **文件末尾不得再有第二个结束标记**

**不要照抄既有文件的写法**——历史遗留里存在 `# MS-001: 作品名 - 第N章：标题`、`# 作品名 - 第N章：标题`、`**第一章完**`、`**终章**` 等已废弃形式。详见 [`worlds/beastshield/AGENTS.md`](../../../AGENTS.md) 的「故事文件格式（强制）」。
