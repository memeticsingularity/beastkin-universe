# 虎科兽盾兵

> 虎兽人是兽盾公司中的精锐战士，以高战斗属性和丰富的战斗技巧著称。常见亚种包括黄虎、白虎、蓝虎、黑虎、红虎等。虎科角色涵盖从 G 级杂兵到部长的完整阶层，多位关键剧情角色（炎魉篇的白虎枪械兵、武馆的红光虎队长）均为虎兽人。虎卫组是第二卷的关键敌对团体。
