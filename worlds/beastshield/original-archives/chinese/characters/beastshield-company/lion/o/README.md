# 狮科兽盾兵 · O级监工

> **制服**：蓝色制服
> **定位**：监工 / 中层管理，带队小队长级，掌握一定权限。
> **叙事功能**：O 级监工是"有权限的杂兵"——他们能对下属发号施令，却依旧逃不过被碾压的结局。其蓝色制服与白袜（袜口蓝条纹）在画面中辨识度高，常与"体面身份 vs 狼狈死法"的反差一同出现。
