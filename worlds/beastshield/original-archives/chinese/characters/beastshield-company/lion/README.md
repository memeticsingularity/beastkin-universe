# 狮科兽盾兵

> 狮兽人以力大无穷、体格健壮著称，在兽盾公司中属于身体素质最为出色的兵种之一。常见亚种包括黄狮、白狮等。狮兽人在剧情中多担任重体力岗位——体训房健身兵、大型守卫，也有以柜中无名裸尸出现的悬疑桥段，鬃毛和胡须为其死亡画面增添了威猛与狼狈的反差。
