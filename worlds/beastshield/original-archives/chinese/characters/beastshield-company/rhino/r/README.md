# 犀牛科兽盾兵 · R级枪械兵

> **制服**：白色紧身制服
> **定位**：远程兵种/枪械兵，经枪法测试筛选，负责远程火力支援。
> **叙事功能**：R 级枪械兵被近身后战斗力骤降，其白色制服在处决场景中具有独特的视觉冲击力——被淫水浸湿变半透明、精液灌满白裤渗透而出。
