# 犀牛科兽盾兵

> 犀牛兽人以皮糙肉厚、体格庞大著称，在兽盾公司中多担任正面防御和重装岗位。常见亚种包括黑犀、白犀等。犀牛兽人凭借其天生的厚重皮甲，在战斗中往往能承受更多伤害，但仍难逃被踩爆蛋蛋、铁箭穿颅、掌劲震精等花样百出的死亡命运。
