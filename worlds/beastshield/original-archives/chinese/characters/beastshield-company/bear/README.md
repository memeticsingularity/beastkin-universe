# 熊科兽盾兵

> 熊科是兽盾公司的主力兵种，从 G 级杂兵到部长级均有分布，体型壮硕、力量惊人。常见亚种包括棕熊、白熊、黑熊、灰熊。熊兽人在剧情中承担从仓库杂役到炼药房守卫的广泛角色，死亡方式横跨勒杀、药池、点穴等多样手段。熊猫兽人作为特例存在，战力远超同级。
