# 狼科兽盾兵

> 狼兽人以敏捷身手和团队协作能力见长，在兽盾公司中多担任侦查巡逻、狙击手等灵敏度要求高的岗位。常见亚种包括灰狼、蓝狼、雪狼等。狼兽人在剧情中既有被秒杀的杂兵，也有以银针封穴术猎杀多人的神秘银狼竞争者。
