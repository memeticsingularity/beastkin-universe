# 豹科兽盾兵

> 豹兽人以速度和敏捷著称，在兽盾公司中多担任侦查、守卫等需要快速反应的岗位。常见亚种包括黑豹、雪豹、花豹等。豹兽人在剧情中多作为快速反应的守卫出现，死亡方式涵盖割喉、踩踏、灌精、碎喉等高效处决方式。
