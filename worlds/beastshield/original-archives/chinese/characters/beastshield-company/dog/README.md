# 犬科兽盾兵

> 狗兽人在兽盾公司中数量庞大，以警觉性高、服从性强著称，多为 G 级杂兵担任巡逻岗位。常见亚种包括德牧、灰狗、鬣狗等。剧情中狗兽人的死亡方式极具反差感——递烟被杀的武斗兵、接电话时意外处决的守卫、被挂警帽撸射的短腿狗兵。
