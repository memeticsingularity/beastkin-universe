# 野猪科兽盾兵

> 野猪兽人以体格强壮、獠牙突出为特征，在兽盾公司中全部为 G 级杂兵，是最底层的员工群体。虽然身份低微，但野猪兽人在剧情中有多处令人印象深刻的死亡——被捏乳头榨干、被倒吊揉龟头射精、被藤蔓钻后穴按压前列腺。那句"早知道就不来兽盾应聘了"成为炎魉篇的名台词。
