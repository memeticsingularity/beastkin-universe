# 赏金猎人 / Bounty Hunters

> 以猎杀兽盾公司员工换取赏金为生的独立猎人，不属于任何一方阵营。
> 本目录收录赏金猎人的角色档案。
> **赏金兑换机制**：兽盾员工袜底印有编号，是领取赏金的凭证——只需提交一只袜子，无需尸体。
