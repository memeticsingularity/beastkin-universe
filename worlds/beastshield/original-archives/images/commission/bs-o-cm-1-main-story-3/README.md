## 二、逐图说明 / Details

### 20260618 · 被铁箭钉在墙上的绿制服狗兽人

[![20260618-dog](./20260618-dog.png)](./20260618-dog.png)

**对应章节**：[Ch.8 龙神浮岛](../../../chinese/chaptered-stories/main/bs-o-cm-1-main-story-3/ch-8-dragon-god-island.md) · 插图位于第 161 行之后

**观察到的细节：**

- **角色**：金黄色狗兽人（黄狗/金毛犬型），四肢粗壮但腿短，体格矮壮
- **制服**：G级 · 军绿色紧身短裤，绿色无指手套
- **袜子**：白色长筒袜，袜口军绿色条纹
- **状态**：一柄长矛/戟状的**长杆武器从背后贯穿胸膛**，矛尖自胸前穿出，血线沿胸腹流下；身体被钉在墙边
- **场景**：饮品店/奶茶店内，身后墙上贴有一张彩色海报（红、黄、绿几何图案）

**对应原文：**

> 接着，勤川走向最后一只被钉在墙上的狗兽人，这只兽人虽然四肢粗壮，但腿却比其他兽人短得多，被铁箭钉在墙上双脚离地，显得十分滑稽。
> —— [ch-8-dragon-god-island.md](../../../chinese/chaptered-stories/main/bs-o-cm-1-main-story-3/ch-8-dragon-god-island.md) 第 161 行

同场景铺垫（第 61 行）：「就被铁箭穿胸带起，倒飞了出去，死死钉在了饮品店的墙上」。角色档案：[`dog-g-vol-3-ch-08-001.md`](../../../chinese/characters/beastshield-company/dog/g/dog-g-vol-3-ch-08-001.md)（G级 · 军绿色制服 + 白袜）。

**与原文的出入（画师再创作）：**

1. **武器形制**：原文是**夔牛弓射出的铁箭**（箭杆一指粗），画面读起来像长矛/戟；贯穿胸膛这一点完全吻合。
2. **死因**：原文第 63 行明说穿胸箭**并不致命**，这只狗是被勤川撸射致死的——插图的「钉在墙上的贯穿伤」与「死亡」是同一场景的两个层次，不构成冲突。
3. **左肩白色绷带**：全卷 22 章中「绷带」**零命中**，无出处。
4. **墙上彩色海报**：全卷「海报」**零命中**，无出处。
5. **毛色**：原文未写这只狗的毛色。

### 20260717 · 跪在熊兽人尸体旁自撸射精的狼兽人

[![20260717-wolf](./20260717-wolf.png)](./20260717-wolf.png)

**对应章节**：[Ch.4 念力防御](../../../chinese/chaptered-stories/main/bs-o-cm-1-main-story-3/ch-4-psychic-defense.md) · 插图位于第 245 行之后

**对应角色档案**：[`wolf-g-vol-3-ch-04-001.md`](../../../chinese/characters/beastshield-company/wolf/g/wolf-g-vol-3-ch-04-001.md)

**观察到的细节：**

- **角色**：灰白色狼兽人，体格粗壮；仰头张嘴吐舌，精液从口角淌到胸前
- **制服**：蓝色短裤（两侧白线），蓝色手套
- **袜子**：白色长筒袜，袜口蓝色条纹；蓝色运动鞋；右小腿有一圈白色绷带/护套
- **姿态**：跪姿——**左手捏着自己的乳头，右手握着自己的肉棒**
- **状态**：正在射精；画面左侧那道长长的白色斜流是**精液**（不是刀剑）
- **同框**：画面左下角躺着一具穿**军绿短裤（金色侧线）+ 白袜（绿条纹）**的兽人尸体 = **熊兽人**

**对应原文：**

> 解决掉熊兽人后，狼兽人便恢复呆滞的表情跪立在熊兽人身旁，左手捏着自己乳头，右手抽出肉棒来回撸动，撸了将近两分钟后身体一抖，发出一声闷哼开始射精，精液全部洒在了熊兽人死不瞑目的脸上和被紧身衣勒出褶皱的胸肌上，射完所有精液后，身体往前一倒，趴在了熊兽人胸膛上，也渐渐停止了呼吸。
> —— [ch-4-psychic-defense.md](../../../chinese/chaptered-stories/main/bs-o-cm-1-main-story-3/ch-4-psychic-defense.md) 第 245 行

前置节拍（同章第 239–243 行）：狼兽人因知道太多被**儡部长**用黑雾控制、四肢垂下一脸呆滞，扑倒熊兽人吮吸其肉棒至死——正是画中「呆滞表情 + 身旁熊兽人尸体」的来处。

**与原文的出入（画师再创作）：**

1. **制服颜色**：角色档案记这只狼是 **G级 · 军绿色短袖 + 军绿色短裤**（[`wolf-g-vol-3-ch-04-001.md`](../../../chinese/characters/beastshield-company/wolf/g/wolf-g-vol-3-ch-04-001.md)），画中为**蓝色**短裤 + 蓝手套 + 蓝鞋（O级配色），白袜袜口也是蓝条纹。属画师配色出入。
2. **精液落点**：原文明写「全部洒在了熊兽人死不瞑目的**脸上**和被紧身衣勒出褶皱的**胸肌**上」；画中精液是从狼自己口中/下体淌出、射向画面外的方向，熊兽人身上未见覆盖。
3. **右小腿的白色绷带/护套**：原文无出处。
4. **画面左下角的尸体**：原文只写「熊兽人」，画中穿军绿短裤 + 金线、白袜 + 绿条纹，与 G级制服规格一致。

### 20260801 · 被一线天倒吊的绿制服野猪兽人

[![20260801-boar](./20260801-boar.png)](./20260801-boar.png)

**对应章节**：[Ch.7 警察局突袭](../../../chinese/chaptered-stories/main/bs-o-cm-1-main-story-3/ch-7-police-station-invasion.md) · 插图位于第 161 行之后

**观察到的细节：**

- **角色**：灰白色野猪兽人，挺着大肚子
- **制服**：G级 · 军绿色紧身短裤（已褪下），军绿色无指手套
- **袜子**：白色长筒袜，袜口军绿色条纹
- **姿态**：**头朝下倒吊**，双脚脚踝处缠着一圈军绿色布状物
- **状态**：身上有多道血痕/伤口；一只棕色毛的手从右侧伸入握住他的肉棒，精液喷溅
- **场景**：室内，被细线绷吊在半空

**对应原文：**

> 犀牛兽人在靠近虎兽人还有三步距离的时候，看到了靠在阳台窗边正在抽烟的勤川……刹那间房内银丝密布，无数根细线由于机关被触发朝着两个兽人卷了过来，一瞬间将犀牛和野猪的躯干肢体紧紧勒住，两只兽人的身体被绷直的细线抬到了半空，野猪甚至头朝下翻了过来。
>
> “鉴于他的态度良好，所以我打算从轻发落，给予人道处决。”勤川说着，走到双腿朝上张开的野猪兽人身边，将他的紧身裤往上掀到脚踝，然后左臂抱住野猪柱子般的白袜右腿将他摇晃的身体固定，右手则握住了野猪勃起的粗圆肉棒，撸下包皮开始抚摸套弄起龟头。
> —— [ch-7-police-station-invasion.md](../../../chinese/chaptered-stories/main/bs-o-cm-1-main-story-3/ch-7-police-station-invasion.md) 第 143 行、第 161 行

角色档案：[`boar-g-vol-3-ch-07-001.md`](../../../chinese/characters/beastshield-company/boar/g/boar-g-vol-3-ch-07-001.md)（G级 · 军绿色紧身制服 + 白袜 · 灰毛野猪 · 被一线天倒吊揉龟头射精）。第 157 行「将他们粗壮的肌肉勒得**鲜血四溅**」对应画中的血痕。

**与原文的出入（画师再创作）：**

1. **脚踝上的「军绿布带」**：原文捆住他的是神武「一线天」的**银丝/细线**（由银背猿王的毛发编织）。但第 161 行明写「将他的**紧身裤**往上掀到**脚踝**」——那截褪到脚踝的**军绿紧身裤**在画面里极容易被读成「军绿布带捆住脚踝」，实际高度吻合。
2. **棕色毛的手**：执行者勤川是猎犬兽人，棕毛的手与此吻合。
3. **军绿手套**：原文未单写，属 G级制服标配。
