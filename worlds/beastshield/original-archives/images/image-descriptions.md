## 三、关键发现汇总

### 3.1 G级杂兵制服要素

| 部位 | 细节                                                                    |
|----|-----------------------------------------------------------------------|
| 短袖 | 军绿色，左胸白色盾牌状兽盾LOGO，**胸前可能有黄色"SHIELD"字样**，背部黄色"SHIELD"字样，两侧金色竖线（部分为双条纹） |
| 短裤 | 军绿色，两侧金色竖线                                                            |
| 袜子 | 白色长筒袜，袜口绿色条纹（部分有**红色条纹变体**），袜身绿色"SHIELD"字样                            |
| 鞋子 | 绿色运动鞋                                                                 |
| 手套 | 绿色无指手套                                                                |
| 帽子 | 部分配有军绿色帽子（带兽盾标志）                                                      |

**新增发现**：

- G级狗兽人可能穿白色短袜而非长筒袜（见g-dog/20231012.jpg）
- **特殊标识**：部分G级狗兽人胸前有**"GUARD"字样**（见g-dog/20210516.jpg），非标准兽盾LOGO
- 袜子存在红色条纹变体（红绿白三色条纹，见g-bear.jpg和ch-11.jpg）
- g-bull/20240318.jpg 为特殊场景（被束缚/倒吊），无上装
- **三角裤款式**：部分G级犀牛兽人穿**军绿色紧身三角裤**（见g-rhino/20230823-2.jpg、20230823-3.jpg），非常规短裤
- 部分G级制服**胸前也有"SHIELD"字样**（见ch-03-2.jpg）

### 3.2 O级监工制服要素

| 部位 | 细节                                 |
|----|------------------------------------|
| 上衣 | 蓝色短袖或蓝色连体紧身服，两侧白色竖线                |
| 短裤 | 蓝色，两侧白色竖线                          |
| 袜子 | 白色长筒袜，袜口蓝色条纹                       |
| 鞋子 | 蓝色运动鞋                              |
| 背部 | 白色"SHIELD"字样（见o-bear/20240306.jpg） |

### 3.3 E级武斗兵制服要素

| 部位     | 细节                                                          |
|--------|-------------------------------------------------------------|
| 短袖     | 黑色紧身，左胸白色盾牌状兽盾LOGO，肩部/袖子有条纹或几何图案                            |
| 短裤     | 黑色，两侧有条纹或几何图案                                               |
| 条纹配色   | 白色/灰色（常见）、**红色（高级成员，配护目镜/护肩）**、**蓝色（虎兽人特殊配色）**              |
| LOGO配色 | 通常为白色，极罕见**红色LOGO**（见e-lion/20240506.jpg）                   |
| 特殊图案   | 部分有白色/蓝色几何图案（类似电路板/科技纹路，见e-tiger/20231030.jpg、20240527.jpg） |
| 袜子     | 黑色长筒袜，袜口白色/灰色/红色/**蓝色**横条纹（双条纹常见）                           |
| 鞋子     | 黑色厚底军靴，部分有白色/蓝色条纹装饰                                         |
| 手套     | 黑色无指手套，部分有白色条纹装饰                                            |
| 护具     | 金属护裆，高级成员有护肩/护胸/**战术腰带/护目镜/电击棒/盾牌**                         |
| 腰带扣    | 通常为黑色，部分高级成员为银色                                             |
| 背部     | 白色或蓝色"SHIELD"字样                                             |
| 配件     | 部分配有**口塞**（特殊场景）                                            |

**重要发现**：

- **虎兽人E级配色**
  ：蓝色条纹是虎兽人E级的特殊配色变体（见e-tiger/20240321.jpg、20240527.jpg、20240529.jpg），与白色/灰色、红色形成三种主要配色体系
- **狮子兽人E级配色**：红色条纹+红色兽盾LOGO（见e-lion/20240506.jpg、20250415.jpg），左胸有"SD"特殊标识
- **完整装备示例**：e-tiger/20240527.jpg展示了E级高级成员的完整装备——护目镜、护肩、战术腰带、电击棒、透明盾牌
- e-bull/20240906.jpg 为浴室场景，上衣已脱下，非制服变体

### 3.4 R级枪械兵制服要素

| 部位 | 细节                             |
|----|--------------------------------|
| 短袖 | 白色紧身，正面兽盾标志                    |
| 短裤 | 白色紧身                           |
| 手套 | 黑色                             |
| 袜子 | 白色长筒袜，袜口蓝色圆环/条纹（部分有**红色条纹变体**） |
| 鞋子 | 卡其色军靴或蓝白运动鞋                    |
| 背部 | 蓝色"SHIELD"字样                   |
| 装备 | 部分配有背带/肩带系统，用于携带武器             |

**特殊发现**：

- R级牛头人有**红色条纹变体**（见r-bull/20241216.jpg）
- R级狗兽人倒地场景（见r-dog/20240320-2.jpg）

**武器**：手持手枪或大型枪械

### 3.5 W级摔跤兵制服要素

| 部位   | 细节                                    |
|------|---------------------------------------|
| 连体服  | 深蓝色（标准），紧身弹性，两侧白色/红色/紫色条纹或几何图案        |
| 特殊配色 | **黑红配色**（极罕见，见w-tiger/20250324-1.jpg） |
| 图案   | 部分有白色/浅色几何图案（V字形和线条组合）                |
| 胸前标志 | 通常为白色兽盾LOGO，黑红配色为**红色LOGO**           |
| 文字   | 部分印有"BEAR"等字样                         |
| 袜子   | 白色长筒袜，袜口蓝色/紫色条纹                       |
| 鞋子   | 深蓝色摔跤靴或运动鞋                            |
| 护具   | 护肩、护膝                                 |
| 护腕   | 部分配有白色护腕                              |
