## 一、简介 / Introduction

《帝国万岁》改编作品区，存放基于原作世界观进行的二次创作、衍生故事及独立短篇。这些作品在保留核心设定的基础上，探索不同角色视角与叙事可能性。

## I. Introduction

Adaptation works for *Long Live the Empire*, housing secondary creations, derivative stories, and standalone short fiction based on the original worldview. These works preserve core settings while exploring different character perspectives and narrative possibilities.
