## 一、虎猛：实验型少主

### 1.1 身份与特权

虎猛被皇帝陛下宣布为帝国接班人后，地位仅在皇帝之下，被称为"少主"。【extra-001-ch-1】

- **免疫撸杀机制**：虽仍为蓝袜兵，但已不受射精死亡机制束缚，被撸时只会全身无力、痛苦异常（皇帝陛下除外）。【extra-001-ch-1】
- **随意处决权**：可随意撸杀不合格士兵，拥有对下属的绝对处置权。【extra-001-ch-1】
- **房间与护卫**：拥有专属房间，门外由白袜兵站岗（平时由蓝袜兵代替）；房间内密室存放白狼长官的封印水晶，需以功勋换取脱困机会。【extra-001-ch-1】【extra-001-ch-6】
- **密道权限**：房间内有密道通往中央建筑底层，可自由穿梭于星舰各区域。【extra-001-ch-2】

### 1.2 基兽融合实验（002标记）

为成为真正的接班人，虎猛接受了与"基兽"的融合实验。【extra-001-ch-6】

- **实验前提**：身体先被退化至最低等黑袜兵标准，才能与基兽融合。【extra-001-ch-6】
- **基兽特性**：专门吞噬精液的红色肉球状生物，已被皇帝血液入侵，完全可控。【extra-001-ch-6】
- **融合过程**：基兽将虎猛整体包裹，伸出触手以吸盘形态吞噬其精液；虎猛体内皇帝血液反向吸收基兽细胞能力。【extra-001-ch-6】
- **实验结果**：基兽干枯碎裂，虎猛获得皇帝约六分之一的力量和能力，背后出现红色帝国标志，内写"002"字样。【extra-001-ch-6】

### 1.3 少主专属能力

融合实验后，虎猛获得以下新能力：【extra-001-ch-6】【extra-001-ch-8】

- **精液为食**：必须以帝国士兵精液为食，每五六天进食一次；精液可消除愤怒焦虑、满足肠胃饥饿。禁止吞噬白袜兵，蓝袜兵一次仅限一个。【extra-001-ch-6】【extra-001-ch-8】
- **虚抓引导射精**：手掌做出虚抓手势即可自动引导基尅兵精液射出，无需直接接触撸动。【extra-001-ch-6】【extra-001-ch-8】
- **意识控制**：可操纵基尅兵思想，使其从求饶变为呆滞服从，并执行自撸谢罪等指令。【extra-001-ch-6】
- **芯片操控**：可强行激活或关闭基尅兵芯片，使其宕机昏迷或更新身份信息（如提拔小队长）。【extra-001-ch-3】【extra-001-ch-8】
- **隐身系统**：胸口护甲启动后身形逐渐透明，巡逻队伍无法察觉。【extra-001-ch-3】
- **力量与速度**：肌肉膨胀后速度极快，普通士兵无法看清动作；可单手提起黑袜兵使其双脚离地。【extra-001-ch-2】【extra-001-ch-3】

## 二、行星级星舰内部结构

番外故事主要发生在帝国行星级星舰内部，其结构如下：【extra-001-ch-2】

- **超级城市**：星舰内部是一座超级城市，六艘星舰的所有士兵投入岗位后，仍只能让城市四分之一运转起来。【extra-001-ch-2】
- **培养工厂**：城市中设有培养工厂，运转后约20天可生产出满足城市运转数量的基尅兵。【extra-001-ch-2】
- **中央高塔（主建筑）**：
  - 顶层：皇帝陛下活动区域。【extra-001-ch-2】
  - 中上层：白袜兵与蓝袜兵的训练休息场所。【extra-001-ch-2】
  - 中下层：绿袜兵驻扎区，保护中央高塔；设有杂物间、走廊、处刑室等。【extra-001-ch-2】
  - 底层：大量绿袜/黑袜兵所在区域，平时不允许任何人接近；存放军械、战机等。【extra-001-ch-2】
- **外围区域**：白袜长官管理的地区，灰袜兵可在外围与中央高塔间活动。【extra-001-ch-2】
- **区域连接**：各区域之间有角落交接处，部分位置设有暗哨（原为进攻时躲藏攻击之用）。【extra-001-ch-3】

## 三、虎猛专属装备

成为少主后，虎猛的装备全面换代，材质与帝国军袜相同：【extra-001-ch-1】【extra-001-ch-6】

| 装备 | 描述 |
|------|------|
| **黑色高弹内衣裤** | 贴合身体曲线，无单独内裤设计，通体亚光黑色，材质与帝国军袜一致 |
| **金属面罩** | 面部为特殊金属硬壳，眼眶部分是黑色特制镜片，口鼻部分为水下呼吸与过滤装置；其余部分以坚韧布料连接 |
| **护裆护甲片** | 贴身弧形三角形护甲，保护要害，弹力与防护能力顶级 |
| **深蓝色加强版军袜** | 标准装备升级版，袜筒略长，三道杠变为帝国标志 |
| **战术腰带** | 用于挂载各类武器道具，运动时无声响 |
| **高弹战术手套** | 掌心部分可改变形态，便于更快执行处决 |
| **护踝** | 配合军袜固定脚部 |

## 四、士兵装备与系统升级

### 4.1 提取器（标准配备）

- 金属环连接可折叠容器，套在龟头上提取精液。【extra-001-ch-2】
- 是每个基尅兵都有的标准装备，必要时应以自我处决避免泄密。【extra-001-ch-2】
- 虎猛可熟练地从士兵战术背心中取出并快速操作。【extra-001-ch-2】

### 4.2 芯片记忆读取器

- 可读取芯片中记录的士兵行为与位置信息。【extra-001-ch-3】
- 虎猛利用权限扫描发现暗哨中藏有两名偷懒士兵。【extra-001-ch-3】

### 4.3 新芯片指令

番外中出现了两项新的芯片预设指令：【extra-001-ch-6】【extra-001-ch-9】

- **自撸谢罪**：上级可强制命令基尅兵自行撸动射精死亡；恐龙护卫曾被虎猛用此指令处决。【extra-001-ch-6】【extra-001-ch-9】
- **反向拧断执行**：雪豹小队长以绿袜权限激活芯片自毁程序，被踢裆者瞬间触发撸杀机制死亡。【extra-001-ch-7】

## 五、新兵种与新角色

### 5.1 灰袜兵（后勤权限细化）

番外中对灰袜兵的职能与限制有更详细描写：【extra-001-ch-1】【extra-001-ch-2】

- **外观**：统一穿着深灰色蛙服套装、灰色军袜、灰色面罩与战术手套。【extra-001-ch-1】
- **职能范围**：只负责后勤维护、打扫卫生、处理尸体、回收装备；可在中央高塔外围区域活动。【extra-001-ch-1】【extra-001-ch-2】
- **技能限制**：芯片中仅有维修维护帝国设施设备的技能，**完全没有撸杀相关内容**，因此不具备处决权限。【extra-001-ch-2】
- **地位**：名义上等级在黑袜兵之上，但黑袜兵常不将其放在眼里；对少主极度畏惧。【extra-001-ch-2】【extra-001-ch-3】
- **特殊权限**：可无视基地中部分身份认证自由穿梭，负责巡查设施运转情况并打卡。【extra-001-ch-2】

### 5.2 雪豹小队长（绿袜兵）

番外第七章登场的新角色，绿袜兵小队长。【extra-001-ch-7】

- **种族稀有性**：雪豹基尅兵在全帝国极为稀有，一经培养即为绿袜兵。【extra-001-ch-7】
- **外貌特征**：双眸闪着凶光，身后有一条大尾巴。【extra-001-ch-7】
- ** tail武器**：尾巴可作为武器使用——可勒住敌人脖子将其提起，或伸入裤裆绞住生殖器摩挲。【extra-001-ch-7】
- **性格与作风**：严苛、正义感强，厌恶偷懒与告密；为取证可伪装成黑袜兵潜入调查；对忠诚于帝国但高密的士兵同样不喜。【extra-001-ch-7】
- **处决风格**：手段残忍（捏碎生殖器、抓碎睾丸），但允许罪犯自撸谢罪；以虎猛之名威慑敌人。【extra-001-ch-7】

## 六、社会仪式与行为规范

### 6.1 脚垫兵/脚凳制度

- 被长官选中做脚垫是亲卫的证明与荣耀。【extra-001-ch-8】
- 长官休息时可将穿军袜的脚掌放在士兵头上，士兵以此为荣；脚掌在头上来回摩擦可表达嘉奖或玩弄。【extra-001-ch-8】
- 虎猛曾让新晋小队长在水中吮吸其脚掌，称为"基尅兵里至高无上的荣誉"。【extra-001-ch-8】

### 6.2 舔袜效忠

- 下级给长官舔袜子是荣誉，证明长官的宠爱；长官也可主动将袜脚贴在手下面部。【extra-001-ch-3】【extra-001-ch-7】
- 雪豹小队长曾让违纪小队长趴在地上舔自己的绿色军袜。【extra-001-ch-7】

### 6.3 新兵处决标准化

- 虎猛向灰袜兵演示"帝国处决的标准流程"：固定于墙面镣铐→双手上举与头平行→双腿自然放开→直接撸杀或提取器处决。【extra-001-ch-2】
- 对新兵（刚培养不久的基尅兵）而言，偷懒被抓后由小队长亲自审问并撸杀是常见处置。【extra-001-ch-3】

### 6.4 黑处暗哨惩罚

- 暗哨原为进攻时躲藏攻击敌人的设施，后被士兵用作偷懒睡觉之所。【extra-001-ch-3】
- 在暗哨中偷懒属于严重违纪，一经发现通常面临整小队集体处决的威胁；小队长亦会受连带惩罚（如被掐裆、激活撸杀指令威胁）。【extra-001-ch-3】

番外中出现了多种新的处决/杀戮方式：

| 处决方式 | 描述 | 出现章节 |
|----------|------|----------|
| **反向拧断（芯片激活）** | 以绿袜权限踢裆，瞬间激活芯片自毁程序，受害者弯腰捂裆数秒内死亡 | ch-7 |
| **獠牙/咬噬** | 虎猛撕破裤子后直接张嘴咬住生殖器，吸血后吮吸精液 | ch-6 |
| **提取器强制榨取** | 将提取器套上后按下开关，同时揉捏睾丸加速射精死亡 | ch-2 |
| **虚抓引导** | 手掌虚抓即可引导精液射出，无需物理撸动 | ch-6、ch-8 |

| **踩踏裆部** | 用脚掌在裤裆处来回揉搓踩踏，配合酸臭气味刺激射精 | ch-7 |

## 八、设施与地点

### 8.1 处刑室

- 位于绿袜兵驻扎区，设有墙面镣铐，可将受刑者双手上举固定、双腿自然分开锁定。【extra-001-ch-2】
- 虎猛曾带灰袜兵与两名偷懒黑袜兵至此，演示标准处决流程。【extra-001-ch-2】

### 8.2 暗哨

- 位于区域交接角落处，原用于进攻时伏击敌人。【extra-001-ch-3】
- 内部空间狭小，可容纳数人；虎猛曾用芯片扫描发现其中藏有两名偷懒的野猪黑袜兵。【extra-001-ch-3】

### 8.3 休息室/值班室

- 各小队设有值班室与休息室，存放柜子、食物等；虎猛曾锁门关灯后处决偷懒士兵。【extra-001-ch-3】

### 8.4 健身房与公共浴室

- **健身房**：黑袜兵锻炼场所，属公共区域，不存在小队间不能互动的规定；士兵只穿紧身体恤与内裤锻炼，汗液与军袜气味浓烈。【extra-001-ch-3】
- **公共浴室**：设有浴池与淋浴区，水温可调；黑袜兵只穿裤衩体恤面罩军袜进入，虎猛曾伪装成黑袜兵在此觅食。【extra-001-ch-3】【extra-001-ch-8】
- **洗衣惯例**：锻炼后顺便洗澡并自行清洗衣物，不成文规定是"自己带回去清洗"，避免弄混。【extra-001-ch-3】

### 8.5 宿舍区

- 黑袜兵大通铺宿舍，士兵睡觉时不可脱衣服（仅洗澡时可脱外层）；有人睡觉时仍会时不时摸摸胸口。【extra-001-ch-3】【extra-001-ch-9】
- 呼噜声与体味、军袜味道混杂，环境闷热。【extra-001-ch-3】【extra-001-ch-9】

### 8.6 雪山基地办公室

- 虎猛担任绿袜兵大队长时的办公场所，用于听取汇报、下达处决命令。【extra-001-ch-7】

### 8.7 融合实验室

- 白色实验室，中央设有实验床，可束缚四肢；周围有蓝袜兵研究员操作；前方地面可升起基兽培养体。【extra-001-ch-6】
- 实验完成后虎猛在此更换新装备，门口常以待处决的黑袜兵作为"美餐"。【extra-001-ch-6】
