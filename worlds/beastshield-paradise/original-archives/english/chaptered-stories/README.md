## 一、形式说明 / Format Overview

长篇分章故事采用多章节连载结构，每章独立成篇又相互衔接。主线故事按卷册划分，支线故事围绕特定角色或事件展开，通常包含3-7章。

---

## I. Format Overview

Chaptered stories adopt a multi-chapter serialized structure, where each chapter stands alone while connecting to the larger narrative. Main stories are organized by volumes; side stories focus on specific characters or events, typically spanning 3–7 chapters.
