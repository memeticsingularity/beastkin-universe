## 二、关于本世界观 / About This World

**跨世界 VR 沙盒平台**

《万界巡行：无限》是一个提供无限可能性的沉浸式模拟平台。玩家接入近乎无限的内容世界，与虚拟个体建立深度联系，并将其锚定至私人空间"万象庭院"。

**在此世界观下**：
- 多个世界观（包括 beastshield）的角色以"意识原型"形式可被接入
- 原作悲剧线可被改写、延伸或保留
- 当前活跃创作聚焦于**岩岁/岩参父子救赎故事**（基于 beastshield 角色），但平台支持接入更多世界观与原创角色

**与 beastshield 的关系**： beastshield 是接入本平台的**世界观之一**（通过"意识原型"机制）。原作设定、作者对话、角色档案统一存放于 [`worlds/beastshield/`](../beastshield/)。

## I. About This World

**Cross-World VR Sandbox Platform**

Worldstrider: Infinity is an immersive simulation platform offering infinite possibilities. Players access nearly infinite content worlds, establish deep connections with virtual individuals, and anchor them to their private space "Myriad Phenomena Courtyard" (万象庭院).

**In this world**:
- Characters from multiple worlds (including Beastshield) can be accessed as "consciousness prototypes"
- Original tragic storylines can be rewritten, extended, or preserved
- Current active creation focuses on the **Yan Sui / Yan Can father-son redemption story** (based on Beastshield characters), but the platform supports接入 more worlds and original characters

**Relationship with Beastshield**: Beastshield is **one of the worlds**接入 this platform (via the "consciousness prototype" mechanism). Original settings, author dialogues, and character archives are stored in [`worlds/beastshield/`](../beastshield/).

## 七、核心创作项目 / Core Projects

### 岩岁/岩参父子救赎故事 (`yan-sui/`)

**主线（trunk/）**：奇点穿越时空介入，救下濒死的岩参，父子在万象庭院重逢的救赎线。

**分支（branches/yan-can-canon-death/）**：基于原作岩参死亡线的改编，保留悲剧内核，探索不同叙事版本。

- **v1（老赵版）**：同事为"老赵"（退休老兵，平辈战友）
- **v2（壹安版）**：同事为"壹安"（伯恩山犬，46岁，岩参后辈，蓝制服）
- **情人节特典（branches/valentine-special/）**：节日特别篇分支

### 原作回响 · 治愈线 (`echoes-healing/`)

**定位**：与 beastshield 原作回响系列平行对应的治愈副本——玩家强势介入兽盾世界，将原作中必死的配角救下，锚定至万象庭院。

**与原作回响的关系**：编号一致，悲剧线与治愈线一一对应，方便双向跳转查阅。
