## 项目定位

原作回响系列中，每个配角都死于原作注定的命运。本系列是其在 **Worldstrider: Infinity** 平台下的改写副本——玩家（介入者）强势接入兽盾世界的特定时间节点，将那些本该死掉的配角救下，锚定至万象庭院。

**与原作回响的关系：**

| 维度 | 原作回响系列 | 治愈线系列 |
|------|-------------|-----------|
| 路径 | `beastshield/adaptation-works/short-stories/series-5-original-echoes/` | `worldstrider-infinity/original-archives/chaptered-stories/echoes-healing/` |
| 核心体验 | 猎物死前的内部体验 | 被救后的余温与新生 |
| 结局 | 死亡（原作约束） | 存活（玩家介入） |
| 世界观 | 纯 beastshield 原作 | worldstrider 接入副本 |
| 主角 | 受害者第一人称 | 玩家第一人称 + 受害者后续 |

**阅读顺序建议：**
- 先读原作回响悲剧线 → 建立角色与情感基础
- 再读治愈线 → 作为情感补偿与平行可能

## 创作规范

1. **每篇与原作回响一一对应**——编号一致，方便跳转查阅
2. **玩家主角无名、无外貌描写**——保持代入感，不说名字、不描述形象
3. **强势介入**——玩家以物理方式直接打断处决流程，不依赖时间暂停或系统UI
4. **NPC 无世界认知**——被救角色不知道万象庭院是什么，只知道自己"被带到了安全的地方"
5. **结尾必须接入万象庭院**——与原作兽盾世界彻底脱离，不干涉原作剧情
6. **篇幅与悲剧线相当**——短篇，20-30分钟阅读时长
7. **保留 lanse 风格标记**——白袜、登场公式、感官描写、短段落
