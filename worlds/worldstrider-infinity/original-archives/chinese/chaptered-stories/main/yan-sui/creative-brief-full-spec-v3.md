# 《岩参原作死亡线 v3》创作设定包（正统口述版）

> 目标：严格遵循 2026-05-07/08 暮游口述原设，根除此前 v1/v2 全部已知设定错误，创作岩参死亡线的正统版本。
>
> 本文档包含：世界观机制、角色档案、故事事件链、关键道具、前版错误清单、理想标准。
>
> **核心原则**：源作者设定优先，禁止以"戏剧完整性"为由擅自填补与设定冲突的情节。

## 一、世界观与核心机制

### 1.1 白之都（Beastshield 世界观）

- **城市格局**：被兽盾公司笼罩的 dystopian 城市。西区是平民区/贫困区，工厂区散发着煤烟和铁锈味。
- **季节**：冬季，严寒。雪是核心意象。
- **社会氛围**：谈兽盾色变，大环境迫害下民众心智扭曲。暴力不是简单的仇杀，而是**病态的情绪宣泄与驯化占有**。

### 1.2 兽盾职级

| 职级 | 颜色 | 说明 |
|------|------|------|
| 绿制服 | 墨绿色 | 基层士兵（岩岁） |
| 蓝制服 | — | 中层管理/指挥官（壹安） |
| 白制服 | — | 分部掌权者（仇染） |
| 黑制服 | — | 空降/总部高层（墨武） |

### 1.3 精槽（性欲值）机制

- **核心规则**：所有攻击/刺激造成的伤害转化为性欲值（精槽值）。达到上限时射精并进入濒死僵滞状态。
- **在死亡线中的应用**：岩参恳求壹安用"刑房里那个最不痛苦的"方式送自己走。即通过精槽满值来转移伤害、结束生命。这是一种兽盾内部熟知的"送行"机制。
- **描写原则**：极度收敛、克制。聚焦壹安的感知（手在抖、数脉搏），而非岩参身体的正面描写。更像仪式，而非情欲描写。可明确写出"精槽满值了"以让读者理解死因，但**不写具体性行为细节**。

## 二、核心角色档案

### 2.1 岩参（Yan Shen）—— 被送终者

| 项目 | 内容 |
|------|------|
| **种族** | 灰白虎兽人 |
| **年龄** | 53岁 |
| **身份** | 前兽盾黄金时代员工，已退役 |
| **身体** | 左腿残疾（膝盖关节变形），拄拐杖，走路一瘸一拐 |
| **家庭** | 单亲父亲，独自抚养岩岁长大 |
| **状态** | 被囚禁约两周后救出，尊严崩溃，求死 |

**外貌细节**：
- 灰白相间的虎毛，夹杂斑驳的灰白（不是大面积变白）
- 琥珀色眼睛，眼窝深陷，眼神锐利但沉重
- 白色虎须从口鼻两侧伸出，长而分明，根部夹杂灰色
- 左腿膝盖处皮肤青紫，呈现长期炎症后的暗红色，关节变形
- 被囚禁后：身体瘦得只剩骨头，脖子有深紫色项圈勒痕，全身新旧伤叠压

**性格核心**：
- 真正的兽盾精神传承者，正直负责
- 深沉内敛的父爱，把所有重的东西扛在自己身上
- 强烈的羞耻心与尊严——被囚禁两周后，认为"无法再以被玷污的身体做父亲"
- 教导壹安的方式：不骂、不强迫，递一根烟，等你慢慢想明白

**关键台词风格**：
- 声音不高，但每一个字都有份量
- 把道理掰开了揉碎了说，不急不缓
- 对后辈永远称"小伯"

### 2.2 壹安（Yi An）—— 送终者

| 项目 | 内容 |
|------|------|
| **种族** | 伯恩山犬兽人 |
| **年龄** | 46岁（比岩参小7岁） |
| **生日** | 8月28日 |
| **身份** | 兽盾蓝制服（在职） |
| **昵称** | 岩参叫他"小伯" |
| **状态** | 存活，执行送终与托孤 |

**外貌细节**：
- 伯恩山犬，颜值很高
- 年事已高但年轻力壮，肩膀宽大得像一扇门
- 伯恩山犬特有的垂耳，情绪紧张时会贴平
- 尾巴蓬松，紧张时夹紧、下垂
- 手比岩参大，肉垫厚，掌心粗糙

**性格核心**：
- 血气方刚（年轻时容易冲动），但已被岩参打磨成形
- 有些傲气，心性未尽完全打磨
- 为人不差，对自己人没话说
- 重情义，感恩岩参的提携
- 晋升蓝制服时底下人不服，岩参一个一个去谈

**与岩参的关系**（v3 核心设定）**：
- **后辈与前辈**：壹安是岩参队伍里的后辈，一起出过五六年任务
- **被扶持上位**：岩参私下与战友商议，共同将壹安扶持为蓝制服。原因是队伍里其他人没当官的心，另一批人是刺头。岩参说："小伯人也不坏，对自己人没话说。"
- **称呼系统**：岩参叫"小伯"，壹安叫"前辈"或"岩参前辈"。**绝不称"兄弟"**。

**送终当晚的行为逻辑**：
1. 耳朵贴平、尾巴夹紧（犬科本能恐惧反应）
2. 但继续执行——因为岩参把命交给他，他不能辜负
3. 事后耳朵慢慢立起来，尾巴松开（接受了结局）

### 2.3 岩岁（Yan Sui）—— 沉睡的儿子

| 项目 | 内容 |
|------|------|
| **种族** | 黄虎兽人 |
| **年龄** | 25岁 |
| **身份** | 兽盾绿制服士兵 |
| **状态** | 当晚在隔壁房间沉睡，对一切不知情 |

**外貌细节**：
- 浅金色虎毛，光泽亮丽
- 琥珀色眼睛，脸盘宽阔
- 肌肉发达，脂包肌质感
- 橙黄色虎尾

**在死亡线中的作用**：
- **核心情感锚点**：岩参求死的全部动机——"不能让岁岁看到我这个样子"
- **结尾场景**：醒来后发现父亲已死。握着父亲的手，额头抵在手背上，安静守望。
- **不知情**：他以为父亲只是出了门，不知道父亲经历了什么，也不知道壹安来过。

**重要设定（v3 修正）**：
- **岩岁在岩参死亡之前就已经在兽盾工作**（为养活父亲而入职）。
- 因此托孤情节**绝不涉及"给岩岁找工作"**。

## 三、故事事件链（v3 正统流程）

### 3.1 前情提要

岩参安顿好被围殴的岩岁后，**出门前往壹安住处**。（v2 中"借钱带岁岁离开白之都"的动机为戏剧化填补，v3 不采用。）

### 3.2 核心事件（必须包含）

| 序号 | 事件 | 关键细节 |
|------|------|---------|
| 1 | **出门遇袭** | 被同一伙平民（此前围殴岩岁的狐兽人团伙）袭击。不是当场打死，而是**带走囚禁**。 |
| 2 | **囚禁两周** | 剥光衣物、戴上项圈铁链、犬化对待（只能像狗一样活着）、殴打泄愤+行动调教。**持续时间约两周（14天左右）**。 |
| 3 | **壹安发现** | 壹安**住在岩参被囚禁区域附近**，**偶然发现**异常（嗅觉寻踪或听到异常声响）。**绝非"托人打听"或情报网络**。失踪约一两周。 |
| 4 | **地下室救援** | 推开铁门，血与恐惧的气味。岩参蜷缩墙角，听到脚步声先缩起来护头。认出壹安后无声落泪。 |
| 5 | **带回住处** | 壹安半扶半拖。岩参太轻了，像一捆干柴。左腿拖在地上。 |
| 6 | **请求送终** | 岩参说"杀了我"。理由：**不是"不想拖累儿子"（经济层面）**，而是"我的身体与尊严已被彻底摧毁，我作为父亲的身份已被玷污"——不能让岁岁知道父亲被拴过、跪过、趴在地上舔过。 |
| 7 | **壹安接受** | 不是立刻答应。两人对坐，炉火噼啪。最终壹安说"我来送您"。 |
| 8 | **擦身穿衣** | 最后一次擦身。换上兽盾黄金时代旧制服（军绿色，肩章有兽爪和盾牌标志）。壹安说"您穿这个最像样子"。 |
| 9 | **抽烟仪式** | 最后一根烟。岩参说"很久没抽了，怕岁岁闻到"。两人共抽一根。 |
| 10 | **执行** | 精槽机制。壹安的手伸进被子。岩参脉搏从快到乱到停止。身体猛地绷直，然后落回床上。 |
| 11 | **核心台词** | **"下辈子还让我当你的后辈"**（不是"做兄弟"）。 |
| 12 | **背尸回家** | 壹安背岩参走雪地。左腿拖在地上，走一步滑一下。 |
| 13 | **整理遗容** | 换上干净衬衫，围旧围巾遮住勒痕。梳好虎须。 |
| 14 | **留条** | "岁岁。我是你父亲的后辈。你父亲走了。病逝的。他走得很——" **划掉最后一个字（"安详"），不再补写**。 |
| 15 | **放药与交流券** | 止血粉（岩参出门原本想买的药）放在条子旁边。交流券压在条子下面。 |
| 16 | **岩岁仍在睡** | 壹安握住门把手，没拧开。"让他多睡一会儿。哪怕多一个小时，在这一个小时里，他还有父亲。" |
| 17 | **托孤（v3 修正）** | 壹安**通过自己的关系**联系兽盾长官，**报告岩参死讯**并**请求关照/保护岩岁**（调岗到相对安全位置、抚恤等）。**绝不涉及"给岩岁找工作"或"从最底层做起"**。或者：壹安**不去找长官**，只留条子、交流券、药，默默离开。 |

## 五、前版错误清单（v3 必须根除）

### 5.1 错误1："岩岁因父之死而入兽盾"

**错误表现**：
- 《无归》7-chapters-v1 ch-7：老周安排岩岁进兽盾。
- creative-brief-full-spec-v2.md 第17条："给岩岁一个位置，从最底层做起。"
- DeepSeek 理想 v2："我替岩岁的名字填了一张基层调令，从最底层做起。"

**根源**：将"托孤"过度戏剧化为"安排就业"，完全违背了暮游明确设定。

**正确做法**：
- 岩岁**已经在兽盾工作**。
- 壹安联系长官的目的**不是给岩岁找工作**，而是报告死讯、请求关照/保护。

### 5.2 错误2：救援过程过于顺利/情报来源不合理

**错误表现**：
- 《天亮之前》v1：老周"托人打听"到岩参被关在西区废弃仓库地下室。
- 《无归》7-chapters-v1 ch-3：岩参刚出门就被同一批平民截住，缺少盯梢铺垫。

**根源**：几个人私下囚禁、犬化虐待前兽盾员工是高度隐秘的犯罪，不可能轻易被外人探知。

**正确做法**：
- 壹安**住在岩参被伏击区域附近**。
- 发现机制：**嗅觉寻踪**（伯恩山犬本能）或偶然听到异常声响，**绝非"托人打听"**。
- 如果是线性叙事（7章版），需在 ch-2 结尾或 ch-3 开头增加狐兽人团伙的**盯梢暗示**。

### 5.3 错误3：称呼系统错误

**错误表现**：
- DeepSeek v1/v2 版本："下辈子还做兄弟"。
- 部分版本中出现"老战友""兄弟"等平辈称呼。

**正确做法**：
- 岩参对壹安：**只能叫"小伯"或"壹安"**。
- 壹安对岩参：**只能叫"前辈"或"岩参前辈"**。
- 岩参求死时的核心台词：**"下辈子还让我当你的后辈"**（不是"做兄弟"）。

### 5.4 错误4：v2 中"老周"角色的遗留

**错误表现**：
- snow-night-v2 和 before-dawn-v2 仍然包含"老周"。

**正确做法**：
- v3 设定中**不存在"老周"**这个角色。
- 壹安自己发现岩参，自己联系长官托孤（或不留）。

### 5.5 错误5：第七章/结尾浪漫化

**错误表现**：
- 《无归》7-chapters-v1 ch-7：使用了"传说""梦境""星星"等意象，软化了悲剧结局。
- DeepSeek 理想 v2：次夜独白段落稀释了交替剪接的戛然而止之力。

**正确做法**：
- 不用解释，不用抒情，不用传说。
- 用画面的力量收束。
- 交替剪接（A线壹安回家 / B线岩岁醒来）的最后一幕应**停在岩岁额头抵手背**，不做多余延伸。

### 5.6 错误6：精槽机制描写尺度过大

**错误表现**：
- 《无归》7-chapters-v2 ch-6：执行段落过于详细，有"精液涌出""溅在手上"等正面描写。
- 部分版本将精槽机制写成了情色场景。

**正确做法**：
- **极度收敛、克制**。
- 聚焦壹安的感知（手在抖、数脉搏），而非岩参身体的正面描写。
- 更像仪式，而非情欲描写。

## 六、理想版本标准（v3 创作目标）

### 6.1 结构：由果溯因

- **起点**：壹安已经把岩参救回屋子，岩参躺在床上浑身发抖。
- **揭露方式**：不通过闪回，而是通过擦身时看到的伤口、被触碰时下意识蜷缩的反应、断断续续对话中的碎片，让读者自己拼凑出那十四天。
- **悬念核心**：不是"岩参会遭遇什么"，而是"他到底经历了什么，才会变成现在这个样子"。

### 6.2 节奏：前奏极长，动作极短

- 推迟到天亮前最后一刻动手，因为天亮后勇气会消散
- 手在抖，做不下去，中途停好几次
- 可能无意识地在数岩参的心跳
- 高潮本身极度收敛、克制

### 6.3 结尾：交替剪接（最高优先级）

- **A 线**：壹安回到自己家，灭了炉子，坐在岩参躺过的床边
- **B 线**：早晨岩岁醒来，发现父亲躺在床上，身体还是温热的，怎么也叫不醒
- **最后一幕**：岩岁跪下，额头抵在岩参的手背上——与存档版团圆结局的"额头抵手背"形成**镜像对照**
- **核心原则**：不用解释，不用抒情，不用传说。用画面的力量收束。

### 6.4 创作宣言

> "用壹安的一夜，讲岩参的一生；用一个人无法拒绝的请求，讲两个人之间的情义；用死亡，讲尊严的重量。"

## 七、绝对不能犯的规则

1. **称呼**：壹安对岩参只能称"前辈"，岩参对壹安只能称"小伯"。**绝不出现"兄弟"**。
2. **老周**：v3 设定中不存在老周这个角色。壹安自己发现岩参，自己处理后续。
3. **求死动机**：不是"不想拖累儿子"（经济层面），而是"我的身体与尊严已被彻底摧毁，我作为父亲的身份已被玷污"。
4. **送终方式**：通过精槽机制（"最不痛苦的"）。不是割喉、不是毒药。
5. **时间**：**单夜结构**，不跳时间。不要"多年后"的框架。
6. **收敛原则**：更多笔墨放在前奏的犹豫和事后的余韵上，中间的过渡明确而迅速。
7. **托孤**：**绝不写"给岩岁找工作""从最底层做起""填调令"**。岩岁已在兽盾任职。

## 八、重构 checklist（每次写作前必查）

- [ ] 岩岁是否已经在兽盾工作？（答案是"是"，故事开始时他已经是绿制服）
- [ ] 托孤情节是否涉及"给岩岁找工作"？（答案必须是"否"）
- [ ] 救援发现是否基于"嗅觉/偶然"而非"情报打听"？
- [ ] 称呼是否正确（前辈/小伯，无"兄弟"）？
- [ ] 是否出现了"老周"？（v3 版本答案必须是"否"）
- [ ] 求死动机是否是"尊严崩溃"而非"经济拖累"？
- [ ] 精槽机制是否收敛、仪式化，而非情色化？
- [ ] 单夜结构是否严格遵守（不跳到次日/多年后）？
