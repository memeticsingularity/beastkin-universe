## 📝 创作原则（V2版本）/ Creative Principles (V2 Version)

根据最新要求，V2版本将遵循：

According to the latest requirements, V2 version will follow:

1. **叙事结构 / Narrative Structure**: 取消分幕，连续叙事 / Cancel acts, continuous narrative
2. **节奏 / Pace**: 慢节奏，不跳环节 / Slow pace, no skipped steps
3. **篇幅 / Length**: 单章至少1万字以上 / At least 10,000+ words per chapter
4. **描写重点 / Focus**:
    - 动作和细节（大量、细致、直白、朴素）/ Actions and details (abundant, meticulous, direct, plain)
    - 感官体验（视觉、触觉、嗅觉、味觉）/ Sensory experience (visual, tactile, olfactory, gustatory)
    - 兽人肉体特征（脂包肌、各肌肉群）/ Beastkin physical features (fat-muscle build, muscle groups)
    - 体温、毛发、服饰、肌肉的交互 / Body temperature, fur, clothing, muscle interaction
5. **推进方式 / Progression**: 人物互动推动，非情节推动 / Character interaction-driven, not plot-driven
6. **五要素齐全 / Five Elements Complete**: 心理、神态、动作、环境、语言 / Psychology, expression, action, environment, dialogue
