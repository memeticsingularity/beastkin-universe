## 一、整体故事弧线（V2版）

### 核心主题

**救赎不是一瞬间的奇迹，而是时间的缓慢愈合。**

### 三幕结构

**第一幕：孤独灵魂的拯救**

- 主角：岩岁
- 情感线：从濒死的绝望 → 对陌生人的戒备 → 第一次信任
- 关键转变：虎尾缠绕手腕（信任的象征）

**第二幕：时间的逆流**

- 主角：岩参
- 情感线：从濒死的遗憾 → 对奇迹的困惑 → 接受新可能
- 关键转变：同意被拯救，"他在家里等我"

**第三幕：重建的家园**

- 主角：三人
- 情感线：
    - 父子：失而复得的珍惜
    - 岩参→奇点：从警惕 → 观察 → 试探 → 认可
    - 岩岁→奇点：从被拯救者 → 平等的依恋
- 关键转变：岩参将肉丝夹给奇点（无声的接纳）

## 二、章节规划（讨论稿）

### 方案A：扩展为6章

**Ch1：冻结时刻的凝视（原Ch1扩展）**

- 时间跨度：冻结的几分钟 + 转移后的整夜
- 核心内容：
    - 奇点观察岩岁的过程（视觉、心理）
    - 对话展开得更慢，层层深入
    - 岩岁讲述背景故事（不一次性讲完，分段）
    - 转移、安置、整夜照护（不跳过）
- 重点感官：
    - 岩岁湿透制服的触感
    - 血腥味与汗味的混合
    - 体温的变化
    - 虎尾的触感

**Ch2：温水、往事与赤裸的信赖（清洁与倾诉核心章节）**

- 时间跨度：一晚（从抵达万象庭院到次日清晨）
- 核心内容：
    - **抵达与准备**：双方以"狼藉"状态抵达，奇点准备简单医疗用品（普通人，非专业）
    - **初步淋浴**：先冲澡，冲掉精液、血迹等污秽（防水敷料后续再贴）
    - **温泉浸泡**：放松肌肉，缓解疼痛，在温暖中卸下防备
    - **聊起往事**：清洁过程中岩岁倾诉（父亲岩参、兽盾经历、被诅咒的世界）
    - **简单处理伤口**：奇点作为普通人的包扎（清洁、简单消毒、纱布覆盖）
    - **更换衣物、简单进食**：米白色睡衣，简单的粥或汤
    - **入睡**：在清洁与安全中入睡
- 重点感官：
    - 精液粘腻的触觉与不适
    - 温水冲刷身体的温暖感
    - 肌肉在水中的放松
    - 伤口被触碰时的刺痛
    - 毛发被清洗的感觉
    - 清洁后皮肤的清爽感
    - 食物的温暖香气
- 情感线：
    - 岩岁：羞耻（被看光）→ 放松（在温暖水流中卸下防备）→ 倾诉（聊起往事）→ 信任
    - 奇点：普通人的笨拙与温柔 → 倾听者 → 在脆弱时刻建立信任
- 关键对话：
    - 岩岁讲述父亲岩参
    - 岩岁讲述兽盾世界的"射精死亡"诅咒
    - 奇点倾听，逐渐了解岩岁的过去
- 内容迁移（移至第三章）：
    - 整夜照护、噩梦哭泣、虎尾缠绕
    - 早餐互动、晨光苏醒

**Ch3：两年前的雪（原Ch3独立）**

- 时间跨度：两年前的一夜 + 两年的康复
- 核心内容：
    - 岩参独自走在雪中的心理
    - 围殴的完整经过（更详细）
    - 濒死体验
    - 奇点出现、救治、转移
    - 漫长的康复过程（ montage式但细致）
- 重点感官：
    - 雪的冰冷、血的温热
    - 疼痛的层次
    - 老年身体的触感

**Ch4：晨光中的相认（原Ch4大幅扩展）**

- 时间跨度：一天（从深夜到夜晚）
- 核心内容：
    - 深夜：岩参被安置在岩岁身边（两人的睡姿描写）
    - 凌晨：岩参先醒，凝视儿子的过程
    - 黎明：岩岁逐渐苏醒的感官体验
    - 相认的情感爆发（不能太快，要有层次）
    - 一整天的相处（早餐、散步、对话）
    - 岩岁讲述这两年（回忆与现实交织）
- 重点感官：
    - 晨光的变化
    - 父子体温的对比
    - 眼泪的触感
    - 拥抱的质感

**Ch5：信任的积累（新增章节）**

- 时间跨度：几天到一周
- 核心内容：
    - 岩参观察奇点的日常
    - 岩参的试探（各种小事）
    - 奇点的回应（获得信任的点点滴滴）
    - 岩岁在中间的角色（粘合剂）
    - 某件小事触发岩参的初步认可
- 重点感官：
    - 日常生活的细节
    - 眼神交流
    - 小动作的含义

**Ch6：天穹之下（原Ch5扩展）**

- 时间跨度：除夕一整天
- 核心内容：
    - 早晨的准备（贴春联？准备食材）
    - 上午的活动
    - 年夜饭的完整过程（每道菜）
    - 饭后的游戏/活动
    - 烟火的设计与观看
    - 光之符文的降临
    - 深夜的安眠
- 重点感官：
    - 食物的全感官描写
    - 烟火的光、声、温度
    - 光之符文的触感

## 三、感情线设计

### 主线：父子情的重建

**阶段1：震惊与不信**（相认瞬间）

- 岩岁：以为是梦 → 确认是真实 → 情感崩溃
- 岩参：贪婪凝视 → 担心是幻觉 → 小心触碰确认

**阶段2：小心翼翼的相处**（相认后第一天）

- 不敢眨眼（怕对方消失）
- 频繁的肢体接触确认
- 说话都变得轻声细语

**阶段3：逐渐恢复正常**（几天后）

- 开始有小摩擦（父亲唠叨儿子）
- 恢复到熟悉的相处模式
- 但更加珍惜

### 副线1：岩参→奇点（信任的建立）

**阶段1：警惕**（最初几天）

- 观察奇点的每一个细节
- 测试奇点的耐心（故意为难）
- 岩岁的解释不起作用

**阶段2：好奇**（几天后）

- 开始问问题
- 观察奇点对岩岁的态度
- 私下与岩岁讨论奇点

**阶段3：试探性的接纳**（一周左右）

- 接受奇点的帮助但不说谢谢
- 开始有一些眼神交流

**阶段4：认可**（除夕）

- 夹菜（无声的感谢与接纳）
- 拥抱（身体的认可）
- 按肩（将儿子托付给他）

### 副线2：岩岁→奇点（从被拯救到依恋）

**阶段1：感激与依赖**（Ch1-Ch2）

- 对拯救者的天然亲近
- 但仍有距离感（称呼、礼貌）

**阶段2：习惯的养成**（Ch3-Ch4）

- 开始期待奇点的存在
- 自然的肢体接触
- 虎尾缠绕成为日常

**阶段3：平等的依恋**（Ch5-Ch6）

- 不再只是"被拯救者"
- 开始关心奇点的感受
- 眼神中有了更深层次的东西
