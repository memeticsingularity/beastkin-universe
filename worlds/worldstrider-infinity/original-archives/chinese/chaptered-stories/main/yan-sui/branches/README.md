# 岩岁故事线 · 分岔分支说明

> 本目录存放从 `trunk/`（V2 主干）分出的平行剧情分支。  
> 所有分支共享 `trunk/` 中的前置章节，从指定章节开始走向不同的叙事线。

## 分支一览

### `yan-can-canon-death/` — 岩参原作囚禁线

| 属性 | 说明 |
|------|------|
| **分岔起点** | **ch-4**（`7-chapters/` 版）；`snow-night/` 与 `before-dawn/` 为独立重述 |
| **共享前置** | `trunk/ch-1.md` 至 `trunk/ch-3.md`（岩岁被救、倾诉、沉睡） |
| **分岔原因** | 岩参在原作正统设定中的遭遇与改编版 V2 不同 |
| **核心差异** | 见下表 |

**V2 主干 vs 本作分支 的关键差异：**

| 维度 | trunk/ V2 | branches/yan-can-canon-death/ |
|------|-----------|------------------------------|
| **岩参遭遇** | 被平民围殴打至濒死，奇点当夜救下 | 被囚禁约两周，遭受犬化驯化与羞辱，后被老同事偶然救出 |
| **救援者** | 奇点（穿越时空主动介入） | 老同事（偶然发现）→ 奇点后续介入 |
| **死亡/求死** | 因围殴与诅咒濒死，被动等待死亡 | 被救后主动恳求老同事送自己上路（尊严崩溃） |
| **奇点介入时机** | 岩参濒死于雪地时 | 老同事救下岩参、岩参求死之际 |
| **岩参获救时精神状态** | 虚弱、羞耻但意志清醒 | 严重创伤后应激，尊严体系濒临瓦解 |
| **岩参获救时身体状态** | 外伤（淤青、裂伤、左腿旧伤） | 长期囚禁导致的饥饿、脱水、伤口感染、肌肉萎缩、精神解离 |

**分岔叙事逻辑：**

- ch-1 至 ch-3 中，岩岁关于父亲的叙述保持**模糊兼容**（"他出门后再也没有回来"），不点明是一夜还是两周，因此两个版本的前置章节可以共用。
- 从 ch-4 开始，奇点通过全介质解析引擎观察到的是**完全不同的岩参时间线**，由此进入分支剧情。

### 内部版本对比

`yan-can-canon-death/` 目录下目前存放**四个叙事版本**，共享同一原设核心，仅在叙事策略上存在差异：

| 维度 | `7-chapters/`《无归》 | `snow-night/`《雪夜》 | `before-dawn/`《天亮之前》 | `claude-synth/`《雪停之前》 |
|------|----------------------|----------------------|---------------------------|---------------------------|
| **创作思路** | 基础完整版 | 仅基于原设节点，从零独立创作 | 基于《无归》七章版素材重新编排 | 融合 DeepSeek 理论 + 《天亮之前》克制 + 七章版设定 |
| **叙事视角** | 第三人称有限（岩参→老赵） | 第一人称（老赵） | 第一人称（老赵） | 第一人称（老赵） |
| **时间结构** | 线性顺叙，约 17 天 | 回忆式倒叙，跨越多年 | 一夜压缩，次日后日谈 | **严格单夜**，无任何时间跳跃 |
| **章节形式** | 七章分章，意象化标题 | 单篇连续叙事 | 单篇连续叙事 | 单篇连续叙事 |
| **死亡描写** | 精槽机制，较完整呈现 | 精槽机制，强调 guilt | 极度收敛 | **极度收敛**，聚焦脉搏与呼吸停止 |
| **核心情感** | 岩参尊严的缓慢碎裂 | 老赵终身未愈的创伤与记忆 | 老赵无法回答的道德困境 | **老赵的不知与永远的缺席** |
| **尾声处理** | 传说与岩岁的梦 | 雪夜 ritual，烟灰缸里一个人的烟灰 | 悼念堂偶遇岁岁问讯 | **交替剪接**：老赵回家 vs 岩岁醒来 |
| **篇幅** | 约 3.9 万字 | 约 1 万字 | 约 8,000 字 | 约 7,500 字 |

## 分支命名规则

- 文件夹名：`{核心角色或事件}-` + `{分支特征}`
- 同一分支线下的多个演绎版本，以子目录形式存放于该分支文件夹内
- 必须在本 README 中登记：分岔起点、共享前置、分岔原因
- 每个分支内部独立维护章节编号（从分岔点延续）

---

## 维护说明

- `trunk/` 为当前主故事线（V2），优先保证其完整性
- 分支版本不与 `trunk/` 争优先度，作为平行探索存在
- 若某分支经充分打磨后被采纳为新主干，可通过 git 操作将其提升为 `trunk/`
