# 《岩参原作死亡线》创作指南（修正版）

> 本指南基于**所有源作者设定文件**严格整理，旨在消除此前各版本（包括《无归》7-chapter-v2、《终夜》claude-ideal-v2、DeepSeek 各版本）中反复出现的设定错误。
>
> **核心原则**：源作者设定优先，禁止以"戏剧完整性"为由擅自填补与设定冲突的情节。

---

## 一、源作者暮游确认的核心设定（不可更改）

### 1.1 岩参死亡线（2026-05-07 口述）

| 项目 | 设定 |
|------|------|
| **施暴者动机** | 不是以"杀死对方"为前提。白之都大环境下心智扭曲，暴力呈现为**病态的情绪宣泄与驯化占有**。 |
| **施暴过程** | 岩参被殴打至失去反抗能力后，**被带走囚禁约两周**，而非当场打死。 |
| **囚禁手段** | 剥光衣物、戴上项圈和铁链、当成狗一样粗暴对待、限制活动范围、只能像狗一样活着、殴打泄愤+行动调教。 |
| **持续时间** | 约**一两周**（14天左右）。 |
| **救援者** | 老同事（v2 设定为壹安），**偶然发现**（住在同一区域附近）。 |
| **求死动机** | **不是"不想拖累儿子"（经济层面）**，而是"我的身体与尊严已被彻底摧毁，我作为父亲的身份已被玷污"。 |
| **死亡方式** | 恳求老同事**亲手送行**（应求）。 |
| **遗体处理** | 老同事背负回家、穿衣整理仪容、下葬前整理、通过关系联系兽盾长官给岩岁送噩耗、托嘱照顾好岩岁。 |

## 二、此前所有版本犯过的设定错误（必须根除）

### 错误1："岩岁因父之死而入兽盾"

**错误表现**：
- 《无归》7-chapters-v1 ch-7：老周安排岩岁进兽盾。
- creative-brief-full-spec-v2.md 第17条："给岩岁一个位置，从最底层做起。"
- DeepSeek 理想 v2："我替岩岁的名字填了一张基层调令，从最底层做起。"

**根源**：我将"托孤"过度戏剧化为"安排就业"，完全违背了暮游明确设定。

**正确做法**：
- 岩岁**已经在兽盾工作**。
- 壹安联系长官的目的**不是给岩岁找工作**，而是：
  1. 报告岩参死讯（通过兽盾系统正式传达）；
  2. 请求长官在兽盾内部**关照/保护**岩岁（因为他失去了父亲）；
  3. 可能涉及抚恤、调岗到相对安全的位置，但**绝不是"安排入职"**。

### 错误2：救援过程过于顺利/情报来源不合理

**错误表现**：
- 《天亮之前》v1：老周"托人打听"到岩参被关在西区废弃仓库地下室。
- 《无归》7-chapters-v1 ch-3：岩参刚出门就被同一批平民截住，缺少盯梢铺垫。

**根源**：
- 暮游明确批评："这种几个人做的事情，除非他们自己张扬，不然别人不可能知道。"
- 几个人私下囚禁、犬化虐待前兽盾员工是高度隐秘的犯罪，不可能轻易被外人探知。

**正确做法**：
- 壹安**住在岩参被伏击区域附近**。
- 发现机制：**嗅觉寻踪**（伯恩山犬本能）或偶然听到异常声响，**绝非"托人打听"**。
- 如果是线性叙事（7章版），需在 ch-2 结尾或 ch-3 开头增加狐兽人团伙的**盯梢暗示**（被吓退后不甘心、一直盯梢），消除"出门就被抓"的巧合感。

### 错误3：称呼系统错误

**错误表现**：
- DeepSeek v1/v2 版本："下辈子还做兄弟"。
- 部分版本中出现"老战友""兄弟"等平辈称呼。

**根源**：设定改了，但依赖旧设定的台词没有被同步清理。

**正确做法**：
- 岩参对壹安：**只能叫"小伯"或"壹安"**。
- 壹安对岩参：**只能叫"前辈"或"岩参前辈"**。
- 岩参求死时的核心台词：**"下辈子还让我当你的后辈"**（不是"做兄弟"）。

### 错误4：v2 中"老周"角色的遗留

**错误表现**：
- snow-night-v2 和 before-dawn-v2 仍然包含"老周"。

**根源**：这些版本是 v1 的简单"换皮"（名字替换），不是真正的 v2 重构。

**正确做法**：
- v2 设定中**不存在"老周"**这个角色。
- 壹安自己发现岩参，自己联系长官托孤。

### 错误5：第七章/结尾浪漫化

**错误表现**：
- 《无归》7-chapters-v1 ch-7：使用了"传说""梦境""星星"等意象，软化了悲剧结局。
- DeepSeek 理想 v2：次夜独白段落（"我把那根虎毛又从口袋里掏出来..."）稀释了交替剪接的戛然而止之力。

**根源**：写到最后"不忍心"，用温暖收束替代了冷硬现实。

**正确做法**：
- 不用解释，不用抒情，不用传说。
- 用画面的力量收束。
- 交替剪接（A线壹安回家 / B线岩岁醒来）的最后一幕应**停在岩岁额头抵手背**，不做多余延伸。

### 错误6：精槽机制描写尺度过大

**错误表现**：
- 《无归》7-chapters-v2 ch-6：执行段落过于详细，有"精液涌出""溅在手上"等正面描写。
- 部分版本将精槽机制写成了情色场景。

**根源**：混淆了"送行仪式"与"性描写"。

**正确做法**：
- **极度收敛、克制**。
- 聚焦壹安的感知（手在抖、数脉搏），而非岩参身体的正面描写。
- 更像仪式，而非情欲描写。
- 可明确写出"精槽满值了"以让读者理解死因，但**不写具体性行为细节**。

## 三、重构 checklist（每次写作前必查）

- [ ] 岩岁是否已经在兽盾工作？（答案是"是"，故事开始时他已经是绿制服）
- [ ] 托孤情节是否涉及"给岩岁找工作"？（答案必须是"否"）
- [ ] 救援发现是否基于"嗅觉/偶然"而非"情报打听"？
- [ ] 称呼是否正确（前辈/小伯，无"兄弟"）？
- [ ] 是否出现了"老周"？（v2 版本答案必须是"否"）
- [ ] 求死动机是否是"尊严崩溃"而非"经济拖累"？
- [ ] 精槽机制是否收敛、仪式化，而非情色化？
- [ ] 单夜结构是否严格遵守（不跳到次日/多年后）？
- [ ] 结尾是否干净收束，不用传说/梦境软化？

## 五、托孤场景的正确写法（v2 版本）

**绝对不能写**：
- "我可以把他安排进兽盾"
- "从最底层做起"
- "填调令"
- 任何暗示岩岁因为父亲之死而获得工作的内容

**可以写**：
- 壹安向长官报告岩参死讯。
- 长官表示会**关照**岩岁（因为岩岁已经在兽盾工作）。
- 壹安请求长官不要让岩岁知道真相（至少现在不要）。
- 壹安请长官在兽盾内部给予岩岁必要的保护或调岗到相对安全的位置。
- 或者：壹安**不去找长官**，只是在岩参家中留下条子和药，默默离开。托孤通过"条子+交流券+药"的静默方式完成。

**推荐做法**（最干净）：
参照《终夜》的处理方式——壹安留下条子、交流券、药，没有去找长官，没有说任何关于岩岁工作的话。因为岩岁已经在兽盾了，他不需要被"安排"。壹安能做的，只是让这个孩子"多睡一会儿"。
