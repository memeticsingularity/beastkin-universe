# 《无归》单章理想版 v3

## 说明

本文是基于 2026-05-07/08 暮游口述原设严格创作的单章连续叙事版本，与 `7-chapters-v3/` 并行存在。

## 结构特点

- **由果溯因**：故事从壹安已将岩参救回住处开始，不通过闪回，而是通过擦身时看到的伤口、被触碰时的下意识反应、断断续续对话中的碎片，让读者自己拼凑出那十四天。
- **悬念核心**：不是"岩参会遭遇什么"，而是"他到底经历了什么，才会变成现在这个样子"。
- **节奏**：前奏极长，动作极短。推迟到天亮前最后一刻动手。
- **结尾**：交替剪接（A线壹安回家 / B线岩岁醒来），停在额头抵手背，无传说无梦境软化。

## 与7章版的区别

| 维度 | 7-chapters-v3 | claude-ideal-v3（本文） |
|------|---------------|------------------------|
| 结构 | 线性叙事（出门→围殴→囚禁→救出→求死→归途→无归） | 由果溯因（从救出后擦身开始，侧面拼凑囚禁） |
| 囚禁描写 | 正面呈现（ch-3/ch-4） | 完全侧面，通过伤口与条件反射暗示 |
| 篇幅 | 七章，约1.5万字 | 单章，约6000字 |
| 节奏 | 快慢交替，有完整动作戏 | 前奏极长，执行极度收敛 |
| 视角重心 | 岩参（ch-1~ch-5）→壹安（ch-6）→交替（ch-7） | 全程紧密跟随壹安 |
