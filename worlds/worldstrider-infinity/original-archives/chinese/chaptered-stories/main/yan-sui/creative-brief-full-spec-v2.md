# 《岩参原作死亡线 v2》创作设定包（全盛姿态版）

> 目标：供 DeepSeek 参考，写一个融合所有版本优点、修正全部已知缺陷的终极版本。
>
> 本文档包含：世界观机制、角色档案、故事事件链、关键道具、前四版优缺点、理想标准。

---

## 一、世界观与核心机制

### 1.1 白之都（Beastshield 世界观）

- **城市格局**：被兽盾公司笼罩的 dystopian 城市。西区是平民区/贫困区，工厂区散发着煤烟和铁锈味。
- **季节**：冬季，严寒。雪是核心意象。
- **社会氛围**：谈兽盾色变，大环境迫害下民众心智扭曲。暴力不是简单的仇杀，而是病态的情绪宣泄与驯化占有。

### 1.2 兽盾职级

| 职级 | 颜色 | 说明 |
|------|------|------|
| 绿制服 | 墨绿色 | 基层士兵（岩岁） |
| 蓝制服 | — | 中层管理/指挥官（壹安） |
| 白制服 | — | 分部掌权者（仇染） |
| 黑制服 | — | 空降/总部高层（墨武） |

### 1.3 精槽（性欲值）机制

- **核心规则**：所有攻击/刺激造成的伤害转化为性欲值（精槽值）。达到上限时射精并进入濒死僵滞状态。
- **在死亡线中的应用**：岩参恳求壹安用"刑房里那个最不痛苦的"方式送自己走。即通过精槽满值来转移伤害、结束生命。这是一种兽盾内部熟知的"送行"机制。
- **描写原则**：极度收敛、克制。聚焦壹安的感知（手在抖、数脉搏），而非岩参身体的正面描写。更像仪式，而非情欲描写。

## 二、核心角色档案

### 2.1 岩参（Yan Shen）—— 被送终者

| 项目 | 内容 |
|------|------|
| **种族** | 灰白虎兽人 |
| **年龄** | 53岁 |
| **身份** | 前兽盾黄金时代员工，已退役 |
| **身体** | 左腿残疾（膝盖关节变形），拄拐杖，走路一瘸一拐 |
| **家庭** | 单亲父亲，独自抚养岩岁长大 |
| **状态** | 被囚禁约两周后救出，尊严崩溃，求死 |

**外貌细节**：
- 灰白相间的虎毛，夹杂斑驳的灰白（不是大面积变白）
- 琥珀色眼睛，眼窝深陷，眼神锐利但沉重
- 白色虎须从口鼻两侧伸出，长而分明，根部夹杂灰色
- 左腿膝盖处皮肤青紫，呈现长期炎症后的暗红色，关节变形
- 被囚禁后：身体瘦得只剩骨头，脖子有深紫色项圈勒痕，全身新旧伤叠压

**性格核心**：
- 真正的兽盾精神传承者，正直负责
- 深沉内敛的父爱，把所有重的东西扛在自己身上
- 强烈的羞耻心与尊严——被囚禁两周后，认为"无法再以被玷污的身体做父亲"
- 教导壹安的方式：不骂、不强迫，递一根烟，等你慢慢想明白

**关键台词风格**：
- 声音不高，但每一个字都有份量
- 把道理掰开了揉碎了说，不急不缓
- 对后辈永远称"小伯"

### 2.2 壹安（Yi An）—— 送终者

| 项目 | 内容 |
|------|------|
| **种族** | 伯恩山犬兽人 |
| **年龄** | 46岁（比岩参小7岁） |
| **生日** | 8月28日 |
| **身份** | 兽盾蓝制服（在职） |
| **昵称** | 岩参叫他"小伯" |
| **状态** | 存活，执行送终与托孤 |

**外貌细节**：
- 伯恩山犬，颜值很高
- 年事已高但年轻力壮，肩膀宽大得像一扇门
- 伯恩山犬特有的垂耳，情绪紧张时会贴平
- 尾巴蓬松，紧张时夹紧、下垂
- 手比岩参大，肉垫厚，掌心粗糙

**性格核心**：
- 血气方刚（年轻时容易冲动），但已被岩参打磨成形
- 有些傲气，心性未尽完全打磨
- 为人不差，对自己人没话说
- 重情义，感恩岩参的提携
- 晋升蓝制服时底下人不服，岩参一个一个去谈

**与岩参的关系**（v2 核心设定）**：
- **后辈与前辈**：壹安是岩参队伍里的后辈，一起出过五六年任务
- **被扶持上位**：岩参私下与战友商议，共同将壹安扶持为蓝制服。原因是队伍里其他人没当官的心，另一批人是刺头。岩参说："小伯人也不坏，对自己人没话说。"
- **称呼系统**：岩参叫"小伯"，壹安叫"前辈"或"岩参前辈"。**绝不称"兄弟"**。

**送终当晚的行为逻辑**：
1. 耳朵贴平、尾巴夹紧（犬科本能恐惧反应）
2. 但继续执行——因为岩参把命交给他，他不能辜负
3. 事后耳朵慢慢立起来，尾巴松开（接受了结局）

### 2.3 岩岁（Yan Sui）—— 沉睡的儿子

| 项目 | 内容 |
|------|------|
| **种族** | 黄虎兽人 |
| **年龄** | 25岁 |
| **身份** | 兽盾绿制服士兵 |
| **状态** | 当晚在隔壁房间沉睡，对一切不知情 |

**外貌细节**：
- 浅金色虎毛，光泽亮丽
- 琥珀色眼睛，脸盘宽阔
- 肌肉发达，脂包肌质感
- 橙黄色虎尾

**在死亡线中的作用**：
- **核心情感锚点**：岩参求死的全部动机——"不能让岁岁看到我这个样子"
- **结尾场景**：醒来后发现父亲已死。握着父亲的手，额头抵在手背上，安静守望。
- **不知情**：他以为父亲只是出了门，不知道父亲经历了什么，也不知道壹安来过。

## 三、故事事件链（v2 标准流程）

### 3.1 前情提要

岩参出门找壹安。动机（v2 重构）：不是单纯叙旧，而是**想向壹安借钱，带岁岁离开白之都**。

### 3.2 核心事件（必须包含）

| 序号 | 事件 | 关键细节 |
|------|------|---------|
| 1 | **出门遇袭** | 被同一伙平民袭击。不是当场打死，而是**带走囚禁**。 |
| 2 | **囚禁两周** | 剥光衣物、戴上项圈铁链、犬化对待（只能像狗一样活着）、殴打泄愤+行动调教。 |
| 3 | **壹安发现** | 壹安住在附近，**偶然发现**（不是老周通知）。失踪约一两周。 |
| 4 | **地下室救援** | 推开铁门，血与恐惧的气味。岩参蜷缩墙角，听到脚步声先缩起来护头。认出一壹安后无声落泪。 |
| 5 | **带回住处** | 壹安半扶半拖。岩参太轻了，像一捆干柴。左腿拖在地上。 |
| 6 | **请求送终** | 岩参说"杀了我"。理由：伤能好，有些东西好不了。不能让岁岁知道父亲被拴过、跪过、趴在地上舔过。 |
| 7 | **壹安接受** | 不是立刻答应。两人对坐，炉火噼啪。最终壹安说"我来送您"。 |
| 8 | **擦身穿衣** | 最后一次擦身。换上兽盾黄金时代旧制服（军绿色，肩章有兽爪和盾牌标志）。壹安说"您穿这个最像样子"。 |
| 9 | **抽烟仪式** | 最后一根烟。岩参说"很久没抽了，怕岁岁闻到"。两人共抽一根。 |
| 10 | **执行** | 精槽机制。壹安的手伸进被子。岩参脉搏从快到乱到停止。身体猛地绷直，然后落回床上。 |
| 11 | **核心台词** | **"下辈子还让我当你的后辈"**（不是"做兄弟"）。 |
| 12 | **背尸回家** | 壹安背岩参走雪地。左腿拖在地上，走一步滑一下。 |
| 13 | **整理遗容** | 换上干净衬衫，围旧围巾遮住勒痕。梳好虎须。 |
| 14 | **留条** | "岁岁。我是你父亲的后辈。你父亲走了。病逝的。他走得很——" 划掉最后一个字。 |
| 15 | **放药与交流券** | 止血粉（岩参出门原本想买的药）放在条子旁边。交流券压在条子下面。 |
| 16 | **岩岁仍在睡** | 壹安握住门把手，没拧开。"让他多睡一会儿。哪怕多一个小时，在这一个小时里，他还有父亲。" |
| 17 | **托孤** | 壹安**通过自己的关系**联系兽盾长官（不是通过老周）。给岩岁一个位置，从最底层做起。 |

## 五、前四版优缺点（必须吸收/避免）

### 5.1 《无归》7-chapters-v2（Claude）

**必须吸收**：
- 出门动机重构："借钱带岁岁离开白之都"——让岩参的出门与壹安的经济能力直接挂钩
- 最完整的叙事闭环：从出门到托孤，每一步都有交代

**可以改进**：
- 托孤部分对壹安蓝制服人脉的利用不够充分（ generic "长官"）

### 5.2 《雪停之前》claude-synth-v2（Claude）

**必须吸收**：
- **核心台词修正**："下辈子还让我当你的后辈"——唯一正确执行了后辈身份的版本
- **精槽机制的明确呈现**：伤害转过去，满了，人走了
- 极度收敛的高潮："把手伸进被子里"——不说做了什么，但读者全懂

**可以改进**：
- 篇幅较短，壹安的心理刻画可以更丰富

### 5.3 《雪夜》snow-night-v2（DeepSeek）

**必须吸收**：
- 氛围营造：煤烟、铁锈味、血与恐惧混合的气味
- 感官细节：项圈皮肉黏连的触感、伯恩山犬垂耳贴平的本能反应

**必须避免**（已被 DeepSeek 自我承认）：
- ❌ "下辈子还做兄弟"——不符合后辈身份
- ❌ 老周出现——v2 设定下不应存在

### 5.4 《天亮之前》before-dawn-v2（DeepSeek）

**必须吸收**：
- 第一人称叙述的稳定性
- "每年下雪"的时间跨度感，强化悼念的仪式感
- "左腿拖在雪地上"的 haunting 意象重复

**必须避免**：
- ❌ 同样保留"下辈子还做兄弟"
- ❌ 老周再次出现，托孤通过老周完成

## 六、理想版本标准（DeepSeek 理论构想 + Claude 评价）

### 6.1 结构：由果溯因

- **起点**：壹安已经把岩参救回屋子，岩参躺在床上浑身发抖。
- **揭露方式**：不通过闪回，而是通过擦身时看到的伤口、被触碰时下意识蜷缩的反应、断断续续对话中的碎片，让读者自己拼凑出那十四天。
- **悬念核心**：不是"岩参会遭遇什么"，而是"他到底经历了什么，才会变成现在这个样子"。

### 6.2 节奏：前奏极长，动作极短

- 推迟到天亮前最后一刻动手，因为天亮后勇气会消散
- 手在抖，做不下去，中途停好几次
- 可能无意识地在数岩参的心跳
- 高潮本身极度收敛、克制

### 6.3 结尾：交替剪接（最高优先级）

- **A 线**：壹安回到自己家，灭了炉子，坐在岩参躺过的床边
- **B 线**：早晨岩岁醒来，发现父亲躺在床上，身体还是温热的，怎么也叫不醒
- **最后一幕**：岩岁跪下，额头抵在岩参的手背上——与存档版团圆结局的"额头抵手背"形成**镜像对照**
- **核心原则**：不用解释，不用抒情，不用传说。用画面的力量收束。

### 6.4 创作宣言

> "用壹安的一夜，讲岩参的一生；用一个人无法拒绝的请求，讲两个人之间的情义；用死亡，讲尊严的重量。"

## 七、绝对不能犯的规则

1. **称呼**：壹安对岩参只能称"前辈"，岩参对壹安只能称"小伯"。**绝不出现"兄弟"**。
2. **老周**：v2 设定中不存在老周这个角色。壹安自己发现岩参，自己联系长官托孤。
3. **求死动机**：不是"不想拖累儿子"（经济层面），而是"我的身体与尊严已被彻底摧毁，我作为父亲的身份已被玷污"。
4. **送终方式**：通过精槽机制（"最不痛苦的"）。不是割喉、不是毒药。
5. **时间**：**单夜结构**，不跳时间。不要"多年后"的框架。
6. **收敛原则**：更多笔墨放在前奏的犹豫和事后的余韵上，中间的过渡明确而迅速。
