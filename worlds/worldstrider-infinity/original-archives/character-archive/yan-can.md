## 二、原作设定

### 2.1 原作中的角色定位

岩参在原作中并未直接出场（正文），但通过岩岁的回忆和设定文件，他是一个**关键的精神象征**和**悲剧源头**：

- **兽盾精神的真正传承者**：在"牙董事长"上任导致兽盾变质前退休，是"真正的兽盾兵"
- **岩岁道德底色的塑造者**：教导儿子"力量与责任并存，拥有力量就意味着承担更多的责任"
- **家庭悲剧的核心**：他的遭遇（被打致残→最终被杀）是岩岁痛苦的根源，也是岩岁入职兽盾的动机

### 2.2 原作背景故事（yan-sui-2-1 / yan-sui-2-2）

**兽盾黄金时代：**

- 岩参是**最初的兽盾员工**，那时的兽盾"没有背离自己的初衷，确实是兽民们结实的后盾"
- 不同于后来"从兽盾中退休等于死亡"的情况，那会的兽盾名副其实
- 岩参身边有不少前兽盾的同事一同生活，形成了积极向上的氛围

**兽盾变质与离职：**

- 兽盾在迎来"牙董事长"后发生180度大转变
- **幸运的是**，岩参刚好在牙董上任之前辞退了兽盾的工作，因此逃过一劫
- 岩岁的童年对兽盾的第一印象并非污浊不堪，正是源于父亲这段经历

**抗议致残：**

- 兽盾质变后，暴行不断扩大笼罩白之都
- 岩参身为前兽盾员工，看到兽盾如此堕落"心中很不是滋味"
- 选择联合身边的前兽盾同事一起去"讨个说法"
- 结果：白之都环境已彻底变成"谈兽盾色变"，抗议遭到兽盾兵暴力殴打
- **不幸变为残疾，卧病在床**
- 左腿残疾，膝盖关节变形，无法像正常人一样行走

**家庭破碎（原作版本）：**

- 岩岁为养活父亲，瞒着他偷偷入职兽盾
- 岩参康复无望（或伤势好转后），**为了不拖累岩岁而选择自尽**
- 留下遗言："
  不要怨恨具体的某一个或者一群人，要恨某一种行为或者是概念，憎恶前者没有任何意义，因为前者随时会从兽人的行为中再度诞生，只有粉碎其源头才是真正的斩断循环。"

**原作世界线结局：**

- 岩参已死亡（自杀/被杀）
- 岩岁在兽盾中迷茫地生存
- 最终在《白兔暗影》第一章被仇染处决
- **父子二人在原作中都是悲剧牺牲品**

### 2.3 父子回忆故事（yan-can-yan-sui-flashback）

**童年回忆（岩岁约4-5岁）：**

*共浴时光：*

- 岩参下班后穿着制服回家，身上带有汗酸味
- 岩岁调皮地要求和父亲一起洗澡
- 岩参作为"肉垫"托举着岩岁，任儿子对自己"又捏又摸"
- 岩岁意外挑逗父亲乳头，被岩参教育"这种地方不能乱碰"
- 岩参因厨房危险而态度冷淡，岩岁误解为"爸爸不要我了"

*交流券的诞生：*

- 岩岁产生偏激想法："只要我把自己换掉，爸爸就会更幸福"
- 岩岁独自出走，岩参焦急寻找后和解
- **岩参手写一沓"交流券"**，承诺"无论如何都一定会和你好好说话"
- 这个设定成为父子情感的核心象征

**成年后的孤独（岩参死后，岩岁的回忆）：**

*新年扫墓：*

- 岩岁独自带着酒去父亲墓前
- 醉酒后的哭诉："岁岁没能成为一个顶天立地的男子汉"
- **烧"交流券"**：将珍贵的交流券点燃，呼唤父亲来梦中相见
- 奇迹发生：醒来时躺在家里的床上，桌上有热饺子和字条

*字条内容：*
> "岁岁，爸爸爱你，新年快乐。"

**故事性质**：留白的温情超自然结局——是幻觉？是父亲的灵魂？还是岩岁的梦境？作者没有明确说明，但情感冲击力极强。

## 三、外貌特征（基于新版改编故事 ch-1至ch-5）

### 3.1 整体形象

岩参是一位**饱经风霜的老虎兽人**，53岁，前兽盾员工的底子让他依然壮实，只是岁月与苦难给身躯添了一层沉重感，左腿残疾让他行走时一瘸一拐，但**老虎的底气仍在**。

**体型特征：**

- **依然壮实**，前兽盾员工的体格底子还在
- **身形微驼**（因为左腿残疾长期不平衡），但骨架宽阔挺拔
- **肌肉保留脂包肌结构**，比年轻时多一层岁月沉淀的厚度，不再是紧绷锋利的状态，而是**沉稳厚重**
- **整体气场**：像一头被困住的老虎——底子还是猛兽，只是被生活磨出了沉稳和疲惫

### 3.2 毛发与肤色

| 部位        | 特征                                |
|-----------|-----------------------------------|
| **皮毛主色**  | 黯淡的橙黄色，夹杂**斑驳的灰白**（不是大面积变白）       |
| **虎纹**    | 黑色虎纹依然可辨，但比年轻时显得柔和                |
| **脸颊/口鼻** | 浅金色毛发夹杂灰白，下颌处的胡须根部有一片灰白          |
| **胸腹部**   | 浅金色短毛覆盖，依然厚实丰满，没有年轻时的紧绷光泽，但毛发整齐有质感 |
| **受伤部位**  | 左腿膝盖处皮肤青紫，呈现长期炎症后的暗红色             |

### 3.3 面部特征

**整体脸型：**
- **脸盘宽阔**，典型的虎吻结构，比岩岁更显沉稳厚重
- **口鼻部略向前突出**，覆盖浅金色短毛夹杂灰白

**五官细节：**

| 部位 | 特征 |
|-----|------|
| **眼睛** | 琥珀色，竖瞳；眼窝深陷，**锐利但带着岁月的沉重**；专注时凌厉，温和时柔软 |
| **鼻子** | 黑色，湿润，宽大；鼻尖随呼吸微微翕动 |
| **嘴唇/嘴部** | 厚实，干燥时会起皮；**白色虎须从口鼻两侧伸出，长而分明**，根部夹杂灰色 |
| **眉毛** | 深棕色夹杂灰白，浓密；专注时紧皱，舒展时显出沉稳 |
| **额纹** | 眉骨上方有几道深色的老虎纹路，岁月让纹路更深刻 |
| **皱纹** | 眼角有几道深刻的鱼尾纹，法令纹明显但不深陷 |
| **头顶毛发** | 浅金色短毛夹杂灰白，比脸颊稍长 |
| **耳朵** | 虎耳从发间探出；耳背覆盖黑色绒毛（夹杂灰色），内侧浅粉色；耳尖有一撮黑色毛簇 |
| **下颌** | 线条硬朗，带着虎族特有的棱角，比年轻时多一层厚重感 |
| **牙齿** | 略微发黄，但依然完整有力 |

### 3.4 身体细节

**躯干：**

- **胸膛**：依然厚实饱满，**脂包肌结构清晰**——胸肌轮廓在毛发下能看出，比年轻时多一层岁月沉淀的厚度
- **胸肌**：保留兽人特有的脂包肌质感，肌肉块垒分明，表面覆盖一层薄薄的脂肪
- **腹部**：肌肉依然结实，**有岁月沉淀的厚度感**，不是年轻人的紧绷六块腹肌，但也绝非松弛
- **腰背**：虽因左腿残疾而略显倾斜，但脊背依然挺直

**手臂：**

- **整体**：**结实有力**，前兽盾员工的训练痕迹还在，肌肉线条清晰但不再紧绷
- **肩膀**：宽阔厚实，斜方肌发达
- **手掌**：粗糙宽大，深色的肉垫厚实，指关节粗大但有力
- **手指**：骨节分明，指甲厚实发黄、边缘不规则；手指因岁月而略显粗糙
- **手背**：浅金色短毛覆盖，毛发依然整齐

**腿部：**

- **左腿（残疾）**：
    - 膝盖关节彻底变形，骨骼错位
    - 软组织肿胀僵硬
    - 皮肤呈现不健康的紫红色
    - 走路时一瘸一拐，发出摩擦声
    - **大腿肌肉因长期不能正常用力而比右腿略瘦**
- **右腿**：依然结实有力，**承担了大部分行走重量**，肌肉甚至比左腿更发达
- **臀部**：依然结实饱满，老虎兽人的天生体格在

**尾巴：**

- **橙黄色虎尾**夹杂斑驳灰白，长度过膝
- **尾毛厚实**（不稀疏），有兽人特有的光泽（虽不如年轻时光亮）
- 自然下垂，思考或紧张时会微微摆动

### 3.5 伤痕

- **左腿**：被兽盾殴打致残的旧伤，永久性残疾，是身上最显眼的痕迹
- **额角**：第四章被石头砸出的新伤（围殴中被平民用石头砸伤）
- **全身**：被围殴时留下的多处淤青、擦伤与皮毛撕扯伤；年轻时作为兽盾士兵留下的零星疤痕
- **腹部**（原作设定）：被匕首刺入的致命伤——**此设定仅在原作中存在，V2新版中岩参的致命伤为围殴导致的全身创伤与失血，并无匕首伤**

### 3.6 与岩岁的相似与差异

**相似点：**
- 同为老虎兽人，琥珀色眼睛，黑色鼻头，白色虎须
- 都有兽人脂包肌的体格特征
- 同样宽阔的肩膀和厚实的胸膛

**差异点：**
- **岩岁**：青年壮虎，肌肉紧绷锋利，毛发光亮鲜艳
- **岩参**：成熟老虎，肌肉沉稳厚重，毛发夹杂灰白
- **岩岁**：眼神锐利但有迷茫
- **岩参**：眼神锐利但有岁月沉淀的厚重

## 四、性格特征

### 4.1 原作设定性格

| 特征       | 描述             |
|----------|----------------|
| **正直负责** | 真正的兽盾精神传承者     |
| **深沉父爱** | 独自抚养儿子，教导正确价值观 |
| **理性光辉** | 遗言中体现超越仇恨的智慧   |
| **牺牲精神** | 为了不拖累儿子选择自尽    |

### 4.2 新版故事展现的性格（基于 ch-4至ch-5）

1. **沉默坚韧**
    - 被围殴时不喊叫、不威胁，像一头被逼到绝境的老兽
    - 爬行回家时用手指抠进雪地，指甲缝里塞满污泥和血，仍盯着家的方向

2. **内敛深沉的父爱**
    - 濒死时向陌生人倾诉对儿子的牵挂，说出口后又自我撤回（"算了……他会自己撑过去的"）
    - 见到沉睡的儿子时无声落泪，额头抵着儿子的手背，不忍惊醒他

3. **强烈的羞耻心与尊严**
    - 被奇点清洁和换衣时感到巨大羞耻，但身体的虚弱让他无力拒绝
    - 最不愿让人看到的就是残疾的左腿和濒死时的不堪

4. **敏锐的观察力**
    - 立刻注意到奇点没有兽人特有的肉垫，确认他不是这个世界的人
    - 注意到奇点手指发抖但眼神专注，判断他"不是专业人士，只是在尽力帮忙"

5. **对奇点的复杂情感（初期）**
    - 最初的警惕与困惑（"你做了什么……这不可能"）
    - 逐渐的信任与感激（接受清洁、温泉、喂食）
    - 尚未达到"认可托付"阶段，但已产生依赖

## 五、关键场景形象（新版故事 V2）

### 5.1 濒死与获救（ch-4）

**环境：** 白之都西区后巷，肮脏的雪地与泥泞

**状态：**

- 深色旧大衣被血和污泥浸透，几乎看不出原色
- 额角被石头砸出裂伤，鲜血顺着脸颊流下，沾湿白色虎须
- 皮毛被撕扯，皮肤被划破，腹部、背部布满淤青
- 左腿以扭曲角度瘫在地上，旧伤被反复踢打，完全失去知觉

**诅咒发作：**

- 在殴打中身体失控，勃起并射精，精液与血液混合浸透裤子
- 巨大的羞耻感比殴打本身更彻底，担心儿子看到自己这副模样

**奇点介入：**

- 年轻人跪在雪地里，手忙脚乱地用围巾按住额角伤口
- 悄悄将咬破手指的鲜血渗入绷带，喂入岩参口中，打破诅咒
- 岩参发现射精后仍未死亡，震惊不已

### 5.2 时空转移与苏醒（ch-4末至ch-5初）

**转移过程：**

- 奇点搀扶岩参，温暖的光芒包裹两人
- 岩参意识清醒，感到身体变轻，伤痕与恐惧在光芒中剥离
- 落地时落在柔软温暖的床铺上，空气中有淡淡的花草香气

**苏醒初期：**

- 观察到陌生的米白色天花板，空气干净温暖
- 奇点仍站在床边，手指微微发抖，但眼神已恢复专注
- 身下是黏腻的湿意（之前失控的精液与血液），感到极度羞耻

### 5.3 康复与清洁（ch-5）

**清洁过程：**

- 奇点解开破旧布带腰带，缓缓褪下沾满精液、血液和污泥的裤子
- 用温热湿毛巾仔细擦拭每一寸皮肤，动作轻得像对待易碎瓷器
- 换上深灰色棉质内裤与深蓝色宽松棉质睡衣

**伤口处理：**

- 额角裂伤：清洗、消毒、上药、包扎
- 手臂擦伤与肋骨附近淤青：清洗并上药
- 左腿变形关节：仅轻轻擦拭周围皮肤，未做特别处理，随后盖好被子

**温泉：**

- 被搀扶至天然温泉池，水温恰到好处
- 水的浮力减轻身体重量，温热渗透进疼痛的肌肉和关节
- 与奇点确认对方"不是这个世界的人"，但未追问细节

**进食：**

- 奇点喂了一碗白粥（熬得很稠，撒切碎青菜和香油）
- 岩参想起从前给儿子熬粥的日子，眼眶发热

### 5.4 父子隔墙相守（ch-5结尾）

**相见场景：**

- 奇点搀扶岩参来到岩岁房间，岩岁在月光下沉睡
- 皮毛健康的橙黄色，眉头微皱但嘴角带微笑
- 岩参坐在床沿（没有躺下），颤抖的手轻触儿子脸颊，确认温暖真实

**情感爆发：**

- 无声落泪，额头慢慢抵在儿子手背上
- 一只手撑床保持平衡，另一只手覆在儿子手背上
- 肩膀微微颤抖，但没有发出声音，怕惊醒儿子

**奇点的位置：**

- 一墙之隔的走廊里，靠墙静静倾听
- 没有进去，站了一会儿后轻轻走开

## 八、原作死亡线（另一世界线）

除救赎线（trunk/）外，岩参在原作设定中的死亡线也在 `yan-sui/branches/yan-can-canon-death/` 中进行了完整改编。

### 8.1 故事梗概（基于 2026-05-07 暮游口述原设）

岩参在安顿好被围殴的岩岁后，出门前往壹安住处。途中被同一伙平民（此前围殴岩岁的狐兽人团伙）伏击。对方并非以杀死他为目的——在确认岩参失去反抗能力后，将他带走囚禁。

**囚禁约两周期间：**
- 剥光衣物，戴上项圈，拴上铁链，限制活动范围
- 当成狗一样粗暴对待，只能像狗一样活着
- 殴打泄愤与行动调教并行
- 岩参的身体和精神被彻底碾碎

**救援：** 约两周后，壹安（住在岩参被囚禁区域附近）偶然发现异常，将岩参救出。

**求死：** 被救出后，岩参因尊严彻底崩溃而恳求壹安杀了自己。求死动机不是"不想拖累儿子"（经济层面），而是"我的身体与尊严已被彻底摧毁，我作为父亲的身份已被玷污"——他不愿让岩岁看到自己被驯化后的模样。

**送终：** 壹安在痛苦中同意，通过精槽机制（兽盾刑房中"最不痛苦的"方式）亲手送岩参上路。

**善后：** 壹安将岩参的尸体背负回家，整理遗容，留下条子和岩参生前想给岁岁买的药。岩岁当时仍在沉睡，对一切不知情。

**重要纠正：** 此前部分版本写"托孤于兽盾/安排岩岁进兽盾"是**错误**的。岩岁在岩参死亡之前就已经在兽盾工作了（为养活父亲而入职），因此托孤情节**绝不涉及"给岩岁找工作"**。
