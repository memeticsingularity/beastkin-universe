## 二、原作设定

### 2.1 基础设定文件（20251227）

**第一部分：来源于原作者对象的设计（亲密关系与特殊体质）**

1. **秘密情侣关系**：岩岁与仇染是秘密的情侣关系，此事并未公开，仅有他们二人知晓
2. **特殊体质设定**：少数兽人（包括岩岁）拥有一种特殊体质，即在射精后不会死亡
3. **体质触发效果**：当这一行为是由特定对象（仇染）导致时，该体质会被触发
4. **效果具体表现**：触发后，岩岁会转变为仇染忠实的奴仆（认主绑定）
5. **效果性质**：此绑定效果推测为一次性，且可能通过性行为触发

**第二部分：来源于原作者Author的设计（岩岁的个人背景与性格）**

1. **本性底色**：最初的性格本质是老实、憨厚、淳朴的
2. **环境压迫与转变**：兽盾世界的残酷环境迫使岩岁逐渐改变了原本的性格，外在表现转向了与本性相反的方向
3. **内心矛盾**：道德良心与兽盾的要求持续冲突，意识到自己并不适合做一个纯粹的坏人
4. **生存策略**：为了在道德水平低下的环境中生存，选择向环境妥协，采用"装作不会痛苦"的自我麻痹策略
5. **外在伪装**：执行任务时刻意表现出凶狠、野蛮的样子，掩盖内心与兽盾理念的不符
6. **私下善举**：在条件允许（确保无记录设备、无同事在场）的情况下，会悄悄对自己监管或任务中遇到的对象释放善意

### 2.2 完整背景故事（yan-sui-2-1 / yan-sui-2-2）

**家庭背景：**

- 单亲家庭，由父亲岩参抚养长大
- 父亲岩参是**前兽盾员工**，在"牙董事长"上任导致兽盾变质前退休
- 岩岁在父亲及前兽盾同事影响下成长，童年对兽盾的第一印象并非污浊

**父亲的教导：**

- 岩参经常教育岩岁："力量与责任并存，拥有力量就意味着承担更多的责任"

**兽盾质变前后：**

- 牙董事长上任后，兽盾发生180度大转变，从"兽民后盾"变成暴政工具
- 岩岁父亲因抗议现任兽盾暴行，被兽盾兵暴力殴打致残，卧床不起
- 岩岁工作的便利店因交不起保护费被兽盾捣毁倒闭

**入职兽盾的动机：**

- 为养活重伤残疾的父亲，**瞒着父亲**偷偷入职兽盾
- 因思想背景良好（受父亲教育），在兽盾内部不受待见
- 但只要收到父亲家书、相信父亲能康复，就觉得值得

**悲剧高潮（遇袭与丧父）：**

- 岩岁在自家附近执勤时遭憎恨兽盾的民众伏击，被匕首捅伤腰部
- 被父亲岩参救回家中
- 岩参出门寻友商议后，遭同一伙人报复杀害
- 岩参留下遗言："不要怨恨具体的某群人，要恨某种行为或概念"

**原作结局：**

- 父亲死后，岩岁在兽盾中迷茫地生存
- 最终在《白兔暗影》第一章被仇染处决

### 2.3 父子回忆故事（yan-can-yan-sui-flashback）

**童年回忆（岩岁约4-5岁）：**

*共浴时光：*

- 岩参下班后穿着制服回家，身上带有汗酸味
- 岩岁调皮地要求和父亲一起洗澡
- 岩参作为"肉垫"托举着岩岁，任儿子对自己"又捏又摸"
- 岩岁意外挑逗父亲乳头，被岩参教育"这种地方不能乱碰"
- 岩参因厨房危险而态度冷淡，岩岁误解为"爸爸不要我了"

*交流券的诞生：*

- 岩岁产生偏激想法："只要我把自己换掉，爸爸就会更幸福"
- 岩岁独自出走，岩参焦急寻找后和解
- **岩参手写一沓"交流券"**，承诺"无论如何都一定会和你好好说话"
- 这个设定成为父子情感的核心象征

**成年后的孤独（岩参死后）：**

*新年扫墓：*

- 新年期间，岩岁独自带着酒去父亲墓前
- 醉酒后的哭诉："岁岁没能成为一个顶天立地的男子汉"
- **烧"交流券"**：将珍贵的交流券点燃，呼唤父亲来梦中相见
- 奇迹发生：醒来时躺在家里床上，桌上有热饺子和字条

*字条内容：*
> "岁岁，爸爸爱你，新年快乐。"

**故事性质**：留白的温情超自然结局——是幻觉？是父亲的灵魂？还是岩岁的梦境？作者没有明确说明。

## 三、外貌特征（基于新版改编故事 ch-1至ch-5）

### 3.1 整体形象

岩岁是一具典型的**成熟虎族雄性躯体**，充满了力量感与生命力。

**体型特征：**

- **身材高大健壮**，骨架宽阔，肌肉发达
- **典型的"脂包肌"质感**——肌肉块垒分明，表面覆盖一层薄薄的脂肪，触感既坚实又柔软
- **整体呈现出力量与温和并存的气质**

### 3.2 毛发与肤色

| 部位          | 特征                 |
|-------------|--------------------|
| **皮毛主色**    | 浅金色短毛，光泽亮丽         |
| **虎纹**      | 黑色虎纹从肩膀延伸至小腿，若隐若现  |
| **胸部/腹部毛发** | 浅金色，密度适中，能清晰看到肌肉轮廓 |
| **面部毛发**    | 脸颊和脖颈覆盖浅金色短毛       |
| **手掌/脚掌**   | 深色肉垫，手/脚背上覆盖金色短毛   |

### 3.3 面部特征

**整体脸型：**
- **脸盘宽阔**，典型的虎吻结构
- **口鼻部略向前突出**，覆盖浅金色短毛

**五官细节：**

| 部位 | 特征 |
|-----|------|
| **眼睛** | 琥珀色，大而深邃，竖瞳；眼窝深陷，眼神温和时柔软，警惕时锐利 |
| **鼻子** | 黑色，湿润，宽大；鼻尖随呼吸微微翕动 |
| **嘴唇/嘴部** | 厚实，干燥时会起皮；白色胡须从口鼻两侧伸出，根根分明 |
| **眉毛** | 深棕色，浓密略显凌乱 |
| **额纹** | 眉骨上方有几道浅色的老虎纹路 |
| **头顶毛发** | 浅金色短毛，比脸颊稍长，呈现自然蓬松感 |
| **耳朵** | 虎耳从发间探出；耳背覆盖黑色绒毛，内侧浅粉色；耳尖有一撮黑色毛簇；能敏感转动 |
| **胡须** | 白色虎须，长而分明，紧张时会微微颤抖 |
| **下颌** | 线条硬朗，带着虎族特有的棱角 |

### 3.4 身体细节（基于ch-2沐浴场景）

**躯干：**

- **胸肌**：饱满鼓胀，轮廓清晰，在浅金色短毛下随着呼吸起伏
- **腹肌**：六块腹肌块垒分明，放松时轮廓柔和，但依然紧实
- **背阔肌**：厚实有力，从肩膀延伸至腰腹
- **斜方肌**：在颈后隆起优美的弧度

**手臂：**

- **肩膀**：宽阔，三角肌饱满鼓胀
- **上臂**：肱二头肌和肱三头肌轮廓分明
- **前臂**：肌肉线条流畅，手腕处骨骼分明
- **手掌**：厚实的虎爪，指节粗壮，掌心深色肉垫，手背覆盖金色短毛

**腿部：**

- **大腿**：肌肉粗壮，股四头肌和股二头肌轮廓清晰
- **小腿**：结实，腓肠肌呈现优美弧线
- **脚踝**：骨骼分明
- **虎尾**：浅金色，尾毛柔软，是表达情感的敏感部位

### 3.5 伤痕

- **腰侧**：有一道寸许长的伤口（被匕首刺伤），已缝合愈合，留下疤痕

## 四、性格特征

### 4.1 原作设定性格

| 维度       | 描述             |
|----------|----------------|
| **本性**   | 老实、憨厚、淳朴       |
| **环境适应** | 被迫伪装凶狠野蛮，与本性相反 |
| **内心矛盾** | 道德良心与兽盾要求持续冲突  |
| **生存策略** | "装作不会痛苦"的自我麻痹  |
| **私下行为** | 偷偷对他人释放善意      |

### 4.2 新版故事展现的性格

1. **注意体面/要强**
    - 即使濒死状态，也要求先清洁身体
    - 无法忍受以污秽状态玷污干净的床铺

2. **对清洁的渴望**
    - 热水擦拭时会放松，喉咙发出"呼噜"声（兽人感到舒适安全的本能）

3. **依赖与信任**
    - 在奇点照顾下逐渐放下防备
    - 允许自己被"摆布"，体验久违的安全感
    - **虎尾缠绕手腕**——兽人表达最高信任与亲密的肢体语言

4. **对父亲的深情**
    - 看到父亲时情感崩溃
    - 细心照顾年迈的父亲
    - 在父亲面前会展现孩子气的一面

## 五、关键场景形象（新版故事）

### 5.1 被救时刻（ch-1）

**穿着：** 湿透的兽盾制服（墨绿色紧身短袖，左肩有盾牌LOGO）

**状态：** 制服紧贴着身体，勾勒出饱满的胸肌、块垒分明的腹肌、紧实的腰肢

**动作：** 虎尾缠绕奇点手腕，表示接受与信任

### 5.2 沐浴场景（ch-2）

**完全赤裸的岩岁：**

- 宽阔的肩膀和厚实的背肌
- 壮硕的双腿和流畅的肌肉线条
- 胯间器物安静沉睡，被浓密金色毛发环绕
- 整体呈现出"奇异的脆弱"——强壮身躯与脆弱处境的对比

### 5.3 与父亲重逢（ch-3/ch-4）

**情感表现：**

- 扑进父亲怀中，将脸埋进灰白毛发
- 眼泪打湿父亲的毛皮
- 像孩子一样寻求确认

## 七、原作死亡线中的岩岁

在 `yan-sui/branches/yan-can-canon-death/` 分支（岩参原作死亡线改编）中，岩岁虽未直接参与主线事件，但作为核心情感锚点存在。

### 7.1 死亡线中的岩岁形象

- **年龄**：25岁（故事发生时）
- **状态**：在兽盾任职，对父亲出门的真正目的不知情
- **关键场景**：《雪停之前》v2 结尾——岩岁醒来，发现父亲已死，床头柜上留着壹安的纸条、交流券和止血粉
- **情感处理**：没有嚎啕大哭，只是握着父亲的手，额头抵在手背上，像小时候趴在父亲背上那样

### 7.2 与救赎线的差异

| 维度 | 救赎线（trunk/） | 死亡线（branches/yan-can-canon-death/） |
|------|----------------|--------------------------------------|
| **父亲命运** | 被奇点救下，父子重逢 | 被壹安送终，尸体背回家 |
| **岩岁的知情** | 全程参与救援与康复 |  asleep，直到父亲死后才知晓 |
| **情感爆发点** | 扑进父亲怀中痛哭 | 握着父亲已经温热的手，安静守望 |
| **交流券** | 珍贵的情感信物 | 被壹安压在遗条下方，成为遗物 |
