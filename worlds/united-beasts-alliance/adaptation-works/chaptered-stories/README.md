## 一、形式说明 / Format Overview

长篇分章故事采用多章节连载结构，每章独立成文并保留连续性。改编作品需基于《万兽盟》原作世界观进行创作。

## I. Format Overview

Chaptered stories follow a multi-chapter serialized structure, with each chapter standing alone while maintaining continuity. Adaptations must be based on the United Beasts Alliance original world.
