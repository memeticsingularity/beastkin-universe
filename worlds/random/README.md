## 关于本目录 / About This Directory

**不归属任何现有世界观的杂项故事合集。** 包括早期试写、翻译练笔、独立短篇、跨世界观实验性文本等。这些作品可能与兽盾或万界巡行共享部分情色设定体系，但在称谓、制服体系、角色身份等方面与主世界观不兼容。
