## 图片场景说明

### ch-01.jpg — 走廊屠杀后

![ch-01](ch-01.jpg)

**对应场景：** 白虎独闯黄坡山寨，从外围一路杀穿。

画面为山寨内部走廊，五名守卫横七竖八倒在石质地面上，身上与身下到处是精液。前景一只橙黄条纹的虎兽人守卫伏在石栏边缘，背对镜头，臀部与后腰沾满白液，姿态瘫软。中央偏下一只蓝灰色的壮硕狼/鼬兽人仰面倒地，嘴微张，胸腹至下体遍布精液。背景一只穿金属护甲的棕熊守卫靠墙瘫坐，头低垂，胯间有白液。右侧地面还有一只灰白兽人俯卧。暖黄与棕红的色调中，地面暗湿反光——白虎身影未入镜，但处处是它的痕迹。

### ch-02.jpg — 牛护卫的末路

![ch-02](ch-02.jpg)

**对应场景：** 白虎在大厅中制服护卫长铁角。

青蓝色皮肤的巨大牛兽人四肢摊开仰身向后，头高仰，口大张，神情处于崩溃边缘——白虎从背后贴紧，右手握其牛根从龟头直撸至根部，致命一击。牛护卫全身粗壮的肌肉在最后的抽搐中绷紧，精液大量喷出，在脚下汇集成滩。画面右下角可见之前被解决的狗兽人尸体横卧。背景是山寨大厅粗粝的石墙与柱廊，昏黄的灯火映在潮湿的石面上。

### ch-03.jpg — 寨主的败亡

![ch-03](ch-03.jpg)

**对应场景：** 白虎死后复活反杀红虎寨主。

红虎寨主仰面倒在青蓝色牛兽人尸体的背上，满头满脸的白色精液，口张目闭，下体还射出最后一股。白虎从画面右下角位置踩住寨主的肉棒和卵蛋完成处刑。寨主浑身火红毛皮，肌肉壮硕，左眼的疤痕仍清晰可辨——但此刻它不再狰狞，只标示着一个死者在生命最后时刻的失态。俯视的视角强调了这一躺一立之间的胜负逆转。

### ch-04.jpg — 犀牛明星的处刑

![ch-04](ch-04.jpg)

**对应场景：** 白虎在足球场休息室暗杀巴顿。

休息室内，犀牛兽人巴顿仰倒在休息凳上，粗壮双腿挂在凳沿，球裤被掀起一角，布满青筋的肉棒无力垂下。白虎骑在巴顿身上，左手按牛根，右手揉搓其胸前粉嫩的乳头——巴顿的敏感点不在下体而在乳头，这是白虎发现的关键弱点。犀牛体型硕大，穿蓝色球衣与白色球袜，一侧的护腿板还完好地绑在小腿上。室内光线冷白，铁皮储物柜反射着惨淡的光。

### ch-05.jpg — 野性赛的终局

![ch-05](ch-05.jpg)

**对应场景：** 野性赛以一敌二结束，白熊与青电倒地。

擂台地面上，身穿蓝色连体摔跤服的白熊仰面瘫倒，胸腹与裆部的紧身布料吸饱白液，鼓起的包块正在缓慢萎靡。猎豹青电伏在左侧，光裸的身体上同样狼藉，紧身三角裤的裆部湿透，白液从侧边滴落。白虎位于两只尸体之间，姿态放松——他已完成战斗。背景隐约可见擂台的围绳与观众席模糊的轮廓。暖色聚光灯打在画面中央，将地板上的湿润反光映得刺眼。

### ch-06.jpg — 地牢脱狱

![ch-06](ch-06.jpg)

**对应场景：** 白虎与鹏鹏联手制服野猪守卫。

地牢内，野猪守卫黑鬃仰面躺在地上，粗壮的身躯在挣扎后放松，下体刚射完精，白液溅在自己胸口与地面。白虎收起钥匙，神情平静——他的口交突击完成得干净利落。铁栅栏后的阴影中隐约可见鹏鹏蹲坐的身影，目击了这一切。地牢光线的唯一来源是走廊顶部的昏黄油灯，将铁栏的影子横斜地投在石壁上。一串钥匙挂在白虎腰间——自由的门已经被打开。

### ch-07.jpg — 奔雷的死斗

![ch-07](ch-07.jpg)

**对应场景：** 白虎与鹏鹏前后夹击，奔雷毙命的瞬间。

画面中，金色的狮子奔雷被两人锁死在中央。白虎从背后紧紧扣住奔雷的胸膛，爪尖抓握其乳尖与胸肌，肉棒埋入其体内。奔雷的头后仰，口张开，表情在快感与死亡的边界线上扭曲。鹏鹏跪立在奔雷前方画面边缘，后穴仍含着狮子的龟头，身体前倾——他是这一战中付出生命代价的另一半。背景隐约可见奔雷卧室的家具轮廓，环境温暖华丽，与三人激烈撕缠的轮廓形成反差。
