## 简介

黄坡山寨是 lanse 创作生涯中最早的兽人世界观故事。这个原型世界奠定了后来兽盾世界观的核心机制之一——生殖器弱点与强制射精致死。

故事讲述一位强大神秘的入侵者独闯黄坡山兽人山寨，以压倒性的实力逐个击杀守卫，向寨主大厅步步逼近。
