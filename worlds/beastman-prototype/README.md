# 兽人原型世界 / Beastman-Prototype World

> **作者**: lanse（笑天神犬）
> **定位**: lanse 创作生涯中最早的兽人世界观原型，后演变为兽盾（Beastshield）世界观

---

## 世界观核心规则

- **再生能力**：兽人身体具有极强的再生能力，百毒不侵（但击晕和迷晕可行）
- **唯一弱点**：生殖器极其敏感，一旦被握住便浑身无力、失去反抗能力
- **唯一击杀方式**：**强制**使其射精（射尽则亡）
- **战斗传统**：单人战斗永远一对一，他人不得插手

---

## 与兽盾世界观的关系

本世界观是兽盾（Beastshield）的前身原型。两者共享核心机制（生殖器弱点、强制射精致死），但本世界观设定更为简单：

- 无兽盾公司的制服体系与职级制度
- 无统御项圈等控制装置
- 无精尽而亡的处决机制（仅有强制射精致死）
- 背景为山寨聚落而非企业帝国
