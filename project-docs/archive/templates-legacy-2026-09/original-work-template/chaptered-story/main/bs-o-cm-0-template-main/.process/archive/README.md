# 归档目录 / Archive

> 存放废弃的旧版本文件及弃用说明。

---

## 归档规则

1. **旧版本正文**迁入本目录时，**必须**创建同名的 `.obsolete.md` 弃用说明文件
2. 弃用说明需回答：为什么弃用、新版本改进了什么、哪些内容可复用
3. 不要归档未完成的草稿——那是计划/笔记，不是旧版本

## 命名规范

| 类型 | 格式 | 示例 |
|------|------|------|
| 旧版本 | `{原名}-v{版本}.md` | `ch-001-tutorial-v1.0.md` |
| 弃用说明 | `{原名}-v{版本}.obsolete.md` | `ch-001-tutorial-v1.0.obsolete.md` |

## 弃用说明模板

```markdown
# {文件名} 弃用说明

**弃用日期**: YYYY-MM-DD
**替代版本**: {新文件名}

## 为什么弃用
{总体原因}

## 具体不足
- {不足1}
- {不足2}

## 新版本改进
- {改进1}
- {改进2}

## 是否可复用
{哪些片段、设定或描写可在未来作品中复用}
```
