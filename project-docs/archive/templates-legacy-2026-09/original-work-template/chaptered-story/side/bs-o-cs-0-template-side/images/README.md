# 图片目录 / Images

> 存放作品相关图片资源。

---

## 可存放的内容

- 章节配图 / 场景概念图
- 角色立绘 / 参考图
- 地图 / 世界观示意图
- 封面图

## 命名规范

| 类型 | 格式 | 示例 |
|------|------|------|
| 章节配图 | `bs_ch{章节号}_{序号}_{描述}.png` | `bs_ch001_1_opening_scene.png` |
| 角色图 | `char_{角色名}_{类型}.png` | `char_azhuang_reference.png` |
| 场景图 | `scene_{地点}_{序号}.png` | `scene_training_camp_01.png` |

## 技术要求

- 推荐使用 PNG（透明背景）或 JPG（照片）
- 单张不超过 2MB，避免仓库膨胀
- 如需大文件，请使用 Git LFS

---

*图片文件不纳入版本评审，但需符合内容分级规范。*
