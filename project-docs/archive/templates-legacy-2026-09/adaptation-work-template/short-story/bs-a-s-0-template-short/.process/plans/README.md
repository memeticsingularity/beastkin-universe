# 计划目录 / Plans

> 存放创作计划、章节大纲、剧情结构文档。

---

## 可存放的内容

- **单章计划**：某一章的详细大纲、场景分解
- **卷/篇计划**：多章的整体结构规划
- **角色弧光计划**：角色成长路线设计
- **转折设计**：关键剧情转折的铺垫规划

## 命名规范

| 类型 | 格式 | 示例 |
|------|------|------|
| 单章计划 | `ch-{三位数字序号}-plan.md` | `ch-001-plan.md` |
| 多章计划 | `volume-{序号}-plan.md` | `volume-2-plan.md` |
| 日期版本 | `YYYY-MM-DD-{描述}-plan.md` | `2026-06-09-ch5-revision-plan.md` |

## 与 notes/ 的区别

| 目录 | 用途 | 正式程度 |
|------|------|---------|
| `.process/plans/` | 确定的创作计划 | 较高 |
| `notes/` | 随想、草稿、参考 | 较低 |

---

*计划文档变更时，建议在 CHANGELOG 中记录重大调整。*
