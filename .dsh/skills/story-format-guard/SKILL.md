# 故事正文格式（强制）

**唯一权威源**：`docs/spec/11-story-format.md`。不要凭记忆、也不要照抄既有文件——历史遗留有多种写法。

## 要点

| | 分章 | 短篇 |
|---|---|---|
| H1 | `# Chapter {自然数} {中文标题}` | `# Story {中文标题}` |
| 结束标记 | `**Chapter {自然数} END**` | `**Story END**` |

结束标记**恰好 1 个**，位置固定：

```
正文 → --- → > *{卷尾语}* → **Chapter {N} END** → --- → {nav 行} → --- → ## 故事评述与感慨
```

## 禁止的旧写法（已全库清除，不得回潮）

| 位置 | 禁止 | 应为 |
|---|---|---|
| H1 | `# MS-001: 作品名 - 第N章：标题` | `# Chapter {N} {标题}` |
| H1 | `# 作品名 - 第N章：标题` | `# Chapter {N} {标题}` |
| H1 | `# SS-00N: 标题` | `# Story {标题}` |
| 结束标记 | `**第一章完**` / `**终章**` | `**Chapter {N} END**` |
| 结束标记 | `**完**` | `**Story END**` |
| 结束标记 | 两个标记挤在同一行 | 各占一行 |

## 文件命名与位置

- 分章：`<作品目录>/chapters/ch-{三位数字}-<slug>.md`（分卷 `chapters/volume-N/`）
- 短篇：`<作品目录>/<作品编码>.md`
- 形态（Chapter 还是 Story）由**作品内多数文件的既有形态**决定，不要按文件名猜

## 自检

```bash
node scripts/qa/check-format.js <作品目录>
```
标题确实无处可取的（无 H1、无文件名 slug、无同章兄弟标题），在
`project-docs/story-format-todo.md` 登记待作者补，**不要臆造标题**。
