## 一、内容分级与标签体系 / Content Rating & Tag System

**成人内容警告 / 18+ Only**

本宇宙中的全部作品采用统一的内容分级体系，从四个维度评估内容强度，并辅以九类内容标签帮助读者快速定位核心元素。

---

### 四维分级矩阵 / 4-Dimensional Rating Matrix

每个作品（及世界观总览）均标注以下四个维度的级别（Lv.0–5）：

| 维度 | 级别范围 | 说明 |
|------|:-------:|------|
| 🔞 性内容 / Sexual Content | **Lv.0–5** | 从背景提及（Lv.1）到 explicit 性行为/体液描写（Lv.4–5） |
| 💀 暴力与死亡 / Violence & Death | **Lv.0–5** | 从战斗提及（Lv.1）到大规模屠杀/虐杀（Lv.5） |
| 🧠 心理黑暗度 / Psychological Darkness | **Lv.0–5** | 从轻度压抑（Lv.1）到系统性绝望/身份撕裂（Lv.4–5） |
| ⚡ 特殊触发 / Specific Triggers | — | 逐项列出可能触发的内容（如`芯片控制` `尸体处理` `背叛`等） |

**分级依据文档**：[docs/spec/13-rating-criteria.md](docs/spec/13-rating-criteria.md)

---

### 九类内容标签 / 9-Category Tag Taxonomy

每部作品README均包含以下九类标签：

| 类别 | 说明 |
|------|------|
| 🐾 物种 | 出场的兽人种族 |
| 🔞 情色与身体 | 性器官/制服/体液/身体描写元素 |
| ⚔️ 死亡与暴力 | 处决/虐杀/战斗/死亡机制 |
| 🏛️ 权力与关系 | 等级/主从/组织/身份关系 |
| 🎭 主题与情感 | 核心情感与叙事主题 |
| 🎨 叙事与风格 | 叙事视角、节奏、风格 |
| 🗺️ 核心场景 | 关键空间与地点 |
| 🧩 世界观机制 | 本作涉及的特有机制 |
| 🎯 结局指向 | HE/BE/开放式/单元悲剧等 |

---

**Adult Content Warning / 18+ Only**

All works in this universe use a unified content rating system, assessing intensity across four dimensions plus nine content tag categories to help readers locate core elements.

**All fictional content is artistic creation and does not encourage similar behavior in reality.**

## 三、世界观概览 / World Overview

### 3.1 Beastshield (兽盾)

**黑暗企业帝国**

一个由兽盾公司掌控的世界，这家庞大的企业帝国控制着社会的方方面面。兽人员工们身穿紧身制服，在军事安保、娱乐产业、地下格斗等领域运作，内部等级森严。核心机制为"性欲值系统"——所有伤害转化为目标的性欲值，蓄满时目标射精死亡。

- [世界观主页](worlds/beastshield/)
- [原作主线](worlds/beastshield/original-archives/chinese/chaptered-stories/main/) · [短篇原作](worlds/beastshield/original-archives/chinese/short-stories/)
- [改编长篇](worlds/beastshield/adaptation-works/chaptered-stories/) · [改编短篇](worlds/beastshield/adaptation-works/short-stories/)

### 3.2 Beastshield Online (兽游世界)

**VR 网游世界**

基于兽盾世界观的沉浸式 VR 网游。玩家通过意识接入，在虚拟世界中体验兽盾宇宙的各种故事线，支持多人在线协作与对抗。

- [世界观主页](worlds/beastshield-online/)

### 3.3 Beastshield Paradise (兽盾天堂)

**温暖治愈向重构**

同一世界观的温暖重构版本。保留了兽盾的角色和基础设定，但叙事聚焦于治愈、友情与日常，减少了黑暗与暴力元素。

- [世界观主页](worlds/beastshield-paradise/)

### 3.4 Beastshield Reforged (兽盾新纪元)

**末日重生**

在文明崩溃后的废墟上，兽盾公司以全新的形态重生。这是一个关于生存、权力重组和人性考验的世界，兽人们在废土上建立新的秩序。

- [世界观主页](worlds/beastshield-reforged/)

### 3.5 Empire Kik Soldiers (帝国万岁)

**星际帝国黑暗科幻**

以 Kik 士兵为主角的星际帝国题材。讲述被基因改造和制度压迫的兽人士兵在庞大军事帝国中的生存、反抗与命运。

- [世界观主页](worlds/empire-kik-soldiers/)

### 3.6 Paradise Kik Soldiers (奇克兽士乐园)

**温暖玩家篇章**

帝国万岁的温暖向对应版本。聚焦于 Kik 士兵在和平时期的日常、友谊与成长故事。

- [世界观主页](worlds/paradise-kik-soldiers/)

### 3.7 United Beasts Alliance (万兽联盟)

**跨种族同盟**

多个兽人种族放下分歧，组成联合联盟对抗共同威胁。探索合作、外交和跨文化理解。

- [世界观主页](worlds/united-beasts-alliance/)

### 3.8 Worldstrider Infinity (万界巡行：无限)

**跨世界 VR 沙盒平台**

以 VR 沙盒平台为载体的原创及改编创作集合。多个世界观（包括 beastshield）的角色以"意识原型"形式可被接入。当前活跃创作聚焦于岩岁/岩参父子救赎故事，但平台不限于 beastshield。

- [世界观主页](worlds/worldstrider-infinity/)

## 六、关于本企划 / About This Project

**Beastkin Universe** 是一个多元兽人题材创作宇宙，包含多个独立且互相关联的世界观，由社区驱动的开放式创作平台。

核心理念是「同一个概念，多重演绎」。每个世界观都从独特的视角探索兽人题材，为创作者和读者提供丰富的体验。

---

**Beastkin Universe** is a multifaceted furry-themed creative universe containing multiple independent yet interconnected worlds, a community-driven open creative platform.

Our core philosophy is "One Concept, Multiple Interpretations." Each world explores furry themes from unique perspectives, offering rich experiences for both creators and readers.

- 统一的翻译标准和格式
- 模板支持中英文切换

### 7.3 社区驱动 / Community-Driven

- 开放的贡献体系和[协作指南](CONTRIBUTING.md)
- 透明的内容审核流程
- 从改编到官方的成长路径

## I. Project Features

- Multi-level setting management system (Original → Recommended → Story Variants)
- Clear promotion mechanism (adaptation → official)

- Unified translation standards and formats
- Template support for Chinese/English switching

### III. Community-Driven
